# Worldspawn и световые клавиши

Ключи карты (worldspawn) и сущностей, которые считывает компилятор для построения и освещения карты. Установите ключи появления мира в **Карта > Свойства карты...**; остальные : это ключи самих сущностей, заданные на [панели сущностей] (../features/entity-properties.md).

<a id="worldspawn-keys"></a>
## Ключи появления мира

| Клавиша | Читать | Эффект | По умолчанию |
|---|---|---|---|
| `_lightsrad` | освещение | Файл освещения текстуры для каждой карты (используется ключ Hammer++). Полный путь или путь относительно папки игры, папки карты или папки Garry's Mod. Читается после `lights.rad` и `-lights` (один раз, когда это тот же файл, что и `-lights`), перед `<map>.rad`. | нет |
| `detailvbsp` | геометрия | Подробный файл определения пропа для материалов `%detailtype`. | `detail.vbsp` |
| `skyname` | геометрия | Небо, текстуры которого копируются в заполнители кубических карт (см. [Кубические карты](cubemaps.md)). | |

Приоритет всегда: сначала флаг командной строки, затем ключ Worldspawn, затем качество по умолчанию.

<a id="lights"></a>
## Свет

Компилятор считывает легкие сущности, такие как VRAD (`light`, `light_spot`, `light_environment`; `light_dynamic` игнорируется).

| Клавиша | Сущности | Эффект |
|---|---|---|
| `_light` | все | Цвет и яркость `r g b brightness` (сделаны линейными, как VRAD). |
| `_lightHDR` | все | Цвет для прохода HDR; отрицательное значение означает «то же самое, что `_light`». |
| `_lightscaleHDR` | все | Умножает яркость HDR. |
| `style` | все | Светлый стиль (от 0 до 255). Именованные источники света получают переключаемый стиль, если на карте его нет. |
| `_constant_attn`, `_linear_attn`, `_quadratic_attn` | `light`, `light_spot` | Затухание `1 / (c + l d + q d^2)`, интенсивность указана за 100 единиц. Все 0 означают константу. |
| `_fifty_percent_distance`, `_zero_percent_distance` | `light`, `light_spot` | Кривая спада на этих расстояниях (используется вместо трех ослаблений, если установлено первое). |
| `_hardfalloff` | `light`, `light_spot` | При расстоянии в пятьдесят процентов: свет заканчивается на расстоянии в ноль процентов. |
| `_distance` | `light`, `light_spot` | На этом свет заканчивается, исчезая в последней четверти (Hammer Pro читается с обоими типами спада). |
| `_inner_cone`, `_cone`, `_exponent` | `light_spot` | Конусы точек в градусах (внутренние значения по умолчанию : 10, внешние : внутренние) и показатель спада между ними. |
| `angles`, `pitch`, `target` | `light_spot`, `light_environment` | направление; объект `target` переопределяет его. |
| `_castentityshadow` | все | Помечает мир светлым, чтобы движок отбрасывал от него тени объектов. |
| `_ambient`, `_ambientHDR`, `_AmbientScaleHDR` | `light_environment` | Окружающий свет неба (половина солнца, когда оно не зашло). |
| `SunSpreadAngle` | `light_environment` | Ширина солнца в градусах: несколько солнечных лучей внутри него, более мягкие тени. Только первая цифра `light_environment` освещает карту. |

Текстурные источники света берутся из `lights.rad` и других файлов освещения, перечисленных выше, а не из ключей объектов.

<a id="brush-entities"></a>
## Браш объектов

| Клавиша | Эффект |
|---|---|
| `vrad_brush_cast_shadows` | `1`: браши этого объекта отбрасывают тени при освещении (в противном случае объекты-браши не отбрасывают ничего). |
| `_minlight` | Минимальная освещенность грани сущности (доля, умноженная на 128 в единицах VRAD). |

<a id="static-props"></a>
## Статический проп

| Клавиша | Эффект в освещении |
|---|---|
| `disableshadows` | Проп не отбрасывает тени. |
| `disablevertexlighting` | Для этой пропа с `-StaticPropLighting` нет освещения по вершинам. |
| `disableselfshadowing` | Проп не затеняет сама себя. |
| `ignorenormals` | Пропеллер освещается постоянным косинусом. |
| `lightingorigin` | Объект, чья позиция освещает объект (также используется для вершин внутри твердого тела). |
| `fademindist`, `fademaxdist`, `screenspacefade` | Записано в статический блок пропа; проп списка статистики без расстояния затухания. |

<a id="other-entities-the-compiler-handles"></a>
## Другие объекты, обрабатываемые компилятором

| Сущность или ключ | Эффект |
|---|---|
| `func_detail` | Детальные браши: они не ухудшают видимость (кроме `-fulldetail`). |
| `func_viscluster` | Принуждает листья внутри него объединиться в один кластер видимости. |
| `func_areaportal` | Разделяет области (см. [Утечки и файлы точек](../features/leaks-pointfiles.md)). |
| `func_occluder` | Его браши становятся полигонами-окклюдерами. |
| `env_fog_controller` `farz` | Первый устанавливает радиус видимости (например, `-radius_override`). |
| `env_cubemap` `cubemapsize`, `sides`, `parallaxobb` | Размер кубической карты, грани, которым она назначена, браш `parallax_obb` для кубических карт с исправленным параллаксом. См. [Кубические карты](cubemaps.md). |
| `func_instance` | В первую очередь объединяется с картой, включая вложенные экземпляры. См. [Экземпляры](../features/instances.md). |
| `prop_detail`, `prop_detail_sprite`, `detail_prop` | Собственные детализированные объекты, добавленные к объектам `%detailtype`. |
| `sky_camera` | Небесные лучи, достигающие неба, снова трассируются через 3D-скайбокс от него, как и VRAD. |
| `mindxlevel`, `maxdxlevel` | При значении `-dxlevel` объекты за пределами уровня удаляются. |

<a id="faq"></a>
## Частые вопросы

**Моя карта Hammer++ имеет `_lightsrad`, она работает?** Да, файл читается так, как задумано Hammer++, и в журнале указано `Map light file (_lightsrad): ...`.
