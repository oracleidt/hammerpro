# Командная строка компилятора

Компилятор является частью `hammerpro.exe`. `hammerpro --bspc` строит геометрию, порталы, тест на утечку и видимость VMF; `hammerpro --rad` загорается BSP. Оба используют имена опций Valve (VBSP и VVIS для `--bspc`, VRAD для `--rad`), поэтому сценарии и последовательности команд Hammer транслируются напрямую. Остальные аргументы `hammerpro.exe` находятся в [ссылка на командную строку](../reference/command-line.md).

<a id="usage"></a>
## Использование

```
hammerpro --bspc [options] <map>
hammerpro --rad  [options] <map>
```

- `<map>` : путь на карте с расширением или без него. `--bspc` читается `<map>.vmf`; `--rad` фары `<map>.bsp` на месте. Карта указывается последней (любой аргумент, который не начинается с `-`, является картой).
- Параметры нечувствительны к регистру. Опция, которой требуется значение, но не имеет его, или значение, не являющееся числом, заканчивается на `Error: ...` и коде выхода 1.
- Каждая строка вывода выводится на стандартный вывод и добавляется к `<map>.log` рядом с картой (строка CRLF заканчивается, как в инструментах Valve).
- Код выхода 0 в случае успеха, 1 в случае любой ошибки (и при утечке с `-leaktest`).

<a id="files-written"></a>
## Файлы написаны

| Файл | Автор | Когда |
|---|---|---|
| `<map>.bsp` | `--bspc`, переписано `--rad` | всегда, кроме утечки с `-leaktest` |
| `<map>.prt` | `--bspc` | только запечатанные карты |
| `<map>.lin` | `--bspc` | путь утечки; или линия видимости с помощью `-trace` |
| `<map>.log` | оба | добавлено |
| `materials/maps/<map>/...` в пакфайле | `--bspc` | патчи и заполнители кубических карт (см. [Cubemaps](cubemaps.md)) |

<a id="--bspc-options"></a>
## `--bspc` варианты

Геометрия и видимость. По умолчанию используются только командная строка; редактор добавляет свои собственные (см. [Параметры компиляции](compile-options.md)).

| Параметр | Значение | Эффект | По умолчанию |
|---|---|---|---|
| `-game`, `-vproject` | папка | Папка с игрой: материалы, модели, `lights.rad`, `detail.vbsp`, инстансы. | Garry's Mod's `garrysmod` |
| `-gmod` | папка | Установка Garry's Mod, содержимое которой смонтировано. | обнаруженная установка |
| `-target` | идентификатор игры | Игра, для которой предназначена карта: ее формат BSP и ограничения (см. [Целевые игры](target-games.md)). | Garry's Mod, или игра `-game` |
| `-insert_search_path` | папка | Другая папка с игрой смонтирована как `-game` (может повторяться). | нет |
| `-threads` | номер | Рабочие потоки (1 или более). | каждое ядро |
| `-low` | | Приоритет простоя. | выкл. |
| `-v`, `-verbose` | | Распечатывает параметры. | выкл. |
| `-leaktest` | | Останавливается при утечке: пишет `<map>.lin`, BSP нет, код выхода 1. | выключено: утекшая карта все еще получает свой BSP |
| `-vis` | | Полная видимость. | выключено: нет видимости |
| `-fastvis` | | Быстрая грубая видимость. | выкл. |

| `-bumpall` | | Потрепанные карты освещения на каждой освещенной поверхности. | выкл. |
| `-lightifmissing` | | Карты освещения для отсутствующих или неосвещенных материалов. | выкл. |

| `-dxlevel` | уровень | Удаляет объекты, исключенные их `mindxlevel`/`maxdxlevel`. | нет |

| `-trace` | кластерный кластер | Записывает линию видимости между двумя кластерами в `<map>.lin`. | нет |
| `-nomerge`, `-nosubdiv`, `-notjunc`, `-noprune` | | Переключатели отладки см. в разделе [Параметры компиляции](compile-options.md). | выкл. |

| `-noaddons` | | Никаких дополнений к папкам. | аддоны установлены |
| `-wsaddons` | | Также подписанные предметы Мастерской. | выкл. |
| `-nowsaddons` | | Ни аддонов папок, ни предметов Мастерской. | выкл. |

Принято для совместимости, не влияет: `-novconfig`, `-allowdebug`, `-steam`, `-verboseentities`, `-tmpout`, `-tmpin`.

Известные опции Valve, которые этот компилятор не делает (предупреждение, компиляция продолжается): `-glview`, `-nocsg`, `-noshare`, `-noweld`, `-noopt`, `-nomergewater`, `-snapaxial`, `-dumpcollide`, `-dumpstaticprop`, `-dumpstaticprops`, `-allowdetailcracks`, `-notjuncsdetail`, `-xbox`, `-fullminidumps`, `-block` (2 значения), `-blocks` (4 значения) и каждый вариант `-mpi...`. Любая другая неизвестная опция получает `Warning: VBSP: Unknown option "..." (ignored)`.

Без игрового контента (не найден Garry's Mod и нет `-game`), материалы угадываются по их названиям, и об этом говорится в журнале.

<a id="--rad-options"></a>
## `--rad` варианты

Освещение. Если опция диапазона отсутствует, `--rad` вычисляет только LDR.

| Параметр | Значение | Эффект | По умолчанию |
|---|---|---|---|
| `-ldr` / `-hdr` / `-both` | | Динамические диапазоны для вычисления. | LDR |
| `-game` | папка | Папка с игрой: `lights.rad`, материалы и модели. | `garrysmod` установки |
| `-gmod` | папка | Garry's Mod установить. | обнаруженная установка |
| `-target` | идентификатор игры | Игра, для которой предназначена карта (ее ограничения и содержание). | Garry's Mod |
| `-insert_search_path` | папка | Дополнительные папки с играми для моделей. | нет |
| `-threads` | номер | Рабочие потоки. | каждое ядро |
| `-low` | | Приоритет простоя. | выкл. |
| `-fast` | | Черновое качество: мало лучей, нет статического освещения вершин, нет резки текстурного освещения. | выкл. |
| `-final` | | Окончательное качество (больше неба и непрямых лучей, статические лучи пропа x4). | выкл. |
| `-bounce` | номер | Максимум отскоков. | 100 |
| `-noextra` | | Никакого суперсэмплинга. | выкл. |
| `-extrasky` | фактор | Больше неба и непрямых лучей (карт освещения и пропа). | нет |
| `-smooth` | степени | Угол сглаживания. | 45 |
| `-softsun` | степени | Солнце распространилось для более мягких теней. | 0 |
| `-luxeldensity` | фактор | Более грубые карты освещения, учитываются только значения ниже 1 (остальные получают предупреждение). | 1 |
| `-noskyboxrecurse` | | Никаких теней и света в 3D-скайбоксе. | выкл. |
| `-fastambient` | | Более быстрый опорный рассеянный свет. | выкл. |
| `-centersamples` | | Принято (всегда выполняется). | |
| `-lights` | файл | Дополнительный файл текстуры света. | нет |
| `-chop` / `-maxchop` / `-dispchop` | люксели | Размер текстурного светлого пятна не менее 1. | 4 / 4 / 8 |
| `-StaticPropLighting` | | Статическое освещение каждой вершины. | выкл. |
| `-StaticPropPolys` | | Подкрепляет тени своими нарисованными треугольниками. | выкл. |
| `-textureshadows` | | Альфа-тестирование теней объектов (с `-StaticPropPolys`). | выкл. |
| `-nossprops` | | Никакого самозатенения пропа. | выкл. |
| `-staticpropsamplescale` | фактор | Больше или меньше опорных лучей (более 0). | 1 |
| `-StaticPropNormals` | | Отладка: проп показывает свои нормали. | выкл. |
| `-nostaticpropshadows` | | Hammer Pro: статической тени вообще нет. | выкл. |
| `-nodispshadows` | | Hammer Pro: тень дисплейсмента отсутствует. | выкл. |
| `-nostylebounce` | | Hammer Pro: именованные (переключаемые) источники не дают отражённого света, как в VRAD. | выкл. |
| `-noaddons`, `-wsaddons`, `-nowsaddons`, `-serveraddons`, `-mount_appid` | | Контент, смонтированный для моделей, например `--bspc`. | установлены аддоны и предметы Мастерской |
| `-radius_override` | единицы | Принимается и пропускается (опция VVIS часто передается каждому инструменту). | |

Любой другой вариант получает `Warning: option ... is not supported by this lighting compiler: ignored`; известные параметры VRAD, принимающие значения (`-vproject`, `-aoscale`, `-aofacesamples`, `-aopropsamples`, `-ambientocclusion`, `-sunsamplesarealight`, `-leafambientsamplereduction`, `-maxdispsamplesize`, `-disppatchradius`, `-mpi_workercount`, `-dumptrace`) также пропустите их значение.

Файлы текстурного освещения считываются в следующем порядке: `lights.rad` игры (папка игры, затем папки установки Garry's Mod, в последнюю очередь ее папки `bin`), файл `-lights`, файл, названный ключом Worldspawn `_lightsrad`, затем `<map>.rad` рядом с картой.

Пока он горит, `--rad` перечисляет его стадии (`Lighting stages: direct lighting, bounce rays, bounced light, leaf ambient, static props, writing`), а затем сообщает о каждой стадии, которая длится дольше секунды:

```
Lighting 41%: direct lighting 60% (stage 2 of 7), 27 s elapsed, about 17 s left
```

Первый процент : это все освещение, второй : сцена. Очередь приходит каждые 5% и минимум каждые 30 секунд. Этап, который не продвинулся ни на минуту, печатает `Warning: the lighting stage "..." has not advanced for ...`, что делает этот этап медленным, а тот, который длится более десяти минут, печатает `Warning: the lighting stage "..." has run for ...`. Редактор читает эти строки для своего индикатора выполнения. В конце `--rad` показывает, на что ушло время, в реальных секундах (фаза, которая не выполнялась, показывает 0.00 s):

```
Light phase times: setup 0.15 s, faces 0.63 s, static prop models 0.41 s, shadow tree 1.56 s, surface tree 0.19 s, blocker tree 0.04 s, direct light 13.50 s, displacement blend 1.24 s, displacement bounce blend 1.00 s, bounce rays 3.23 s, bounce passes 3.02 s, seams 0.31 s, leaf ambient 0.45 s, write 0.77 s
```

`direct light` включает источники света, солнце и небо, `static prop models` : чтение моделей пропов (читаются только модели пропов, которые отбрасывают тень или получают повершинное освещение), `seams` : согласование люкселей, общих для соседних граней; `light probes` и `detail props` появляются, когда выполняются. Проблемы, обнаруженные при окончательной проверке, которые уже были в BSP до освещения (карта, составленная другими инструментами), являются предупреждениями; только новые останавливают запись.

<a id="examples"></a>
## Примеры

Быстрый тест карты Garry's Mod:

```
hammerpro --bspc -fastvis -leaktest -game "D:\Steam\steamapps\common\GarrysMod\garrysmod" C:\maps\gm_test
hammerpro --rad -ldr -fast -bounce 1 C:\maps\gm_test
```

Релизная сборка:

```
hammerpro --bspc -vis -leaktest C:\maps\gm_test.vmf
hammerpro --rad -both -final -StaticPropLighting C:\maps\gm_test
```

Та же карта для Team Fortress 2:

```
hammerpro --bspc -target tf -vis C:\maps\ctf_test
hammerpro --rad -target tf -both C:\maps\ctf_test
```

Изменились только сущности:

```
hammerpro --bspc -onlyents C:\maps\gm_test
```

<a id="faq"></a>
## Частые вопросы

**Моя карта не имеет видимости после `hammerpro --bspc`.** Командная строка вычисляет видимость только с `-vis` или `-fastvis` (отдельный шаг VVIS отсутствует).

**Могу ли я сохранить свой старый пакетный файл VBSP/VVIS/VRAD?** Замените `vbsp.exe` на `hammerpro --bspc`, отбросьте строку `vvis.exe` и добавьте `-vis` (или `-fastvis`) в строку `--bspc`, замените `vrad.exe` на `hammerpro --rad`.

**Где журнал компиляции?** `<map>.log` рядом с картой, добавляется при каждом запуске.
