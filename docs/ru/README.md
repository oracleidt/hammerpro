# Hammer Pro документация

[Team Mapping: совместная работа, безопасность и ограничения](features/team-mapping.md)

Добро пожаловать в базу знаний Hammer Pro 1.2.0, редактора уровней для карт на движке Source, созданного в первую очередь для Garry's Mod. У каждой функции есть своя страница: что это такое, как ее открыть, каждая опция со своими значениями по умолчанию, советы и краткий FAQ. Страницы ссылаются друг на друга, поэтому начните с любого места.

Впервые в Hammer Pro? Прочтите [Установка](getting-started/installation.md), [Настройка игры](getting-started/game-setup.md) и [Ваша первая карта](getting-started/first-map.md) в указанном порядке.
