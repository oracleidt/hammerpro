# Совместимость с VMF

Hammer Pro открывает и сохраняет стандартные файлы `.vmf`, поэтому вы можете использовать его вместе с Hammer и Hammer++ на одних и тех же картах. На этой странице рассказывается об открытии, сохранении, экспорте и о том, что хранится в файле.

<a id="opening-maps"></a>
## Открытие карт

| Как | Описание |
|---|---|
| **Файл > Открыть карту...** (`Ctrl+O`) | Открывает файл `.vmf`, `.vmx` или `.vmm`. Стиль Quake `.map` (Valve 220) также можно импортировать: он открывается как новый документ; используйте **Сохранить как**, чтобы сохранить его как VMF. |
| Перетащите | Поместите `.vmf`, `.vmx` или `.vmm` в окно, чтобы открыть его. Другие удаленные файлы также маршрутизируются: файлы-точки (`.lin`, `.pts`) загружаются, файлы портала (`.prt`) и пакеты (`.bsp`, `.gma`, `.vpk`) открываются в просмотрщике, изображения открывают импорт текстур и моделей (`.fbx`, `.obj`, `.gltf`, `.glb`) импорт модели. |
| **Файл > Последние карты** | Последние 12 карт пронумерованы. **Очистить последние карты** очищает список (также в разделе **Настройки > Общие**). |
| Командная строка | `hammerpro path\to\map.vmf`. |
| [Палитра команд](../features/command-palette.md) | `Ctrl+P`, затем введите название последней карты. |

Карты открываются в фоновом режиме: текущая карта остается доступной для использования, а в строке состояния отображается «Открытие <name>... N s» с кнопкой остановки. Каждая открытая карта имеет свою вкладку; вместо того, чтобы дважды загружаться, отображается уже открытая карта (см. [Несколько открытых карт](../features/multiple-maps.md)). Если параметр **Настройки > Общие > Открывать карты в новых вкладках** отключен, открытая карта заменяет текущую после запроса на сохранение ее изменений.

При наличии нового автосохранения карты Hammer Pro запрашивает **Восстановить автосохранение?** с помощью **Открыть автосохранение** или **Сохранить сохраненную карту** (см. [Автосохранение и восстановление после сбоя](../features/autosave-crash.md)).

<a id="damaged-files"></a>
### Поврежденные файлы

Разбор снисходителен. Ключи без значения и случайные закрывающие скобки игнорируются, объекты без действительного идентификатора получают новый, а значения, которые невозможно прочитать, сохраняются неизменными; во всплывающем сообщении говорится: «Открыто <name> с N проблемами», и консоль перечисляет их. Усеченный файл (незамкнутые блоки, обрезанная посередине строка) открывается как новый документ с именем «<name> (поврежденный)», поэтому сохранение не может перезаписать поврежденный файл: используйте **Сохранить как**, чтобы сохранить его под другим именем.

<a id="saving"></a>
## Сохранение

| Команда | Описание |
|---|---|
| **Файл > Сохранить** (`Ctrl+S`) | Сохраняет карту. Сохранение атомарное (временный файл, затем переименование) и, как и в Hammer, предыдущий файл сначала копируется в `<name>.vmx`. |
| **Файл > Сохранить как...** (`Ctrl+Shift+S`) | Сохраняется под новым именем. Диалоговое окно открывается в **Папке карты** в **Настройки > Игра**, если оно установлено. |
| **Файл > Сохранить как новую версию...** | Запрашивает новое имя карты (предлагается: `gm_x` дает `gm_x_v2`, `gm_x_v2` дает `gm_x_v3`; строчные буквы, цифры, только `_` и `-`), сохраняет карту под ней, затем копирует скомпилированную карту (с переименованными сгенерированными путями, поэтому построенные кубические карты сохраняются). работает), его навигационная сетка и скрипты для каждой карты (частицы, звуки уровней, звуковые ландшафты) под новым именем. Существующие файлы никогда не заменяются. Карта, которая никогда не сохранялась, вместо этого получает **Сохранить как**. |

Как и в случае с Hammer, сохранение записывает на карту текущую 3D-камеру и настройки сетки (`nGridSpacing`, `bSnapToGrid`, `bShowGrid` из `viewsettings`).

<a id="lossless-round-trip"></a>
## Поездка туда и обратно без потерь

- Все, что Hammer Pro не понимает (неизвестные ключи, неизвестные блоки, недекодируемые данные), сохраняется и записывается обратно без изменений. Загрузка и сохранение файла никогда не приводит к потере данных.
- Сохраняется текстовый формат, обнаруженный при загрузке: текст Windows-1252, окончания строк CRLF и написание номера Hammer. Карта, написанная Hammer и сохраненная нетронутой, возвращается в том виде, в котором ее написал Hammer.
- Идентификаторы, группы, визгруппы, кордоны, камеры, скрытые объекты и связи сущностей сохраняются как в Hammer.

<a id="hammer-data"></a>
### Hammer++ данные

Блоки, добавленные Hammer++, сохраняются: точные вершины граней `vertices_plus` с каждой стороны и блоки уровня карты `*_plus` (`palette_plus`, `colorcorrection_plus`, `light_plus`, `bgimages_plus` и другие). Карта может перемещаться между Hammer++ и Hammer Pro.

<a id="the-sidecar-file"></a>
## Сопутствующий файл

Данные редактора, которые не принадлежат VMF, хранятся отдельно, в одном небольшом файле TOML для каждой карты: `%LOCALAPPDATA%\HammerPro\maps\<map key>.toml` (ключ идентифицирует полный путь к карте). Он содержит такие удобства, как состояние просмотра, игнорируемые проблемы, отпечаток последней компиляции, целевую игру карты, последний путь экспорта и идентификатор Мастерской. Пишется при сохранении и закрытии карты. Отсутствующая или сломанная коляска просто читается по умолчанию: она никогда не является единственной копией вашей работы, и VMF остается обычным VMF для Hammer. См. [Файлы и папки](../reference/files-and-folders.md).

<a id="importing-and-exporting"></a>
## Импорт и экспорт

| Команда | Описание |
|---|---|
| **Файл > Импортировать карту в текущий...** | Объединяет другой VMF с открытой картой как один шаг отмены. Группы, визгруппы и скрытые объекты сохраняются. |
| **Файл > Экспортировать выбранное в формате VMF...** | Записывает выбранные объекты в новый VMF (имя по умолчанию `prefab.vmf`) с указанием групп, к которым они принадлежат, и их визуальных групп. |
| **Файл > Экспортировать копию...** | Записывает всю карту в другой VMF без переименования открытого документа. Путь запоминается вместе с картой. |
| **Файл > Экспортировать еще раз** (`Alt+B`) | Снова записывает копию в последний путь экспорта этой карты, не спрашивая. |
| **Файл > Экспортировать OBJ...** | Геометрия браши и дисплейсмента с координатами текстуры для 3D-инструментов (см. [Инструменты BSP](../features/bsp-tools.md)). |

Экспорт записывается в рабочий поток атомарно.

<a id="faq"></a>
## Частые вопросы

**Могу ли я снова открыть свою карту в Hammer после ее редактирования в Hammer Pro?** Да. Файл представляет собой стандартный VMF. Большая часть данных, относящихся к Hammer Pro, находится в дополнительном файле. Исключением являются пользовательские сетки карты, записанные в блоке `hammerpro_grids` VMF (см. [Grids](../features/grids.md)).

**Потеряет ли Hammer++ свои дополнительные данные, если я сохраню их в Hammer Pro?** Номер `vertices_plus` и блоки `*_plus` будут записаны обратно.

**Что это за файл `.vmx` рядом с моей картой?** Предыдущая версия карты, копируемая при каждом сохранении, как это делает Hammer. Откройте его с помощью **Файл > Открыть карту...**, чтобы вернуться назад.

**Может ли Hammer Pro открыть скомпилированный `.bsp`?** Да, с помощью **Файл > BSP Decompiler...**, который декомпилирует его в новую карту (см. [Инструменты BSP](../features/bsp-tools.md)).
