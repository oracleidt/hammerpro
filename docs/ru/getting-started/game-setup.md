# Настройка игры

Hammer Pro считывает текстуры, модели и определения объектов из папки игры и компилирует карты для этой игры. Garry's Mod стоит по умолчанию. На этой странице описаны помощник при первом запуске и страница настроек **Игра**.

<a id="the-setup-assistant"></a>
## Помощник по настройке

Помощник настройки **Hammer Pro** открывается при первом запуске (при отсутствии файла настроек). Запустите его еще раз в любое время с помощью **Справка > Ассистент настройки...**. Он имеет 3 шага; `Enter` переходит к следующему шагу, **Назад** возвращается, **Пропустить** (или `Escape`) закрывает его и сохраняет текущие настройки.

| Шаг | Что вы выбираете |
|---|---|
| 1. Добро пожаловать | Язык интерфейса (английский, французский или русский) и **Используется Hammer или Hammer++?**: **Нет, Hammer Pro значения по умолчанию**, **Hammer** или **Hammer++**. При этом набор сочетаний клавиш и элементы управления камерой устанавливаются вместе; сочетания клавиш, которые вы изменили сами, остаются. |
| 2. Для какой игры вы используете карту? | Игра (см. ниже). Для Garry's Mod при первом запуске этого шага в ваших библиотеках Steam выполняется поиск его папки; «Все необходимое нашлось». подтверждает это. |
| 3. Содержание | **Дополнения для монтирования**, **Загрузки из Мастерской монтирования**, **Используйте игры mount.cfg** (только для Garry's Mod) и **папки с пользовательскими текстурами**. |

**Начать сопоставление** на последнем шаге сохраняет выбранные варианты, снова монтирует контент и загружает определения объектов («Настройка завершена. Загрузка игрового контента...»).

Язык можно изменить позже в **Вид > Язык** или в **Настройки > Общие**. Набор сочетаний клавиш находится в **Настройки > Клавиатура**, а элементы управления камерой : в **Настройки > Окна просмотра** (см. [Сочетания клавиш](../features/keyboard-shortcuts.md) и [Камера и навигация](../features/camera-navigation.md)).

<a id="the-game-settings-page"></a>
## Страница настроек игры

Откройте **Инструменты > Параметры...** (`Ctrl+,`), страницу **Игра**. Каждое изменение сохраняется сразу; изменения содержимого вступают в силу, когда вы нажимаете **Применить и перезагрузить содержимое** в нижней части окна или когда вы его закрываете.

<a id="game"></a>
### Игра

| Параметр | Описание | По умолчанию |
|---|---|---|
| Список игр | Карты игры созданы для того, чтобы: их содержимое монтировалось, определения сущностей загружались, а карты компилировались в своем формате и пределах. На первом месте стоят игры, найденные в библиотеках Steam; Также перечислены неустановленные игры (карты по-прежнему компилируются в своем формате). Также перечислены моды `steamapps/sourcemods`. | Garry's Mod |
| **Искать еще раз** | Повторный поиск в библиотеках Steam (после установки или удаления игры). | |
| **Папка с игрой** (не Garry's Mod) | Папка, содержащая `gameinfo.txt`. Пусто: найдено в Steam. В сводке ниже показаны найденная папка, формат («Формат: ..., версия BSP ..., статические пропы ..., ограничения»), найденный файл FGDs и исполняемый файл игры. | Пустой |

Карта также может иметь свою собственную игру, отличную от игры по умолчанию: **Целевая игра** окна компиляции, хранящаяся вместе с картой (см. [Целевые игры](../compiler/target-games.md)). Аддоны, Мастерская, `mount.cfg`, переключатель скайбокса Lua, тестирование в игре с аддоном моста и публикация Мастерской : это функции Garry's Mod: в других играх они отключены.

<a id="garrys-mod-folder"></a>
### Папка Garry's Mod

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Папка Garry's Mod** | Папка установки (та, которая содержит `garrysmod` и `bin`). Пустой: обнаруживается при запуске из Steam. Установите его для использования другой установки. | Пусто (авто) |
| **Обнаружение** | Сейчас ищет в ваших библиотеках Steam. | |
| **Просмотр...** | Выбирает папку вручную. | |
| Проверить результат | «VPK архивы: N» и «Дополнения: N» с **Проверить еще раз**. Папка без `garrysmod/gameinfo.txt` считается неустановленной Garry's Mod. | |

<a id="content-garrys-mod"></a>
### Контент (Garry's Mod)

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Монтировать аддоны** | Загружает материалы и модели из `garrysmod/addons` (папка addons и файлы `.gma`). | Вкл. |
| **Загрузки Мастерской ездовых животных** | Загружает содержимое дополнений Workshop, на которые вы подписаны, `.gma` и устаревших `.bin` (более медленный запуск). | Выкл. |
| **Используйте игры mount.cfg** | Устанавливает другие игры Source, перечисленные в `garrysmod/cfg/mount.cfg`. | Вкл. |
| **Подключайте контент, загруженный с серверов** | Нагружает `garrysmod/download` и `garrysmod/cache/workshop`. Эти файлы могут отсутствовать у игроков: при проверке выпуска упаковывается то, что используется на карте. | Вкл. |

Мастерская и загруженный контент открываются после остальных, в фоновом режиме: в строке состояния отображается «Мастерская Н/М», пока они не будут готовы.

Порядок приоритета, самый высокий: папки с пользовательскими текстурами, дополнения, `garrysmod.vpk`, свободные файлы `garrysmod`, остальные VPKs из `gameinfo.txt`, папки игрового режима `content`, свободные файлы `sourceengine`, игры `mount.cfg`, дополнительные папки игр, Steam игры от AppID (в порядке списка), предметы Мастерской, загруженный контент. Файл, найденный в источнике более высокого уровня, скрывает тот же файл ниже.

<a id="custom-texture-folders"></a>
### Пользовательские папки с текстурами

Добавьте любую папку с файлами VTF/VMT или простыми изображениями (PNG, JPG, TGA, BMP) с помощью **Добавить папку...**. В каждой строке есть поле включения, путь, **префикс** и кнопка удаления. Изображения становятся материалами с именем `prefix/file` и при компиляции преобразуются в VTF + VMT. Префикс не используется, если папка имеет подпапку `materials` или находится внутри папки `materials`; он «обнаруживается» по VMTs готового пака. Подробности: [Папки с пользовательскими текстурами] (../features/custom-texture-folders.md).

<a id="extra-game-folders"></a>
### Дополнительные папки с игрой

Папки модов (с `gameinfo.txt` или свободным содержимым) тоже нужно смонтировать. Добавьте с помощью **Добавить**, удалите с помощью крестика.

<a id="steam-games-by-appid"></a>
### Steam-игры по AppID

Подключите содержимое других установленных игр Steam по их AppID для любой целевой игры (Garry's Mod или нет): например, 220 Half-Life 2, 240 Counter-Strike: Source, 300 Day of Defeat: Source, 380 Half-Life 2: Episode One, 420 Half-Life 2: Episode Two, 400 Portal, 440 Team Fortress 2, 4000 Garry's Mod.

| Контроль | Описание |
|---|---|
| Поле **AppID** и **Добавить**. | Добавляет один AppID или несколько (`240, 440`), также с `Enter`. Значение, не являющееся числом, отклоняется вместе с сообщением. |
| **Установленные игры** | Перечисляет игры Source, установленные в ваших библиотеках Steam, с их AppIDs: щелкните одну, чтобы добавить ее. |
| Искать еще раз (круглая стрелка) | Повторный поиск в библиотеках Steam после установки или перемещения игры. |
| Список строк | AppID и название игры (наведение: папки с игрой). *Не установлено* отображается оранжевым цветом, если в Steam нет такой игры на этом компьютере. Стрелки вверх и вниз меняют приоритет; крест удаляет игру. |

Hammer Pro находит каждую игру через Steam: папку Steam (реестр `SteamPath`, иначе папка установки по умолчанию), каждую библиотеку `steamapps/libraryfolders.vdf`, затем `steamapps/appmanifest_<AppID>.acf` и ее `installdir`. Затем он монтирует то, что указано в списке `gameinfo.txt` игры (ее VPKs и папки, базовые игры, на которых она основана), после содержимого собственной игры карты. Браузеры ресурсов, 3D-просмотр и компиляция (редактор передает папки игры компилятору с помощью `-insert_search_path`) : все они используют его. Сохранено как `mount_app_ids` в таблице `[game]` `settings.toml`. С Garry's Mod `garrysmod/cfg/mount.cfg` тоже работает (**Используйте игры mount.cfg**). AI помощники используют инструменты MCP `list_app_mounts` и `set_app_mounts`; командная строка компилятора принимает `-mount_appid 240,440` (см. [Командная строка компилятора](../compiler/command-line.md)).

<a id="entity-definitions-fgd"></a>
### Определения сущностей (FGD)

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Основной FGD** | Заменяет игровое FGD (`bin/garrysmod.fgd` для Garry's Mod, в противном случае FGD игры). | Пусто (игра FGD) |
| **Дополнительные файлы FGD (загружаются после основного)** | Игровой режим FGDs, Mapbase, ваш собственный. | Нет |

Порядок загрузки: основной FGD (или собственный файл игры), затем FGD Hammer++ (`hammerplusplus_fgd.fgd`), если Hammer++ установлен в папку игры `bin/win64/hammerplusplus` или `bin/hammerplusplus`, затем дополнительные файлы. `@include`, `@mapsize`, поддерживаются исключения материалов и автоматические визуальные группы, а FGD, отредактированный на диске, перезагружается в течение нескольких секунд. В консоли сообщается об отсутствующем файле.

<a id="maps"></a>
### Карты

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Папка с картой** | Начальная папка **Открыть** и **Сохранить как**. | Пустой |

<a id="testing-in-game-garrys-mod"></a>
### Тестирование в игре (Garry's Mod)

**Hammer Pro Мост** : это небольшой аддон в `garrysmod/addons/hammerpro_bridge`, который позволяет Hammer Pro разместить вас у камеры редактора и импортировать проп, который вы расставляете в игре. Он никогда не вставляется в ваши карты и действует только в локальных играх (серверах прослушивания). **Установить**, **Обновить** и **Удалить** управлять им; перезапустите игру после этого. **Появление возле камеры редактора** (требуется мост) помещает игрока туда, где находится 3D-камера при загрузке карты. См. [Запуск игры](../features/game-launch.md).

<a id="reloading-content"></a>
## Перезагрузка контента

- **Применить и перезагрузить контент** (внизу окна настроек) снова монтирует игровой контент с новыми настройками.
- **Инструменты > Контент и редакторы > Перезагрузить содержимое с диска** : перезагружает содержимое и определения объектов без изменения настроек, например после добавления файлов в дополнение.

<a id="faq"></a>
## Частые вопросы

**Garry's Mod не найден.** Нажмите **Обнаружить** или **Обзор...** и перейдите к его папке (той, которая содержит `garrysmod` и `bin`, обычно `steamapps/common/GarrysMod`). В строке состояния отображается «Нет игрового контента», пока оно не будет установлено; щелчок по нему открывает эту страницу.

**Могу ли я использовать карту для Counter-Strike: Source или Team Fortress 2?** Да: выберите игру из списка. Его содержимое и FGD используются, и карта компилируется в своем формате. См. [Целевые игры](../compiler/target-games.md) и [Перенос карты в другую игру](../guides/port-to-another-game.md).

**Текстуры моей Мастерской отсутствуют.** Включите параметр **Подключить загрузки Мастерской**, затем **Применить и перезагрузить контент**.

**Где добавить игровой мод FGD?** В разделе **Дополнительные файлы FGD** на этой странице.
