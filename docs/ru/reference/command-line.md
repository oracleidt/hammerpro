# Командная строка

`hammerpro.exe` : редактор, компилятор карт и мост MCP в одной программе. На этой странице перечислены все принимаемые аргументы.

<a id="usage"></a>
## Использование

```text
hammerpro [map.vmf] [--lang en|fr|ru] [--size WxH] [--screenshot out.png] [--frames N]
          [--maximize-view 0..3] [--tool NAME] [--script file.txt] [--bench-open map.vmf]
hammerpro --mcp
hammerpro --bspc [compiler options] <map.vmf>
hammerpro --rad [lighting options] <map.bsp>
hammerpro --import-models FILE_OR_DIR... --out DIR [options]
```

`--mcp`, `--bspc`, `--rad`, `--import-models` и `--light-preview` должны быть **первым** аргументом: они запускают режим без окна. Все остальные аргументы принадлежат редактору и могут идти в любом порядке.

`--no-save-settings` загружает обычные настройки, но сохраняет изменения предпочтений в памяти для этого сеанса. Он оставляет доступным обычное редактирование, отмену и сохранение карты. Это полезно для временной проверки масштаба интерфейса или параметров рендеринга.

<a id="editor-arguments"></a>
## Аргументы редактора

| Аргумент | Описание | По умолчанию |
|---|---|---|
| `map.vmf` | Любой аргумент, который не начинается с `--`, представляет собой карту, открываемую при запуске (например, **Файл > Открыть карту...**). Если их несколько, побеждает последний. | нет (пустая карта) |
| `--lang en` / `--lang fr` / `--lang ru` | Язык интерфейса только для этой сессии. Язык, сохраненный в настройках, не меняется. Любое другое значение игнорируется. | сохраненный язык |
| `--size WxH` | Размер содержимого окна в пунктах, например `--size 1920x1080`. Вокруг него добавляется поле рамки окна, минимальный размер : 960x600. | `1600x960` |
| `--screenshot out.png` | Автоматический запуск: рисует N кадров (см. `--frames`), сохраняет PNG всего окна в заданный файл и закрывается. | выкл. |
| `--frames N` | Количество кадров, отрисованных до захвата `--screenshot` (минимум 2). | `90` |
| `--maximize-view N` | Начинается с одного развернутого вида. N : индекс вида: `0` 3D, `1` Сверху, `2` Спереди, `3` Сбоку в макете по умолчанию. | нет |
| `--tool NAME` | Инструмент активен при запуске. Имена (регистр игнорируется): `select`, `camera`, `entity`, `block`, `texture`, `decal`, `overlay`, `clip`, `vertex`, `path`, `polygon`, `curve`, `sprinkle`, `displacement`, `cordon`. Неизвестное имя игнорируется. | `select` |
| `--script file.txt` | Автоматический запуск: воспроизводит команды файла сценария (мышь, клавиши, действия, снимки экрана, утверждения). См. [Команды сценария](script-commands.md). | выкл. |
| `--bench-open map.vmf` | Автоматический запуск: открывает карту, ждет, пока она будет нарисована и игровой контент стабилизируется, выводит время запуска и открытия на стандартный вывод в виде пар `key=value` и закрывается. | выкл. |
| `--restore-session list.txt` | Открывает карты списка, составленного Hammer Pro, при перезапуске после потери графического устройства (одна вкладка на карту, измененные карты из сохраненных изменений), затем удаляет список. См. [Графическое устройство потеряно] (../troubleshooting/graphics-device-lost.md). | выкл. |

Неизвестный аргумент, начинающийся с `--`, печатает `unknown argument: ...` в stderr и игнорируется.

<a id="modes-without-a-window"></a>
## Режимы без окна

| Аргумент | Описание |
|---|---|
| `--mcp` | Мост MCP, через который приложения AI запускаются сами. Он не открывает никаких окон и перенаправляет вызовы инструментов в окно Hammer Pro, сервер MCP включен. stdout содержит только сообщения MCP. См. [сервер MCP](mcp-server.md). |
| `--bspc [options] <map>` | Компилятор карт Hammer Pro (геометрия, порталы, тест на утечки и видимость) с аргументами VBSP (`-game`, `-leaktest`...). Он пишет `<map>.bsp` рядом с картой, `<map>.lin` при утечке карты, `<map>.prt` для запечатанной карты и `<map>.log`. |
| `--rad [options] <map>` | Освещение Hammer Pro с аргументами VRAD (`-ldr`, `-hdr`, `-both`, `-final`, `-fast`, `-bounce N`...) плюс собственные параметры Hammer Pro. (`-nostaticpropshadows`, `-nodispshadows`...). На месте загорается `<map>.bsp`. |
| `--import-models FILE_OR_DIR... --out DIR [options]` | Пакетное преобразование файлов OBJ, FBX, glTF и GLB в модели Garry's Mod без окна и без игры (см. «Пакетный импорт» в [Импорт модели] (../features/model-import.md#batch-import)). |
| `--light-preview ...` | Внутреннее: освещение превью запеченного освещения, запускаемое самим редактором. Вам никогда не придется его запускать. |
| `--apply-update <zip> <program> <pid>` | Внутренний: помощник обновления, который редактор запускает из своей копии при нажатии **Обновить**. У него нет окна: он ждет завершения процесса `<pid>`, извлекает `hammerpro.exe` из `<zip>`, заменяет `<program>` (сохраняя `<program>.old`, откатываясь в случае сбоя) и запускает его. См. [Обновления](../features/updates.md). |

Каждый флаг `--bspc` и `--rad` с его эффектом и значением по умолчанию документирован в [Командной строке компилятора](../compiler/command-line.md).

<a id="batch-model-import"></a>
## Пакетный импорт модели

```text
hammerpro --import-models FILE_OR_DIR... --out DIR [options]
```

Должен быть **первым** аргументом. Каждый файл или папка преобразуется в `DIR/models/hammerpro/<name>.mdl` (с `.vvd`, `.dx90.vtx` и `.phy`), а его текстуры : в `DIR/materials/models/hammerpro/<name>/`. Ничего не читается и не записывается в игру. Сохраненные настройки дают значения по умолчанию для уровней детализации и параметров материала.

| Параметр | Описание | По умолчанию |
|---|---|---|
| `--out DIR` | Выходная папка (обязательно, кроме `--dry-run`). | нет |
| `--recursive`, `-r` | Рекурсивный поиск по папкам. | выкл. |
| `--formats LIST` | Форматы взяты из папок: `obj`, `fbx`, `gltf` (также `glb`), через запятую. | все |
| `--template T` | Шаблон имени с `{name}`, `{folder}` и `{index}`. | `{name}` |
| `--prefix P` | Текст перед каждым именем. | нет |
| `--scale S` | Дополнительная шкала, от 0,001 до 1000. | `1` |
| `--no-units` | Одна единица файла равна одной единице Source (без преобразования метров). | выкл. |
| `--up auto\|y\|z` | Верхняя ось файлов. | `auto` |
| `--no-center` | Сохраните начало файла вместо нижнего центра. | выкл. |
| `--kind static\|physics` | `prop_static` или `prop_physics`. | `static` |
| `--surface NAME` | Свойство поверхности. | `default` |
| `--mass KG` | Масса физических объектов: от 0,1 до 50 000. | `20` |
| `--collision pieces\|box\|none` | Модель столкновения. | `pieces` |
| `--no-lod`, `--lod-levels N`, `--lod-keep PCT` | Уровни детализации: выключено, от 3 до 6 уровней, сохраняется от 20 до 90 % на уровень. | сохраненные настройки |
| `--no-material-params` | Цвет, альфа и двусторонняя только в VMTs. | сохраненная настройка |
| `--overwrite` | Заменить существующие модели (по умолчанию они пропускаются). | выкл. |
| `--threads N` | Файлы конвертируются одновременно. | половина потоков процессора, от 1 до 4 |
| `--dry-run` | Только читайте файлы и печатайте треугольники, размер, имя и предупреждения. | выкл. |
| `--quiet`, `-q` | Распечатайте только резюме. | выкл. |

Для каждого файла печатается одна строка (`OK`, `Warning`, `Error` или `Skipped`, файл, название модели, причина), затем краткое описание. Коды выхода: `0` каждый файл преобразован или пропущен, `1` хотя бы один файл не найден или файл не найден, `2` неправильный вариант (выводится сообщение и строка использования).

<a id="automated-runs"></a>
## Автоматизированные прогоны

`--script`, `--screenshot` и `--bench-open` выполняют автоматический запуск. Он создан так, чтобы никогда не трогать ваши собственные файлы или вашу игру:

- Он запускается с **настройками по умолчанию** и никогда не пишет `settings.toml`. Мастер первого запуска не отображается.
- Автосохранение отключено, скомпилированная карта не копируется в папку игры `maps` и игра никогда не запускается (компиляция, запуск, игровая сессия, публикация: отказ с сообщением «пропущено: автоматические запуски никогда не записывают в папку игры и не запускают игру»).
- Нет файла журнала, нет отчета о сбое, нет запроса на восстановление после сбоя, нет присутствия Discord и нет проверки обновлений (если не установлено `HP_UPDATE_API_URL`). Кэш миниатюр и дополнительные файлы для каждой карты остаются в памяти.
- Собственные оконные рамы не используются (отрисовывается собственная рамка Hammer Pro).

Коды выхода: `0` нормальный конец, `2` файл сценария не может быть прочитан или строка не может быть проанализирована (ошибка называет строку), `3` команда `assert_selected` или `assert_tabs` не выполнена.

<a id="environment-variables"></a>
## Переменные среды

| Переменная | Описание |
|---|---|
| `WGPU_BACKEND` | Принудительно отображает графику API, например `dx12`, `vulkan` или `gl`. Полезно, когда на вашем GPU не работает стандартный. |
| `HAMMERPRO_INSTANCE` | Для `--mcp`: идентификатор процесса окна Hammer Pro, который должен использовать мост. |
| `HAMMERPRO_MCP_DIR` | Перемещает записи экземпляра MCP (тесты и автоматические проверки). |
| `HP_UPDATE_API_URL` | Заменяет адрес выпуска GitHub для проверки обновлений (тестов). См. [Обновления](../features/updates.md). |
| `HP_UPDATE_CURRENT_VERSION` | Делает вид, что установлена другая версия (тесты обновления). |

<a id="examples"></a>
## Примеры

```bat
rem Open a map in French
hammerpro.exe "C:\maps\gm_mymap.vmf" --lang fr

rem Screenshot of the editor with the block tool, 3D view maximized
hammerpro.exe gm_mymap.vmf --tool block --maximize-view 0 --screenshot shot.png --frames 120

rem Compile a map from a batch file
hammerpro.exe --bspc -game "C:\...\GarrysMod\garrysmod" "C:\maps\gm_mymap.vmf"
hammerpro.exe --rad -both -final -game "C:\...\GarrysMod\garrysmod" "C:\maps\gm_mymap.bsp"
```
