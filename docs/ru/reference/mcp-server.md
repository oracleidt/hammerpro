# MCP-сервер

Hammer Pro имеет встроенный сервер MCP. MCP (Протокол контекста модели) : это то, как AI приложения, такие как Claude Code, Claude Desktop, Codex и Gemini CLI, используют инструменты: с его помощью помощник AI может читать карту, открытую в Hammer Pro, отредактируйте его, проверьте, скомпилируйте и сделайте скриншоты представлений, чтобы проверить его работу. На этой странице описаны настройка и безопасность. Полный список инструментов с их аргументами находится в [MCP справочнике инструментов](../MCP.md).

<a id="how-it-works"></a>
## Принцип работы

```text
AI app (Claude, Codex, Gemini)
    | starts "hammerpro.exe --mcp" and talks MCP on its stdin and stdout
hammerpro --mcp                     the bridge: no window
    | 127.0.0.1, random port, secret token
Hammer Pro window with MCP on       runs the tools on the map it shows
```

- Каждое окно Hammer Pro имеет **свой сервер, по умолчанию отключенный**.
- Приложение AI запускается само по себе `hammerpro.exe --mcp` после установки. Этот процесс не открывает никаких окон: он перенаправляет вызовы инструментов в окно Hammer Pro, сервер которого включен.
- Если ни в одном окне не включен MCP, AI все равно видит инструменты, и каждый инструмент отвечает, что вы должны открыть Hammer Pro и включить MCP.
- Вызовы инструментов выполняются в собственном потоке редактора между двумя кадрами, как один из ваших щелчков мыши. Мост ожидает ответа до 150 секунд.
- Мост поддерживает версии протокола MCP 2025-11-25, 2025-06-18, 2025-03-26 и 2024-11-05 (JSON-RPC 2.0 через stdio).

## Таблетка MCP

В правом конце верхней панели таблетка показывает состояние сервера этого окна:

| Таблетка | Значение |
|---|---|

| **MCP на · порте · клиентах** | Сервер включен, его локальный порт и количество подключенных приложений AI (**1 клиент**, **2 клиента**...). |

- **Нажмите на таблетку**, чтобы включить или выключить сервер. В его всплывающей подсказке также отображается последний вызванный инструмент и количество вызовов.
- **Маленькая стрелка** рядом с таблеткой (или щелчок правой кнопкой мыши по таблетке, **Установить в приложениях, настройках и инструментах AI**) открывает окно MCP.
- Те же команды находятся в меню **Инструменты**: **MCP сервер** (on/off), **Установить MCP в Claude, Codex и Gemini** и **MCP...** (окно MCP).

Чтобы сервер включался при запуске Hammer Pro, установите флажок **Запускать сервер MCP при запуске Hammer Pro** на странице **MCP** окна настроек (**Инструменты > Параметры...**, `Ctrl+,`). По умолчанию выключено (настройка `mcp.start_with_app`). На той же странице есть кнопки **Включить**/**Выключить**, **Установить и настроить...** (открывает окно MCP) и список **Инструменты, доступные для приложений AI**.

<a id="install-in-an-ai-app"></a>
## Install in an AI app

1. Включите таблетку (**MCP выключен** станет **MCP включен**).
2. Откройте окно MCP (стрелка рядом с табличкой или **Инструменты > Интеграции > MCP...**).
3. Нажмите **Установить в Claude, Codex, Gemini**. Hammer Pro добавляет себя ко всем приложениям, которые находит на этом компьютере, в следующем порядке: Claude Code, Claude Desktop, Codex, Gemini CLI, затем проверяет каждое из них. Вы также можете установить одно приложение с помощью отдельной кнопки **Установить**.
4. Перезапустите приложение AI (или начните новый сеанс), чтобы оно увидело новый сервер.

Что меняется при каждой установке:

| Приложение | What is changed |
|---|---|
| Клод Код | Выполняется `claude mcp add --scope user hammer-pro -- "<hammerpro.exe>" --mcp`, проверяется с помощью `claude mcp get hammer-pro`. `~/.claude.json` никогда не редактируется напрямую. |
| Клод Рабочий стол | `mcpServers` из `%APPDATA%\Claude\claude_desktop_config.json` (или копии из Microsoft Store под `%LOCALAPPDATA%\Packages\Claude_*`). |
| Кодекс | `[mcp_servers.hammer-pro]` из `~/.codex/config.toml` (или из `%CODEX_HOME%`). |
| Близнецы CLI | `mcpServers` из `~/.gemini/settings.json`. |

Перед первым изменением каждый файл копируется в `<file>.hammerpro.bak`. Файлы записываются через временный файл, все остальное в них сохраняется (другие серверы, комментарии в TOML-файле) и результат считывается для его проверки. JSON-файл с комментариями не трогается: добавьте запись вручную.

Переместили Hammer Pro в другую папку? Откройте окно MCP: в приложениях отображается **Настроено для другой копии Hammer Pro**. Нажмите **Обновить** (или **Установить в Claude, Codex, Gemini**).

<a id="manual-setup"></a>
## Ручная настройка

Если вы предпочитаете или если автоматическая установка не может редактировать файл, добавьте сервер самостоятельно (в окне MCP показаны эти фрагменты с вашим реальным путем):

Код Клода:

```bash
claude mcp add --scope user hammer-pro -- "C:\Program Files\Hammer Pro\hammerpro.exe" --mcp
```

Claude Desktop (`claude_desktop_config.json`) и Gemini CLI (`~/.gemini/settings.json`):

```json
{
  "mcpServers": {
    "hammer-pro": {
      "command": "C:\\Program Files\\Hammer Pro\\hammerpro.exe",
      "args": ["--mcp"]
    }
  }
}
```

Codex (`~/.codex/config.toml`):

```toml
[mcp_servers.hammer-pro]
command = 'C:\Program Files\Hammer Pro\hammerpro.exe'
args = ["--mcp"]
```

Любое другое приложение MCP: сервер stdio с командой `hammerpro.exe` и аргументом `--mcp`.

<a id="security"></a>
## Безопасность

- **Выкл. по умолчанию** для каждого окна. Ничего не слушается, пока вы не включите таблетку.
- **Только локально**: сервер прослушивает `127.0.0.1`, никогда не находится в сети и отклоняет любые соединения, кроме этого компьютера.
- **Секретный токен**: каждый раз при запуске сервера он создает случайный 32-байтовый токен. Каждое соединение должно отправить его первым, иначе оно будет закрыто. Токен записывается только в запись экземпляра окна, `%LOCALAPPDATA%\HammerPro\mcp\instances\<pid>.json`, в вашем собственном профиле. Запись удаляется, когда сервер останавливается или Hammer Pro закрывается; записи о разбитых окнах игнорируются и очищаются.
- **Ограничения**: количество сообщений до 8 MB, 8 одновременных подключений в каждом окне, тайм-аут при каждом вызове инструмента.
- **Без затрат в простое**: поток сервера спит до прихода соединения (без периодического опроса), поэтому окно с включенным MCP и без подключенного AI не нагружает процессор. Долгий вызов инструмента в фоне (пакетный импорт, преобразование текстуры) будит окно по завершении, а не заставляет его перерисовываться все это время.
- **Пути к файлам**: инструмент, принимающий файл или папку, отклоняет сетевые пути (UNC, `\\сервер\ресурс`) и пути устройств (`\\?\`, `\\.\`, `CON`, `NUL`, `COM1`...), поэтому путь, подброшенный в запросе, не может заставить Windows отправить ваши учетные данные на другой компьютер. Относительные пути остаются внутри своей папки (без `..`), а инструменты, которые пишут рядом с картой (графы шейдеров, текстуры, изображения, звуки, таблицы цветов), принимают только папку карты и пользовательские папки текстур.
- **Никаких программ, если вы не попросите, никаких произвольных файлов**: инструменты не запускают собственных команд. Карты открываются и сохраняются только как `.vmf`; для сохранения поверх другого существующего файла требуется явный `overwrite`. Игра запускается только тогда, когда AI явно этого требует. При компиляции используется компилятор, выбранный для игры (по умолчанию собственный компилятор Hammer Pro); для создания или изменения компилятора, запускающего другие программы (`create_compiler`, `set_compiler` с шагами), требуется `confirm: true`. См. [Выбор компилятора](../compiler/compilers.md).
- **Подтверждение**: `run_action` запускает любую команду меню, кроме нескольких, требующих `confirm: true`, которые AI выполняет только тогда, когда вы запросили именно это: выход, выключение MCP, установка MCP в другие приложения, публикация, запуск игры или общение с ней, компиляция с игрой, редактирование экземпляра в другом окно, открывающее веб-браузер и команды, которые отображают диалоговое окно файла.
- **Настройки**: `set_setting` никогда не меняет пути к файлам, папкам, программам, командным строкам, папкам игрового содержимого или настройкам MCP: вы меняете их в окне настроек. Для добавления или удаления дополнительного файла FGD (только `.fgd`) требуется `confirm: true`.
- Инструменты автоматизации UI (`ui_click`, `ui_key`, `ui_type`...) действуют только внутри окна Hammer Pro.
- Автоматические запуски (`--script`) никогда не запускают игру, независимо от того, подтверждено это или нет.

<a id="several-windows"></a>
## Несколько окон

Имея несколько окон Hammer Pro, мост использует то окно с MCP, на котором вы фокусировались последним, и остается с ним во время работы. AI может отображать окна с помощью `list_instances` и переключаться с помощью `use_instance`. Чтобы закрепить одно окно в конфигурации приложения, установите для переменной среды `HAMMERPRO_INSTANCE` идентификатор его процесса.

<a id="undo"></a>
## Отменить

Каждое изменение, вносимое AI, представляет собой **один шаг отмены** с именем «MCP:», за которым следует то, что было сделано (например **MCP: применить материал**), в меню **Редактировать** и в истории отмены. `Ctrl+Z` возвращает его, как и любые ваши собственные изменения. AI также может отменять и повторять действия (`undo`, `redo`, `undo_steps`, `redo_steps` или `run_action` с `undo` и `redo`) и читать историю (`get_history`). В сеансе Team Mapping они проходят через общую историю сеанса точно так же, как `Ctrl+Z` и `Ctrl+Y`, по одному шагу за вызов, чтобы другие участники увидели изменение.

[Размещение по реальным формам](../features/real-shape-placement.md#для-ии-mcp)). |
