# Справочник по настройкам

Каждая опция Hammer Pro 1.0.2 хранится в одном файле TOML, `settings.toml`, в `%APPDATA%\HammerPro` в Windows (папка конфигурации пользователя в других системах). На этой странице перечислены все таблицы и ключи этого файла, их значение по умолчанию и то, что они делают, а также место в интерфейсе, где вы их меняете.

Обычно вы никогда не редактируете этот файл вручную: [Окно настроек](../features/settings-dialog.md) (**Инструменты > Параметры...**, `Ctrl+,`) и меню меняют его, и каждое изменение сохраняется сразу. Редактировать его вручную тоже безопасно:

- У каждого ключа есть значение по умолчанию. Отсутствующие ключи принимают значения по умолчанию, неизвестные ключи игнорируются, поэтому старая и новая версии Hammer Pro могут использовать один файл.
- Таблица записывается только в том случае, если одно из ее значений отличается от значений по умолчанию, поэтому новый файл будет коротким.
- Если файл не может быть прочитан (опечатка в TOML), Hammer Pro запускается со значениями по умолчанию и записывает предупреждение в журнал. Закройте Hammer Pro перед редактированием файла, иначе ваши изменения будут перезаписаны следующим сохранением.
- Файл записывается атомарно (временный файл, затем переименование).
- Инструменты MCP `get_settings` и `set_setting` считывают и изменяют эти ключи по пунктирному пути (`render.water_preview`, `edit.grid_size`).

Значения в таблицах используют синтаксис TOML: `true`, `16.0`, `"Dark"`. Перечисления записываются с именем варианта, указанным в таблице.

<a id="top-level-keys"></a>
## Ключи верхнего уровня

| Клавиша | По умолчанию | Описание |
| --- | --- | --- |
| `language` | системный язык | `"En"`, `"Fr"` или `"Ru"`. Язык интерфейса. При первом запуске это происходит из системного языка. **Настройки > Общие** или аргумент `--lang` для одного запуска. |
| `language_chosen` | `false` | Устанавливается после того, как был сделан первый выбор языка. |
| `recent_files` | `[]` | Карты из **Файл > Последние карты**, сначала самые новые, максимум 12. **Настройки > Общие > Последние карты** очищает его. |
| `keybindings` | `{}` | Ваш сочетание клавиш изменится: идентификатор действия = текст сочетания клавиш (`undo = "Ctrl+Alt+Z"`, `""` для отсутствия сочетания клавиш). Пишутся только измененные действия. Идентификаторы указаны в разделе [Действия и сочетания клавиш] (actions-shortcuts.md). **Настройки > Клавиатура**. |
