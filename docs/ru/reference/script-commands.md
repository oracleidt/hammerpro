# Команды сценария

`hammerpro.exe --script file.txt` воспроизводит текстовый файл команд в редакторе: движения и клики мыши, клавиши, действия, параметры инструментов, снимки экрана и проверки. Он создан для автоматизированного сквозного тестирования и пошагового воспроизведения ошибки. Запуск скрипта : это автоматический запуск: настройки по умолчанию, в ваши настройки, журналы или игру ничего не записывается (см. [Командная строка](command-line.md)).

<a id="file-format"></a>
## Формат файла

- Одна команда в строке. Пустые строки пропускаются.
- `#` начинает комментарий: все, что находится после него в строке, игнорируется (поэтому текст `type` не может содержать `#`).
- Аргументы разделяются пробелами. Команды, принимающие путь или текст (`open`, `save`, `screenshot`, `type`, `log`...), считывают остальную часть строки, включая пробелы.
- Строка, которую невозможно прочитать, останавливает выполнение до того, как оно начнется с `script line N: cannot parse ...` и кода выхода 2.
- Каждая команда выводит `script: ...` на стандартный поток ошибок при запуске, что упрощает отслеживание вывода.
- Выполнение не закрывает окно в конце скрипта: завершите с помощью `exit`.

<a id="positions-pos"></a>
## Позиции (POS)

| Форма | Значение |
|---|---|
| `X,Y` | Координаты окна в точках, от верхнего левого угла окна. |
| `@vN:FX,FY` | Часть (от 0 до 1) прямоугольника вида N. В макете по умолчанию `@v0` : это 3D-вид, `@v1` Сверху, `@v2` Спереди, `@v3` Сбоку. `@v1:0.5,0.5` : центр вида сверху. |
| `@top:A,B` | Мировые координаты на первом виде сверху (X, Y). Также `@front:A,B` (Y, Z) и `@side:A,B` (X, Z). |

<a id="buttons-and-modifiers"></a>
## Кнопки и модификаторы

- Кнопки мыши: `left` (по умолчанию), `right`, `middle`.
- Модификаторы (MODS): `ctrl`, `shift`, `alt`, объединенные с `+`, например `ctrl+shift`.
- Комбинации клавиш (COMBO): модификаторы и одна клавиша, объединенная с помощью `+`, например `Ctrl+Shift+S`, `Enter`, `Escape`, `Delete`, `F9`, `Space`, `ArrowUp`, `A`. Имена клавиш : это имена клавиш egui.
- Модификаторы, удерживаемые с помощью `keydown`, применяются к каждому последующему событию до `keyup`.

<a id="commands"></a>
## Команды

<a id="timing"></a>
### Тайминг

| Команда | Описание |
|---|---|
| `wait N` | Ожидает N кадров. Кадры, а не время: при большой нагрузке частота кадров может упасть до нескольких кадров в секунду, так что будьте щедры. |
| `idle MS` | Позволяет пройти MS миллисекунд реального времени без принудительного создания кадров (редактор рисует только те кадры, которые он запрашивает сам, например, когда никто не трогает мышь), а затем печатает, сколько кадров было нарисовано. |

<a id="mouse"></a>
### Мышь

| Команда | Описание |
|---|---|
| `move POS` | Перемещает указатель. |
| `click POS [button] [mods]` | Нажмите и отпустите. |
| `dclick POS [button] [mods]` | Двойной щелчок. |
| `drag POS POS [button] [steps] [mods]` | Нажмите на первую позицию, перейдите ко второй на `steps` ходов (по умолчанию 8), отпустите. Модификаторы остаются нажатыми на протяжении всего перетаскивания. |
| `press POS [button] [mods]` | Нажимайте только кнопку мыши: она остается нажатой при выполнении следующих команд (`idle`, `move`...). |
| `release POS [button] [mods]` | Отпустите кнопку мыши, нажатую с помощью `press`. |
| `scroll POS DY [mods]` | Колесо мыши. Положительное значение DY увеличивает масштаб или перемещает вперед. `scroll @v1:0.5,0.5 1 ctrl` изменяет размер сетки. |

<a id="keyboard"></a>
### Клавиатура

| Команда | Описание |
|---|---|
| `key COMBO` | Нажмите и отпустите клавишу, например `key Ctrl+Shift+S`, `key Enter`. `Ctrl+C` и `Ctrl+X` также отправляют текстовые поля событий копирования и вырезания, которые прослушиваются. |
| `keydown COMBO` | Нажимайте клавиши и модификаторы и удерживайте их, например `keydown Shift`, `keydown Space` (панорамирование с последующим перетаскиванием). |
| `keyup COMBO` | Клавиши выпуска и модификаторы удерживаются с помощью `keydown`. |
| `hold KEY FRAMES` | Удерживайте одну клавишу для некоторых кадров (по умолчанию 30), например, для управления 3D-камерой. |
| `type TEXT` | Вводит текст в выделенное поле. |

<a id="editor"></a>
### Редактор

| Команда | Описание |
|---|---|
| `action ID` | Запускает действие по его идентификатору, например, по пункту меню или сочетанию клавиш (`compile_now`, `toggle_grid`...). Идентификаторы указаны в [Действия и сочетания клавиш](actions-shortcuts.md). Неизвестный идентификатор печатает `unknown action`. |
| `tool NAME` | Инструмент переключения: `select`, `camera`, `entity`, `block`, `texture`, `decal`, `overlay`, `clip`, `extrude`, `bevel`, `vertex`, `path`, `polygon`, `curve`, `sprinkle`, `displacement`, `cordon`, `road`. |
| `tool_option KEY VALUE` | Устанавливает параметр активного инструмента (см. «Параметры инструмента» ниже). Значением является одно слово: используйте запятые внутри списков (`custom_axis 0,0,1`). Неизвестный ключ или неверное значение печатает `tool ... has no option ...`. |
| `open PATH` | Открывает карту и ждет ее загрузки (до 120 секунд). На уже открытой карте отображается вкладка. |
| `save PATH` | Сохраняет карту в PATH без диалогового окна. |
| `material NAME` | Устанавливает текущий материал (новые браши и Apply). |
| `select_id ID` | Выбирает объект с этим идентификатором или тело с этим идентификатором. |
| `grid SIZE` | Устанавливает размер сетки. |
| `camera X Y Z YAW PITCH` | Размещает 3D-камеру. |
| `player X Y Z YAW PITCH` | В представлении игрока: помещает глаза туда, глядя в ту сторону (поднятие тангажа положительное), в noclip, чтобы игрок оставался. |
| `setting PATH VALUE` | Изменяет настройку по пунктирному пути, как инструмент MCP `set_setting`. VALUE : это JSON или простая строка: `setting render.normal_maps false`. Ключи находятся в [Справочнике настроек] (settings.md). |
| `custom_folder PATH [\| prefix]` | Добавляет пользовательскую папку текстур (включена) и перемонтирует содержимое. Без префикса он предлагается из названия папки. |
| `import_model PATH` | Открывает диалог импорта модели с файлом (FBX, OBJ, glTF, GLB). |
| `import_model_now PATH` | Импортирует модель с параметрами по умолчанию. |
| `mesh_to_disp PATH` | Открывает окно [Сетка для дисплейсмента](../features/displacement-tool.md#mesh-to-displacement) с файлом сетки (OBJ, FBX, glTF, GLB). |
| `mesh_to_disp_now PATH` | Считывает файл сетки и создает плитки дисплейсмента с параметрами по умолчанию. |
| `import_models_batch PATH` | Открывает [пакетный импорт] (../features/model-import.md#batch-import) с этим файлом или папкой (включая подпапки), уже считанными в таблицу предварительного просмотра. |
| `import_model_scaled SCALE PATH` | Импортирует модель с этим масштабом (больше 0). Скрипт при запуске записывает модель во временную папку с содержимым, а не в игру. |

<a id="window-and-look"></a>
### Окно и взгляд

| Команда | Описание |
|---|---|
| `theme dark` / `theme light` | Переключает тему интерфейса. |
| `background OPACITY PATH` | Показывает изображение поверх окна (например, **Настройки > Общие**, фоновое изображение), непрозрачность от 0 до 1. |
| `window_size W H` | Изменяет размер главного окна в пунктах (его минимальный размер по-прежнему применяется). |
| `window_maximize on` / `off` | Разворачивает или восстанавливает главное окно. |

<a id="output-and-checks"></a>
### Вывод и проверки

| Команда | Описание |
|---|---|
| `screenshot PATH` | Сохраняет скриншот главного окна в формате PNG. |
| `screenshot_window NAME PATH` | Сохраняет снимок экрана диалогового окна, отображаемого в отдельном окне: `compile`, `uv_editor` или `portals` (как инструмент MCP `screenshot_window`). |
| `log TEXT` | Печатает `script: TEXT` на stderr. |
| `stats` | Печатает частоту кадров, время кадра, худший кадр, количество тел, граней, сущностей и выбранных объектов, состояние актива, а также статистику рендеринга, частиц и кубической карты. В представлении проигрывателя также печатаются стили освещения. |
| `vram` | Печатает использование графической памяти: использование и бюджет в MB, откуда берется использование (`driver` или `estimate`), давление (`normal`, `high`, `critical`), предполагаемое разделение (геометрия, текстуры, модели, карты освещения, скомпилированный мир, другое, карты, припаркованные в фоновые вкладки), предельный размер текстуры, обнаруженные ошибки нехватки памяти и количество раз, когда память была освобождена. |
| `history` | Печатает шаги отмены и повтора, открыто ли редактирование, а также границы выделения. |
| `assert_selected N` | Останавливает выполнение с кодом выхода 3, если не выбрано ровно N объектов. |
| `assert_tabs N` | Останавливает прогон с кодом выхода 3, если не открыто ровно N карт. |
| `exit` | Закрывается Hammer Pro. |

<a id="tool-options"></a>
## Опции инструмента

`tool_option` использует те же имена опций, что и инструменты MCP `get_tool_options` и `set_tool_options`. Переключатели принимают `on`/`off`, `true`/`false` или `1`/`0`.

<a id="selection-tool-tool-select"></a>
### Инструмент выбора (`tool select`)

| Клавиша | Ценности |
|---|---|
| `handles` | `scale`, `rotate` или `skew`: что делают ручки поля выбора в 2D-видах. |
| `box` | `touching`, `inside` или `centers`: какие объекты занимает выделение рамки в 2D-виде. |
| `gizmo` | on/off: инструмент трансформации в 3D-виде. |
| `gizmo_mode` | `move`, `rotate` или `scale`. |
| `gizmo_local` | on/off: гизмо одноточечного объекта повторяет его углы (сохраняется в настройках). |
| `stretch_handles` | on/off: растянуть стрелки на гранях выбранных брашов в 3D-виде (сохраняется в настройках). |

<a id="block-tool-tool-block"></a>
### Инструмент «Блок» (`tool block`)

| Клавиша | Ценности |
|---|---|
| `kind` | `block`, `wedge`, `cylinder`, `spike`, `sphere`, `arch`, `torus`, `stairs`, `spiral_stairs`, `ramp`, `pillar` или `doorway`. |
| `sides` | Стороны круглых примитивов от 3 до 64. |
| `wall` | Ширина стены арки в единицах (1 или более). |
| `arc` | Дуга арки в градусах от 1 до 360. |
| `start` | Начальный угол арки в градусах. |
| `rise` | Добавленная высота арки в единицах. |
| `tube_sides` | Количество сторон торовой трубки: от 3 до 64. |
| `ring` | Ширина кольца тора в единицах (1 или более). |
| `torus_arc` | Развертка тора в градусах (свыше 360 образует спираль с подъемом). |
| `torus_start` | Начальный угол тора в градусах. |
| `torus_rise` | Высота, полученная за развертку тора, в единицах. |
| `steps` | Лестницы и винтовые лестницы: количество ступеней от 1 до 256. |
| `step_height` | Лестницы и винтовые лестницы: высота ступени в единицах, 0 использований `steps`. |
| `open` | on/off: открытые ступени (плиты) вместо сплошных колонн. |
| `inner` | Винтовая лестница: внутренний радиус в единицах, 0 для круговых ступенек. |
| `spiral_angle` | Винтовая лестница: общий поворот в градусах от -3600 до 3600 (более 360 необходимо `open`). |
| `spiral_start` | Винтовая лестница: начальный угол в градусах. |
| `slope` | Рампа: угол наклона в градусах, от 1 до 89. |
| `direction` | Лестницы, винтовые лестницы и пандусы: сторона, в которую они поднимаются, `+y` (по умолчанию), `-y`, `+x`, `-x` или `longest`. |
| `base` | Столб: высота основания в единицах, 0 : нет. |
| `capital` | Столб: высота капители в единицах, 0 : нет. |
| `inset` | Столб: насколько уже вал, чем основание и капитель. |
| `door_width` | Дверной проем: ширина проема в единицах, 0 : половина стены. |
| `door_height` | Дверной проем: высота проема в единицах, 0 : три четверти стены. |
| `thickness` | Дверной проем: толщина стены в единицах, 0 заполняет глубину коробки. |
| `door_arch` | on/off: дверной проем с закругленной вершиной. |
| `door_arch_radius` | Арка дверного проема: радиус в единицах, не менее половины проема, 0 : половина (полукруг). |
| `door_arch_segments` | Арка дверного проема: количество прямых частей круглого верха от 2 до 64. |
| `reorient` | on/off: примитивы, нарисованные на виде спереди или сбоку или на стене, располагаются по глубине вида (сохраняются). |
| `preview` | on/off: окно предварительного просмотра большой формы. |
| `tex_scale` | Масштаб текстур новых граней: от 0,01 до 64. |
| `create_as` | `world` или класс сущности браши (`func_detail`, `trigger_multiple`...). |
| `keep_active` | on/off: оставаться в инструменте блока после создания. |

<a id="curve-tool-tool-curve"></a>
### Инструмент «Кривая» (`tool curve`)

| Клавиша | Ценности |
|---|---|
| `subdivisions` | Количество брашов по кривой от 2 до 4096. |
| `thickness` | Ширина брашов по кривой: от 1 до 1024 единиц. |
| `height` | Высота по глубине вида, от 1 до 16384 единиц (также изменяет рисуемую кривую) или `auto`: из выделения, как при использовании инструмента «Блок». |
| `tex_scale` | Масштаб текстур новых граней: от 0,01 до 64. |
| `create_as` | `world` или класс сущности браши (`func_detail`...), содержащий каждую браш. |
| `keep_active` | on/off: оставаться в инструменте кривой после создания. |

<a id="road-tool-tool-road"></a>
### Дорожный инструмент (`tool road`)

| Клавиша | Ценности |
|---|---|
| `selected_point` | Выберите точку, пронумерованную от 1. |
| `point_x`, `point_y`, `point_z` | Координаты выбранной точки. Изменение Z отключает отслеживание ландшафта. |
| `fit_width` | Установите `on`, чтобы уменьшить ширину до тех пор, пока не будет соответствовать текущему жесткому изгибу; сохраняет путь на месте. |
| `lanes` | Количество полос от 1 до 8. |
| `lane_width` | Ширина одной полосы движения от 16 до 256 ед. |
| `shoulder` | Ширина обочины с каждой стороны от 0 или 1 до 256 единиц. |
| `thickness` | Глубина залегания плиты под поверхностью от 2 до 128 ед. |
| `step` | Длина целевого сегмента от 16 до 512 единиц. |
| `tex_scale` | Масштаб текстур граней от 0,01 до 64. |
| `material`, `shoulder_material`, `line_material`, `center_material` | Материалы полос, обочин, линий и центральной линии (пустой материал обочины или центральной линии: такой же, как полосы или линии). |
| `center_line`, `edge_line`, `divider_line` | `none`, `solid`, `dashed` или `double`. |
| `line_width`, `dash`, `gap` | Ширина линий, длина тире и пробела. |
| `roll_start`, `roll_end`, `auto_bank`, `auto_bank_limit` | Банковское дело, как в инструменте кривой. |
| `follow_terrain` | on/off: дорога следует по земле под ней. |
| `lift` | Высота над землей при движении по местности от -256 до 256. |
| `base_height` | Высота первой точки, когда земля не найдена, от -16384 до 16384. |
| `create_as` | `world` или класс сущности браши (`func_detail`...), содержащий каждую браш. |
| `keep_active` | on/off: оставаться в инструменте дороги после создания. |

<a id="path-tool-tool-path"></a>
### Инструмент «Путь» (`tool path`)

| Клавиша | Ценности |
|---|---|
| `class` | Класс новых точек: `path_corner`, `path_track`, `path_corner_crash`, `keyframe_rope`... |
| `base_name` | Базовое имя точек (`path` называет их `path_1`, `path_2`...). |

| `relink` | on/off: Delete в этом инструменте связывает соседей удаленных точек. |
| `offset` | Высота над поверхностью точек, размещенных в 3D-виде, от -1024 до 1024. |

<a id="extrude--carve-tool-tool-extrude"></a>
### Инструмент выдавливания/вырезания (`tool extrude`)

| Клавиша | Ценности |
|---|---|
| `mode` | `carve` (вкопать контур в браш) или `extrude` (вытащить его за пределы грани). |
| `depth` | Глубина в единицах: от 0,125 до 16384. |

<a id="bevel-tool-tool-bevel"></a>
### Инструмент для снятия фаски (`tool bevel`)

| Клавиша | Ценности |
|---|---|
| `radius` | Радиус скругления в единицах от 0,25 до 16384 (ограничен гранями при скосе). |
| `segments` | Грани скругления, от 1 (плоская фаска) до 32. |
| `inverse` | on/off: вогнутая фаска (выемка или закругление, заполняющее внутренний угол). |
| `new_faces` | `face` (текстуры по краям, обернутые) или `current` (текущий материал) на закругленных гранях. |

Чтобы выполнить скос из сценария, наведите курсор на край и отправьте его ключ: `move @v0:0.5,0.4`, затем `key Ctrl+B`, `scroll @v0:0.5,0.4 2` для еще 2 сегментов, `key B` для обратного скоса, `key Enter` для применения.

<a id="texture-tool-and-uv-editor-tool-texture"></a>
### Инструмент текстуры и редактор UV (`tool texture`)

| Клавиша | Ценности |
|---|---|
| `uv_place` | `panel` (закреплено на панели редактирования «Грань») или `window` (отдельное окно). |
| `uv_all_faces` | on/off: редактор UV редактирует каждое выбранное грань или только редактируемое. |
| `uv_mode` | `face`, `edge` или `vertex`. |
| `uv_layer` | `base`, `base2`, `bump`, `bump2`, `detail`, `envmask` или `blendmod` (если он есть в материале). |
| `uv_keep_layers` | on/off: перемещение базовой текстуры сохраняет положение слоев на грани. |
| `uv_fit_tiles` | Плитки по краю для параметра «Подогнать по краю», от 0,25 до 64. |
| `uv_vertices` | Выбранные вершины редактируемой грани, индексы разделены запятыми (пусто или `none`: ничего). Переключает в вершинный режим. |
| `uv_edges` | Выделенные ребра редактируемой грани (индекс первой вершины каждой), разделенные запятыми. Переключает в краевой режим. |

<a id="displacement-tool-tool-displacement"></a>
### Инструмент перемещения (`tool displacement`)

| Клавиша | Ценности |
|---|---|
| `mode` | `select`, `geometry` (также `paint`), `alpha`, `sculpt` или `tag`. |
| `effect` | Геометрическое рисование: `raise`, `lower`, `smooth` или `set` (также `raise_to`). |
| `axis` | `normal`, `subdiv`, `center` (также `brush_center`), `view`, `x`, `y`, `z` или `custom`. |
| `custom_axis` | Направление пользовательской оси: `x,y,z`. |
| `radius` | Радиус кисти в единицах от 1 до 8192. |
| `strength` | Увеличение и уменьшение скорости в единицах в секунду, от 0 до 8192. |
| `smooth` | Сила сглаживания от 0 до 1. |
| `target_height` | Высота установленного эффекта от -16384 до 16384. |
| `falloff` | `constant`, `linear` или `smooth`. |
| `spatial` | on/off: 3D-расстояние на поверхности (окрашивает стены и плитку). |
| `line_of_sight` | on/off: только то, что камера видит на браши. |
| `autosew` | on/off: живое шитье соседей. |
| `selected_only` | on/off: если выбраны дисплейсменты, закрашиваются только они. |
| `continuous` | on/off: удерживая кнопку, рисование продолжается. |
| `alpha_effect` | `add`, `remove`, `set` или `smooth`. |
| `alpha_value` | Целевая альфа установленного эффекта: от 0 до 255. |
| `alpha_strength` | Альфа добавляет и удаляет скорость в секунду, от 0 до 16384. |
| `blend_channel` | `alpha` (также `none`) для двухтекстурной смеси или от `1` до `4` для текстуры 4-сторонней смеси. |
| `sculpt` | `push`, `carve`, `project`, `pinch`, `grab`, `inflate`, `flatten`, `relax`. |
| `relax_strength` | Сила Relax от 0 до 1; вместе с `mode sculpt`, `sculpt relax`. |
| `push_mode` | `absolute` (единицы) или `adaptive` (процент радиуса). |
| `sculpt_bounds` | `attenuated` или `additive`. |
| `falloff_position` | Push: процент радиуса, на который попадает все смещение, от 0 до 100. |
| `falloff_final` | Push: процент смещения, спад никогда не опускается ниже, от 0 до 100. |
| `push_distance` | Смещение нажатия в единицах от 0 до 4096. |
| `push_percent` | Смещение нажатия в процентах от радиуса, от 0 до 400. |
| `carve_depth` | Глубина вырезания в единицах от 0 до 4096. |
| `carve_profile` | `v`, `u`, `flat` или 5 глубин от 0 до 1, разделенных запятыми. |
| `project_range` | Проект: браши дальше этого значения игнорируются, от 1 до 16384. |
| `scale_factor` | Коэффициент кнопки масштабирования от -16 до 16. |
| `noise_type` | `random` или `fractal`: тип шума «Добавить шум». |
| `noise_scale` | Фрактальный шум: размер крупнейших объектов в единицах от 1 до 65536. |
| `noise_octaves` | Фрактальный шум: уровни детализации от 1 до 8. |
| `noise_persistence` | Фрактальный шум: вес каждого более тонкого слоя от 0,05 до 1. |
| `terrain_seed` | Начальное значение фрактального шума и гидравлического дождя: от 0 до 4294967295. |
| `thermal_iterations` | Проходит термоэрозия, 1 к 1000. |
| `thermal_talus` | Термическая эрозия: крутой наклон в градусах, на котором остается материал, от 0 до 89. |
| `thermal_strength` | Термическая эрозия: доля излишков, соскальзывающих за проход, от 0 до 1. |
| `hydraulic_iterations` | Гидравлическая эрозия проходит от 1 до 2000. |
| `hydraulic_rain` | Гидравлическая эрозия: вода добавляется на каждую вершину и проход, от 0 до 100. |
| `hydraulic_evaporation` | Гидравлическая эрозия: доля воды, которая испаряется за проход, от 0 до 1. |
| `hydraulic_capacity` | Гидравлическая эрозия: перенос наносов на единицу воды и уклон от 0 до 10. |
| `hydraulic_deposition` | Гидравлическая эрозия: доля избыточного осадка, оседающего за проход, от 0 до 1. |
| `hydraulic_strength` | Гидравлическая эрозия: доля недостающей производительности, растворяемая за проход, от 0 до 1. |
| `blend_width` | Смешивание по высоте: ширина переходной зоны в единицах от 0,01 до 65536. |
| `blend_falloff` | Смешивание по высоте: `linear`, `smooth`, `ease_in` или `ease_out`. |
| `blend_mode` | Смешивание по высоте: `average`, `a_over_b`, `b_over_a`, `max` или `min`. |
| `blend_match_edges` | on/off: сместите каждую сторону на расстояние по высоте на линии встречи. |
| `blend_alpha` | on/off: растушуйте альфа-текстуру по всей зоне. |
| `blend_match_powers` | on/off: сначала пересчитывайте дисплейсменты с меньшей степенью до наибольшей степени. |
| `slope_max_angle` | Предел наклона: угол наибольшего угла треугольника в градусах от 1 до 89. |
| `slope_terrace` | on/off: перед ограничением разрежьте высоту на плоские террасы. |
| `slope_terrace_step` | Высота ступени террасы в единицах от 1 до 4096. |
| `slope_terrace_strength` | Насколько высоты привязываются к террасам, от 0 до 1. |
| `slope_ramp_angle` | Рампа: точный наклон в градусах от 0 до 89. |
| `slope_ramp_direction` | Рампа: направление подъема в градусах (0 : +X, 90 : +Y). |
| `slope_ramp_pivot` | Рампа: `average`, `lowest` или `highest`, то, что остаётся на месте. |
| `slope_ramp_strength` | Рампа: доля пути к самолету, от 0 до 1. |
| `slope_ramp_detail` | Рампа: доля текущего рельефа сохраняется, от 0 до 1. |
| `slope_uniform_strength` | Равномерный уклон: доля пути к постоянному уклону, от 0 до 1. |
| `slope_uniform_detail` | Равномерный уклон: сохраняется доля текущего рельефа, от 0 до 1. |
| `slope_path` | Путь постоянного наклона: точки `x y z; x y z` в мировых единицах. |
| `slope_path_width` | Путь: полуширина в единицах от 0,001 до 65536. |
| `slope_path_falloff` | Путь: `linear`, `smooth`, `ease_in` или `ease_out`. |
| `slope_path_strength` | Путь: доля пути к уровню, от 0 до 1. |
| `slope_smooth_passes` | Проходы сглаживания наклона, от 1 до 1000. |
| `slope_smooth_strength` | Сглаживание наклона: доля перемещается к среднему значению соседей за проход, от 0 до 1. |
| `slope_select_angle` | Выбор по наклону: угол в градусах от плоского, от 0 до 90. |
| `slope_select_mode` | Выберите по наклону: `above` или `below`. |
| `slope_select_match` | Выберите по наклону: треугольники `any` или `all`. |
| `slope_select_op` | Выберите по наклону: `replace`, `add` или `remove`. |
| `tag_kind` | `walkable`, `buildable` или `remove`. |

| `mask_select` | on/off: не тонировать выбранные дисплейсменты. |

| `create` | `2`, `3` или `4`: создает дисплейсменты этой силы на выбранных гранях (кнопки «Создать»). |
| `select` | `all`, `adjacent`, `solids` или `none`: кнопки выбора панели. |
| `cast_shadows` | on/off на выбранных дисплейсментах. |
| `lightmap_scale` | От 1 до 1024 по выбранным дисплейсментам. |
| `tag_selection` | Любое значение: применяет текущие `tag_kind` и `tag_value` ко всему выделению. |

## Пример

```text
# Draw a 256 unit block in the Top view, check it, compile, save a screenshot
tool block
tool_option kind block
drag @top:0,0 @top:256,256
key Enter
wait 10
assert_selected 1
action compile_now
idle 3000
screenshot C:\temp\after.png
exit
```
