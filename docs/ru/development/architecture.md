# Архитектура

Hammer Pro разбит на небольшие, сфокусированные ящики под `crates/`, причем зависимости текут в одном направлении (без циклов). На этой странице в одной строке перечислены все ящики и показано, как они зависят друг от друга. Полный документ разработчика (цели, соглашения, системы координат, поток данных) : [ARCHITECTURE.md](../../ARCHITECTURE.md) на английском языке.

<a id="crates"></a>
## Ящики

<a id="file-formats-and-libraries"></a>
### Форматы файлов и библиотеки

| Ящик | Роль |
|---|---|
| `hp-kv` | Быстрый и удобный анализатор и запись текста Valve KeyValues (VMF, VMT, `gameinfo.txt`, Steam `.vdf`). |
| `hp-vmf` | Модель документа VMF, загрузчик и запись: без потерь, быстрая, совместимая с Hammer и Hammer++. |
| `hp-vmt` | Разбор и запись материалов VMT (шейдер, параметры, прокси, резервные варианты). |
| `hp-vtf` | Декодер и кодер формата текстуры Valve. |
| `hp-vpk` | Потокобезопасное чтение архивов VPK. |
| `hp-gma` | Потокобезопасное чтение архивов дополнений Garry's Mod (GMA), включая устаревший LZMA `.bin`. |
| `hp-fgd` | Анализатор и преобразователь файлов определения объектов FGD. |
| `hp-mdl` | Загрузчик студийных моделей (`.mdl` + `.vvd` + `.vtx`), версии MDL с 44 по 49. |
| `hp-bsp` | Усиленное чтение и запись файлов BSP версий с 19 по 21: «комки», пак-файлы, кубические карты, игровые «комки». Защитите свой BSP. |
| `hp-nav` | Читатель навигационных сеток (`.nav`), версии с 1 по 16. |
| `hp-pcf` | Системы частиц из файлов `.pcf` (двоичный DMX) и небольшая предварительная симуляция. |
| `hp-meshio` | Чтение моделей OBJ, glTF/GLB и FBX и компиляция их в файлы игровых моделей. |
| `hp-shader` | Движок редактора шейдеров: граф узлов (`.hpshader` JSON), каталог узлов, оценка CPU, предустановки и запись выходных данных как VTF и VMT. Нет кода UI. |

<a id="geometry-content-and-compiling"></a>
### Геометрия, содержание и составление

| Ящик | Роль |
|---|---|
| `hp-geom` | Геометрия браши: плоскости, полигоны, математика текстур, CSG, примитивы, выбор, дисплейсменты. |
| `hp-fs` | Файловая система игры и индекс ресурсов: обнаружение игры, `gameinfo.txt`, VPKs, дополнения, Мастерская, `mount.cfg`, папки с пользовательскими текстурами. |
| `hp-light` | Помощники по освещению, используемые компилятором, запеченный предварительный просмотр и источники освещения предварительного просмотра редактора (анализ света, файлы `.rad`, иерархия лучей). |
| `hp-bspc` | Компилятор карт: VMF в BSP, написанный с нуля на этапах VBSP от Valve, плюс видимость и освещение. |
| `hp-compile` | Конвейер компиляции: запускает `hammerpro --bspc` и `--rad`, упаковывает пользовательский контент, копирует карту и запускает игру, передает журнал. |
| `hp-decompile` | Восстанавливает редактируемую карту из скомпилированного BSP в духе BSPSource. |

<a id="editor-core-and-application-services"></a>
### Ядро редактора и сервисы приложений

| Ящик | Роль |
|---|---|
| `hp-editor` | Ядро редактирования: документ, выделение, undo/redo, операции редактирования, комплектование. Нет кода UI или GPU. |
| `hp-render` | Модуль рендеринга GPU (wgpu): 3D- и 2D-виды, пакетная обработка, наложения. |
| `hp-app` | Общее ядро приложения: состояние, настройки, действия, i18n, тема, математические представления, интерфейс инструментов и точки расширения пакетов. |
| `hp-assets` | Система ассетов: монтирование игрового контента и FGDs в фоновом режиме, потоковая передача материалов, моделей и спрайтов, синхронизация сцен рендерера. |
| `hp-mcp` | Сервер MCP окна, мост stdio `--mcp` и установщик приложения AI (см. [MCP.md](../MCP.md)). |
| `hp-discord` | Discord Rich Presence по локальному протоколу Discord IPC. |
| `hp-update` | Автоматическое обновление: проверка выпуска GitHub, загрузка (WinHTTP), программа чтения zip-архивов и помощник, заменяющий программу (см. [Обновления](../features/updates.md)). |

<a id="user-interface-and-tools"></a>
### Пользовательский интерфейс и инструменты

| Ящик | Роль |
|---|---|
| `hp-ui-shell` | Строка меню, панель инструментов, палитра инструментов, строка состояния, консоль, всплывающие уведомления, окно настроек, палитра команд, сочетания клавиш и диалоговые окна «О программе», мастер первого запуска. |
| `hp-ui-viewports` | Виды 2x2: макет, разделители, навигация по камере, рендеринг, маршрутизация ввода к инструментам, контекстное меню, перетаскивание. |
| `hp-ui-textures` | Браузер текстур, инструмент применения текстур (Face Edit), поиск и замена текстур, редактор материалов (VMT), импорт изображений, окно редактора шейдеров. |
| `hp-ui-entities` | Свойства объектов (SmartEdit, флаги, I/O, значения ключей), средство выбора классов, браузер модели, поиск объектов, отчет об объектах, свойства карты. |
| `hp-ui-mapping` | Визгруппы, планировщик, окно компиляции с живым журналом, проверка на наличие проблем, преобразование, специальная вставка, переход к идентификатору, информация о карте, файлы точек. |
| `hp-ui-lab` | Расширенные функции: логическое представление, отображение навигационной сетки, открытие скомпилированных карт, предварительный просмотр частиц, сравнение карт. |
| `hp-tools-select` | Инструмент выбора (щелкните и выберите поле, маркеры, перетаскивание клона, 3D-гизмо, смещение) и инструмент камеры. |
| `hp-tools-create` | Инструменты создания: блок (примитивы), объект, многоугольник, кривая, дорога, путь, обрезка, декаль, наложение, кордон, посыпка. |
| `hp-tools-mesh` | Инструмент вершин и инструмент дисплейсмента. |
| `hammerpro` | Приложение (eframe/egui): пакеты, диспетчеризация действий, инструменты MCP, сценарии, командная строка, обработка сбоев. |

<a id="dependency-direction"></a>
## Направление зависимости

Зависимости всегда указывают вниз по этому списку слоев, а не вверх (внутри слоя UI `hp-ui-lab` также используется `hp-ui-viewports`):

```
hammerpro                      the application, depends on everything below
hp-ui-*, hp-tools-*            UI and tools
hp-assets                      asset streaming
hp-app                         shared state, settings, actions, i18n
hp-editor, hp-render           editing core, renderer
hp-bspc, hp-decompile          compiler, decompiler
hp-light, hp-compile           lighting helpers, compile pipeline
hp-fs, hp-geom                 game filesystem, brush geometry
hp-vmf, hp-vmt                 formats built on hp-kv
hp-kv, hp-bsp, hp-vpk, hp-gma, hp-vtf, hp-mdl, hp-fgd, hp-nav, hp-pcf, hp-meshio
hp-discord, hp-mcp, hp-update   standalone (no internal dependency)
```

Некоторые бетонные края:

```
hp-kv <- hp-vmf <- hp-geom <- hp-editor <- hp-app <- hp-ui-*, hp-tools-* <- hammerpro
hp-kv, hp-vpk, hp-gma, hp-vtf, hp-vmt, hp-mdl, hp-bsp <- hp-fs <- hp-light <- hp-bspc
hp-bsp, hp-kv <- hp-compile
hp-vmf, hp-geom, hp-bsp <- hp-decompile <- hp-ui-lab
hp-discord <- hp-ui-shell
```

Библиотеки возвращают ошибки и никогда не паникуют из-за неправильных входных данных; тяжелая работа выполняется в рабочих потоках и сообщается по каналам, поэтому поток UI остается свободным.

<a id="adding-a-feature"></a>
## Добавление функции

Пакеты функций подключаются к общим реестрам `hp-app` (действия, настройки, меню, страницы настроек, сегменты строки состояния, наложения, дополнительные данные) вместо редактирования ядра. См. [Расширение Hammer Pro](extending.md).
