# Продление Hammer Pro

Hammer Pro построен на основе пакетов функций, которые подключаются к общим реестрам вместо редактирования файлов друг друга. Эта страница представляет собой краткую карту этих точек расширения. Полное руководство разработчика с кодом каждого хука : [docs/EXTENDING.md](../../EXTENDING.md) (на английском языке, написано для участников).

<a id="the-rule"></a>
## Правило

Работайте со своими файлами. Если хост-файл принадлежит другому пакету, подключите его через перехватчик. Каждый пакет имеет ключ, используемый в именах файлов: оболочка, выделение (1), браш (2), рабочий процесс (3), экземпляры (4), видимость (5), помощники (6), сетка (7), объекты (8), рендеринг (9), освещение (10), размещение (11), компиляция (12), запуск (13), запуск (14), контент (15), здоровье (16), лаборатория (17) и mcp.

<a id="extension-points"></a>
## Точки расширения

| Точка расширения | Для чего это нужно | Где |
| --- | --- | --- |
| Действия | Каждая команда (меню, панель инструментов, сочетания клавиш, палитра команд, ссылка `F1`, настройки клавиатуры, сценарии, MCP). Одно перечисление, объявленное в одном файле для каждого пакета с номером `action_list!`: идентификатор, меню, группа меню, сочетание клавиш по умолчанию, статус. | `crates/hp-app/src/actions/<package>.rs` |
| Меню | Размещение действия в меню или подменю (`MenuGroup`), отсортированное по разделам и порядку. | `crates/hp-app/src/actions/groups.rs` |
| Отправка | Код, который запускает действие. | `crates/hammerpro/src/dispatch/<package>.rs` |
| Настройки | Одна структура на пакет, хранящаяся как отдельная таблица TOML, каждое поле имеет значение по умолчанию. | `crates/hp-app/src/settings/<package>.rs` |
| Страницы настроек | Страницы окна настроек. | `crates/hp-ui-shell/src/settings_dialog/<package>.rs` |
| Строка состояния | Сегменты строки состояния. | `crates/hp-ui-shell/src/status/` |
| Коляска | Данные карты хранятся за пределами VMF. | `crates/hp-app/src/sidecar.rs` |
| Наложение слоев | Геометрия, нарисованная видами поверх сцены. | `crates/hp-ui-viewports/src/layers/` |
| Продюсеры сцен | Объекты, добавленные в визуализированную сцену. | см. EXTENDING.md |
| Крючки для инструментов и комплектация | Инструменты, реагирующие на ввод, выбор представлений. | см. EXTENDING.md |
| Расширение редактора | Дополнительные блоки VMF (таким образом сохраняются блоки Hammer++ `*_plus`). | `crates/hp-editor` |
| Скомпилируйте и запустите | Шаги конвейера компиляции, аргументы запуска. | `crates/hp-compile`, `crates/hp-ui-mapping/src/compile/` |
| Переводы | Каждый текст UI представляет собой `(key, English, French)` строк таблицы `TR`. | каждый ящик |
| Строки хранения | Каждый кеш, выходная или временная папка Hammer Pro записывается, отображается и очищается с помощью «Настройки» > «Хранилище и MCP». | `crates/hp-app/src/storage/locations.rs` (`TABLE`) |
| Инструменты MCP | Семантические инструменты сервера MCP. Каждое действие и настройка уже доступны через `run_action` и `set_setting`. | `crates/hammerpro/src/dispatch/mcp/tools_<area>.rs` |

<a id="translations"></a>
## Переводы

Каждый видимый пользователю текст проходит через слой i18n с текстом на английском и французском языках. Ключи имеют префикс области (`shell.`, `tex.`, `disp.`...) и должны быть уникальными для всех ящиков. Проверка таблицы отклоняет пустой текст, повторяющиеся ключи и символы длинного тире или тире. Во французском языке перед `:`, `?` и `!` используется пробел. Добавление языка означает добавление варианта `hp_app::i18n::Lang` и столбца в таблицы.

<a id="look-and-colors"></a>
## Внешний вид и цвета

Интерфейс черно-белый: каждый цвет UI происходит из токенов `hp_app::theme`. Цвет зарезервирован для содержимого (виды, миниатюры, цвета объектов). Цвета, которые несут значение в данных (категории узлов шейдера и типы контактов, каналы R, G и B цветовой градации, сетка ландшафта), живут в `crates/hp-app/src/data_colors.rs`, единственном файле, который тест темы позволяет хранить оттенки цветов.

<a id="adding-an-mcp-tool"></a>
## Добавление инструмента MCP

1. Опишите инструмент в `SPECS` файла области `crates/hammerpro/src/dispatch/mcp/tools_<area>.rs`.
2. Реализуйте это в файле `run`, где каждое редактирование выполняется посредством одного шага отмены с именем «MCP: <tool>».
3. Добавьте метку отмены от `shell.undo.mcp_<tool>` до `crates/hp-app/src/actions/mcp.rs`.
4. Восстановите список инструментов `docs/MCP.md` с помощью `HP_UPDATE_MCP_DOCS=1 cargo test -p hammerpro docs_list_every_tool`.

<a id="note"></a>
## Примечание

[docs/EXTENDING.md](../../EXTENDING.md) был написан во время сборки пакетов: в его таблицах некоторые действия до сих пор называются «Запланированные». В версии 1.0.2 реализованы все перечисленные там действия (см. [Действия и сочетания клавиш](../reference/actions-shortcuts.md)).
