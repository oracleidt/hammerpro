# Содействие

Вклады приветствуются: код, переводы, отчеты об ошибках и документация. На этой странице кратко изложены правила; ссылка : [CONTRIBUTING.md](../../../CONTRIBUTING.md) в корне репозитория (на английском языке).

<a id="setup"></a>
## Настройка

- Установите стабильную версию Rust 1.95 или новее с помощью `rustup`.
- Garry's Mod не является обязательным, но многие интеграционные тесты используют его, если он присутствует. Установите `HAMMERPRO_GMOD_DIR`, если он находится в произвольном месте.
- `cargo run` запускает редактор, `cargo run -- path/to/map.vmf` открывает карту. См. [Сборка из исходного кода](building.md).

<a id="before-opening-a-pull-request"></a>
## Прежде чем открыть запрос на включение

```bash
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

CI выполняет одни и те же команды в Windows и Linux.

<a id="code-guidelines"></a>
## Рекомендации по кодированию

| Правило | Почему |
|---|---|
| Сначала прочитайте [ARCHITECTURE.md](../../ARCHITECTURE.md); держите ящики сосредоточенными, а зависимости - в одном направлении. | См. [Архитектура](architecture.md). |
| Библиотеки никогда не паникуют из-за неправильных входных данных: они возвращают ошибки. | Карты и игровые файлы можно получить откуда угодно. |
| Сохраняйте поток UI свободным: тяжелая работа выполняется в рабочих потоках и сообщается обратно по каналам. | Редактор должен работать плавно на огромных картах. |
| Каждая видимая пользователю строка проходит через `hp_app::i18n`, а в таблице `TR` ящика содержится текст на английском и французском языках. Тесты ящика проверяют отсутствие переводов. | Интерфейс переключает язык во время выполнения. |
| Никаких символов длинного тире или тире нигде (код, комментарии, текст UI, документы). CI отвергает их. | Стиль проекта. |
| Возьмите каждый цвет UI из жетонов `hp_app::theme`. Цвет предназначен только для содержимого (виды, миниатюры, цвета объектов). | Интерфейс черно-белый. |
| Пишите «Hammer Pro» во всем, что читают пользователи; имена ящиков, двоичных файлов, папок и файлов остаются `hammerpro`. | Одно название продукта. |
| Добавьте тесты на новое поведение. Тесты, которым нужны файлы игры, пропускаются, если файлы отсутствуют. | На CI игра не установлена. |
| Действия и настройки достигают сервера MCP без нового кода (`run_action`, `set_setting`); операция, заслуживающая собственного инструмента MCP, получает его, и список инструментов MCP.md создается заново. | Приложения AI управляют всем редактором (см. [MCP.md](../MCP.md) и раздел «инструменты MCP» в [EXTENDING.md](../../EXTENDING.md)). |

Новые функции подключаются к реестрам `hp-app` (действия, настройки, меню, страницы настроек, строка состояния, наложения, дополнительные данные): см. [Расширение Hammer Pro](extending.md) и [EXTENDING.md](../../EXTENDING.md).

<a id="translations"></a>
## Переводы

В каждом ящике UI есть таблица `TR` с `(key, English, French)` записями. Чтобы улучшить перевод, отредактируйте текст в этой таблице. Чтобы добавить язык, добавьте вариант к `hp_app::i18n::Lang` и столбец в таблицы.

<a id="reporting-bugs"></a>
## Сообщить об ошибках

Включите версию Hammer Pro, свою версию GPU и, если возможно, версию VMF, которая показывает проблему, а также отчет о сбое и файл журнала. См. [Сообщение об ошибках](../troubleshooting/reporting-bugs.md).
