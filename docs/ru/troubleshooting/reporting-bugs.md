# Сообщить об ошибках

Сообщения об ошибках очень приветствуются. Хороший отчет позволяет быстро воспроизвести проблему: на этой странице указано, что включить и где это найти.

<a id="where-to-report"></a>
## Куда сообщить

**Справка > Сообщить о проблеме** открывает страницу проблемы проекта в вашем браузере. Сначала посмотрите, сообщалось ли уже о проблеме; добавьте свои данные в существующий отчет, если он есть.

<a id="what-to-include"></a>
## Что включить

| Информация | Где найти |
|---|---|
| Hammer Pro версия | **Справка > О Hammer Pro** (версия и сборка). |
| Версия Windows и видеокарта | В файле журнала указаны имя графического адаптера и используемый API («графический адаптер: ...»). |
| Что вы сделали, чего ожидали, что произошло | Короткие пронумерованные шаги. Упомяните инструмент, команду меню или клавишу, которую вы использовали. |
| Карта | `.vmf`, показывающий проблему, если вы можете ею поделиться (или небольшую карту, созданную для ее воспроизведения). При проблемах с компиляцией также журнал компиляции. |
| Отчет о катастрофе после аварии | При следующем запуске в окне **Hammer Pro неожиданно закрытом** отображается файл отчета: **Копировать отчет** помещает его текст в буфер обмена для вставки в сообщение, **Показать файл отчета** открывает его папку (`%APPDATA%\HammerPro\crash\`). |
| Файл журнала | `%LOCALAPPDATA%\HammerPro\logs\hammerpro.log` (текущий запуск) и `hammerpro.old.log` (предыдущий запуск). Ошибки рабочих потоков и видеокарты есть и в панели консоли. |
| Настройки, если это необходимо | `%APPDATA%\HammerPro\settings.toml` (он содержит пути к вашему компьютеру; удалите то, чем не хотите делиться). |

<a id="tips"></a>
## Советы

- **Скопируйте консоль.** На панели консоли (`` ` ``) есть кнопка, которая копирует видимые сообщения: сначала отфильтруйте их по предупреждениям и ошибкам.
- **Воспроизведение со значениями по умолчанию.** Если вы изменили много настроек, повторите попытку, переименовав `settings.toml` (см. [Сбои и журналы](crashes-and-logs.md)). Скажите в отчете, сохраняется ли проблема.
- **Проблемы с графикой.** Скажите, меняет ли что-либо принудительное использование другого API с помощью `WGPU_BACKEND`, и приложите снимок экрана.
- **Проблемы с компиляцией.** Скажите, какую предустановку (Draft, Normal, Final) и целевую игру вы использовали, а также компилируется ли та же карта с помощью инструментов Valve.
- **Медленный редактор.** Включите частоту кадров (**Настройки > Общие > Показать частоту кадров**) и информацию о 3D-просмотре (`O`) в том месте, где она медленная.
- **Переводы.** Неправильный или отсутствующий текст на французском языке тоже является ошибкой: процитируйте текст и укажите, где он появляется.
