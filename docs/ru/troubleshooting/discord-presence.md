# Наличие Discord не отображается

Hammer Pro может показывать то, что вы отображаете в своем профиле Discord (карту, активный инструмент, игру и время, проведенное на карте), например Hammer++. Если ничего не появляется, просмотрите этот контрольный список. Сама функция описана в [Discord Rich Presence] (../features/discord.md).

<a id="checklist"></a>
## Контрольный список

1. **Прочитайте статус.** **Настройки > Discord** отображает строку **Статус:**: *Подключено*, *Соединение с Discord...*, *Discord не работает*, *Discord отказано в соединении*, *Присутствие отключено*, *Недопустимое приложение ID*. Значение каждого из них находится в [Discord Rich Presence](../features/discord.md#status). Помощники AI читают то же самое с помощью инструмента MCP `get_discord_status`.
2. **Показывать активность в Discord включено** (**Настройки > Discord**, включено по умолчанию). При его отключении активность сразу очищается.
3. **Приложение ID.** Оставьте **Discord приложение ID** пустым: Hammer Pro использует собственное приложение Discord. Пользовательский номер ID должен состоять из 17-20 цифр со страницы **Общая информация** вашего приложения; при неправильном статус говорит *Discord отказано в соединении (Неверный клиент ID (4000))*.
4. **На этом компьютере работает настольное приложение Discord.** Discord в веб-браузере не может получить информацию о присутствии: Hammer Pro обращается к локальному клиенту Discord через каналы IPC (от `\\.\pipe\discord-ipc-0` до `discord-ipc-9` в Windows).
5. **В Discord разрешен обмен действиями.** В настройках Discord в разделе **Конфиденциальность действий** включите **Поделиться обнаруженными действиями**.
6. **Подождите немного.** Обновления отправляются не чаще, чем каждые 15 секунд (сразу отображается новая карта). Когда Discord не запущен, Hammer Pro спокойно повторяет попытку, сначала через 5 секунд, затем реже (до каждых 20 секунд): запуск Discord после Hammer Pro работает, это занимает до 20 секунд.

Автоматические прогоны (`--script`, тесты) никогда не общаются с Discord (статус *Выкл. при автоматических прогонах*).

<a id="using-your-own-discord-application"></a>
## Использование собственного приложения Discord

Только для отображения другого имени или других изображений, кроме Hammer Pro:

1. Откройте портал разработчиков Discord и создайте приложение (его имя указано в вашем профиле).
2. В разделе **Rich Presence > Art Assets** загрузите большое изображение с ключом `hammerpro` (без него в действии изображение не отображается).
3. На странице **Общая информация** скопируйте **Приложение ID**.
4. В Hammer Pro, **Инструменты > Параметры...** (`Ctrl+,`), страница **Discord**, вставьте его в **Discord приложение ID**. Очистите поле, чтобы вернуться к приложению Hammer Pro.

<a id="the-discord-settings-page"></a>
## Страница настроек Discord

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Показать активность в Discord** | Включает или выключает присутствие. | Вкл. |
| **Discord приложение ID** | Пусто: собственное приложение Hammer Pro. В противном случае ID вашего собственного приложения. | Пустой |
| **Показать название карты** | Выкл.: «Редактирование карты» вместо названия карты. | Вкл. |
| **Показать активный инструмент** | Выключено: вместо этого отображается целевая игра (и сообщение «Компиляция...» во время компиляции). | Вкл. |
| **Показать прошедшее время** | Время, проведенное на карте. | Вкл. |
| **Ссылка на кнопку «Получить Hammer Pro»** | Дополнительная веб-страница (`https://...`), отображаемая в виде кнопки под действием; пусто: нет кнопки. | Пустой |

Они хранятся в таблице `[discord]` `settings.toml` (`enabled`, `application_id`, `show_map`, `show_tool`, `show_elapsed`, `project_url`).

<a id="faq"></a>
## Частые вопросы

**Активность отображается, но без логотипа.** При использовании приложения Hammer Pro подождите несколько минут: Discord может медленно отправлять изображения. В вашем собственном приложении ключ художественного актива должен быть точно `hammerpro`.

**Другие люди не видят название карты.** Установите флажок **Показать название карты**. Когда он выключен, Discord показывает «Редактирование карты».

**Все работало, но после перезапуска Discord перестало.** Hammer Pro самостоятельно переподключается в течение 20 секунд; статус показывает *Discord не запущен*.
