# Ресурсы карты

На вкладке **Ресурсы карты** перечислены все файлы, которые использует открытая карта (материалы с их текстурами, модели с их файлами и материалами, звуки с их скриптами, файлы частиц), показано, откуда взялся каждый файл и чего не хватает, а также копируются их в чистую папку с помощью **Собрать**. Во втором разделе перечислены файлы папки содержимого (например, дополнения), которые карта не использует.

<a id="opening-it"></a>
## Как открыть

- **Карта > Ресурсы карты** : вкладка на правой панели. Запустите его еще раз, пока отображается вкладка, чтобы скрыть ее.
- Вкладка остается в доке, пока вы ее не скроете (настройка `content.show_map_assets`, по умолчанию отключена).
- Сначала необходимо загрузить игровой контент. Без него на вкладке написано *Контент игры не загружен (сначала настройте игру в настройках).* См. [Настройка игры](../getting-started/game-setup.md).

Список создается в фоновом режиме (*Поиск файлов, которые использует карта...*) на основе того же поиска зависимостей, который используется в окне выпуска: грани браши, ключи сущностей, экземпляры и текстуры редактора материалов. Нажмите **Обновить**, чтобы повторить поиск после значительных изменений.

<a id="the-list"></a>
## Список

В заголовке отображается сводная информация: количество записей, файлов, текстур, файлов моделей и общий размер, а также количество недостающих файлов, выделенное красным.

| Контроль | Описание |
| --- | --- |
| **Только по индивидуальному заказу** | Вид по умолчанию. Файлы, не являющиеся частью базовой игры (аддоны, Мастерская, пользовательские папки, отдельные файлы) и отсутствующие файлы. |
| **Все** | Каждый файл, включая базовую игру. |
| **Отсутствует** | Только недостающие файлы. |
| **Искать путь...** | Фильтрует записи по пути. |
| **Отметить все** / **Отметить ничего** | Устанавливает или снимает галочку с каждой записи в списке для сбора. |
| **Свернуть все** | Складывает каждую развернутую запись. |
| **Обновить** | Снова строит список. |

Записи сгруппированы по категориям **Материалы**, **Модели**, **Звуки**, **Частицы** и **Другое**. Щелкните имя группы, чтобы свернуть ее, щелкните стрелку записи, чтобы просмотреть нужные файлы (модель показывает файлы модели и материалы, материал : его текстуры). Флажок записи означает *Соберите эту запись и все необходимое*.

В каждой строке файла указана метка, путь, размер и начало координат:

| Марк | Значение |
| --- | --- |
| Заполненная точка (зеленая) | Пользовательский контент: он будет собран. |
| Полая точка (серая) | Часть базовой игры: собирается только с помощью **Также копировать ресурсы базовой игры**. |
| Предупреждающий знак | Запись присутствует, но чего-то, что ей нужно, не хватает. |
| Крест (красный) | Отсутствует: этот файл отсутствует в смонтированном контенте. |

Происхождение: **Базовая игра**, **Дополнение**, **Мастерская**, **Пользовательская папка**, **Свободный файл**, **Загрузить**, **Смонтированная игра**, **Дополнительно**, **Сгенерировано**, **Отсутствует**. Наведите курсор на строку, чтобы увидеть полный путь, тип файла, откуда он взят, его размер и зачем он нужен карте (какие грани, ключи объектов или экземпляры). Щелкните правой кнопкой мыши строку **Копировать путь**.

<a id="collect"></a>
## Собрать

Раздел **Сбор** копирует отмеченные записи и все необходимое в выходную папку под `materials/`, `models/`, `sound/`... Файлы, находящиеся внутри VPKs и GMAs, извлекаются. В конце в выходную папку записывается отчет.

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Выход** | Папка для копирования файлов (полный путь). Кнопка папки открывает средство выбора папки. Вспомнили в `content.collect_folder`. | пустой |
| **Также скопируйте ресурсы базовой игры** | Они уже есть у каждого плеера: выключены, копируются только остальные файлы. | выкл. |
| **Заменить существующие файлы** | Выключено: файл, который уже есть в папке с другим содержимым, сохраняется и отображается в отчете. Включено: заменяется после подтверждения (**Заменить файлы?**). | выкл. |
| **Собрать N файлов (размер)** | Запускает копирование. Во время работы отображается индикатор выполнения и **Отмена**. | |

Выходная папка не может быть папкой с смонтированным игровым контентом (вы получите сообщение об ошибке с запросом другой папки). Файлы с тем же содержимым, что и уже существующая копия, считаются *уже существующими* и не перезаписываются.

После сбора на вкладке отображается *Последний сбор: скопировано, заменено, уже есть, сохранено, не удалось, отсутствует* с **Открыть папку** и **Показать отчет**.

Отчет находится в папке вывода под номером `<map>_assets.txt` (`<map>_assets_2.txt` и т. д., если отчет уже существует и параметр **Заменить существующие файлы** отключен). В нем перечислена выходная папка, счетчики, записанные байты, каждый файл с его результатом (скопирован, заменен, уже есть, сохранен, произошел сбой) и недостающие файлы.

<a id="unused-files-of-a-content-folder"></a>
## Неиспользуемые файлы папки содержимого

В сворачиваемом разделе **Неиспользуемые файлы в папке с содержимым** перечислены файлы под `materials`, `models`, `sound` и `particles` папки (например, надстройки, которую вы очищаете), которые не используются на этой карте. Это только отчет: ничего не удалено.

1. Введите папку в поле **Папка содержимого (дополнение...)** или выберите ее с помощью кнопки папки.
2. Нажмите **Найти неиспользуемые файлы** (**Отмена** останавливает поиск; список становится неполным).
3. Результат гласит: *N из M файлов не используются картой (размер)*. Отфильтруйте список с помощью **Найти путь...**, скопируйте его с помощью **Копировать список** или откройте папку с помощью **Открыть папку**.

<a id="mcp"></a>
## MCP

Каждая часть вкладки доступна из приложений AI через сервер MCP: `list_map_assets`, `collect_map_assets`, `get_map_assets_status`, `cancel_collect_map_assets` и `find_unused_assets`. См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="tips"></a>
## Советы

- Оставьте вариант **Только пользовательские**, чтобы увидеть, что вам нужно отправить; переключитесь на **Отсутствует** перед выпуском, чтобы исправить неработающие имена.
- Чтобы подготовить дополнение Workshop, в окне выпуска ([Создать и сохранить как содержимое](build-content-release.md)) файлы за вас упаковываются. Collect предназначен для создания аддона, созданного вручную, резервного копирования или отправки контента товарищу по команде.
- Отчет о неиспользуемых файлах удобен перед публикацией дополнения, созданного на нескольких версиях карты.

<a id="faq"></a>
## Частые вопросы

**Почему файл помечен как «Отсутствует», хотя карта в редакторе выглядит нормально?** Редактор может нарисовать заполнитель (фиолетово-черную шахматную доску), или файл получен из содержимого, которое больше не смонтировано. Проверьте настройки игры и пользовательские папки, затем нажмите **Обновить**.

**Изменяет ли Collect мою карту?** Нет. Он только читает карту и копирует файлы.

**Собираются ли файлы из предметов Мастерской?** Да, это пользовательский контент (происхождение **Мастерская**) и извлекается из их GMA.

**Можно ли удалить неиспользуемые файлы?** Нет. В разделе только они перечислены. Delete их самостоятельно после проверки списка.
