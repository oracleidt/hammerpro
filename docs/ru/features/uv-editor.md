# UV редактор

UV-редактор рисует выбранную грань поверх ее текстуры (в текселах текстура повторяется) и позволяет перемещать, масштабировать и вращать ее с помощью мыши, как UV-редакторы 3D-моделистов. Его режимы Edge и Vertex выравнивают край по оси, придают ему угол, размещают плитки вдоль него или перетаскивают вершины по текстуре. Он также перемещает другие слои материала (карту рельефа, детали, вторую текстуру смешивания, маску envmap, маску смешивания).

UV-редактор загружает подробную текстуру в фоновом потоке (до 4096 пикселей по каждой стороне), вместо увеличения миниатюры браузера. При увеличении границы текселей остаются чёткими; основная текстура и остальные слои имеют отдельные предпросмотры.

<a id="opening-it"></a>
## Как открыть

Редактор UV : это раздел **Редактор UV** панели **Редактирование грани** инструмента [текстуры](texture-tool.md) (`Shift+A`), открытый по умолчанию. Выберите одну или несколько граней в 3D-виде, чтобы заполнить их.

- **Открыть как отдельное окно** помещает его в отдельное окно, например окно «Компиляция и запуск»: переместите его за пределы Hammer Pro или на другой экран, где он будет использовать все пространство окна. Затем на панели появляется надпись: **Редактор UV находится в отдельном окне.**
- **Вернуться на панель** (на панели или кнопке в заголовке окна) возвращает его обратно.

<a id="how-source-maps-textures"></a>
## Как Source отображает текстуры

Грань браши Source не имеет UV на каждую вершину: ее текстура представляет собой одну плоскую проекцию (оси U и V, масштабы, сдвиги), одинаковую для дисплейсмента и его базовой грани. Таким образом, каждый жест редактора : это изменение этой проекции: движение, поворот, масштабирование или наклон, но никогда : искривление текстуры. Наведите указатель мыши на надпись **Одна проекция на грань** в режимах «Край» и «Вершина», чтобы получить напоминание.

<a id="toolbar"></a>
## Панель инструментов

| Контроль | Описание | По умолчанию |
|---|---|---|
| **Все грани (n)** | Перемещайте, масштабируйте и вращайте каждое выбранное грань вместе (каждое вокруг своего контура). Выкл.: отображается только грань. Показан с несколькими гранями. | на |
| `◀` **Грань i из n** `▶` | Показывает предыдущее или следующее выбранное грань. | |
| **Рамка** | Соответствует виду на грани. | |
| **Грань** / **Ребро** / **Вершина** | Режим выбора (см. ниже). | **Грань** |
| **Слой:** чипсы | **Базовая текстура** и другие слои материала: **Базовая текстура 2**, **Карта рельефа**, **Карта рельефа 2**, **Детализация**, **Маска Envmap**, **Маска смешивания**. | **Базовая текстура** |

Навигация по холсту: перетащите фон (или перетащите вправо, или перетащите среднюю часть) для панорамирования, колесо масштабирует. При наведении курсора мыши отображается то, что можно получить при нажатии (выделение, курсор и подсказка над холстом). Другие выбранные грани с той же текстурой также рисуются, каждая в копии своего контура, ближайшей к редактируемой грани; щелкните один, чтобы отредактировать его. Каждое перетаскивание представляет собой один шаг отмены.

<a id="face-mode"></a>
## Режим грани

| Жест | Результат |
|---|---|
| Перетащите грань | Перемещает свой контур по текстуре (текстура остается). |
| Перетащите угол или край квадрата | Масштабирует его. `Shift`: обе оси одинаковы. |
| Перетащите круглый маркер | Поворачивает его на 15 градусов. `Alt`: бесплатно. |
| Нажмите на другое выбранное грань | Делает это отредактированное грань. |

Кнопки под холстом: **Перевернуть U**, **Перевернуть V**, `⟲ 90`, `⟳ 90` (четверть оборота) и **Центр** (помещает середину грани в середину текстуры). При выборе **Все грани** они применяются к каждому выбранному грани. Линия показывает масштаб, смещение и поворот грани.

<a id="edge-mode"></a>
## Краевой режим

| Жест | Результат |
|---|---|
| Щелкните край | Выбирает его. `Shift`: добавить, `Ctrl`: переключить. Перетаскивание грани или фона рисует рамку выбора. |
| Перетащите выбранный край | Он следует за мышью, дальние вершины остаются. |
| Перетащите круглую ручку | Поворачивает текстуру примерно посередине основного края (последнего выбранного) на 15 градусов (`Alt`: свободно). |
| Дважды щелкните край | Выравнивает его по ближайшей оси. |
| `X` / `Y` (наведите указатель мыши на холст) или маленькие кнопки **X** и **Y** рядом с краем. | Поворачивает текстуру так, чтобы край лежал на этой оси (чем меньше поворот, тем масштаб сохраняется). |
| Стрелки | Сдвиньте выделение на 1 тексель (`Shift`: 8 текселей). |
| `Escape` | Очищает выбор. |

При выборе края на панели доступны **Выравнивание по оси X**, **Выравнивание по оси Y**, поле **Угол** (направление основного края в градусах от оси X, по часовой стрелке с V вниз, от -180 до 180; при изменении этого значения текстура поворачивается примерно посередине края), кнопки `⟲ 15`, `⟳ 15`, `⟲ 90`, `⟳ 90` и **Подогнать по краю** с количеством плиток (от 0,25 до 64, по умолчанию 1): край выравнивается по ближайшей оси и масштабируется текстура так, чтобы ее охватывало множество плиток, угол плитки в ее начале. При выборе варианта **Все грани** другие грани используют край, наиболее параллельный основной.

<a id="vertex-mode"></a>
## Вершинный режим

| Жест | Результат |
|---|---|
| Щелкните вершину | Выбирает его. `Shift`: добавить, `Ctrl`: переключить, поле выбирает несколько. |
| Перетащите выделение | Выбранные вершины следуют за курсором мыши над текстурой (привязка к линиям плитки, `Alt`: бесплатно); вершины в рамке остаются, остальные перемещаются как можно меньше. |
| Дважды щелкните вершину | Ставит на него угол плитки. |
| Стрелки | Сдвинуть на 1 тексел (`Shift`: 8 текселей). |
| `Escape` | Очищает выбор. `Delete` ничего не делает (грань браши сохраняет свои вершины). |

**Угол плитки на вершине** смещает текстуру так, что угол плитки лежит на последней выбранной вершине (при выборе **Все грани** : на гранях, разделяющих его). На панели отображается **Выбрано N вершин** (или **Выбрано N ребер**) и **Очистить**.

Поскольку все грань имеет одну проекцию, три угла прямоугольника не могут оставаться неподвижными, пока движется четвертый: вы получаете проекцию, ближайшую к вашему жесту.

<a id="other-layers-of-the-material"></a>
## Другие слои материала

Выберите слой в разделе **Слой:**, чтобы редактировать его на том же холсте. На холсте показана текстура, нанесенная на грань посредством сопоставления грани и преобразования слоя, с **Базовой текстурой под ней** (включенной по умолчанию) и ползунком непрозрачности для базовой текстуры. Те же жесты затем меняют преобразование слоя (`$bumptransform`, `$detailtexturetransform`, `$envmapmasktransform`...) вместо грани.

| Контроль | Описание |
|---|---|
| **Масштаб**, **Shift**, **Вращение**, **Центр** (U и V) | Значения слоя трансформируются. |
| **Детальный масштаб** | `$detailscale`, для слоя **Детали**: детализация повторяется много раз для каждой базовой текстуры. |
| **Перевернуть U**, **Перевернуть V**, `⟲ 90`, `⟳ 90`, **Центр**, **Подогнать к грани**, **Сбросить** | Быстрые операции над слоем: зеркало, четверть поворота, середина грани на середине тайла, один тайл поверх грани или вообще отсутствие трансформации. |
| **Отменить**, **Повторить** | Изменения слоя имеют собственную отмену, пока они не будут применены. |
| **Вернуть** | Вернемся к значениям файла материала. |
| **Применить к этим граням (n)** | Записывает вариант материала (`patch`) в вашу первую пользовательскую папку и передает его только этим граням (один шаг отмены). Он упаковывается в карту при компиляции. |
| **Применить к материалу** | Изменяет VMT материала: меняется каждое использующее его грань (сохраняется резервная копия файла). |

**Пока не применено** напоминает, что нужно внести изменения. Строка над значениями сообщает, что шейдер делает со слоем: читает ли игра это преобразование, игнорирует его или вообще не рисует слой (**Не рисуется игрой с этим материалом**). 3D-виды не рисуют эти слои (**Базовая текстура 2** рисуется с использованием базовой текстуры, как в игре): проверьте их здесь или в игре.

<a id="layers-the-shader-does-not-move"></a>
### Слои, которые шейдер не перемещает

Некоторые шейдеры рисуют слой с базовым отображением текстуры и игнорируют его преобразование (например, карту рельефа и детали LightmappedGeneric или `$basetexture2` WorldVertexTransition). Hammer Pro все равно перемещает их путем запекания: применение записывает копию текстуры с перемещенными пикселями (нормали превращаются в карту рельефа) в вашу первую пользовательскую папку, и материал использует ее. Затем жесты привязываются к тому, что может содержать текстура: четверть поворота, переворот, полное количество повторений и любой сдвиг. Карта рельефа с самозатенением (`$ssbump`) может сдвигаться, повторяться и зеркально отражаться только вдоль V.

Для применения к граням или материалу требуется пользовательская папка текстуры (**Добавьте пользовательскую папку (вкладка «Текстуры») для хранения вариантов материала.**). Материал внутри архива нельзя изменить на месте: скопируйте его в пользовательскую папку с помощью [редактора материалов] (material-editor.md) или примените к граням.

<a id="moved-layers-stay-in-place"></a>
### Перемещенные слои остаются на месте

На слое **Базовая текстура** параметр **Перемещенные слои остаются на месте** (включен по умолчанию) сохраняет перемещенные сюда слои на том месте, где они находятся на грани при перемещении базовой текстуры: они перемещаются в противоположном направлении на том же этапе отмены. Слои, которые вы никогда не перемещали, следуют базовой текстуре, как карта рельефа, нарисованная для нее.

<a id="tips"></a>
## Советы

- Используйте режим **Край** и `X` или `Y`, чтобы выпрямить текстуру на наклонной грани одним ключом.
- **Укладка по краю** с двумя плитками : это самый быстрый способ уложить ровно две доски вдоль балки.
- Отключите редактор на второй экран и сохраните 3D-изображение большим.

<a id="faq"></a>
## Частые вопросы

**Почему перемещение одной вершины приводит к перемещению остальных?** Грань Source имеет одну проекцию для всей грани; редактор находит проекцию, наиболее близкую к вашему жесту.

**Почему я не могу повернуть карту рельефа на 30 градусов?** Шейдер игнорирует это преобразование, поэтому Hammer Pro запекает движение в текстуру, которая содержит только четверти поворота, перевороты, целые повторы и сдвиги.

**Где написаны варианты?** В вашей первой папке с пользовательскими текстурами; они упаковываются в карту во время компиляции.

**Могут ли сценарии или AI управлять редактором UV?** Да: параметры инструмента текстуры `uv_place`, `uv_all_faces`, `uv_mode`, `uv_layer`, `uv_keep_layers`, `uv_fit_tiles`, `uv_vertices` и `uv_edges` (MCP `set_tool_options`), а также инструменты MCP ниже.
