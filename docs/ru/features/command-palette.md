<a id="command-palette"></a>
# Палитра команд

Палитра команд запускает любую команду Hammer Pro путем ввода нескольких букв ее имени: каждое действие меню, каждый инструмент, команды, у которых нет меню, ваши последние карты и языки интерфейса.

<a id="opening-it"></a>
## Как открыть

**Инструменты > Палитра команд...** или `Ctrl+P`. Палитра открывается поверх окна с фокусом на поле поиска (*Введите команду, инструмент или карту...*).

<a id="using-it"></a>
## Как пользоваться

| Клавиша | Описание |
| --- | --- |
| Тип | Фильтрует список с помощью нечеткого поиска. |
| `Up` / `Down` | Перемещает выделение. |
| `Page Up` / `Page Down` | Перемещает выделение на страницу. |
| `Enter` | Запускает выделенную запись. |
| `Esc` | Закрывает палитру. |

Щелчок по записи также запускает ее. Нижний колонтитул напоминает вам о клавишах (*навигация, запуск, закрытие*). Если ничего не совпадает, на палитре отображается сообщение **Ничего не найдено**. В списке отображается не более 200 результатов.

В каждой строке отображается значок, имя, место его расположения (меню, **Инструмент** для инструментов, **Последние карты** для карты, **Вид** для языка) и его сочетание клавиш, если он есть. Команды, которые не могут быть запущены прямо сейчас (например, ничего не выбрано), выделены серым цветом и ничего не выполняют.

<a id="what-you-can-find"></a>
## Что вы можете найти

| Вход | Найден пользователем |
| --- | --- |
| Каждое действие Hammer Pro | Его имя на языке интерфейса, его английское имя или его идентификатор с пробелами (`toggle grid`). Сюда входят команды, которых нет в меню, например **Гизмо в локальном пространстве** или **Создать браш-подсказку**. |
| Каждый инструмент | Его название (например, **Инструмент обрезки**). |
| **Открыть: название карты** | Одна запись для каждой последней карты: имя файла, полный путь или `open`. |
| **Язык: английский** / **Язык: французский** | `language`, название языка, или `lang en`/`lang fr`. |

При пустом поиске в палитре сначала отображаются шесть команд, которые вы запускали в последний раз (во время этого сеанса), а затем все остальное.

<a id="tips"></a>
## Советы

- Палитра : это самый быстрый способ доступа к команде без сочетания клавиш: введите 3 или 4 буквы и нажмите `Enter`.
- Английские имена всегда работают, даже если интерфейс на французском языке, поэтому учебник, написанный на английском языке, все равно поможет.
- Чтобы назначить команде сочетание клавиш, см. [Сочетания клавиш](keyboard-shortcuts.md).

<a id="faq"></a>
## Частые вопросы

**Команда в палитре выделена серым цветом.** Она не может быть запущена в текущем состоянии, как и ее пункт меню. Выберите что-нибудь или сначала откройте карту.

**Сохраняются ли последние команды после перезапуска?** Нет, список последних команд сохраняется на протяжении всего сеанса.

**Можно ли выполнять поиск по сочетанию клавиш?** Не в палитре; ссылка на сочетание клавиш (`F1`) выполняет поиск по сочетанию клавиш.
