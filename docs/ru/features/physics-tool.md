# Симулятор физики

Выберите браши, пропы или ragdoll, затем откройте **Инструменты > Симулятор физики** либо нажмите значок весов на панели инструментов. Управление появится на правой панели.

| Команда | Действие |
| --- | --- |
| Запустить / Пробел | Запустить или продолжить симуляцию. |
| Пауза / Пробел | Приостановить симуляцию. |
| Один шаг | Выполнить один шаг физики во время паузы. |
| Сохранить положения | Применить положения и повороты к карте одним шагом отмены. |
| Сбросить / Escape | Отменить симуляцию и восстановить исходные положения. |
| ЛКМ в 3D | Захватить объект в указанной точке; удерживать для перемещения, отпустить для освобождения. |
| ПКМ в 3D | Приложить импульс выстрела в точке попадания. |
| Средняя кнопка в 3D | Создать взрыв в указанной точке. |

Браши, displacement и невыделенные пропы служат поверхностями столкновений. Модели используют геометрию столкновений `.phy`. Для ragdoll используются отдельные физические тела и ограничения суставов. Объёмы воды создают плавучесть и сопротивление движению.

Во время симуляции карта не изменяется. Переход к другому инструменту сохраняет положения; **Сбросить** или **Escape** отменяет их. **Ctrl+Z** во время симуляции отменяет предпросмотр, а после сохранения отменяет всё размещение. Изменение карты или переход к другой карте отменяет устаревший предпросмотр.

## Настройки

| Настройка | По умолчанию |
| --- | --- |
| Гравитация | 600 единиц Source/с² |
| Плотность воздуха | 2 кг/м³ |
| Скорость симуляции | 1 |
| Скорость выстрела | 300 единиц/с |
| Скорость взрыва | 500 единиц/с |
| Радиус взрыва | 256 единиц |

Настройки сохраняются между сеансами. Физические положения не привязываются к сетке редактора. Позы ragdoll сохраняются в VMF через ключ Source `angleOverride`.

Модели без подходящего файла столкновений пропускаются с уведомлением. Displacement остаются поверхностями столкновений и не превращаются в подвижные тела.

Для быстрого размещения без интерактивной симуляции остаётся доступно [физическое размещение](transform-align.md).

## MCP и скрипты

`set_tool_options` с инструментом `physics` управляет симулятором без мыши (также из файлов `--script`: `tool physics`, затем `tool_option simulate 3`):

| Параметр | Действие |
| --- | --- |
| `simulate` | Сразу просчитать столько секунд физики (от 0,01 до 120, умноженные на масштаб времени) для выбранных брашей, пропов и ragdoll, затем поставить на паузу. Первый вызов строит симуляцию из выделения, следующие продолжают ее. 0 ничего не делает (это считываемое значение). Карта не меняется. |
| `simulated` | Только чтение: уже просчитанные секунды. |
| `paused` | `off` дает симуляции идти в редакторе (инструмент должен быть активен), `on` замораживает ее. |
| `keep` | `on` применяет положения, повороты и позы ragdoll к карте одним шагом отмены, как **Сохранить положения**. |
| `reset` | `on` отменяет симуляцию, как **Сброс**. |
| `bodies` | Только чтение: число симулируемых объектов. |

Гравитация, плотность воздуха, масштаб времени и значения выстрела и взрыва : это настройки `physics.gravity`, `physics.air_density`, `physics.time_scale`, `physics.shoot_speed`, `physics.explosion_speed` и `physics.explosion_radius` (`set_setting`). Пример: выделите несколько пропов, затем `set_tool_options` `{"tool": "physics", "options": {"simulate": 3}}` и `{"tool": "physics", "options": {"keep": true}}` уронит их на пол одним шагом отмены.
