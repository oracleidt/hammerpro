# Визгруппы

Визгруппы : это именованные наборы объектов, которые вы показываете и скрываете вместе: крыша, детали, триггеры области. Hammer Pro имеет собственные визгруппы (сохраненные в VMF, совместимые с Hammer и Hammer++) и автоматические визгруппы, построенные на основе объектов (геометрия мира, триггеры, источники света, браши инструментов...).

<a id="opening-it"></a>
## Как открыть

- Вкладка **Визгруппы** на правой панели, отображаемая или скрытая с помощью **Вид > Панели > Визгруппы** (отображается по умолчанию, `ui.show_visgroups`).
- **Просмотр > Переместить в визгруппу...** открывает окно Hammer «Переместить в визгруппу» для выбора.
- **Просмотр > Создать визгруппу скрытых объектов** превращает объекты, скрытые с помощью параметра **Скрыть выбранные**, в визгруппу.
- На вкладке **Визгруппы** панели объектов перечислены визгруппы выбранного объекта (см. [Свойства объекта](entity-properties.md)).

Вкладка состоит из трех разделов: ваши визгруппы, **Кордоны** (см. [Кордоны](cordons.md)) и **Автовизгруппы**.

<a id="your-visgroups"></a>
## Ваши визгруппы

<a id="toolbar-of-the-tab"></a>
### Панель инструментов вкладки

| Кнопка | Описание |
| --- | --- |
| **+** | **Новая визгруппа из выбранного** (или **Новая пустая визгруппа**, если ничего не выбрано). Новая визгруппа получает уникальное имя и запускается в режиме переименования. |
| Глаз | **Показать все визгруппы**. |
| Стрелка вниз | **Развернуть все**. |
| Стрелка вверх | **Свернуть все**. |
| Папка | **Переместить в визгруппу...** (нужно выбрать). |
| Граф | Количество визгрупп, включая вложенные. |

<a id="a-row"></a>
### Ряд

| Элемент | Описание |
| --- | --- |
| Стрелка | Разворачивает или сворачивает дочерние элементы. |
| Флажок | Показывает или скрывает визгруппу и ее дочерние элементы. Смешанно, когда прячут какого-нибудь ребенка; щелчок по смешанной или скрытой визгруппе показывает ее полностью. |
| Образец цвета | Нажмите, чтобы изменить **Цвет Visgroup**. Последовательные изменения средства выбора объединяются в один шаг отмены. |
| Имя | Дважды щелкните, чтобы переименовать (`Enter` фиксирует, `Escape` отменяет). |
| Граф | Объекты непосредственно в визгруппе. В подсказке также указана сумма со своими дочерними элементами. |
| Нажмите | Выделяет строку. |
| Перетащите на другую визгруппу | Делает его дочерним элементом этой визгруппы. Опуститесь ниже строк («Переместитесь сюда, чтобы перейти на верхний уровень»), чтобы переместить его на верхний уровень. Визгруппу нельзя переместить в ее собственных дочерних элементов. |

<a id="right-click-menu-of-a-row"></a>
### Контекстное меню строки

| Вход | Описание |
| --- | --- |
| **Выбрать участников** | Выбирает видимые объекты визгруппы и ее дочерних элементов. Скрытые члены не выбираются, как в Hammer. |
| **Добавить выделение** | Добавляет выбранные объекты в визгруппу. |
| **Снять выделение** | Удаляет из него выбранные объекты. |
| **Переместите выделение сюда** | Помещает выделение в эту визгруппу и удаляет его из других визгрупп. |
| **Вверх** / **Вниз** | Изменяет порядок визгруппы среди ее родственных элементов. |
| **Новая дочерняя визгруппа** | Создает пустую визгруппу под этой. |
| **Переименовать** | Переименовывает его. |
| **Delete визгруппа** | Удаляет его. Его дочерние элементы перемещаются к родительскому, а его объекты остаются на карте: они только покидают визгруппу. |

Каждое изменение (создание, переименование, цвет, перемещение, отображение или скрытие, членство) представляет собой один шаг отмены.

<a id="move-to-visgroup"></a>
## Перейти в визгруппу

**Просмотр > Переместить в визгруппу...** (или кнопка папки на вкладке) открывает окно: «Переместить N выбранных объектов в:» с деревом ваших визгрупп и **Новая визгруппа...** (с полем **Имя:**). Опции:

| Параметр | Описание |
| --- | --- |
| **Удалить из других визгрупп** | Объекты покидают каждую вторую визгруппу. |
| **Скрыть визгруппу** | После этого скрывает визгруппу (покажите ее снова с помощью флажка). После этого объекты отменяются. |

**Переместить** применяет его как один шаг отмены. Значения по умолчанию для обеих опций взяты из настроек ниже.

<a id="visgroup-of-hidden-objects"></a>
## Визгруппа скрытых объектов

**Просмотр > Создать визгруппу скрытых объектов** («Преобразовать объекты QuickHide в визгруппу» в Hammer++) перемещает каждый объект, скрытый с помощью **Скрыть выбранное** (`H`), в новую визгруппу с именем `_FromQuickHide(N)`, очищает их скрытый флаг и вместо этого скрывает визгруппу. Объекты остаются скрытыми, но теперь вы можете снова показать их по имени. Один шаг отмены. Кнопка **В визгруппу** строки **Скрытые объекты** (автовизгруппы) выполняет то же самое.

<a id="auto-visgroups"></a>
## Авто визгруппы

Автоматические визгруппы вычисляются по карте, ничего не сохраняется: в каждой строке есть флажок и счетчик. Группы с участниками могут быть расширены. Дети, не имеющие членов, не указаны.

| Группа | Дети |
| --- | --- |
| **Геометрия мира** (тела, не принадлежащие ни одному объекту) | **Небо**, **Дисплейсменты**, **Вода**, **Браши без прорисовки граней** |
| **Детали мира** (func_detail и проп) | **func_detail**, **Проп** |
| **Объекты** | **Точечные объекты**, **Браши**, **Триггеры**, **Освещение**, **NPCs**, **Спрайты**, **Кубические карты**, **Наложения и надписи**, **Экземпляры** |
| **Браши-инструменты** (каждая грань использует текстуру инструмента) | **Клипы**, **Подсказки и пропуск**, **Ареапорталы**, **Окклюдеры**, **Невидимые**, **Лестницы**, **Другие текстуры инструментов** |
| **Скрытые объекты** | Объекты скрыты с помощью кнопок **Скрыть выбранное**, **Показать все** и **В визуальную группу**. |

Второй список, **Из определений объектов (FGD)**, показывает группы `@AutoVisGroup` загруженных файлов FGD с указанием количества их объектов («Определения объектов не загружены: группы FGD недоступны», когда FGD не загружен). Кнопка с изображением глаза в заголовке раздела (**Показать все объекты, скрытые автоматической визуальной группой**) снова показывает их все. Подсчеты обновляются через мгновение после изменения карты.

<a id="visgroup-colors"></a>
## Цвета Визгруппы

Каждая новая визгруппа приобретает приятный цвет. Если **Инструменты > Параметры... > Визуализация > Цвета визгруппы** включено (`render.use_visgroup_colors`, по умолчанию отключено), браши рисуются в 2D-видах в цвете их визгруппы. Цвет отображения, выбранный для объекта, идет первым (см. [Цвета отображения](display-colors.md)).

<a id="options"></a>
## Параметры

**Инструменты > Параметры... > Кордоны и визгруппы**, раздел **Переместить в визгруппу** (`[visibility]` в `settings.toml`):

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Удалить объекты из других визуальных групп** (`move_remove_others`) | По умолчанию **Удалить из других визгрупп**. | Вкл. |
| **После этого скрыть визгруппу** (`move_hide`) | По умолчанию **Скрыть визуальную группу**. | Выкл. |

<a id="tips"></a>
## Советы

- Объекты, скрытые визгруппой, не учитываются при компиляции, если не установлен флажок **Компилировать скрытые объекты**, как в Hammer (см. [Окно компиляции и запуска](../compiler/compile-window.md)).
- Скрытые объекты выбрать нельзя: сначала покажите визгруппу.
- MCP инструменты: `list_visgroups`, `create_visgroup`, `edit_visgroup`, `delete_visgroup`, `set_visgroup_members`, `move_to_visgroup`, `set_visgroup_visible`, `hidden_to_visgroup`, `select_group` (см. [ссылку на инструмент MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Я нажал «Выбрать участников», но ничего не было выбрано.** Все участники скрыты. Сначала покажите визгруппу с ее флажком.

**Удаляет ли удаление визгруппы ее объекты?** Нет. Объекты только покидают ее; его дочерние визгруппы перемещаются на один уровень вверх.

**Сохраняются ли автоматические визуальные группы на карте?** Группы каждый раз вычисляются на основе карты. То, что они скрывают, хранится в каждом объекте в ключе Hammer `visgroupautoshown`, поэтому скрытые автоматические визуальные группы остаются скрытыми после сохранения. Отображение или скрытие автоматической визгруппы является шагом отмены.

**Прочитает ли Hammer мои визгруппы?** Да, это собственные блоки `visgroups` и ключи `visgroupid` Hammer.
