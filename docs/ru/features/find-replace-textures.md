# Найти и заменить текстуры

Окно **Найти и заменить текстуры** заменяет материал на другой на гранях всей карты или выделенного фрагмента, по точному имени или с помощью подстановочных знаков, с подсчетом граней, которые он изменит. Он также может сохранять размер текстуры в мире, когда новая текстура имеет другое разрешение.

<a id="opening-it"></a>
## Как открыть

| Как | Результат |
|---|---|
| **Инструменты > Текстуры > Найти и заменить текстуры...** (`Ctrl+Shift+R`) | Открывает окно. Если поле **Find** пусто, оно заполняется текущим материалом. |
| **Замените...** в заголовке [браузер текстур](texture-browser.md). | Открывает его с текущим материалом в **Найти**. |
| Щелкните правой кнопкой мыши миниатюру > **Заменить этим...** | Открывает его с текущим материалом в **Найти** и выбранным материалом в **Заменить на**. |

При использовании предустановок раскладки клавиш Hammer и Hammer++ `Ctrl+Shift+R` означает **Найти и заменить в объектах...**, и в этом окне нет сочетания клавиш (см. [Сочетания клавиш](keyboard-shortcuts.md)).

<a id="the-window"></a>
## Окно

| Контроль | Описание | По умолчанию |
|---|---|---|
| **Найти** | Название материала или узор. Имена сравниваются без регистра; косая черта, префикс `materials/` и расширение `.vmt` очищаются. | текущий материал |
| Кнопка изображения рядом с надписью **Найти** | Щелчок: открывает или закрывает окно выбора материала (см. ниже). Щелчок правой кнопкой мыши: помещает текущий материал в поле. | |
| Кнопка курсора (**Использовать выбранный материал**) | Помещает первый выбранный материал в **Найти**. Отключено без выбора. | |
| **Заменить на** | Запасной материал. | пустой |
| Кнопка изображения рядом с надписью **Заменить на** | Тот же сборщик, для замены. | |
| **В**: **Вся карта** / **Выбор** | Каждая грань карты или грани выбранных объектов плюс выбранные грани. | **Вся карта** |
| **Совпадение**: **Точное имя** / **Подстановочные знаки** | Точно: полное имя. Подстановочные знаки: `*` соответствует любому тексту, `?` одному символу. | **Точное имя** |
| **Сохраняйте размер текстур в мире** | Регулирует масштаб текстуры каждой грани, когда новая текстура имеет другое разрешение, поэтому текстура сохраняет свой размер на стенах. | выкл. |
| **Заменить** | Запускает замену (также `Enter` в поле). Отключено до тех пор, пока грань не совпадет и не будет заполнено поле **Заменить на**. | |
| **Закрыть** | Закрывает окно (также `Escape`). | |

`Tab` меняется от **Найти** к **Заменить на**.

Под опциями в окне отображается **N соответствующих граней (M материалов))**, выделенное зеленым цветом, если что-то совпадает. При наличии нескольких совпадающих материалов или в режиме подстановочных знаков в списке отображается каждый материал с указанием количества граней, а при заполнении поля **Заменить на** указывается материал, которым он станет. При вводе `*` или `?` в точном режиме отображается **Имя содержит * или ?: выберите режим подстановочных знаков** и блокируется замена.

Вся замена (и изменение масштаба) представляет собой один шаг отмены. После этого в окне появится сообщение **Заменено N граней**. Грани, масштаб которых невозможно изменить из-за неизвестного размера текстуры, перечислены в консоли.

<a id="wildcards"></a>
## Подстановочные знаки

В режиме подстановочных знаков `*` в **Заменить на** повторно использует текст, которому соответствует `*` из **Найти**:

| Найти | Заменить на | Результат |
|---|---|---|
| `dev/*` | `tools/*` | `dev/dev_measurewall01a` становится `tools/dev_measurewall01a` |
| `concrete/concretefloor00?a` | `concrete/concretefloor001a` | каждый пронумерованный вариант становится одним и тем же этажом |
| `*` | `dev/dev_measuregeneric01b` | каждая грань прицела покрыта одним и тем же материалом |

<a id="the-material-picker"></a>
## Выбор материала

Кнопки изображения открывают компактное средство выбора под полем:

- Строка **Текущий материал** вверху: щелкните ее, чтобы использовать материал, выбранный в браузере текстур.
- Поле поиска с правилами браузера текстур (слова, `-word`, `src:`, `kw:`, `is:`, `shader:`, см. [Браузер текстур](texture-browser.md)).
- Фишки разделов **Используется на карте (n)**, **Последние (n)**, **Избранное (n)**, **Все (n)**. **Найти** открывается в разделе **Используется на карте**, **Заменить на** в разделе **Последние** (в разделе **Все**, если у вас нет недавних материалов); после этого каждый сборщик сохраняет раздел, который вы выбрали последним. Если в разделе нет совпадений, параметр **Искать по всем материалам** переключается на **Все**.
- Сетка миниатюр, по пять в строке: щелкните одну, чтобы заполнить поле.

Клавиатура: поле поиска находится в фокусе; `Down` входит в сетку, стрелки перемещаются по ней, `Enter` выбирает (первый результат, когда ничего не выделено), `Escape` закрывает только сборщик (второй `Escape` закрывает окно). Щелчок за пределами средства выбора или повторный щелчок по его кнопке закрывает его.

<a id="tips"></a>
## Советы

- Чтобы ретекстурировать всю область, выделите ее, выберите **Выделение** и замените `*` своим материалом.
- При замене текстуры 512 на текстуру 1024 установите флажок **Сохранить размер текстуры в мире**, чтобы кубики сохранили свой размер.
- Сначала нажмите **Отметить** в браузере текстур, чтобы увидеть, где используется материал.

<a id="faq"></a>
## Частые вопросы

**Счетчик остается равным 0.** Проверьте **Вход** (при использовании **Выбор** ничего не выбрано, значит, ничего не совпадает) и режим сопоставления: в точном режиме должно совпадать все имя.

**Могу ли я отменить замену?** Да, `Ctrl+Z` отменяет всю замену за один шаг.

**Изменяет ли это материалы объектов (наложения, декали, пропы)?** Нет, только грани брашов (включая дисплейсменты). Для текстов в ключах сущностей используйте **Найти и заменить в сущностях...** (см. [Свойства сущности](entity-properties.md)).
