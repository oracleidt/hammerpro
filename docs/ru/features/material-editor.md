# Редактор материалов

Окно **Редактор материалов** редактирует файлы VMT, не выходя из Hammer Pro. Он имеет два режима: **Один материал**, полноценный редактор, такой как VMT Editor (шейдер, параметры по страницам с реальными виджетами, предварительный просмотр и текст VMT рядом), и **Несколько материалов**, пакетный редактор, который устанавливает или удаляет одни и те же параметры в целом списке материалов одновременно. При редактировании сохраняются комментарии и форматирование файлов, и каждый файл на диске получает резервную копию `.vmt.bak` перед первым изменением.

<a id="opening-it"></a>
## Как открыть

- **Редактировать материал** в заголовке [браузера текстур](texture-browser.md): открывает редактор текущего материала или множественного выбора браузера (`Ctrl+click`, `Shift+click`).
- Щелкните правой кнопкой мыши миниатюру > **Редактировать материал...**: открывает его для этого материала (или для множественного выбора, если материал является его частью).
- [Инструмент «Текстура»] (texture-tool.md): **Редактировать материал** рядом с **Обзор...** открывает его на материале выбранных граней.
- `Escape` или кнопка закрытия окна закроет его.

<a id="loading-materials"></a>
## Загрузка материалов

Верхняя строка заполняет список материалов, над которыми работает окно:

| Контроль | Описание |
|---|---|
| **Загрузка:** **Текущий материал** | Текущий материал браузера текстур. |
| **Выбор браузера (n)** | Материалы, выбранные с помощью `Ctrl+click` или `Shift+click` в браузере текстур. |
| **Используется выбранным** | Материалы выбранных граней и объектов. |
| **Добавить материал по названию** + **Добавить** | Добавляет один материал (также `Enter`). |
| **Перезагрузить** | Снова читает файлы. |
| **Очистить** | Очищает список. |

Затем выберите режим: **Один материал** (по умолчанию) или **Несколько материалов**.

Каждый материал имеет свое местоположение:

| Расположение | Значение |
|---|---|
| **Файл** | Файл VMT на диске (наведите указатель мыши на его путь): записан на месте. |
| **Изображение** | Создается из образа пользовательской папки: при сохранении рядом с изображением создается настоящий файл VMT. |
| **Архив** | Внутри VPK или GMA (только чтение): его необходимо скопировать в пользовательскую папку для редактирования. |
| **Отсутствует** | Не найден в загруженном контенте. |

<a id="one-material"></a>
## Один материал

| Контроль | Описание |
|---|---|
| `◀`, список материалов, `▶` | При загрузке нескольких материалов выбирает отредактированный. Переключение с несохраненными изменениями запрещено: **Сначала сохраните или отмените изменения этого материала**. |
| Метка местоположения | См. выше. Для заархивированного материала параметр **Копировать в:** выбирает пользовательскую папку, в которую будет помещена копия. |
| **Изменено** | Отображается, когда текст отличается от файла. |
| **Сохранить** | Записывает VMT (оригинал сохраняется как `.vmt.bak`). Архивированный материал записывается в виде копии в выбранную пользовательскую папку; в нем создается недостающий материал. |
| **Отменить изменения** | Вернемся к тексту файла. |
| **Шейдер** | Изменяет шейдер (параметры остаются): LightmappedGeneric, VertexLitGeneric, UnlitGeneric, UnlitTwoTexture, WorldVertexTransition, Lightmapped_4WayBlend, Water, Refract, Sprite, SpriteCard, DecalModulate, Cloud, Sky, Patch, Wireframe. |
| **Каждый параметр** | Также показывает параметры, считываемые другими шейдерами. По умолчанию отключено: только параметры текущего семейства шейдеров. |
| **Поиск параметра** | Фильтрует параметры страницы по ключу или описанию. |

Материалы с шейдером `Water_DX9_HDR` также распознаются как вода.

В левом столбце перечислены страницы: **Базовая текстура**, **Прозрачность**, **Карта рельефа**, **Детализация**, **Отражения**, **Фонг**, **Контурный свет**, **Самосвещение**, **Освещение и поверхность**, **Качание дерева**, **Вода**, **Преломление**, **Спрайт**, **Компиляция флагов**, **Другие параметры**. Страницы с установленными параметрами показывают их количество жирным шрифтом; страницы, для которых шейдер не имеет значения, скрыты.

Для Lightmapped_4WayBlend в **Базовой текстуре** также перечислены параметры 4-стороннего смешивания: `$basetexture3`, `$basetexture4`, `$textureN_lumstart` и `$textureN_lumend`, `$textureN_blendstart` и `$textureN_blendend`, `$lumblendfactorN`, `$textureN_uvscale` и `$textureN_blendmode`; На **карте рельефа** указано `$textureN_bumpblendfactor`. За ними следуют 3D-изображения (см. [4-way blends](displacement-tool.md#4-way-blends-lightmapped_4wayblend)).

В каждой строке параметра отображается его ключ (жирный шрифт, если он установлен), виджет, кнопка `✖` (**Удалить (возврат к значениям по умолчанию)**), когда он установлен, и строка, сообщающая, что он делает. Виджеты следуют параметру:

| Вид параметра | Виджет |
|---|---|
| Вкл. или выкл. | Флажок (выключение удаляет ключ). |
| Номер | Ползунок для небольших диапазонов, в противном случае : поле перетаскивания. |
| Цвет | Текстовое поле (`[1 1 1]`, можно вводить значения выше 1) и палитра цветов. |
| Выбор | Раскрывающийся список с именованными значениями. |
| Свойство поверхности | Раскрывающийся список общих значений `$surfaceprop`. |
| Текстура | Кнопка **VTF** (открывает текстуру в VTFEdit, VTFEdit++, VTFEdit Reloaded или другом установленном редакторе VTF или во встроенном [редакторе VTF] (vtf-editor.md); щелкните правой кнопкой мыши для выбора), поле пути (`folder/texture`) и кнопка `…` (**Выберите файл текстуры**): файл (VTF, PNG, TGA, JPG) должен находиться внутри папки `materials`, путь к нему прописывается без расширения. |
| Текст или вектор | Текстовое поле, показывающее значение по умолчанию. |

В разделе **Другие параметры** перечислены параметры файла, неизвестные страницам, каждый из которых можно редактировать с помощью кнопки удаления, а также строка для добавления любого параметра (`$parameter`, **значение**, **Добавить**). В тексте редактируются блоки типа `Proxies`.

Справа предварительный просмотр сохраненного материала (**Предварительный просмотр сохраненного материала**) и **Текст VMT**, редактируемый: виджеты и текст меняются вместе. Если текст не является допустимым VMT, в окне отображается сообщение **Текст не является допустимым VMT: исправьте это ниже** и отображается только текст.

<a id="several-materials"></a>
## Несколько материалов

В пакетном режиме отображается таблица загруженных материалов (**Материал**, **Местоположение**, **Шейдер**, кнопка для удаления строки) и **Изменения**, которые необходимо внести во все из них:

| Параметр | Выбор |
|---|---|
| **Базовая текстура** (`$basetexture`), **Обычная карта** (`$bumpmap`), **Карта окружения** (`$envmap`), **Ключевые слова** (`%keywords`) | **Сохранить**, **Установить** (со значением), **Удалить** |
| **Свойство поверхности** (`$surfaceprop`) | **Сохранить**, **Установить** (текстовое поле и список общих значений), **Удалить** |
| **Оттенок карты окружения** (`$envmaptint`) | **Сохранить**, **Установить** (`[1 1 1]`), **Удалить** |
| **Полупрозрачный** (`$translucent`), **Альфа-тест** (`$alphatest`), **Двусторонний** (`$nocull`), **Самосвещение** (`$selfillum`) | **Держать**, **Вкл.**, **Выкл.** |

Каждая строка начинается с **Сохранить**. **Другие параметры** и **+ Добавить параметр** добавляют строки с любым ключом.

В нижнем колонтитуле указано **Файлы: N, из изображений: N, в архивах: N, отсутствующие: N**. Для заархивированных материалов: **Скопируйте заархивированные материалы в** и скопируйте их в пользовательскую папку перед редактированием (копия за пределами префикса папки получает новое имя: **... будет скопирована как ...**). **Применить к N материалам** записывает все файлы в фоновом режиме (**Запись файлов...**), затем сообщает **N материалов обновлено** (ошибки выводятся на консоль). Оно отключено до тех пор, пока хотя бы для одной строки не будет установлено значение **Сохранить** (**Выберите хотя бы одно изменение**).

<a id="tips"></a>
## Советы

- Чтобы сделать набор материалов двусторонним, выберите их в браузере с помощью `Ctrl+click`, откройте **Редактировать материал**, переключитесь на **Несколько материалов** и установите для **Двусторонний** значение **Вкл.**.
- **Используется при выборе** загружает все материалы комнаты одним щелчком мыши.
- Резервная копия `.vmt.bak` создается только один раз, перед первым изменением: в ней сохраняется исходный файл.

<a id="faq"></a>
## Частые вопросы

**Почему я не могу редактировать материал игры?** Он находится в архиве VPK или GMA. Выберите пользовательскую папку (**Копировать в:** в режиме **Один материал**, **Копировать заархивированные материалы в** в режиме **Несколько материалов**): при сохранении туда записывается отредактированная копия.

**У меня нет пользовательской папки.** В окне написано: **Сначала добавьте пользовательскую папку в браузере текстур**. См. [Папки с пользовательскими текстурами](custom-texture-folders.md).

**Сохраняются ли мои комментарии?** Да, параметры изменяются внутри существующего текста; комментарии и форматирование остаются.

**Обновляется ли 3D-вид?** Да, материал перезагружается после сохранения.
