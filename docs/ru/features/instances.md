# Экземпляры

`func_instance` помещает содержимое другого файла VMF на вашу карту: постройте дверь, лампу или целую комнату один раз, поместите их много раз, отредактируйте файл, и последует каждая копия. Hammer Pro рисует содержимое каждого экземпляра, редактирует файлы экземпляра, сворачивает экземпляры на карту, а его компилятор объединяет их, как VBSP.

<a id="opening-it"></a>
## Как открыть

**Инструменты > Создание экземпляров**:

| Действие | Описание | Сочетание клавиш по умолчанию |
| --- | --- | --- |
| **Создать экземпляр из выделенного...** | Сохраняет выделение в новый файл экземпляра и заменяет его на `func_instance`. | `Alt+S` |
| **Изменить экземпляр** | Открывает файл выбранного экземпляра. | нет |
| **Свернуть выбранные экземпляры** | Заменяет выбранные экземпляры их содержимым. | нет |
| **Свернуть все экземпляры...** | То же самое для каждого видимого экземпляра карты после подтверждения. | нет |
| **Экземпляры: скрытые** / **Экземпляры: тонированные** / **Экземпляры: обычные** | Как отрисовывается содержимое экземпляров. | нет |

На вкладке **Экземпляр** правой панели отображаются файл и параметры выбранного экземпляра.

<a id="how-an-instance-is-merged"></a>
## Как происходит объединение экземпляров

Правила представляют собой VBSP, используемые представлениями, **Collapse** и компилятором:

- содержимое перемещается на `origin` и поворачивается на `angles` из `func_instance` (браши с блокировкой текстуры, ключи объектов по их типу FGD);
- каждое ключевое значение и выходное значение получают замены экземпляра (`replace01`... ключи, содержащие `$variable value`, каждое вхождение, нечувствительно к регистру);
- имена объектов, цели и цели вывода фиксируются с помощью имени экземпляра: `name-x` (префикс, по умолчанию), `x-name` (постфикс) или оставлено отдельно (нет). Имена, начинающиеся с `@` (глобальные) или `!` (например, `!activator`), никогда не изменяются; безымянный экземпляр использует `InstanceAuto<n>`;
- `func_instance_parms` сущности удаляются;
- вложенные экземпляры также объединяются с защитой от экземпляра, содержащего самого себя, ограничения глубины и размера.

Файлы экземпляров ищутся то в папке карты (относительно нее клавиша `file`), то в игровом контенте (только чтение).

<a id="display"></a>
## Дисплей

| Режим | Что ты видишь |
| --- | --- |
| **Экземпляры: скрыты** | Только сущность `func_instance`. |
| **Экземпляры: тонированные** (по умолчанию) | Содержимое окрашено примерно в Hammer. |
| **Случаи: обычные** | Содержимое нарисовано так же, как и остальная часть карты. |

Содержимое выбранных экземпляров отображается в общих чертах (включая вложенные экземпляры), а их файлам присваиваются имена в каждом представлении. Экземпляр, файл которого не может быть найден или прочитан, получает красный крест и метку в его источнике.

<a id="create-instance-from-selection"></a>
## Создать экземпляр из выделения

`Alt+S` (Клавиша Hammer++) открывает **Создать экземпляр из выделения**:

| Поле | Описание |
| --- | --- |
| **Имя файла:** | Имя нового VMF (без разделителя папок, без `: * ? " < > \|`). |
| **Папка:** | Где он сохраняется, с помощью **Обзор...**. По умолчанию используется настройка **Папка по умолчанию** (`instances` относительно папки карты). Для несохраненной карты требуется полный путь к папке. |
| **Происхождение:** | X, Y, Z. Выбор сохраняется вокруг этой точки, которая становится началом координат `func_instance`. Начинается в центре выделения и привязан к сетке. |
| **Заменить существующий файл** | Отображается, когда файл существует. |
| Ключ файла экземпляра | Значение `file`, которое получит экземпляр (относительно папки карты, если это возможно). |

**Создать** записывает файл в фоновом режиме (атомарная запись), а затем заменяет выделение на `func_instance` этого файла за один шаг отмены. Выделение перемещается на минус от начала координат (текстуры заблокированы); полностью выбранные группы сохраняются, визгруппы : нет.

<a id="edit-instance"></a>
## Редактировать экземпляр

**Редактировать экземпляр** (или кнопка **Редактировать экземпляр** на вкладке «Экземпляр») открывает файл экземпляра на новой вкладке, при этом родительская карта остается открытой. Если параметр **Открывать карты в новых вкладках** отключен, карта открывается в новом окне Hammer Pro. Если включен параметр **Показывать карту вокруг редактируемого экземпляра**, родительская карта рисуется вокруг экземпляра, окрашивается и доступна только для чтения. Когда вы сохраняете файл экземпляра, родительский элемент перерисовывает его экземпляры. Файл, полученный из игрового контента, редактировать нельзя.

<a id="collapse"></a>
## Свернуть

**Свернуть выбранные экземпляры** и **Свернуть все экземпляры...** заменяют экземпляры их фиксированным содержимым (включая вложенные экземпляры). Содержимое присоединяется к визгруппам экземпляра, который он заменяет, созданные объекты выбираются, и это один шаг отмены. Экземпляры, файл которых не может быть найден, пропускаются и сообщаются. **Свернуть все экземпляры...** сначала спрашивает («Заменить N видимых экземпляров карты их содержимым?») и отмечает: «Объекты, скрытые в файлах экземпляров, не учитываются». когда эта настройка включена.

<a id="the-instance-tab"></a>
## Вкладка «Экземпляр»

При выборе `func_instance` (первый, если их несколько), на вкладке отображается:

- файл (**File:**), был ли он найден, или «Читать из содержимого игры (только чтение)»;
- Кнопки **Редактировать экземпляр** и **Свернуть выбранные экземпляры**;
- **Параметры экземпляра**: одно поле на каждый параметр, объявленный сущностью `func_instance_parms` файла (`parmN` = `$name type [default]`), набранный как его тип FGD (флажок, числа, цвет, текст). В поле записывается соответствующий ключ `replaceNN` (новое значение занимает первый свободный слот). **Удалить значение** очищает его («Не установлено: экземпляр сохраняет {default}»);
- **Другие замены**: замены, не соответствующие ни одному объявленному параметру, в виде необработанных строк с **Добавить замену (значение $variable)**.

Те же поля параметров отображаются под ключевыми значениями `func_instance` на панели объектов.

<a id="options"></a>
## Параметры

**Инструменты > Параметры... > Экземпляры** (`[instances]` в `settings.toml`):

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Содержимое func_instance** (`display`) | **Скрытый**, **Тонированный** или **Нормальный**. | Тонированный |
| **Обвести выбранные экземпляры** (`outline_selected`) | Рисует границы содержимого выбранных экземпляров и имя их файла. | Вкл. |
| **Показать карту вокруг отредактированного экземпляра** (`show_context`) | Рисует родительскую карту вокруг экземпляра, открытого с помощью **Редактировать экземпляр**, с тонировкой и только для чтения. | Вкл. |
| **Папка по умолчанию** (`folder`) | Где **Создать экземпляр из выделенного** сохраняет новые экземпляры: относительно папки карты или полного пути. | `instances` |
| **Не включать скрытые объекты в файлах экземпляров** (`collapse_skips_hidden`) | Как и в Hammer++: объекты, скрытые в файле экземпляра, не добавляются на карту, когда она свернута. | Вкл. |

<a id="tips"></a>
## Советы

- При компиляции сохраняются `func_instance` объектов, а встроенный компилятор объединяет их по одним и тем же правилам, поэтому вам не нужно сворачивать их перед компиляцией.
- Используйте имена `@` для объектов, которые должны сохранять свое точное имя в каждой копии (глобальное реле).
- Инструменты MCP: `list_func_instances`, `create_instance`, `set_instance_parameters`, `collapse_instances`, `make_instance`, `get_instance_file` (см. [Справочник инструментов MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Экземпляр отмечен красным крестом.** Его файл отсутствует или не читается. Проверьте ключ `file`: он относится к папке с картой.

**Свернуть означает, что файл экземпляра все еще загружается.** Файлы загружаются в фоновом режиме; Hammer Pro ждет до 30 секунд, затем сдается, ничего не меняя. Повторите попытку, как только появится контент.

**Почему я не могу редактировать экземпляр игры?** Файлы, считываемые из содержимого игры, доступны только для чтения. Скопируйте файл рядом с вашей картой и наведите клавишу `file` на копию.
