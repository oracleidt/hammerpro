# Окно настроек

Окно **Настройки** содержит все параметры Hammer Pro, отсортированные по страницам. Изменения применяются сразу и сохраняются автоматически. На этой странице перечислены все страницы и их содержание; Полная таблица клавиш, значений по умолчанию и эффектов находится в [Справочнике по настройкам] (../reference/settings.md).

<a id="opening-it"></a>
## Как открыть

- **Инструменты > Параметры...** (`Ctrl+,`).
- **Настроить...** в ссылке на сочетание клавиш (`F1`) открывает страницу **Клавиатура**.
- Некоторые сегменты строки состояния и сообщения открывают страницу, на которой они находятся.

<a id="the-window"></a>
## Окно

Список страниц находится слева и разбит на разделы: **Приложение** (Общие, Обновления, Место на диске, Клавиатура, Ввод), **Игра и контент** (Игра, Сущности и браузеры), **Виды и отрисовка** (Виды, Вспомогательные объекты, Отрисовка, Освещение, Навигационная сетка и частицы), **Редактирование** (Редактирование, Выбор, Браши, Вершины и дисплейсменты, Экземпляры, Кордоны и визгруппы, Префабы), **Компиляция и проверка** (Компиляция, Состояние карты) и **Интеграции** (Discord, Blender, Редактор VTF, MCP). Выбранная страница находится справа.

**Найти параметр**, поле над списком, находит параметр по названию: введите несколько букв, и в списке останутся только страницы с подходящим параметром, под названием каждой показан найденный текст (наведите на него, чтобы прочитать целиком). Регистр и диакритика не учитываются; поиск идёт на языке интерфейса, а также по английским названиям. Под страницей показывается прежде всего название параметра, которое начинается с введённого текста. Очистите поле, чтобы снова увидеть все страницы. В нижней части окна находятся:

| Контроль | Описание |
| --- | --- |
| **Восстановить настройки по умолчанию** | Сбрасывает все параметры отображаемой страницы. Первый щелчок активирует его (**Нажмите еще раз, чтобы подтвердить**, в течение 4 секунд), второй щелчок сбрасывает. Он есть на каждой странице, кроме **Игра**. |
| **Применить и перезагрузить контент** | Отображается после изменения настроек игры: снова монтирует содержимое игры и перезагружает определения сущностей с новыми настройками. Закрытие окна также применяет их. |
| *Изменения сохраняются автоматически* | Напоминание: кнопки OK нет. |
| **Закрыть** | Закрывает окно (тоже `Esc`). |

Настройки сохраняются в `settings.toml`, в `%APPDATA%\HammerPro` в Windows (см. [Файлы и папки](../reference/files-and-folders.md)). Файл записывается атомарно; если его невозможно прочитать, Hammer Pro запускается со значениями по умолчанию и регистрирует предупреждение. Тема и язык применяются немедленно.

**Найти параметр** ищет по параметрам, пояснениям и сообщениям всех страниц, кроме **Обновления** и **Место на диске** (их открывайте напрямую); поиск по названию действия находит страницу **Клавиатура**, у которой есть своё поле (**Действия поиска или сочетания клавиш**) для поиска самого сочетания. [Справочник настроек](../reference/settings.md) и инструмент MCP `get_settings` перечисляют все ключи.

<a id="mcp"></a>
## MCP

`get_settings` считывает каждую настройку (или таблицу, или один ключ), а `set_setting` изменяет одну по пунктирному пути, например `health.live_checks`. См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="tips"></a>
## Советы

- **Восстановить настройки по умолчанию** сбрасывает только отображаемую страницу: экспериментируйте на одной странице, не теряя остальных.
- После изменения папки игры или параметров контента нажмите **Применить и перезагрузить контент**, чтобы увидеть результат, не закрывая окно.
- Создайте резервную копию `settings.toml` перед большими изменениями; копирование его на другой компьютер открывает все ваши возможности (включая сочетания клавиш).

<a id="faq"></a>
## Частые вопросы

**Есть ли кнопка OK или «Применить»?** Нет. Каждое изменение применяется и сохраняется сразу. Только игровой контент ожидает **Применить и перезагрузить контент** (или закрытия окна).

**Я что-то сломал. Как мне сбросить все?** Используйте **Восстановить настройки по умолчанию** на каждой странице или закройте Hammer Pro и удалите `settings.toml` (вы снова увидите мастер первого запуска).

**Почему на странице игры нет функции «Восстановить настройки по умолчанию»?** При сбросе настроек папки с игрой и настройки контента будут потеряны; измените эти параметры один за другим.
