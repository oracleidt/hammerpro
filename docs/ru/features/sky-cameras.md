# Небесные камеры

`sky_camera` находится в небольшой комнате (3D-скайбокс), которую игра рисует вокруг карты в своем масштабе. Hammer Pro просматривает 3D-скайбокс в 3D-виде, обрабатывает карты с помощью нескольких камер неба и отправляет объект переключения скайбокса, `point_hammerpro_skybox`, который меняет 3D-скайбокс в игре (день и ночь, по одному скайбоксу на каждую область).

<a id="opening-it"></a>
## Как открыть

| Действие | Меню | Сочетание клавиш по умолчанию |
| --- | --- | --- |
| **3D-скайбокс** (предварительный просмотр) | **Вид > Параметры отображения > 3D-скайбокс** | `Alt+V` |
| **Предварительный просмотр неба** (2D-небо) | **Вид > Параметры отображения > Предварительный просмотр неба** | нет |
| **3D-камера скайбокса** | **Вид > 3D-камера скайбокса** (отображается, если на карте есть две или более камеры скайбокса) | нет |
| **Используйте предварительно просмотренную камеру неба в игре** | **Вид > Параметры отображения** или подменю **3D-камера Skybox**. | нет |

<a id="previewing-the-3d-skybox"></a>
## Предварительный просмотр 3D-скайбокса

Если включен **3D-скайбокс** (по умолчанию, `render.skybox_3d`), комната вокруг камеры неба рисуется вокруг карты в точке `scale`, как в игре. **Предварительный просмотр неба** (`render.sky_preview`, вкл.) отображает 2D-небо места появления мира `skyname` позади него. Грани неба (`toolsskybox`) сохраняют свою текстуру инструмента, если не включен параметр **Просмотр неба через Toolsskybox** (**Настройки > Рендеринг**). `Alt+V` показывает «3D-скайбокс показан» или «3D-скайбокс скрыт».

При включенном **Предварительном просмотре тумана** 3D-скайбокс берет туман со своей камеры неба (**Включение тумана**, цвета, смешивание, направление, начало, конец, максимальная плотность), измеренный в единицах скайбокса, а не туман карты, как в игре; см. [Туман на карте] (render-modes-display.md#map-fog).

Камера неба без действительного `scale` (целое число не менее 1) использует 16, значение FGD по умолчанию, и в меню помечается как «недействительное».

<a id="several-sky-cameras"></a>
## Несколько небесных камер

На карте может быть несколько камер неба, каждая в своей комнате. В играх Garry's Mod и Source 2013 отображается трехмерный скайбокс **последнего sky_camera карты** (того, который появился последним). [Проверка проблем](check-problems.md) напоминает вам об этом, если на карте их несколько.

В подменю **Вид > 3D-камера скайбокс** перечислены:

- **Как в игре: <camera>**: предварительный просмотр следует за камерой, которую использует игра (по умолчанию);
- каждая небесная камера с именем «имя (#id, масштаб N)» или «sky_camera #id (масштаб N)», та, которую использует игра, с пометкой «используется в игре». Выбор одного из них позволяет просмотреть его (и включить предварительный просмотр 3D-скайбокса);
- **Использовать камеру предварительного просмотра неба в игре**: делает камеру предварительного просмотра той, которую использует игра, перемещая ее после других объектов на карте. Один шаг отмены. Сообщение «В игре теперь используется <camera>» подтверждает это.

<a id="the-skybox-switch-point_hammerpro_skybox"></a>
## Переключатель скайбокса: point_hammerpro_skybox

В игре одновременно отображается один 3D-скайбокс. `point_hammerpro_skybox` : это Lua-объект Garry's Mod, который Hammer Pro добавляется в список сущностей (его FGD загружается после игрового), чтобы показывать 3D-скайбокс другого `sky_camera`, когда он получает `Activate`.

Настройка:

1. Присвойте `sky_camera` **Имя** (для этого Hammer Pro добавляет ключ `targetname` к `sky_camera`).
2. Поместите `point_hammerpro_skybox` и присвойте этому имени **Камере неба**. В представлениях их соединяет линия.
3. Выстрелите `Activate` со спускового крючка, кнопки, `logic_timer`...

Ключи и флаги:

| Клавиша | Описание | По умолчанию |
| --- | --- | --- |
| **Имя** | Имя переключателя. | |
| **Камера неба** (`skycamera`) | Имя `sky_camera`, чей 3D-скайбокс показывает этот переключатель. | |
| **Режим** (`mode`) | **Глобальный (все)**: меняет 3D-скайбокс для каждого игрока. **На игрока**: рисуется на каждом клиенте для игрока, активировавшего переключатель, поэтому несколько игроков могут видеть разные скайбоксы одновременно. Каждый игрок рисует трехмерную геометрию скайбокса выбранной камеры; дальнее 2D-небо и туман остаются на карте. | Глобальный |
| **Начать активно (глобально)** (флаг появления 1) | Показывает этот скайбокс при запуске карты (только в глобальном режиме). | Выкл. |

| Ввод | Описание |
| --- | --- |
| `Activate` | Показывает 3D-скайбокс небесной камеры. |
| `Deactivate` | Снова показывает собственный 3D-скайбокс карты, когда отображается этот переключатель. |
| `Toggle` | Активируйте, когда он неактивен, иначе деактивируйте. |

| Выход | Когда |
| --- | --- |
| `OnActivated` | Показан скайбокс этого переключателя. |
| `OnDeactivated` | Скайбокс этого переключателя перестает отображаться. |

Когда карта компилируется, каждый переключатель получает ключи своей небесной камеры (`sky_origin`, `sky_scale`, клавиши тумана...), поэтому он работает в игре, не глядя на камеру. Туманные клавиши камеры копируются в глобальном режиме.

<a id="shipping-the-script"></a>
### Отправка сценария

Коммутатору нужен Lua в игре (`lua/entities/point_hammerpro_skybox.lua` и `lua/autorun/hammerpro_skybox.lua`). Hammer Pro отправит его вам:

- тестовые компиляции помещаются в **надстройку для разработки** (настройки компиляции);
- **Создать и сохранить как контент** добавляет его в дополнение, когда на скомпилированной карте есть переключатель.

Журнал компиляции сообщает вам, когда карта с переключателями компилируется без дополнения разработки. [Проверка проблем](check-problems.md) предупреждает о переключателе, у которого не существует камеры неба, и о переключателях для каждого игрока (если на сервере запущен аддон, который также рисует небо, например аддон погоды, они могут конфликтовать).

<a id="tips"></a>
## Советы

- Одна карта, день и ночь: две комнаты скайбокса, две названные небесные камеры, два переключателя, активируемые `logic_timer` или кнопкой.
- Чтобы изменить камеру, используемую в игре, без переключателя, просмотрите ее и используйте **Использовать предварительно просмотренную камеру неба в игре**.
- Инструменты MCP: `list_sky_cameras`, `preview_sky_camera`, `use_sky_camera_in_game`, `create_skybox_switch` (см. [Справочник по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**В моей игре отображается неправильный 3D-скайбокс.** В игре используется последний `sky_camera` карты. Просмотрите нужную камеру в меню **Вид > 3D-камера скайбокса** и выберите **Использовать просмотренную камеру неба в игре**.

**Переключатель ничего не делает в игре.** Отсутствует Lua: включите **Дополнение для разработки** для тестовых компиляций или выпустите с параметром **Создать и сохранить как контент**. Также убедитесь, что **Камера неба** соответствует **Имени** камеры.

**Работает ли этот переключатель в других играх?** Нет. Это объект Lua из Garry's Mod.
