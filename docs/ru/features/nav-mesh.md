# Навигационная сетка

Навигационная сетка (`.nav`) сообщает NPCs и ботам, куда они могут ходить. Hammer Pro создает его на карте без запуска игры и рисует любой файл `.nav` поверх карты, чтобы вы могли обнаружить дыры и области, отрезанные от остальных.

<a id="opening-it"></a>
## Как открыть

| Действие | Меню | Сочетание клавиш по умолчанию |
| --- | --- | --- |
| **Создать навигационную сетку** | **Инструменты > Создать навигационную сетку** | нет |
| **Загрузить навигационную сетку...** | **Карта > Загрузить навигационную сетку...** | нет |
| **Показать сетку навигации** | **Вид > Параметры отображения > Показать сетку навигации** | нет |

<a id="generating"></a>
## Создание

**Инструменты > Создать навигационную сетку** создает сетку в фоновом режиме и записывает `<map>.nav` рядом с VMF (где средство просмотра и **Создание и сохранение как содержимое** ищут ее). Сначала сохраните карту. Когда это будет сделано, включатся «Создана навигационная сетка: N областей за N мс» и **Показать навигационную сетку**.

Как это работает, как у Valve `nav_generate`:

- прогулка начинается с момента старта игрока (классы начинаются с `info_player_` и `gmod_player_start`). Карта без него получает сообщение «На карте нет игроков: добавьте info_player_start там, где ходят игроки.»;
- пробы почвы отбираются каждые 25 единиц. Образец сохраняется там, где поместится игрок (стоит или приседает), а два образца связываются, когда между ними игрок может ходить, шагать (до 18 единиц), подпрыгивать или опускаться;
- образцы объединены в прямоугольники почти ровной поверхности (площадки), соединенные по краям.

Что блокирует игроков: браши видимого мира, объекты браши `func_detail`, `func_brush`, `func_wall`, `func_wall_toggle` и `func_lod`, дисплейсменты и твердые статические пропы (в виде коробок). Двери, бьющиеся предметы и движущиеся браши не учитываются (они открываются, ломаются или двигаются; генератор игры проходит и через них). Игроки проходят через триггер, подсказку, пропуск, портал области, окклюдер, зажим NPC, туман, блокировку LOS, блокировку световых текстур и воду.

Предупреждения в консоли: старт игрока без земли под ним пропускаются, а очень большая карта останавливается на пределе выборки.

<a id="showing-a-nav-mesh"></a>
## Показ навигационной сетки

**Показать сетку навигации** отображает сетку на каждом виде. Это тот файл, который выбран с помощью **Карта > Загрузить навигационную сетку...**, в противном случае : `.nav` рядом с картой, в противном случае : файл в папке `maps` игры (также рядом с декомпилированным BSP). Он читается снова, когда он изменяется на диске. Hammer Pro читает версии навигации с 1 по 16 (Garry's Mod записывает версию 16).

| Рисование | Значение |
| --- | --- |
| Контур области зеленый | Прогулочная. |
| Синий | Крауч. |
| Желтый | Прыгай. |
| Красный | Избегайте. |
| Голубой | Лестница. |
| Пурпурный | Отрезана от основной части сетки (где спавнятся игроки, остальное большая часть). |
| Белая линия | Соединение в обе стороны. |
| Оранжевая линия со стрелкой | Одностороннее соединение. |
| Фиолетовая рамка | Лестница. |

Области заполняются на 3D-виде и обрисовываются на 2D-виде. В строке состояния отображается «Области навигации: N» (и «Отрезано: N»); в консоли перечислены области, лестницы, односторонние ссылки и ссылки на недостающие области загруженной сетки.

<a id="options"></a>
## Параметры

**Инструменты > Параметры... > Навигационная сетка и частицы** (`[lab]` в `settings.toml`):

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Показать сетку навигации** (`show_nav_mesh`) | Рисует сетку. | Выкл. |
| **Заполните области в 3D-виде** (`nav_fill`) | Без заливки рисуются только контуры областей. | Вкл. |
| **Соединения между областями** (`nav_connections`) | Белый: в обе стороны. Оранжевый со стрелкой: в одну сторону. | Вкл. |

<a id="tips"></a>
## Советы

- Пурпурные области : это те области, до которых боты никогда не доходят: исправьте разрыв, который их отсекает, или удалите их в игре (подсказка `nav_flood_select` вики Valve находит их).
- [Окно выпуска] (build-content-release.md) также может создавать навигационную сетку в игровом сеансе, и его контрольный список проверяет наличие такой сетки на карте.
- Инструмент MCP: `nav_mesh` (показана сетка или загрузите файл `.nav` из папки карты; см. [Справочник по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Генерация сообщает, что земля, по которой можно ходить, не найдена.** Игрок начинает парить над чем-то или стоять внутри твердого тела. Положите `info_player_start` на пол.

**Сетка проходит через мои двери.** Двери намеренно опущены, как в игровом генераторе.

**Нужна ли игра для генерации?** Нет. Генератор считывает карту в редакторе.
