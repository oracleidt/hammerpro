# Обозреватель текстур

Браузер текстур : это вкладка **Текстуры** на правой панели. В нем перечислены все материалы смонтированного контента (игра VPKs, аддоны, Мастерская, папки с пользовательскими текстурами) в сетке миниатюр с мгновенным поиском, фильтрами, избранным и текущим материалом: инструмент текстуры, инструмент блока и **Применить текущую текстуру**, наложенные на грани.

Миниатюры blend-материалов показывают обе основные текстуры с диагональным переходом; материалы с четырьмя слоями показывают все четыре текстуры. Миниатюра помогает выбрать материал; на карте смешивание по-прежнему определяется нарисованным альфа-каналом displacement.

<a id="opening-it"></a>
## Как открыть

- Откройте вкладку **Текстуры** на правой панели.
- **Просмотр > Панели > Браузер текстур** отображает вкладку и помещает курсор в поле поиска. Сочетания клавиш по умолчанию нет.
- В инструменте текстуры кнопка **Обзор...** на панели **Редактирование грани** открывает браузер: следующий выбранный вами материал применяется к выбранным граням, затем панель возвращается (см. [Инструмент Текстура](texture-tool.md)).
- Когда ключ материала на панели объектов запрашивает материал, баннер в верхней части браузера говорит: **Выберите материал для...**: дважды щелкните материал (или нажмите `Enter` в поиске), чтобы передать его ключу, **Использовать текущий материал** дает текущий материал, **Отмена** возвращает на панель объекта.

<a id="the-current-material"></a>
## Текущий материал

В верхней части вкладки отображается текущий материал: большая миниатюра, его имя, звездочка, папка, размер и шейдер, а также содержимое, из которого он получен. **Отсутствует в игровом контенте**, выделенный красным, означает, что ни один смонтированный файл не имеет такого имени. **Изменение размера в игре** означает, что материал представляет собой простое изображение, стороны которого не являются степенями двойки: игра меняет его размер (наведите курсор на метку размеров), а масштабирование текстур использует размер игры.

| Контроль | Описание |
|---|---|
| Миниатюра | Перетащите его на грань, чтобы применить материал. Двойной щелчок: применить его к выделению. |
| Звездочка (**Добавить в избранное** / **Удалить из избранного**) | Добавляет или удаляет материал из избранного. |
| **Применить к выбранному** | Применяет материал к выбранным граням или к каждой грани выбранных объектов. Отключено, когда ничего не выбрано. |
| **Заменить...** | Открывает [Найти и заменить текстуры](find-replace-textures.md) с этим материалом в поле **Найти**. |
| **Редактировать материал** | Открывает [редактор материалов] (material-editor.md) для этого материала или для множественного выбора, когда вы его сделали (`Ctrl+click`). |
| **Отметить** | Выбирает каждую грань, использующую этот материал, и переключается на инструмент текстуры. |

Текущий материал меняется, когда вы щелкаете миниатюру, выбираете материал грани с помощью `Alt+click` в инструменте текстуры или применяете материал путем перетаскивания. Каждый используемый вами материал идет первым в списке **Последние** (максимум 64 материала).

<a id="search"></a>
## Поиск

Введите **Поиск материалов...**: список фильтруется при каждом нажатии клавиши, даже при наличии 40 000 материалов. Каждое слово должно совпадать, регистр и акценты не учитываются. Нажмите `Enter` в поле поиска, чтобы первый результат стал текущим материалом.

| Слово | Сохраняет материалы... |
|---|---|
| `brick wall` | имя которого содержит `brick` и `wall`. |
| `-dev` | имя которого не содержит `dev`. |
| `kw:urban` | чьи ключевые слова VMT (`%keywords`) содержат `urban`. |
| `src:workshop` | чья исходная метка содержит слово (имя дополнения, `workshop`, имя пользовательской папки...). |
| `is:translucent` | с `$translucent` или `$additive`. |
| `is:alpha` | чья альфа-текстура прозрачна в игре (смешанная или альфа-тестированная, по решению движка). |
| `is:selfillum` | с `$selfillum`. |
| `is:envmap` | с `$envmap` (отражения). |
| `is:blend` | это смешанные материалы (WorldVertexTransition). |
| `is:missing` | чей VMT или базовую текстуру невозможно найти. |
| `-is:flag` | без этого флага (например, `is:translucent -is:envmap`). |
| `shader:lightmapped` | чей шейдер содержит слово. |
| `-shader:vertexlit` | чей шейдер не содержит слова. |

Слово, вставленное в качестве пути к файлу, сокращается до имени материала: `c:/game/materials/brick/brickwall001a.vmt` ищет `brick/brickwall001a`. Словам `kw:`, `is:` и `shader:` нужны ключевые слова и свойства каждого материала: они считываются в фоновом режиме при первом использовании такого слова (**Индексирование ключевых слов...**, **Чтение свойств материала...** рядом с количеством), тогда поиск происходит мгновенно.

Кнопка `X` в конце поля поиска очищает его.

<a id="filters"></a>
## Фильтры

| Фильтр | Описание | По умолчанию |
|---|---|---|
| Source фишек **Все**, **Игра**, **Дополнения**, **Мастерская** и по одной фишке в каждой папке. | Показаны только материалы этого источника. Чип появляется только тогда, когда у контента есть такой источник. Наведите курсор на чип папки, чтобы увидеть его путь и количество материалов. | **Все** |
| Фишки категорий **Все**, **Используется на карте**, **Избранное (n)**, **Последние**, **Инструменты** | **Использованы в карте**: материалы открытой карты (в том числе отсутствующие). **Избранное**: отмеченные вами материалы. **Последние**: последний использованный, самый последний : первым. **Инструменты**: только текстуры инструментов. | **Все** |
| Чипы свойств **Прозрачный**, **Альфа**, **Самосвечение**, **Отражающий**, **Смешение**, **Отсутствует** | Каждая фишка добавляет или удаляет соответствующее слово `is:` в поле поиска. | нет |
| **Шейдер:** раскрывающийся список | **Все** или один шейдер с указанием количества материалов (чаще всего используется первым). В поиске пишет `shader:name`. | **Все** |
| **Скрыть VertexLitGeneric** | Скрывает материалы модели (шейдер VertexLitGeneric): они не переходят на браши. Текстуры инструментов остаются. Сохранено в `hidden_shaders` из `[browser]`. | выкл. |
| **Скрыть текстуры инструментов** | Скрывает текстуры инструментов (кроме категории **Инструменты**). Сохранено как `hide_tool_textures`. | выкл. |
| Ползунок размера миниатюр | Размер миниатюры: от 48 до 256 точек с шагом 8. Сохраняется как `thumbnail_size` в `[ui]`. | 96 |
| **Показать альфу** | Рисует материалы, альфа-версия которых прозрачна в игре, на шахматной доске. Сохранено как `show_alpha`. | выкл. |

В строке под фильтрами отображается **N из M материалов** и **N выбрано** со знаком `X`, чтобы отменить множественный выбор.

<a id="hidden-folders"></a>
### Скрытые папки

Некоторые папки с материалами скрыты из браузера (текстуры инструментов и материалы карты всегда остаются видимыми):

- Щелкните правой кнопкой мыши материал и выберите **Скрыть папку...**, чтобы скрыть его папку. Список `excluded_folders` из `[browser]`; отредактируйте его в **Настройки > Объекты и браузеры > Браузер текстур > Скрытые папки:** (введите `folder` или `folder/sub`, затем **Добавить**; `×` удаляет одну).
- **Скрыть папки, которые исключаются из данных игры** (та же страница настроек, по умолчанию включено, `fgd_exclusions`) также скрывает папки, перечисленные `@MaterialExclusion` в файлах FGD.

<a id="the-grid"></a>
## Сетка

| Действие | Результат |
|---|---|
| Нажмите | Делает материал актуальным. |
| `Ctrl+click` | Добавляет или удаляет материал из множественного выбора (используется командой **Редактировать материал**). |
| `Shift+click` | Выбирает диапазон из материала, по которому последний раз щелкали. |
| Двойной щелчок | Применяет материал к выделению (или передает его ключу сущности, ожидающему материала). |
| Перетащите на грань 3D-вида. | Применяет его к этому грани (грань обводится контуром при наведении на него курсора). |
| Перетащите в 2D-вид | Применяет его к каждой грани выбранных объектов (или к выбранным граням). |
| Наведите указатель мыши | Подсказка: полное имя, размер, шейдер, свойство поверхности, ключевые слова, флаги (текстура инструмента, полупрозрачность, альфа-тест, вода, смесь) и источник. |
| Щелкните правой кнопкой мыши | Контекстное меню (см. ниже). |

Когда указатель мыши находится над сеткой (и ни одно текстовое поле не находится в фокусе), клавиатура перемещается по ней: стрелки, `Page Up`, `Page Down`, `Home`, `End` изменяют текущий материал, с помощью `Shift` они расширяют множественный выбор, а `Enter` применяет текущий материал к выделению. Когда мышь покидает сетку, эти клавиши возвращаются к инструментам (например, подталкиванию).

На миниатюрах с красным названием отсутствуют материалы (фиолетовая и черная шахматная доска).

<a id="context-menu"></a>
### Контекстное меню

| Товар | Описание |
|---|---|
| **Применить к выбранному** | Применяет материал к выделению. |
| **Выбирайте грани с его помощью** | Выделяет каждую грань с помощью материала и переключается на инструмент текстуры. |
| **Добавить в избранное** / **Удалить из избранного** | Переключает звезду. Избранное сохраняется в папке `favorites` из `[browser]`. |
| **Скопировать имя** | Копирует имя материала в буфер обмена. |
| **Замените этим...** | Открывает [Найти и заменить текстуры] (find-replace-textures.md) с текущим материалом в **Найти** и этим в **Заменить на**. |
| **Открыть папку, в которой находится** | Открывает папку VMT, VTF или образа в проводнике (только для файлов на диске, а не внутри архивов VPK или GMA). |
| **Редактировать материал...** | Открывает [редактор материалов](material-editor.md) для него (или для множественного выбора, если он является его частью). |
| **Редактировать текстуру (редактор VTF)...** | Открывает базовую текстуру материала во встроенном [VTF-редакторе](vtf-editor.md). |
| **Изменить в редакторе шейдеров** | Открывает [редактор шейдеров](shader-editor.md) для материала: на его сохраненном графике, если он есть рядом с его файлами, в противном случае : на его базовой текстуре. |
| **Скрыть папку ...** | Скрывает папку с материалом из браузера. |

<a id="custom-folders"></a>
## Пользовательские папки

В сворачиваемом разделе **Пользовательские папки (n)** перечислены ваши пользовательские папки с текстурами с их переключателем, количеством материалов, префиксом и предупреждениями, а также имеются кнопки **Добавить папку...**, **Повторное сканирование** и **Импортировать изображения...**. См. [Папки с пользовательскими текстурами](custom-texture-folders.md). По умолчанию он закрыт и открывается снова только при нажатии на него.

<a id="tips"></a>
## Советы

- Введите несколько букв каждой части имени: `conc flo` находит `concrete/concretefloor001a`.
- `is:alpha -is:translucent` находит вырезанные материалы (заборы, листва).
- Отмечайте материалы, которые вы используете постоянно, и держите **Избранное** открытым, пока создаете текстуры.
- Используйте **Отметить** на материале, чтобы увидеть, где он используется на карте, а затем измените их все на панели **Редактирование грани**.

<a id="faq"></a>
## Частые вопросы

**Добавленная мною текстура не отображается.** Нажмите **Повторное сканирование** в **Пользовательские папки**: содержимое игры и пользовательские папки будут перезагружены. Также убедитесь, что его папка не скрыта и что **Скрыть текстуры инструмента** или чип не фильтрует ее.

**Почему некоторые материалы отсутствуют в списке?** Проверьте чипы источника и категории, чипы свойств (они пишут `is:` слов), раскрывающийся список **Шейдер:**, **Скрыть VertexLitGeneric** и скрытые папки.

**Что означает загрузка Мастерской?** Пока аддоны Мастерской читаются, в списке отображается **Загрузка Мастерской (N аддонов), по завершении список увеличивается...**: их материалы появляются, когда чтение заканчивается.

**Могу ли я видеть только то, что есть у каждого игрока Garry's Mod?** В браузере текстур такого переключателя нет; используйте исходный чип **Game**. Параметр **Только контент Garry's Mod** относится к браузерам моделей, звуков и частиц.
