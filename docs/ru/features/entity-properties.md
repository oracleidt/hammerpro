# Свойства сущности

Вкладка **Entity** в правой доке : это свойства объекта Hammer: она редактирует значения ключей, флаги, выходные данные, модель и визуальные группы выбранных объектов с помощью типизированного редактора (SmartEdit), управляемого игровыми данными (FGD). Вокруг Hammer Pro есть инструменты, которые работают с ключами объектов: пипетки, редактор цвета, копирование и вставка значений ключей, максимальное расстояние, помощь по объектам, поиск объектов, поиск и замена в объектах, отчет об объектах и ​​свойства карты.

<a id="opening-it"></a>
## Как открыть

- **Правка > Свойства** (`Alt+Enter`) или **Просмотр > Панели > Свойства объекта** отображает вкладку **Объект** на правой панели закрепления.
- Вкладка всегда следует за выбором:
  - выбраны одна или несколько сущностей: их ключи (несколько сущностей редактируются вместе);
  - выбраны только мировые браши: страница «привязка к объекту» (см. ниже);
  - ничего не выбрано: мир, то есть свойства карты.
- Каждое изменение : это один шаг отмены. Непрерывные изменения (перетаскивание числа, цвета) сливаются в один шаг на каждую клавишу.

<a id="the-panel-header"></a>
## Заголовок панели

При изменении класса добавляются отсутствующие ключи по умолчанию нового класса, которые применяются к каждому выбранному объекту. Объект-браш, который становится классом с ключом `origin` (`func_tracktrain`, `func_tanktrain`, `func_rotating`...) и не имеет его, помещает его в центр своих брашов, как Hammer. |
| **?** | Открывает справку по сущности класса. |
| **☰** (**Подробнее**) | Меню с **Копировать значения ключей**, **Вставить значения ключей** (с именем скопированного класса и количеством его ключей), флажком **Вставить также имя (целевое имя)**, **Найти и заменить в сущностях...**, **Установить максимальное расстояние...** и **Справку по объектам**. |
| **Выбрано объектов: N** | Отображается, когда редактируются несколько объектов. |
| **Перейти в мир** | Отображается для объектов-брашов: возвращает браши в мир и удаляет объекты-браши (`Ctrl+Shift+W`). |
| **Описание** | Свернутый раздел с описанием класса FGD. |

Предупреждения появляются под заголовком, когда FGD не загружен (**Нет загруженных игровых данных (FGD): свойства отображаются в виде обычного текста**) или когда класс не определен в FGD (его ключи затем отображаются в виде обычного текста).

Для `fog_volume` в заголовке указано, какой туман он получает и что не так, оранжевым цветом: **Нет имени тумана**, **Нет env_fog_controller с именем «x»**, **Туман «x» отключен (Fog Enable: No): в игре этот том очищает туман**, **Предварительный просмотр: вид тумана по умолчанию**, **Запуск отключен** и состояние **PostProcessName** и **Имя цветокоррекции** (найдено, отсутствует или объект другого класса). Для `env_fog_controller`, когда **Fog Enable** установлено значение «Нет», указывается, просматривает ли 3D-вид этот туман и сколько `fog_volume` используют его. См. [Объемы тумана] (render-modes-display.md#fog-volumes).

<a id="only-world-brushes-selected"></a>
### Выбраны только мировые браши

На панели отображается **Выбранные мировые браши: N** и предлагается присвоить им класс: выберите класс объекта браши (по умолчанию `func_detail` или объект браши по умолчанию в настройках) и нажмите **Привязать к объекту** (`Ctrl+T`). Кнопки **Быстрая связь:** создают `func_detail`, `func_brush`, `func_illusionary`, `trigger_multiple` или `trigger_once` одним щелчком мыши (только те классы, которые есть в вашем FGD). См. [Операции с брашем](brush-operations.md).

<a id="properties-tab-smartedit"></a>
## Вкладка «Свойства» (SmartEdit)

Над списком:

- **Ключи** переключает между отображаемыми именами FGD и необработанными именами ключей.
- **Свойства фильтра** сохраняют строки, ключ или отображаемое имя которых содержит текст.

Каждая строка имеет метку и виджет. Символ `*` перед меткой отмечает значение, которое отличается от значения по умолчанию FGD. Ключи, которые FGD не определяет, показаны курсивом. Если выбрано несколько объектов, ключ, который различается между ними, отображается **(несколько значений)**; Показанные клавиши FGD являются общими для каждого выбранного класса.

Наведите указатель мыши на метку, чтобы увидеть отображаемое имя, ключ, тип, описание, значение по умолчанию, а для клавиш расстояния : примечание о том, что делает максимальное расстояние в игре. Щелкните правой кнопкой мыши ярлык для:

- **Сброс по умолчанию** (по умолчанию FGD или удаление ключа, если его нет);
- **Копировать значение**, **Копировать имя ключа**;
- **Удалить ключ**;
- на ключе имени: **Переименование выходных обновлений** (включено по умолчанию). Когда имя изменяется, выходные данные других сущностей, нацеленных на старое имя, следуют за ним, только если ни одна другая сущность не сохраняет это имя.

Текстовые поля применяются `Enter` или когда они теряют фокус; `Escape` отменяет редактирование. Двойные кавычки не принимаются в значениях (файл карты не может быть прочитан обратно).

<a id="eyedroppers-and-mark"></a>
### Пипетки и Марк

| Кнопка | Использование |
|---|---|
| Пипетка сущности (целевые ключи) | Щелкните объект в представлениях: его имя записывается в ключ. Если у него нет имени, в подсказке будет предложено свободное имя (`class_1`, `class_2`...), присвоено ему имя и задан ключ за один шаг. `Escape` отменяет; повторное нажатие кнопки также отменяет. |

<a id="flags-tab"></a>
## Вкладка «Флаги»

Одна группа на ключ флагов (обычно `spawnflags`): необработанное значение (сумма проверенных битов, редактируемая) и один флажок на каждый бит. Наведите указатель мыши на поле, чтобы узнать значение его бита и узнать, включено ли оно по умолчанию. Биты, неизвестные FGD, отображаются как **Неизвестный флаг N**. При наличии нескольких объектов бит, установленный только для некоторых из них, отображает смешанный блок.

<a id="raw-tab"></a>
## Вкладка «Сырье»

Таблица каждого ключа и значения. `classname` доступно только для чтения (используйте кнопку класса). Отредактируйте имя ключа, чтобы переименовать его, отредактируйте значение, чтобы изменить его, **×** удаляет ключ. В последней строке добавляется ключ: введите имя и значение, затем **+** или `Enter`. `id` и `classname` нельзя добавить отсюда.

<a id="model-tab"></a>
## Вкладка «Модель»

Отображается, когда выбранные объекты имеют общую модель `.mdl`.

- Имя и путь модели, предварительный просмотр (перетаскивание на орбиту), количество треугольников и вершин, а также раздел **Статистика**.
- **Отображение**: **Каркас**, вспомогательные наложения (ограничивающая рамка, рамка движения, хитбоксы, кости, физическая модель, вложения, нормали, исходные оси, земля, положение освещения, поле последовательности) и **Поле обзора**. Помощники, которых нет в модели, отключены.
- **Скины**: устанавливает клавишу `skin`.
- Один раскрывающийся список для каждой группы тел с минимум двумя вариантами выбора: устанавливает ключ `body`.
- **Последовательности (N)**: кнопка воспроизведения воспроизводит последовательность в предварительном просмотре (**Остановить анимацию**, **Перезапустить анимацию**). Нажатие на имя последовательности устанавливает `DefaultAnim`, когда класс имеет этот ключ. Недавно показанная модель воспроизводит свой `DefaultAnim` (иначе свою первую последовательность).

<a id="visgroups-tab"></a>
## Вкладка «Визгруппы»

Один флажок для каждой визгруппы карты с отступом, как у дерева визгрупп, с указанием цвета. Блок является смешанным, когда только некоторые из выбранных объектов принадлежат визгруппе. Нажатие добавляет или удаляет каждый выбранный объект. См. [Визгруппы](visgroups.md).

<a id="color-editor"></a>
## Редактор цвета

**Правка > Изменить цвет...** (`C`) открывает окно **Цвет: ключ** для первого цветового ключа первого выбранного объекта (первый ключ `color255` его класса, иначе `_light`, `rendercolor`, `_ambient` или `color`). Без него появится сообщение: **Выбор не имеет цветового ключа**.

- Палитра цветов, поля **R G B** (от 0 до 255) и **HS V**.
- Ползунок **Яркость** (от 0 до 2000, логарифмический) для значений освещенности.
- **Палитра карты**: на карте сохраняется 16 цветов (блок Hammer++ `palette_plus`). Щелкните образец, чтобы использовать его, щелкните правой кнопкой мыши, чтобы сохранить в нем текущий цвет.

Изменения применяются в реальном времени к каждому выбранному объекту и объединяются в один шаг отмены для каждой клавиши.

<a id="copy-and-paste-keyvalues"></a>
## Скопируйте и вставьте ключевые значения

- **Редактировать > Копировать значения** копирует все ключи первого выбранного объекта, кроме `id`, `classname`, `origin` и `targetname` (отдельно). Ключи также попадают в системный буфер обмена в виде строк `"key" "value"`.
- **Правка > Вставить значения** записывает их для каждого выбранного объекта за один шаг. Класс не меняется.
- **Вставьте также имя (целевое имя)** (меню панели) или **Настройки > Объекты и браузеры > Вставить ключевые значения также вставляет имя (целевое имя)** также вставляет имя. По умолчанию выключено (`[entities] paste_targetname`).

<a id="set-maximum-distance"></a>
## Установить максимальное расстояние

**Правка > Установить максимальное расстояние...** открывает окно **Максимальное расстояние**: одно расстояние (сначала 2048 единиц, до 1 000 000; кнопка **0** означает отсутствие ограничений), записанное в ключе, который каждый класс учитывает в игре.

| Классы | Ключ написан |
|---|---|
| `light`, `light_spot` | `_distance`: свет останавливается здесь (модели в игре; компилятор Hammer Pro также затемняет карты освещения за последний квартал). |
| `light_dynamic`, `point_spotlight` | `distance`, `SpotlightLength`: только укорачивается, но никогда не удлиняется. |
| Проп, предметы, оружие и другие классы с клавишами исчезновения, `info_overlay`, `env_detail_controller` | `fademaxdist`, с началом `fademindist`, поэтому они исчезают, а не появляются. Для `env_detail_controller` это применяется ко всем деталям карты. |
| `env_lightglow` | `OuterMaxDist`. |
| `func_lod` | `DisappearMaxDist` и `DisappearMinDist`. |

Логические объекты, триггеры и другие классы, которые игра не может ограничить, пропускаются. В окне показано, сколько сущностей будет изменено, уже установлено и пропущено; **Применить** включается, когда что-то меняется. Результат сообщается в уведомлении.

<a id="entity-help"></a>
## Помощь по сущности

**Справка > Справка по объекту** или **?** в заголовке панели открывает **Справка: класс** для первого выбранного объекта (без выбора : класс инструмента создания объектов). Он показывает тип и описание класса, ссылку **Страница сообщества разработчиков Valve**, фильтр и разделы **Ключи (N)** (имя, ключ, тип, значение по умолчанию, описание), **Флаги (N)**, **Входы (N)** и **Выходы (N)**. `Escape` закрывает его.

<a id="find-entities"></a>
## Найти объекты

**Правка > Найти объекты...** (`Ctrl+Shift+F`) открывает **Найти объекты**.

| Параметр | Описание |
|---|---|
| Режим | **Имя или класс** (текст с поиском `=` `key=value`), **Имя**, **Класс**, **Ключ=значение**. |
| Поле поиска | Текст с подстановочными знаками `*` и `?`. Без подстановочных знаков текст может появляться где угодно. |
| **Только видимый** | Оставляет скрытые объекты вне поля зрения. |
| **Точное совпадение** | Выкл.: текст может появляться в любом месте имени. |
| **Выбрать все результаты** | Выбирает каждый результат. |

Класс списка результатов, имя и происхождение. Дважды щелкните строку (или `Enter` в поле), чтобы выбрать объект и отцентрировать на нем виды. `Escape` закрывает окно.

<a id="find-and-replace-in-entities"></a>
## Найти и заменить в сущностях

**Правка > Найти и заменить в объектах...** (`Ctrl+Alt+R`, `Ctrl+Shift+R` с предустановками клавиш Hammer и Hammer++) открывается **Найти и заменить в объектах**. Он ищет ключевые значения, имена классов и выходные данные (выход, цель, вход, параметр).

| Параметр | По умолчанию |
|---|---|
| **Найти что**, **Заменить** | пустой |
| **Только целые слова** | выкл. |
| **Спичка** | выкл. |
| **Имена клавиш** (также находите и переименовывайте названия клавиш) | выкл. |
| **Вся карта** / **Выбор** | Вся карта |
| **Только видимый** | выкл. |

В строке состояния подсчитываются совпадения, поля и сущности. **Найти следующее** (или `Enter` в поле поиска) переходит к следующему совпадению и выбирает его объект; **Заменить** заменяет текущее поле и движется дальше; **Заменить все** заменяет каждое совпадение за один шаг отмены. Дважды щелкните строку результата, чтобы выбрать ее объект. Двойные кавычки при замене не принимаются.

<a id="entity-report"></a>
## Отчет о сущности

**Карта > Отчет об объектах** содержит список всех объектов: **Класс**, **Имя**, **Сведения** (модель, материал, файл экземпляра или система частиц), **Происхождение**, **Вид**, **Видимый**. Щелкните заголовок столбца для сортировки.

- Фильтр: слова, соответствующие классу, имени и деталям; слово `key=value` соответствует ключу (`*` и `?` разрешены). Каждое слово должно совпадать.
- Тип фильтра (**Все**, **Точка**, **Браш**) и **Скрыть невидимое**.
- Нажмите, `Ctrl+click` и `Shift+click` выберите строки; **Выбрать**, **Перейти** (выбрать и центрировать виды) и **Delete** действовать в соответствии с ними. Дважды щелкните строку, чтобы перейти к ней.

Объекты браши размещаются в центре своих брашов. На картах, содержащих более 3000 объектов, списки обновляются несколько раз в секунду во время редактирования.

|---|---|
| **Файл освещения (lights.rad)** (`_lightsrad`) | Файл текстуры света для этой карты. |

См. [Ключи появления мира] (../compiler/worldspawn-keys.md).

<a id="tips"></a>
## Советы

- Когда файл FGD изменяется на диске, Hammer Pro перезагружает определения объектов в течение нескольких секунд (об этом говорит строка журнала).
- Используйте **Отметить** на целевом ключе, чтобы сразу проверить, каких объектов он достигает.
- Каждая функция здесь доступна через MCP: `get_entity`, `set_entity_keyvalues`, `set_keyvalue`, `set_entity_class`, `set_spawnflags`, `copy_keyvalues`, `set_max_distance`, `find_entities`, `find_text`, `replace_text`, `entity_report`, `get_entity_class`, `get_map_properties`, `set_map_properties`, `set_visgroup_members` и `run_action` для окон. См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="faq"></a>
## Частые вопросы

**Почему мои ключи отображаются в виде обычного текста?** FGD не загружен или класс в нем отсутствует. Проверьте данные игры в **Настройки > Игра** (см. [Настройка игры](../getting-started/game-setup.md)).

**Я выбрал проп и источник света: где остальные клавиши?** При наличии нескольких классов на панели отображаются клавиши, общие для каждого класса. Выберите один класс, чтобы увидеть все его ключи.

**Вставка значений ключей не приводит к изменению класса.** Никогда не происходит: измените класс с помощью кнопки класса, а затем вставьте.

**Установлено максимальное расстояние для пропуска некоторых объектов.** Их классы не имеют расстояния, учитываемого игрой (логические объекты, триггеры, объекты простой браши, спрайты, декали).

**Как удалить ключ?** Щелкните правой кнопкой мыши его ярлык и выберите **Удалить ключ** или используйте **×** на вкладке **Необработанный**.
