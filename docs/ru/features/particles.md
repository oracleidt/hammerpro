# Частицы

Hammer Pro имеет браузер частиц, в котором перечислены все системы частиц смонтированных файлов частиц (`.pcf`), а также предварительный просмотр частиц, который воспроизводит эффекты объектов `info_particle_system` в 3D-представлениях, например Hammer++.

<a id="particle-browser"></a>
## Браузер частиц

<a id="opening-it"></a>
### Как открыть

- **Просмотр > Панели > Браузер частиц** добавляет вкладку **Частицы** в правую док-станцию (или удаляет ее). Сохранено как `show_particle_browser` в `[browser]` (по умолчанию выключено).
- Кнопка обзора ключа частицы (`effect_name` или `info_particle_system`) на панели объектов открывает его в режиме выбора.
- Нет сочетания клавиш по умолчанию. При использовании предустановленной раскладки клавиатуры Hammer++ (**Настройки > Клавиатура**) сочетание клавиш : `Shift+F11`.
- Кнопка `⊞` (**Открыть в окне**) переводит браузер в плавающее окно; `⊟` (**Назад на док**) возвращает его обратно.

<a id="options"></a>
### Параметры

| Контроль | Описание | По умолчанию |
|---|---|---|
| **Сетка** / **Список** | Сетка миниатюр или одна строка на систему с небольшим эскизом, файлом частиц и значком источника. Оставил до сессии. | Сетка |
| Ползунок размера плитки (только сетка) | **Размер плитки** частиц и сетки модели: от 48 до 256 точек с шагом 8. `tile_size` в `[browser]`. | 96 |
| **Поиск по системам частиц (кроме !word)** | Сохраняет системы, имя или файл которых содержит каждое слово; `!word` исключает. | |
| Раскрывающийся список файлов частиц | **Все файлы частиц** или системы одного файла. | Все |
| Source фишек **Все**, **Игра**, **Дополнения**, **Мастерская** | Держите системы одного вида источника (фишка появляется только тогда, когда она есть в контенте). | Все |
| **Только контент Garry's Mod** | Только то, что есть у каждого игрока Garry's Mod. Совместно используется с моделью и звуковыми браузерами (`gmod_only` в `[browser]`). | Выкл. |
| **Системы: Нет** | Количество перечисленных систем («Чтение файлов частиц...» во время их загрузки). | |

Миниатюры показывают материал системы (`?`, когда его нет или он отсутствует). Наведите курсор на систему, чтобы увидеть ее имя, файл, материал и источник.

<a id="using-a-system"></a>
### Использование системы

- Щелчок выбирает систему.
- Двойной щелчок (или `Enter`, когда указатель находится над списком): в режиме выбора записывает систему в ключ; в противном случае устанавливает его для выбранных объектов `info_particle_system`.
- Нижний колонтитул: выбранное имя, его файл и источник, **Применить к выбранному (N)** (устанавливает систему как `effect_name` из выбранных `info_particle_system` объектов, один шаг отмены) и **Копировать имя**.

<a id="picking-for-a-key"></a>
### Выбор для ключа

Ключ частиц на панели объектов (см. [Свойства объекта](entity-properties.md)) имеет кнопку `▾`, в которой перечислены системы частиц игрового контента с их файлом (доступны для поиска, и вы можете ввести значение, которого нет в списке), и кнопку обзора («Выбрать в браузере частиц (дважды щелкните систему)»).

В режиме выбора браузер отображает «Выбрать для *ключа*: дважды щелкните элемент или выберите его и нажмите «Использовать». с выбранным текущим значением. Двойной щелчок, `Enter` или **Использовать** записывает систему (один шаг отмены) и возвращает на вкладку **Объект**; **Отмена** выходит из режима выбора.

<a id="particle-preview-in-the-views"></a>
## Предварительный просмотр частиц на видах

<a id="turning-it-on"></a>
### Включение

| Параметр | Где | Описание | По умолчанию |
|---|---|---|---|
| **Показать частицы** | **Вид > Параметры отображения** и **Настройки > Навигационная сетка и частицы** | Воспроизводит эффекты объектов `info_particle_system` рядом с камерой в 3D-видах. `show_particles` в `[lab]`. | Вкл. |
| **Только выбранные частицы** | Те же места | Воспроизводит только эффекты выбранных систем частиц. `particles_selected_only` в `[lab]`. | Выкл. |
| **Предварительный просмотр объёмных эффектов** | Те же места | Текстурированное анимированное воспроизведение `func_smokevolume`, `env_embers`, `func_dustcloud` и `func_dustmotes` (см. ниже). `show_entity_fx` в `[lab]`; действие `toggle_entity_fx`. | Вкл. |

<a id="what-plays"></a>
### Что играет

- Определения берутся из файлов частиц смонтированного контента: сначала файлы манифеста частиц карты (`maps/<map>_particles.txt`), затем каталог частиц контента. Они читаются в фоновом режиме, по внешнему виду их материалов (`$additive`, `$overbrightfactor`, `$addself`, размеров затухания, листа спрайтов базовой текстуры). Дочерние системы тоже загружаются.
- Каждый эффект воспроизводится в любом своем начальном состоянии (`start_active`) в своих контрольных точках: самом объекте с его углами и объектах, названных его клавишами от `cpoint1` до `cpoint63`. Непрерывные эффекты начинают работать уже с опережением на 1,5 секунды.
- Воспроизводятся эффекты в пределах 4096 единиц от камеры, не более 24 одновременно, начиная с ближайших. Каждая система PCF сохраняет `max_particles` до игрового предела 5 000; родительская и дочерние системы используют общий бюджет эффекта. Браузер и редактор частиц используют тот же предел на систему. Для проверки плотного эффекта на тяжелой карте включите показ частиц только выделенных систем.
- `Color Lit Per Particle` использует скомпилированное или рассчитанное освещение карты в позиции каждой частицы; `Color Random` может брать оттенок в выбранной контрольной точке. Без рассчитанного освещения используется полная яркость. Новый расчет обновляет кэш оттенков для новых частиц без перезапуска существующих.
- `Cull relative to Ray Trace Environment` использует физические объёмы объектов `func_precipitation` с частицами и `func_precipitation_blocker` отдельно от обычных проверок столкновений. В редакторе эти объёмы рассчитываются из брашей; в режиме игрока для скомпилированной карты они читаются из физики BSP. Крыши из геометрии мира не добавляются в эти именованные окружения трассировки.
- Размещение на модели использует набор хитбоксов объекта, связанного с выбранной контрольной точкой. `Movement Lock to Bone` следует отображаемой позе, включая позы симулятора физики; связанные модели загружаются до запуска эффекта. `Position In CP Hierarchy` учитывает связи `cpointN_parent`, рост, изгиб и смещение распределения. Размещение вдоль пути использует квадратичные кривые Безье и ориентацию выбранной контрольной точки.
- `Noise Scalar` и `Noise Vector` вычисляют нативный пространственный шум в мировой позиции каждой частицы с учётом масштаба координат и аддитивного режима. У неподвижной частицы значение шума не меняется с возрастом; векторный шум использует нативные смещения каналов. `Velocity Noise` учитывает время создания частицы, пространственные и временные смещения, абсолютное значение и инверсию по каждой оси, а также локальную ориентацию выбранной контрольной точки.
- `Remap Noise to Scalar` и `Lifetime Pre-Age Noise` используют пространственный и временной шум с параметрами абсолютного значения и инверсии. Начальные значения задаются до модификаторов, поэтому предварительный возраст учитывает уже заданное время жизни и может достигать 100%. Для каждого атрибута используется первый базовый инициализатор; затем модификаторы выполняются в исходном порядке.
- При непрерывной эмиссии время рождения частиц распределяется внутри каждого кадра. `emit noise` использует временной шум Source и начальную частицу; учитываются коэффициенты контрольных точек и количества родительских частиц. Рождения, отклонённые из-за заполнения системы, отбрасываются и не накапливаются для последующего всплеска.
- Частицы рисуются средством рендеринга с рамкой листа спрайтов, выровнены по экрану, вертикальны, плоские или растянутые (следы, веревки), смешанные или аддитивные. Предварительный просмотр является приблизительным: некоторые операторы системы частиц не моделируются.
- В [просмотре игрока](player-view.md) со скомпилированным миром вместо этого воспроизводятся системы частиц скомпилированной карты.

Наведите указатель мыши или выберите `info_particle_system` в 3D-виде, чтобы увидеть над ним название эффекта с его состоянием: ничего больше при воспроизведении, «(не воспроизводится: слишком далеко или слишком много)», «(загрузка...)» или «(не найдено в файлах частиц)».

<a id="volume-effects-in-the-views"></a>
## Эффекты объема в видах

`func_smokevolume`, `env_embers`, `func_dustcloud` и `func_dustmotes` являются брашевыми сущностями, которые отрисовывает движок игры. **Предпросмотр объемных эффектов** приближенно воспроизводит их в 3D-видах по границам видимых брашей и подключенным материалам. Точечная сущность без брашей не имеет корректного объема и не отображает такой эффект. Выделение сущности работает обычным образом.

Этим четырем эффектам нужны границы брашей в мировых координатах. Сохранение и экспорт исправляют старый `origin` в центре браша, не перемещая объем; начала координат поездов и положения точечных сущностей сохраняются. После обновления затронутой карты сохраните ее и один раз выполните **полную компиляцию геометрии**, в том числе при использовании внешнего компилятора. Обновление только сущностей не исправляет границы, уже записанные в старый BSP. Материалы эффектов включаются в подготовку ресурсов и список для упаковки.

| Сущность | Используемые ключи | Спрайт | Смотри |
|---|---|---|---|
| `func_smokevolume` | `Color1`, `Color2` (каждая затяжка выбирает цвет между собой), `ParticleDrawWidth` (размер затяжки), `ParticleSpacingDistance` (затяжки располагаются на сетке с таким интервалом), `Density` (непрозрачность), `MovementSpeed` (качание), `RotationSpeed` (вращение), `Material` | `particle/particle_smokegrenade` (или клавиша `Material`) | Мягкие затяжки на сетке, медленно поворачивающиеся и покачивающиеся |
| `env_embers` | `rendercolor`, `renderamt`, `density` (искры в секунду), `lifetime`, `speed` | `particle/fire` | Маленькие искры по направлению углов, размер от 1 до 0; необязательное влияние env_wind |
| `func_dustcloud` | `Color`, `SizeMin`, `SizeMax` (половинный размер спрайта), `SpawnRate`, `LifetimeMin`, `LifetimeMax`, `SpeedMax` (случайная скорость по каждой оси), `FallSpeed`, `Alpha`, `DistMax` | `particle/sparkles` | Крупные спрайты с затуханием по времени и расстоянию; могут покидать браш |
| `func_dustmotes` | Те же ключи | `particle/sparkles` | Спрайты с размером по глубине и единицами motes движка Source |

Значения по умолчанию берутся из FGD. `env_embers` без имени включается сразу; именованной сущности нужен **Start On** (флаг 1) или вход во время игры. Пыль учитывает `StartDisabled` и `Frozen`; игровые входы и выходы не моделируются. Явно заданное имя `Material` сохраняется даже при отсутствии материала, чтобы стандартная замена не скрывала ошибку. Для встроенных спрайтов возможна известная резервная замена. Предпросмотр ограничен 24 ближайшими эффектами, 2048 частицами на эффект (2048 клубами дыма), 8192 частицами всего и расстоянием 3072 единицы либо меньшим `DistMax`. Скрытые браши не формируют объем предпросмотра. Игра использует исходную плотность и интервал, поэтому очень малый интервал дыма может требовать гораздо больше ресурсов, чем ограниченный предпросмотр.

<a id="wind-from-env_wind"></a>
### Ветер от env_wind

Если включен **Эффекты предварительного просмотра**, `func_dustmotes` и `func_dustcloud` реагируют на контроллеры `env_wind` карты. Чтобы эффект появился, **Влияние ветром** должно быть включено (по умолчанию включено для пылинок), **Заморозка** должна быть отключена, а **Запуск отключен** должен быть выключен. Отключение **Affected By Wind** сохраняет собственное случайное движение и скорость падения объекта.

| настройка env_wind | Предварительный просмотр |
|---|---|
| **Углы** | Начальное горизонтальное направление ветра; используется рыскание |
| **Min/Max нормальная скорость** | Базовая скорость ветра между порывами |
| **Min/Max скорость порыва** | Скорость во время порывов ветра |
| **Min/Max задержка порыва** | Случайное время между порывами ветра |
| **Продолжительность порыва** | Продолжительность каждого порыва |
| **Максимальное изменение направления порыва** | Изменение направления при начале порывов ветра |
| **Радиус** | `-1` влияет на всю карту; положительный радиус влияет на частицы внутри этой сферы |

Местные диспетчеры имеют приоритет в пределах своего радиуса действия; в противном случае используется первый глобальный контроллер. Скрытые контроллеры исключены. Редактирование контроллера или параметров затронутого объекта напрямую обновляет предварительный просмотр. Пыль ускоряется навстречу текущему горизонтальному ветру, сохраняя при этом скорость вертикального падения. Это соответствует поведению реакции на ветер в [Source SDK](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/client/c_func_dust.cpp).

При выборе `env_wind` отображается анимированная стрелка направления и ее текущая скорость в трехмерном представлении с надписью **Нормальный ветер** или **Порыв**. Существующие помощники радиуса показывают область контроллера. В предварительном просмотре используется детерминированная последовательность порывов ветра, а не случайная последовательность целевой игры, и не выполняется объект I/O..

Веревки карты (`move_rope` и `keyframe_rope`) также реагируют, когда включены **Показать веревки** и **Имитировать веревки**, если только не включен параметр **Отключить ветер**. Моделирование ветра ограничено узлами веревки в пределах 1000 единиц от камеры. `func_smokevolume` сохраняет собственное движение. Искры `env_embers` следуют ветру при `AffectedByWind` = 1. Операторы систем частиц ограничены возможностями симулятора предпросмотра.

Через MCP используйте `get_entity` и `set_entity_keyvalues` для чтения или изменения контроллера и клавиши `AffectedByWind`, `Frozen` и `NoWind`. `set_setting` управляет `lab.show_entity_fx`, `helpers.show_ropes` и `helpers.simulate_ropes`.

<a id="particle-preview-window"></a>
## Окно предварительного просмотра частиц

Кнопка `▶` рядом с полем **Имя системы частиц** (`effect_name`) `info_particle_system` (также **Просмотр > Панели > Предварительный просмотр частиц...**, действие `particle_preview`) открывает окно с:

- поле поиска (все слова должны присутствовать в имени или файле; `!word` исключается) и список каждой системы индекса контента и файлов частиц с соответствующим файлом во всплывающей подсказке;
- просмотр выбранной системы в реальном времени, воспроизведенный из реального файла частиц с той же симуляцией, тем же рендерером и теми же спрайтами, что и 3D-просмотры (закадровый рендеринг рендерера, показанный в виде изображения, не более 400 частиц): текстурированные спрайты, аддитивное и альфа-смешение, рамки листов спрайтов, следы и веревки. Перетащите на орбиту, прокрутите для увеличения, дважды щелкните, чтобы сбросить настройки камеры. Контрольные точки находятся в начале координат без углов, как `info_particle_system` без клавиш `cpoint`. Под ним находятся **Пауза**/**Воспроизведение**, **Перезапуск** и **Поворот** (автоматическое вращение), количество частиц и операторы не моделируются. Открытие его с помощью действия `particle_preview`, когда выбрано `info_particle_system`, начинается с его эффекта;
- **Назначить N объектам** (или **Использовать для этого поля** при открытии из поля): записывает имя в ключ (один шаг отмены). Двойной щелчок по системе делает то же самое. **Копировать имя** копирует его.

Закрытие окна во время ожидания выбора отменяет этот выбор.

<a id="integrated-particle-editor"></a>
## Встроенный редактор частиц

Откройте **Другое > Редактор частиц** (действие `particle_editor`). Этот редактор создает и изменяет системы внутри файла PCF. Браузер частиц и его меньшее окно предварительного просмотра остаются доступными для выбора существующих игровых эффектов.

<a id="files-and-systems"></a>
### Файлы и системы

**Новый** создает пустой документ. **Открыть PCF** читает внешний файл. Поле пути принимает абсолютный путь или смонтированный путь, например `particles/fire_01.pcf`; **Загрузить** открывает его, а **Подключено PCFs** выводит список проиндексированных файлов игры, отфильтрованных по полю пути. Открытие смонтированного файла не перезаписывает архив игры: выберите внешний путь с помощью **Сохранить как**. Диалоговые окна файлов и папок запускаются независимо от окна редактора.

Левая панель фильтрует системы по названию. Выберите систему, чтобы отобразить ее свойства, операторов и дочерних элементов. Enter имя и используйте **Создать** или **Переименовать**; **Дублировать** копирует систему и ее граф операторов под уникальным именем. **Delete** удаляет систему и ее дочерние ссылки. Документ имеет собственную историю **Отмены** и **Повторить**, отдельную от редактирования карты. Используйте строку заголовка X или кнопку **Закрыть** на панели инструментов, чтобы закрыть редактор. Закрытие, замена или очистка несохраненного документа открывает модальное окно на переднем плане с вопросом, следует ли отменить изменения. Отмена, Escape или нажатие за пределами подсказки возвращает к редактированию без потери изменений. Выбор **Отменить изменения** при закрытии восстанавливает последний сохраненный документ (или пустой документ для нового файла), очищает отброшенную историю изменений и закрывает редактор. При выходе из Hammer Pro повторно не запрашиваются отмененные изменения и не открывается редактор повторно. Звездочка в заголовке окна отмечает несохраненные изменения, а возврат к сохраненному состоянию очищает их.

При сохранении записывается двоичный файл DMX версии 5. В документе сохраняются идентификаторы элементов, ссылки на элементы, порядок операторов, типизированные атрибуты, внешние ссылки и полезные данные двоичных атрибутов, а не перестройка файла из подмножества, понятного в предварительном просмотре. Таким образом, при открытии и сохранении файла сохраняются операторы, которые не реализованы в предварительной версии. Неверные ссылки, недопустимые значения и файлы, размер которых превышает предельный размер PCF, отклоняются.

<a id="operators-and-parameters"></a>
### Операторы и параметры

В каждой системе есть группы **Эмиттеры**, **Инициализаторы**, **Операторы**, **Генератор силы**, **Ограничения** и **Рендереры**. Библиотека операторов предоставляет общие функции Source и их начальные параметры. Открытие или импорт PCF также добавляет определения операторов в библиотеку сеанса. Имя функции можно ввести напрямую, чтобы добавить еще один оператор Source.

Выберите оператор в дереве, чтобы редактировать каждый сохраненный параметр, включая его `functionName`. **Проверить ссылочный элемент** следует за вложенными ссылками на элементы DMX в их собственные свойства. **Копировать** и **Вставить** операторы копирования между системами. **Переместить вверх**, **Переместить вниз** или перетащить строку на другую строку в той же категории меняет порядок выполнения. Каждая операция поддерживает отмену. Добавляйте или удаляйте параметры, используя их точные имена Source; неизвестные параметры сохраняют свои значения и типы.

| Тип параметра | Редактор |
|---|---|
| Целое число, число с плавающей запятой, логическое значение, строка | Числовой элемент управления перетаскиванием, флажок или текстовое поле |
| Цвет | Выбор цвета и альфа-канала |
| Вектор 2, 3 или 4 | Отдельные числовые компоненты |
| Ссылка на элемент | Раскрывающийся список элементов документа, включая пустую ссылку |
| Массивы | Индексированные значения с вставкой и удалением |
| Плавающие массивы | Числовые значения и перетаскиваемая кривая |
| Цветовые массивы | Цветовые остановки и предварительный просмотр градиента |
| Углы, кватернион, матрица | Числовые компоненты, сохраняющие исходный тип DMX. |
| Другие двоичные типы | Редактор шестнадцатеричных полезных данных, сохраняющий тип DMX. |

Изменения в числовых и текстовых элементах управления фиксируются, когда заканчивается редактирование жеста или поля, поэтому отмена возвращает значение до редактирования. Сохранение и замена документа фиксируют ожидающие изменения перед обработкой действия. Minimum/maximum несоответствия, неверные индексы контрольных точек и другие проблемы появляются в **Проверке**.

Для известных операторов Source используются типы параметров, ожидаемые игрой. Например, `use animation rate as FPS` имеет логический тип, а `spin_rate_degrees` является целым числом. Числовые значения преобразуются только тогда, когда подходят требуемому типу; неоднозначные значения отклоняются без изменения документа. Проверка сообщает о неверных типах в импортированных файлах, не переписывая их параметры. Неизвестные параметры сохраняются.

Операторы `radius scale` и `alpha fade and decay` также имеют перетаскиваемые маркеры lifetime/value, которые редактируют их фактическое время Source и поля scale/alpha. Оператор `color fade` показывает градиент от базового цвета системы к цвету затухания. Отдельные параметры Source остаются доступными для редактирования под этими элементами управления.

Свойства системы включают материал, максимальное и начальное количество частиц, радиус, цвет и ограничивающую рамку. Используйте **Выбрать материал спрайта** рядом с полем материала, чтобы найти смонтированные материалы и выбрать их эскизы. Для предварительного просмотра используются существующий шейдер Source и лист текстуры материала.

**Дочерние системы** связывают другую систему в документе с задержкой запуска. Выберите дочернюю строку, чтобы изменить ее ссылку, настройки задержки и окончания или удалить ее. Циклические дочерние графы отклоняются. Другие параметры контрольной точки и оператора редактируются через сохраненные в них поля.

<a id="live-preview"></a>
### Предварительный просмотр в реальном времени

Правая панель использует ту же симуляцию частиц и рендерер GPU, что и 3D-вид карты. Он отображает выбранную систему и ее дочерние элементы с установленными спрайтовыми материалами, смешиванием alpha/additive, кадрами анимации, следами и веревками, поддерживаемыми этим средством визуализации.

Перетащите на орбиту, прокрутите для увеличения и дважды щелкните, чтобы восстановить камеру. **Pause/Play**, **Перезапуск**, скорость воспроизведения от 0,05x до 4x, **Сетка** и управление цветом фона влияют только на предварительный просмотр. Добавьте контрольные точки, введите их координаты или перетащите их маркеры CP на холст. Статистика показывает количество частиц и измеренное время моделирования CPU. Предварительный просмотр ограничивает активные частицы на уровне 30 000 и отображает предупреждение при достижении ограничения.

Редактор PCF может сохранять и редактировать больше операторов, чем позволяет симуляция. На панели предварительного просмотра и проверки явно перечислены функции, которые не моделируются. Такие функции по-прежнему сохраняются для Source; сохраненный эффект необходимо проверить в целевой игре, прежде чем считать его окончательным. Средство визуализации модели или экранного пространства не преобразуется в приблизительный средство визуализации спрайтов.

<a id="templates-importing-and-addon-export"></a>
### Шаблоны, импорт и экспорт дополнений

Шаблоны **Огонь**, **Дым**, **Искры**, **Дождь** и **Взрыв** добавляют в текущий документ редактируемые системы. При повторном импорте используются уникальные системные имена. **Импортировать системы** считывает другой PCF, копирует его системы и переназначает ссылки на их графы.

**Экспорт аддона** выбирает корень аддона и записывает `particles/<file>.pcf` плюс `particles/particles_manifest.txt`. Существующие записи манифеста сохраняются. Окно регистрации предоставляет вызовы `game.AddParticles` и `PrecacheParticleSystem`, которые можно скопировать в Lua аддона. При экспорте PCF материалы спрайтов не упаковываются: они должны существовать в игровом контенте или быть включены в дополнение.

**Назначить выбору** записывает имя выбранной системы в `effect_name` выбранных `info_particle_system` объектов или в поле ожидающих частиц. Смена карты : это один шаг отмены карты. Save/export отредактированный PCF и сделайте его доступным для игры, чтобы туда можно было загрузить названный эффект.

<a id="mcp-access"></a>
### Доступ к MCP

| Инструмент | Цель |
|---|---|
| `get_particle_document` | Чтение текущего документа, систем, введенных параметров и состояния редактора. |
| `list_particle_operators` | Откройте для себя категории операторов, имена функций и параметры по умолчанию. |
| `particle_editor` | Выполнение операций с файлом, системой, оператором, параметром, дочерним элементом, историей, предварительным просмотром и назначением. |
| `capture_particle_preview` | Захватите предварительный просмотр живого редактора через общий рендерер GPU. |

Операции `particle_editor` включают в себя `new`, `open`, `read`, `import`, `save`, `export`, `validate`, `create`, `rename`, `duplicate`, `delete`, `select`, `preset`, `add_operator`, `remove_operator`, `move_operator`, `copy_operator`, `paste_operator`, `set_parameter`, `remove_parameter`, `add_child`, `remove_child`, `undo`, `redo`, `preview` и `assign`. Они используют тот же документ и отменяют историю, что и окно. Используйте [сгенерированную ссылку MCP] (../../MCP.md) для текущей схемы аргументов и поддерживаемых типов значений. Редактор должен быть открыт и обработан перед сохранением его предварительного просмотра.

## Советы

- На карте с множеством эффектов включите параметр **Только выбранные частицы**, чтобы просматривать по одному эффекту за раз.
- Через MCP `toggle_entity_fx` и `particle_preview` (`run_action`), `lab.show_entity_fx` (`set_setting`), `search_particles` выполняет поиск в системах контента и `list_particle_systems` сообщает о состоянии каждого `info_particle_system` карты (см. [MCP ссылка на инструмент](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Эффект говорит: «Не найден в файлах частиц».** Ни один смонтированный файл частиц не определяет это имя. Проверьте правильность написания, смонтируйте игру или аддон, в котором он есть, или добавьте его файл в манифест частиц карты.

**Эффект не воспроизводится, хотя он находится в поле зрения.** Он находится на расстоянии более 4096 единиц или уже воспроизводятся 24 более близких эффекта. Пододвиньте камеру ближе.

**Почему в браузере ничего не отображается?** Контент игры не загружается, либо поиск, фильтр файлов, исходные чипы или **Только контент Garry's Mod** скрывают все.

### Воспроизведение затемнения

Выберите один `env_fade` и нажмите **Воспроизвести** над свойствами. Предпросмотр действует в 3D-видах и учитывает `rendercolor`, `renderamt`, `duration`, `holdtime`, **Fade In** и **Modulate**. Fade In сначала удерживает цвет, затем убирает его; Fade Out сначала набирает цвет, затем удерживает его. Воспроизведение автоматически заканчивается после duration + holdtime, даже с **Stay Out**. **Остановить** сразу убирает эффект. Карта и выходы не изменяются. Смена карты, удаление или скрытие сущности убирают видимый эффект.

### Управление тенями

Видимый `shadow_control` показывает проецируемые тени моделей в текстурированных и освещенных 3D-видах. Используются углы (либо старая direction), цвет, distance и `disableallshadows`. Солнце не требуется, окружение освещения не меняется. Скрытые модели и модели с отключенными тенями их не отбрасывают. Предпросмотр с картой теней приближает результат Source, но не повторяет его метод render-to-texture полностью.

### Струи пара и точность

`env_steam` и старая `env_steamjet` используют **Initial State** (`InitialState`): по умолчанию в игре **Off** (0), для немедленного испускания **On** (1). **Emissive** (флаг 1) независимо управляет освещением. Учитываются углы, цвет/альфа, Speed, SpreadSpeed, JetLength, Rate, StartSize, EndSize и RollSpeed.

**Heat Wave** (`type` 1) использует `sprites/heatwave`, карту нормалей материала, знаковый `$refractamount`, `$bluramount` и `$nofog` для преломления сцены за струей. Глубина объектов перед струей проверяется с MSAA и без него. Проверяйте преломление в 3D-виде карты: изолированный браузер содержит только однотонный фон.

Дым и обычный пар используют свет сцены в освещенном виде и видах со скомпилированным освещением; **Emissive** прибавляет их цвет к свету. Другие режимы сохраняют вид для редактирования. Пыль и пылинки используют глубину по оси камеры для затухания и размера пылинок. Частицы PCF и сущностей сортируются вместе по глубине; альфа материала применяется один раз. Если позволяет бюджет, количество не уменьшается только из-за удаления камеры.

Искры затухают по цвету, альфе и размеру, не вращаются и постепенно замедляются. Дым учитывает ширину, непрозрачность и затухание у камеры; пыль может покидать браш и учитывает нулевые размер, частоту и альфу. Бюджеты, случайные последовательности, обмен частицами дыма, столкновения и неподдерживаемые операторы PCF могут отличаться; проверяйте итог в игре.
