# Префабы

Префаб : это фрагмент карты, сохраненный в виде файла VMF (лестница, осветительный прибор, торговый автомат с его объектами), который вы вставляете столько раз, сколько захотите. В отличие от [экземпляра](instances.md), вставленный префаб становится обычным объектом вашей карты. Вкладка **Префабы** : это ваша библиотека префабов с папками, поиском и миниатюрами.

<a id="opening-it"></a>
## Как открыть

| Действие | Меню | Сочетание клавиш по умолчанию |
| --- | --- | --- |
| Вкладка «Префабы» | **Просмотр > Панели > Префабы** | нет |
| **Создать префаб...** | **Инструменты > Размещение и пропы > Создать префаб...** | `Ctrl+R` |
| **Вставить сборный блок в исходном размере** | **Инструменты > Размещение и пропы > Вставить префаб в исходном размере** | `Alt+Shift+C` |

<a id="the-library"></a>
## Библиотека

На вкладке перечислены файлы `.vmf` папок сборных файлов, сканированные в фоновом режиме. Подпапки : это категории. Папки:

| Корень | Где | записываемый |
| --- | --- | --- |
| **Мои префабы** | Папка библиотеки: `%APPDATA%\HammerPro\prefabs` по умолчанию или папка, выбранная в настройках. | Да |
| **Папка сборных** | Каждая дополнительная папка добавляется в настройках. | Нет |
| Игра (**Garry's Mod**) | Папки префабов Hammer для установки игры (`bin/prefabs`, `bin/win64/prefabs`). | Нет |

Tab элементы управления:

| Контроль | Описание |
| --- | --- |
| **+** | **Создать префаб из выделенного...** (то же самое, что `Ctrl+R`). |
| Обновить | **Сканируйте папки сборных еще раз**. |
| Папка | **Откройте мою папку с префабами**. |
| Слайдер | **Размер плитки** (от 56 до 192 точек). |
| **Поиск префабов...** | Фильтрует плитки по имени. |
| Список категорий | **Все префабы** или одна папка. |
| Граф | «N из M префабов» (в очень больших папках отображаются только первые файлы). |

На каждой плитке отображается миниатюра, нарисованная в фоновом режиме и кэшированная на диске, поэтому в следующий раз вкладка откроется мгновенно. В подсказке указаны имя, категория и путь.

| Жест на плитке | Описание |
| --- | --- |
| Нажмите | Выбирает префаб (для **Вставить префаб исходного размера**). |
| Двойной щелчок | Активирует префаб для [инструмента сущности] (entity-tool.md). |
| Перетащите в вид | Вставляет его туда, куда вы его бросили. |
| Щелкните правой кнопкой мыши | **Поместить с помощью инструмента создания объектов**, **Вставить в исходном размере**, **Показать в папке**. |

<a id="inserting-a-prefab"></a>
## Вставка префаба

- **Вставить префаб исходного размера** (`Alt+Shift+C`): выбранный на вкладке префаб размещается в центре 2D-вида в исходном размере (его глубина сохраняется).
- **Инструмент объекта**: после двойного щелчка (или **Поместить с помощью инструмента объекта**) инструмент объекта размещает префаб до тех пор, пока вы не нажмете `Escape`. В 3D-виде щелчок помещает его на поверхность под курсором в исходном размере. В 2D-виде щелчок центрирует его в точке сетки, а перетаскивание вставляет его в масштабе нарисованного вами прямоугольника. Смещения привязываются к сетке, поэтому префабы, построенные на сетке, остаются на ней. На панели параметров отображается **Префаб:** с его размером, флажок **Группировать** и **Вернуться к объектам** («Снова разместить объекты вместо префаба (Escape)»).
- **Перетащите** с вкладки в представление.

Каждая вставка представляет собой один шаг отмены «Вставить префаб». Объекты получают новые идентификаторы, группируются, когда включена опция **Группировать вставленные префабы** (если они уже не образуют одну группу), и выбираются.

<a id="the-i-token"></a>
### Токен `&i`

Напишите `&i` в именах внутри префаба (например, `door_&i` и выходной таргетинг `door_&i`). Каждая вставка заменяет каждый `&i` в значениях ключей и выходных данных (имена, родительские имена, цели, выходные параметры) числом, уникальным на карте, поэтому каждая копия имеет свои собственные имена, а имена, указывающие за пределы префаба, остаются такими, какие они есть.

<a id="creating-a-prefab"></a>
## Создание префаба

Выберите объекты и нажмите `Ctrl+R`. В окне **Создать префаб** появится запрос:

| Поле | Описание |
| --- | --- |
| **Имя:** | Имя файла префаба. |
| **Папка:** | Папка вашей библиотеки, **(библиотека)** для ее корня, **или новая папка** (подпапки с `/`). Создается при необходимости. |
| **Заменить существующий префаб** | Отображается, когда имя существует. |

**Сохранить** записывает VMF в фоновом режиме (атомарная запись). Имена и папки не могут содержать `\ / : * ? " < > |` или зарезервированные имена.

<a id="options"></a>
## Параметры

**Инструменты > Параметры... > Префабы** (`[placement]` в `settings.toml`):

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Показать вкладку «Префабы»** (`show_prefabs`) | Показывает вкладку в правой доке. | Вкл. |
| **Папка библиотеки:** (`prefab_library`) | Где сохраняются новые префабы. **Обзор...**, **Использовать папку по умолчанию**. | `%APPDATA%\HammerPro\prefabs` |
| **Больше сборных папок (только чтение):** (`prefab_dirs`) | Дополнительные папки указаны только для чтения. **Добавить папку...**, удалить крестиком. | Нет |
| **Перечислите префабы Garry's Mod** (`game_prefabs`) | Перечисляет папки префаба Hammer для установки игры, только для чтения. | Вкл. |
| **Группировать вставленные префабы** (`group_prefabs`) | Объекты каждого вставленного префаба образуют группу. | Вкл. |
| Размер плитки (`prefab_tile`) | Размер тайлов от 56 до 192. | 96 |

<a id="tips"></a>
## Советы

- Префабы из Hammer (игровой номер `bin/prefabs`) работают как есть.
- Создавайте префабы на сетке рядом с началом координат: вставки привязывают свое смещение к сетке.
- Инструменты MCP: `list_prefabs`, `insert_prefab`, `create_prefab` (см. [Справочник по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Префаб или экземпляр?** Префаб копируется на вашу карту и затем живет самостоятельно. [Экземпляр](instances.md) остаётся связанным со своим файлом: отредактируйте файл, и каждая его копия изменится.

**Мой новый префаб не отображается.** Библиотека сканируется в фоновом режиме; нажмите кнопку обновления, если вы добавили файлы вручную.

**Две копии моего префаба запускают выходные данные друг друга.** Используйте `&i` в именах, чтобы каждая копия получила уникальные имена.
