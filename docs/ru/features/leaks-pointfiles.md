# Утечки и файлы точек

Утечка : это путь от сущности к пустоте за пределами карты: компилятор не может отличить внутреннее от внешнего, поэтому видимость и освещение ухудшаются. Hammer Pro находит утечки во время редактирования (мгновенная проверка утечек), загружает файл точек компиляции, проводит вас по пути утечки и показывает порталы и видимость карты, чтобы вы могли ее оптимизировать. Он также может запечатать дверной проем с помощью портала.

<a id="the-instant-leak-check"></a>
## Мгновенная проверка на утечку

Во время редактирования заливка, подобная компилятору, ищет утечки в фоновом режиме без компиляции (настройка **Искать утечки при редактировании** включена по умолчанию). Когда он находит такую ​​утечку, в строке состояния отображается красный значок **Утечка**, а путь отображается в представлениях (настройка **Нарисовать путь найденной утечки** включена по умолчанию). Компиляция остается ссылкой.

Мгновенная проверка быстрая, но работает с приближением карты, поэтому никогда не рисует утечку сама по себе: когда она находит утечку, та же заливка, что и при настоящей компиляции (порталы компилятора), проверяет карту до появления значка и пути. Если компилятор считает карту герметичной, утечки нет (щели тоньше того, что сохраняет компилятор, например крошечные зазоры углового соединения вне сетки, не протекают). Если карта действительно протекает, рисуется путь компилятора, а его подпись: **Утечка (заливка компилятора)**. Новая правка останавливает еще идущую проверку компилятора, поэтому большие карты не тратят время на устаревшую проверку. Как и в компиляторе, браши с материалом с альфа-тестом, полупрозрачным или нетвердым (решетки, лестницы, стекло) не герметизируют карту. Когда кордоны активны и включен параметр компиляции `compile_cordon_only` (по умолчанию), проверка смотрит только внутри коробок кордона, закрытых так же, как при компиляции. Инструмент MCP `get_leak` отвечает `compiler_checked`, когда решение принял компилятор.

**Карта > Проверить наличие утечек** запускает проверку сейчас, а затем:

- *Утечка карты: сущность N (класс) достигает пустоты (всего M сущностей). Его путь отображается в представлениях.* Протекающий объект выбирается, и виды центрируются по нему.
- *Утечек нет: карта запечатана (проверено за N мс)*.
- *Ни одна мировая браш пока не запечатывает карту: проверять нечего*.
- *Карта слишком сложна для мгновенной проверки утечек: скомпилируйте ее, чтобы найти утечки*.

Щелчок по значку **Утечка** в строке состояния делает то же самое.

<a id="pointfiles-of-a-compile"></a>
## Файлы точек компиляции

Когда при компиляции обнаруживается утечка, компилятор записывает файл точек (`<map>.lin`). При выборе **Загружать файл точек утечки автоматически** (Настройки > Компиляция, включено по умолчанию) он загружается в конце компиляции и выбирается объект утечки. Окно компиляции также может останавливаться сразу после утечки геометрии (**Остановка при утечке карты**, см. [Окно компиляции](../compiler/compile-window.md)).

| Команда | Описание |
| --- | --- |
| **Карта > Утечки и видимость > Загрузить файл точек утечки...** | Загружается `<map>.lin`, иначе `<map>.pts`, рядом с картой или в папке сборки (`.hammerpro_build`). Без него запрашивается файл (фильтр **Leak pointfile**, `.lin` и `.pts`). |
| **Карта > Утечки и видимость > Выгрузить файл точек** | Удаляет путь из представлений. |
| Перетащите файл `.lin` или `.pts` в окно. | Загружает. |

Загруженный файл точек заменяет путь мгновенной проверки в представлениях. Когда объект утечки удаляется, путь выгружается (*Утечка объекта исчезла: путь утечки выгружен. Скомпилируйте еще раз, чтобы проверить, что карта запечатана.*).

<a id="the-leak-path-navigator"></a>
## Навигатор пути утечки

Загруженный файл точек открывает небольшое плавающее окно **Путь утечки: N точек**, в котором камера движется по пути так, как вы устраняете утечку: точка 1 : это объект утечки, а **Следующая** движется к пустоте.

| Контроль | Описание |
| --- | --- |
| **Точка N от M** | Где ты находишься на пути. |
| **Предыдущий** | Предыдущий пункт, к утекающей сущности. |
| **Далее** | Следующий пункт, в сторону пустоты. |
| **Посмотрите на текущий момент** | Перемещает 3D-камеру для просмотра точки. |
| **Выгрузить** | Выгружает файл точек. |

Представления обозначают концы пути: **Начало утечки: сущность** и **Конец утечки: void**.

<a id="portal-files-and-the-visibility"></a>
## Файлы портала и видимость

Файл портала (`<map>.prt`) содержит порталы между кластерами видимости, которые создаются на этапе геометрии. Их просмотр показывает, где видимость разделяет карту и как ее меняют подсказки и `func_detail`.

| Команда | Ключ по умолчанию | Описание |
| --- | --- | --- |
| **Карта > Утечки и видимость > Загрузить файл портала...** | | Загружает `.prt` карты (или запрашивает ее). Добавление `.prt` в окно тоже работает. |
| **Карта > Утечки и видимость > Выгрузить файл портала** | | Удаляет порталы. |
| **Карта > Создание порталов (только геометрия)** | `Ctrl+Shift+P` | Строит только геометрию текущей карты (секунды в папке сборки) и загружает порталы: сразу увидите эффект подсказок и `func_detail`. |
| **Карта > Утечки и видимость > Порталы и видимость...** | | Открывает окно ниже. |
| **Вид > Показать видимые кластеры** | | Раскрашивает видимые с камеры порталы кластеров (нужна карта, составленная с учетом видимости). |

После компиляции, которая записала новый файл портала, Hammer Pro предлагает его (*Компиляция записала новый файл портала.* **Загрузить** / **Не сейчас**), если только вы не отключили **Предлагать новый файл портала после компиляции**. Уже показанные порталы перезагружаются автоматически.

<a id="seal-an-opening-with-an-areaportal"></a>
## Запечатайте отверстие с помощью арепортала

Выберите дверь (`func_door`, `func_door_rotating`, `prop_door_rotating`, `func_movelinear` или одну из них) и запустите **Карта > Утечки и видимость > Запечатать проем с помощью арепортала**. Hammer Pro прикрепляет браш `func_areaportal` к дверному проему, связывает ее с дверью (дверь получает имя `door_<id>`, если его нет), заставляет ее открываться или закрываться, как дверь, и выбирает ее. Один шаг отмены. Если не выбрана дверь, вы получите *Выберите дверь (func_door, prop_door_rotating...), чтобы запечатать дверной проем*.

Проверки арепорта [Проверить наличие проблем] (check-problems.md) сообщают вам, когда арепорт и его дверь не совпадают, пересекают воду или окклюдер, или имеют более одной браши.

<a id="mcp"></a>
## Оптимизация карты

**Карта > Оптимизировать карту...** это советник, который компилирует видимость карты в фоне и перечисляет по степени влияния то, что не оптимизировано (visleaves, func_detail, hint-браши, ареапорталы, освещение), с тем, что делать, и кнопкой **Перейти**. Сам он карту не меняет. См. [Оптимизация карты](../guides/optimizing-a-map.md).

## MCP

`check_leaks`, `get_leak`, `load_pointfile` и `portal_file` предоставляют приложениям AI одинаковые инструменты. См. [справку по инструменту MCP](../MCP.md).

<a id="tips"></a>
## Советы

- Устраните утечку со стороны объекта: начните с точки 1 и нажимайте **Далее**, пока не увидите дыру.
- После добавления подсказок или `func_detail` нажмите `Ctrl+Shift+P`, чтобы увидеть новые порталы за считанные секунды без полной компиляции.
- Включите **Цвет по стоимости рендеринга** после компиляции с видимостью, чтобы найти дорогие области.

<a id="faq"></a>
## Частые вопросы

**Мгновенная проверка показывает, что карта запечатана, но компиляция протекает. Почему?** Компиляция остается ссылкой: некоторые случаи (объекты в нечетных местах, очень сложная карта) улавливаются только компилятором. Загрузите его файл точек.

**Где файл точек?** Рядом с картой или в папке сборки `.hammerpro_build` рядом с ней. **Загрузить файл точек утечки...** просматривает оба.

**Показать видимые кластеры ничего не показывает.** Требуется карта, скомпилированная с учетом видимости (*Данных о видимости пока нет: скомпилируйте карту с учетом видимости*).
