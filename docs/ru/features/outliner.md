<a id="outliner"></a>
# Планировщик

На вкладке **Структур** карта отображается в виде дерева: мир с его группами и телами, а также объекты, отсортированные по классам. Он доступен для поиска, синхронизируется с выбором и работает быстро даже на очень больших картах (отрисовываются только видимые строки).

<a id="opening-it"></a>
## Как открыть

**Просмотр > Панели > Outliner** показывает или скрывает вкладку в правой панели. По умолчанию он скрыт (`ui.show_outliner`).

<a id="the-tree"></a>
## Дерево

| Узел | Содержит |
| --- | --- |
| **Мир** | Группы (**Group #id**, вложенные, как на карте) и мировые тела (**Solid #id**). |
| **Объекты** | По одному узлу на класс (отсортировано без регистра), объекты этого класса в порядке файлов. Сущность браши представляет собой твердые тела. |

В нижней строке подводятся итоги карты: «Мировые тела: N, объекты: N, выбранные: N». Узлы **Мир** и **Сущности** начинают расширяться.

<a id="controls"></a>
## Элементы управления

| Контроль | Описание |
| --- | --- |
| Поле поиска | «Поиск по имени, классу, идентификатору или материалу». Строки сохраняются, когда они или дочерний элемент совпадают, а родительские элементы совпадений расширяются. Класс, соответствующий по имени, остается свернутым. |
| Кнопка со стрелкой вниз | **Развернуть все**. |
| Кнопка со стрелкой вверх | **Свернуть все** (оставляет **Мир** и **Сущности** открытыми). |
| Глаз ряда | **Скрыть** или **Показать**, что обозначает строка (объект, группа, класс, мир). Отображается перечеркнутым, когда все, что находится под ним, скрыто. |
| Стрелка ряда | Разворачивает или сворачивает его. |

<a id="selecting"></a>
## Выбор

| Жест | Описание |
| --- | --- |
| Щелкните строку | Выбирает видимые объекты (строка группы выбирает ее членов, строка класса : ее сущности). |
| `Ctrl`+кликните | Добавляет строку к выделению или удаляет ее, когда все ее видимые объекты уже выбраны. |
| `Shift`+кликните | Выбирает диапазон строк из последней выбранной строки. |
| Двойной щелчок | Выбирает и центрирует 2D- и 3D-виды по выделенному фрагменту. |
| `Up` / `Down` (указатель над списком) | Выбор предыдущей или следующей строки. |
| `Right` | Расширяет текущую строку. |
| `Left` | Сворачивает текущую строку или переходит к ее родительскому элементу. |
| `Enter` | Центрирует виды по выделенному фрагменту. |

Скрытые объекты никогда не выбираются: строка, содержащая только скрытые объекты, сохраняет текущий выбор и сообщает вам: «Скрытые объекты нельзя выбрать: сначала покажите их (кнопка с глазом)». Щелчок по строке не переводит фокус клавиатуры, поэтому `Delete`, `H` и клавиши инструментов продолжают работать над выбором, сделанным вами в планировщике.

Когда вы выбираете объекты в другом месте, планировщик разворачивает родителей первого выбранного объекта и прокручивается до него.

<a id="tips"></a>
## Советы

- Выполните поиск по названию материала, чтобы найти твердые тела, в которых оно используется.
- Найдите идентификатор (число **Solid #id**), чтобы перейти к браши, названной в результате ошибки компиляции. **Карта > Перейти к браши или идентификатору объекта...** (`Ctrl+Shift+G`) делает это из любого места (см. [Проверить наличие проблем](check-problems.md)).
- MCP: `list_entities`, `list_solids`, `list_groups` дают ту же информацию, что и текст (см. [Справочник по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Вкладка отсутствует.** Включите **Вид > Панели > Outliner**.

**При нажатии на строку ничего не выбрано.** Все в этой строке скрыто. Щелкните глаз, чтобы отобразить его, затем еще раз щелкните строку.

**Почему клавиши со стрелками не перемещают мой выбор в 2D-виде?** Пока указатель находится над контуром, клавиши со стрелками перемещаются по списку. Переместите указатель обратно к виду.
