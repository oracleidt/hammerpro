# Сочетания клавиш

Каждая команда Hammer Pro может иметь сочетание клавиш. Значения по умолчанию берутся из набора сочетаний клавиш (Hammer Pro, Hammer или Hammer++, чтобы ваши пальцы сохранили свои привычки), и вы можете изменить любое сочетание клавиш в **Настройки > Клавиатура**. `F1` показывает их все.

Полная таблица действий с их сочетаниями клавиш по умолчанию и предустановленными различиями находится в [Действия и сочетания клавиш](../reference/actions-shortcuts.md).

<a id="the-shortcut-reference-f1"></a>
## Ссылка на сочетание клавиш (F1)

**Справка > Сочетания клавиш** (`F1`) открывает окно со списком всех действий меню (Файл, Редактировать, Карта, Вид, Инструменты, Окно, Справка) с его сочетанием клавиш, а также дополнительные сочетания клавиш предустановки (показаны как *также ...*). Действия без сочетания клавиш показывают `-`.

- **Поиск действий или сочетаний клавиш** фильтрует список по названию действия (на английском языке или на языке интерфейса), по идентификатору действия или по сочетанию клавиш (`ctrl+shift+s` находит «Сохранить как»; названия клавиш на французском языке тоже работают).
- В конце списка показаны **элементы управления областью просмотра** для вашей схемы камеры (кнопки мыши, клавиши перемещения, колесо, клавиши сетки, щелчки, маркеры растягивания). См. [Камера и навигация](camera-navigation.md).
- **Настроить...** открывает **Настройки > Клавиатура**.

<a id="settings--keyboard"></a>
## Настройки > Клавиатура

Откройте его с помощью **Инструменты > Параметры...** (`Ctrl+,`), страницы **Клавиатура** или с помощью **Настроить...** в окне F1.

| Контроль | Описание |
| --- | --- |
| **Набор сочетаний клавиш** | Выбирает источник сочетаний клавиш по умолчанию: **Hammer Pro**, **Hammer** или **Hammer++**. Последует подтверждение (*Использовать сочетания клавиш X? Измененные вами сочетания клавиш остаются.*) с помощью **Использовать эти сочетания клавиш** и **Отменить**. |
| **Действия поиска или сочетания клавиш** | Фильтрует действия, как в окне F1. |
| **Сбросить все сочетания клавиш** | Восстанавливает все сочетания клавиш по умолчанию из текущего набора (ваши изменения удаляются). |
| Линия конфликта | *Сочетания клавиш, используемые для нескольких действий: N*, показаны оранжевым цветом, если они существуют. |

Ниже действия сгруппированы по меню. В каждой строке есть:

- имя действия (жирным шрифтом, если вы изменили его сочетание клавиш; дополнительные сочетания клавиш предустановки после него; наведите на него курсор, чтобы увидеть идентификатор действия);
- кнопка быстрого доступа: нажмите ее, затем нажмите новую комбинацию (**Нажмите комбинацию клавиш...**); `Esc` отменяет и сохраняет старый. Сочетание клавиш, используемый другим действием, отображается красным цветом, а его всплывающая подсказка гласит: *Также используется: ...*;
- **Удалить сочетание клавиш** (крестик): действие больше не имеет сочетания клавиш;
- **Восстановить сочетание клавиш по умолчанию** (стрелка): возврат к значению по умолчанию для текущего набора.

Изменения применяются сразу и сохраняются автоматически.

<a id="recording-rules"></a>
### Правила записи

- Удерживая Ctrl, Shift или Alt, вы увидите модификаторы (`Ctrl+Shift+...`); сочетание клавиш записывается только с ключом, который его завершает.
- `Esc`, `Tab` и `Enter` нельзя записать отдельно (для них нужен модификатор).
- Цифровые клавиши записываются по положению, поэтому `Alt+4` работает на клавиатуре AZERTY, где эта клавиша вводит апостроф.
- `Ctrl+C`, `Ctrl+X` и `Ctrl+V` можно записать, как и любой другой сочетание клавиш.
- Нажатие клавиши, которая уже является сочетанием клавиш, во время записи не запускает ее действие.

## Наборы сочетаний клавиш

| Установить | Для кого | По умолчанию |
| --- | --- | --- |
| **Hammer Pro** | По умолчанию. | Сочетания клавиш Hammer Pro плюс две дополнительные клавиши Hammer, которые ни с чем не сталкиваются: `Shift+Q` также очищает выделение, `Shift+R` также показывает или скрывает сетку. |

Отличия набора **Hammer** от Hammer Pro:

| Действие | Hammer Pro | Hammer |
| --- | --- | --- |
| Показать сетку | `Shift+G` | `Shift+R` |
| Выделить всё | `Ctrl+A` | `Ctrl+Shift+A` |
| Снять выделение | `Ctrl+Shift+A` | `Shift+Q` |
| Сбросить разделение вида | нет | `Ctrl+A` |
| Перевернуть вертикально | нет | `Ctrl+I` |
| Инвертировать выделение | `Ctrl+I` | `Ctrl+Shift+I` |
| Найти и заменить в сущностях... | `Ctrl+Alt+R` | `Ctrl+Shift+R` |
| Найти и заменить текстуры... | `Ctrl+Shift+R` | нет |
| Скомпилируйте и запустите... | `Ctrl+F9` | `F9` |
| Скомпилировать сейчас | `F9` | `Ctrl+F9` |

В набор **Hammer++** добавлено:

| Действие | Hammer++ |
| --- | --- |
| Браузер модели | `Shift+F10` |
| Браузер частиц | `Shift+F11` |
| Звуковой браузер | `Shift+F12` |
| Показать текстуры инструментов | `Ctrl+Shift+F2` |
| Показать объекты редактора | `Alt+O` |

Набор не затрагивает сочетания клавиш, которые вы изменили самостоятельно: они остаются поверх любого набора. Элементы управления камерой (мышь и клавиши управления полетом) выбираются отдельно: **Элементы управления камерой** в **Настройки > Окна просмотра** (см. [Камера и навигация](camera-navigation.md)). Мастер первого запуска устанавливает оба параметра из редактора, из которого вы пришли (повторно откройте его с помощью **Справка > Ассистент настройки...**).

<a id="i-e-and-the-digit-keys-inset-extrude-and-the-pick-element"></a>
### I, E и цифровые клавиши: вставка, выдавливание и выбор элемента.

`I` запускает интерактивную вставку, а `E` интерактивное выдавливание на выбранных гранях или на грани под мышью, если ни одна не выбрана, в то время как в 3D-виде есть мышь (см. [Инструмент «Выдавливание»] (extrude-tool.md#interactive-inset-i)). `E` : действие `extrude_interactive`; инструмент выбора сохраняет `E` для масштаба выбранных объектов, за исключением случаев, когда выбраны грани. Цифровые клавиши `1`, `2`, `3` и `4` выбирают вершины, ребра, грани или объекты с помощью инструмента выделения ([Pick](selection-tool.md#selecting-faces-edges-or-vertices-pick)). Во время выполнения вставки или вытягивания: `Ctrl` принудительно активирует сетку, `Alt` освобождает вставку или переключает вытягивание на альтернативную сетку, `Enter` или применяется щелчок, `Escape` или щелчок правой кнопкой мыши отменяется.

<a id="ctrlb-snap-to-grid-and-bevel"></a>
### Ctrl+B: привязка к сетке и скос

`Ctrl+B` : это **Привязка выделения к сетке** в каждом наборе. Он также выполняет скос: в [инструменте «Скос»] (bevel-tool.md), а также в инструментах «Выделение» и «Вертекс», когда курсор находится на краю браши в 3D-виде, он начинает скашивать этот край. В любом другом месте он привязывается к сетке, как и раньше. Повторная привязка **Привязать выделение к сетке** перемещает оба.

<a id="where-shortcuts-are-stored"></a>
## Где хранятся сочетания клавиш

В settings.toml:

```toml
[workflow]
keymap_preset = "Hammer"        # "HammerPro", "Hammer" or "HammerPlusPlus"

[keybindings]
save_map = "Ctrl+S"             # action id = shortcut
show_console = ""               # empty: no shortcut
```

Только измененные вами сочетания клавиш записываются в `[keybindings]`. Идентификаторы действий указаны в разделе [Действия и сочетания клавиш] (../reference/actions-shortcuts.md).

<a id="when-shortcuts-do-not-fire"></a>
## Когда сочетания клавиш не срабатывают

Сочетания клавиш карты никогда не запускаются, пока вы вводите текстовое поле, пока открыто меню, всплывающее или модальное диалоговое окно, пока 3D-камера летает с помощью клавиатуры или пока записывается сочетание клавиш. После перемещения фокуса на кнопку или список с `Tab` простые клавиши (буквы, цифры, Delete, стрелки, Enter, Space) принадлежат интерфейсу, поэтому `Delete` или `H` после поля свойства никогда не удаляет и не скрывает редактируемый объект. Сочетания клавиш с Ctrl или Alt и функциональные клавиши по-прежнему работают.

## MCP

<a id="tips"></a>
## Советы

- Поиск по ключу: введите `alt+` в поле поиска, чтобы просмотреть все сочетания клавиш Alt.
- Команды без сочетания клавиш можно запускать из палитры команд (`Ctrl+P`); дайте здесь ключ тем, которыми вы часто пользуетесь.
- При переключении наборов сохраняются ваши собственные сочетания клавиш, поэтому вы можете попробовать **Hammer++** и вернуться обратно.

<a id="faq"></a>
## Частые вопросы

**Два действия имеют общий сочетание клавиш. Какой из них выполняется?** Устраните конфликт: строка имеет красный цвет, а во всплывающей подсказке указано другое действие. Удалите или измените один из них.

**Как мне вернуть F9 Hammer?** Выберите набор **Hammer** или **Hammer++**: `F9` открывает окно компиляции и `Ctrl+F9` компилируется.

**Могу ли я поделиться своими сочетаниями клавиш?** Скопируйте строку `[workflow] keymap_preset` и таблицу `[keybindings]` вашего файла settings.toml на другой компьютер.
