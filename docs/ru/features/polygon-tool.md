# Инструмент «Многоугольник»

Инструмент «Многоугольник» (например, инструмент Hammer++) создает одну браш из выпуклого контура: вы щелкаете по его точкам в 2D-виде, и контур вытягивается по глубине этого вида.

<a id="opening-it"></a>
## Как открыть

- **Инструменты > Инструмент «Многоугольник»**, палитра инструментов или `Shift+N`.
- Инструмент работает только в 2D-видах; щелчки в 3D-виде игнорируются.

<a id="drawing-a-brush"></a>
## Рисуем браш

1. Щелкните на 2D-виде, чтобы разместить первую точку, а затем следующие. Точки привязываются к сетке (удерживайте `Alt`, чтобы разместить их без привязки).
2. При перемещении мыши длина рисуемого края отображается рядом с курсором.
3. Точка, которая сделала бы контур вогнутым, отклоняется: маркер становится красным с надписью **Вогнутость: точка отклонена**. Точка, уже находящаяся в контуре, игнорируется. В схеме содержится не более 128 точек (**Слишком много точек**).
4. Как только контур наберет 3 или более точек, нажмите `Enter`, дважды щелкните мышью или нажмите **Создать**, чтобы создать браш. В строке состояния указано, сколько очков еще необходимо до этого.

`Backspace` (или кнопка **Удалить точку**) удаляет последнюю точку. `Escape` отменяет контур.

<a id="editing-the-outline-before-creating"></a>
## Редактирование контура перед созданием

- **Перемещение точки**: перетащите ее на вид, где нарисован контур. Ход, который может сделать контур вогнутым или ухудшиться, отклоняется.
- **Глубина**: диапазон выдавливания по оси вида определяется, как и у инструмента «Блок», от границ выделения, в противном случае : от последнего объекта, созданного инструментом «Блок» или «Многоугольник», в противном случае : 64 единицы. В других двухмерных представлениях контур выглядит как прямоугольник: перетащите один из его концов, чтобы изменить глубину, или перетащите его внутрь, чтобы переместить весь диапазон. Изменения глубины привязываются к сетке.
- Контур принадлежит тому виду, в котором он был начат (сверху, спереди или сбоку). Щелчки в других 2D-видах изменяют только глубину; нажмите `Escape`, чтобы начать заново в другом представлении.
- В 3D-виде показана призма и ее размер.

<a id="options"></a>
## Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Масштаб** | Масштаб текстур новых граней (мировые единицы на тексел, от 0,01 до 64). | Настройка **Масштаб текстуры по умолчанию** (0,25) |
| Создать как | **Мировая браш**, **func_detail** или любой класс сущности браши из FGD (список с возможностью поиска, допускается печатное имя класса). Благодаря классу браш становится новым объектом браши со значениями ключей FGD по умолчанию. | Мировая браш |
| Текущий материал | Материал, наносимый на каждую грань (материал по умолчанию, если ни один не выбран). Нажмите на нее, чтобы открыть браузер текстур. | `dev/dev_measuregeneric01b` |
| Пин (оставаться активным) | После создания браши оставьте инструмент «Многоугольник» активным. Когда выключено, инструмент выбора возвращается. | на |
| **Удалить точку** | Удалите последнюю точку (`Backspace`). | |
| **Создать** | Создайте браш (`Enter` или двойной щелчок). | |
| Количество очков | **N точек**: количество точек контура. | |

Новая браш станет выделением; создание : это один шаг отмены.

<a id="tips"></a>
## Советы

- Инструмент принимает только выпуклые контуры. Для вогнутой формы нарисуйте рядом несколько выпуклых брашов.
- Сначала выберите пол: контур принимает выбранный диапазон высот, поэтому стены и колонны, нарисованные на виде сверху, сразу получают правильную высоту.
- После создания используйте [Инструмент Вершина] (vertex-tool.md), если вам нужно наклонить или согнуть браш.
- Инструмент MCP `create_polygon_brush` создает браш такого же типа из списка точек (см. [Справочник по инструменту MCP](../MCP.md)).
- `set_tool_options` с инструментом `polygon` задает параметры самого инструмента: `tex_scale`, `create_as` (`world` или класс брашевой сущности) и `keep_active`.

<a id="faq"></a>
## Частые вопросы

**Почему моя точка отклонена?** Это сделает контур вогнутым (или это та же самая точка, что и другая). Расположите точки по порядку вокруг фигуры, всегда поворачивая в одну и ту же сторону.

**Могу ли я рисовать в 3D-виде?** Нет. Используйте инструмент «Блок», чтобы рисовать на поверхностях в 3D.

**Как изменить толщину после рисования контура?** Перед созданием браши перетащите концы прямоугольника контура в одном из двух других 2D-видов.
