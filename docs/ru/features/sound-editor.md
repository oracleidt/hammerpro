# Звуковой редактор

Звуковой редактор открывает звук игрового контента, дополнений, карты или вашего диска, показывает его форму волны, позволяет изменять его громкость, обрезать, затухать и зацикливать, воспроизводит результат и сохраняет его в виде WAV-файла в выбранной вами папке. Сохраняемый файл всегда представляет собой 16-битный формат PCM WAV, формат, который читает движок Source: файлы MP3 и OGG можно открывать и записывать обратно в формате WAV.

<a id="opening-it"></a>
## Как открыть

- **Инструменты > Контент и редакторы > Звуковой редактор...** (действие `sound_editor`) открывает окно и снова закрывает его.
- MCP: `open_media_editor` с `editor`, установленным на `sound` (и `path` для загрузки звука).

<a id="picking-a-sound"></a>
## Выбор звука

В списке слева есть два источника:

| Source | Что он перечисляет |
|---|---|
| **Звуки игры** | Звуковые файлы (WAV, MP3, OGG) смонтированного игрового контента, аддоны и архивы Мастерской имеют тот же индекс, что и [звуковой браузер] (sound-browser.md) и инструмент MCP `search_sounds`. |
| **Используется картой** | Звуковые файлы, названные по ключевым значениям объектов открытой карты (сообщения `ambient_generic`, звуки триггеров, любое значение ключа, заканчивающееся на `.wav`, `.mp3` или `.ogg`). |

Поле поиска сохраняет звуки, содержащие каждое слово. **Открыть звуковой файл...** выбирает любой файл WAV, MP3 или OGG на вашем диске.

<a id="the-editor"></a>
## Редактор

В строке под названием указывается частота дискретизации, каналы, продолжительность, пиковый уровень и размер. Source корректно воспроизводит звуки на частоте 11025, 22050 и 44100 Гц; для любой другой частоты предупреждение предлагает использовать элемент управления **Частота выборки**.

| Контроль | Описание |
|---|---|
| Форма волны | Сохраненная часть рисуется акцентным цветом, вырезанные части затемняются. Перетащите курсор рядом с зеленой линией, чтобы переместить начало, и рядом с красной линией, чтобы переместить конец. Желтая линия : позиция воспроизведения, синяя линия : начало цикла. |
| **Играть** / **Стоп** | Воспроизводит отредактированный звук (зацикливается, если включен параметр **Зациклить звук**). **Оригинал** воспроизводит неотредактированный звук. **Громкость** - это только громкость предварительного просмотра. |
| **Сброс** | Возвращается к неотредактированному звуку (с сохранением маркеров цикла, которые были в комплекте). |
| **Объем (усиление)** | Усиление от -40 до +24 dB. Маленькая цифра : пиковый уровень после усиления; вывод обрезается на 0 dBFS. |
| **Нормализация** + **Установка усиления** | Устанавливает усиление таким образом, чтобы самый громкий семпл сохраняемой партии достигал уровня (по умолчанию -1 dB). |
| **Начало**, **Конец**, **Длительность** | Сохраненная часть, за секунды. Изменение длины перемещает конец. |
| **Нарастание**, **Постепенное исчезновение** | Линейные затухания на концах сохранившейся части. |
| **Петля** | **Зациклить звук** записывает маркеры цикла, которые считывает движок для повторения звука: фрагмент `cue ` и фрагмент `smpl` с одним прямым циклом от начала цикла до последнего сэмпла. **from** : начало цикла в секундах от начала сохраняемой части (по умолчанию 0). Звуки, у которых уже есть маркеры петли, открытые при включенной петле. |
| **Каналы** | **Сведите к моно** для получения стереозвука (моно-звук воспроизводится в трехмерных позициях с эффектами `snd_*`, стерео : нет). |
| **Частота выборки** | **Сохранить**: 11025, 22050 или 44100 Гц (линейная передискретизация). |

Воспроизведение ничего не стоит, когда не используется: поток воспроизведения спит, пока вы не нажмете **Играть**, а аудиовыход закрывается через 10 секунд после окончания звука (следующее воспроизведение открывает его снова за несколько миллисекунд), поэтому Windows не держит открытым аудиопоток Hammer Pro.

<a id="saving"></a>
## Сохранение

- **Папка** : это корень, в котором записан файл. По умолчанию это папка над папкой `maps` сохраненной карты (вашего дополнения или проекта), в противном случае : папка с игрой. **Обзор...** выбирает другую папку.
- **Файл** : это путь к этой папке, `sound/` добавляется при его отсутствии, а расширение всегда : `.wav`. В строке ниже показан путь, который будет записан. По умолчанию используется путь к исходному звуку с расширением `.wav`, поэтому отредактированная копия `sound/ambient/wind.mp3` в папке вашего дополнения заменяет оригинал в игре.
- Если файл существует, установите флажок **Заменить существующий файл**.
- **Сохранить как WAV** записывает файл и обновляет индекс содержимого, чтобы новый звук отображался в браузерах.

Файлы, записанные в папку с игрой, не являются частью операции отмены.

<a id="mcp"></a>
## MCP

Редактор полностью доступен через инструменты (см. [Справочник инструментов MCP](../MCP.md)):

| Инструмент | Использование |
|---|---|
| `sound_info` | Скорость, каналы, длительность, пик, маркеры цикла, форма сигнала. |
| `sound_edit` | Весь редактор за один вызов: `gain_db` или `normalize_db`, `start` с `end` или `length`, `fade_in`, `fade_out`, `looped`, `loop_start`, `mono`, `sample_rate`, `output`, `root`, `overwrite`, `dry_run`. |
| `sound_preview` | Воспроизводит монтаж или останавливает (`stop`). |
| `list_map_sounds` | Список «Используется картой». |
| `search_sounds` | Список звуков игры. |
| `open_media_editor` | Открывает окно, опционально с загруженным звуком. |
