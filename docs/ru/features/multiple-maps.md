<a id="multiple-maps"></a>
# Несколько карт

Hammer Pro сохраняет открытыми несколько карт одновременно, каждая на отдельной вкладке над видами, со своими камерами, выбором, историей отмены и загруженным файлом точек. Вы также можете сохранить расположение видов и панелей как именованные макеты.

<a id="tabs-of-open-maps"></a>
## Вкладки открытых карт

Панель вкладок расположена над видами: одна вкладка для каждой открытой карты, знак `*` после имени, если на карте есть несохраненные изменения, и полный путь во всплывающей подсказке (*Еще не сохранен* для новой карты).

| Жест | Описание |
| --- | --- |
| Щелкните вкладку | Показывает эту карту. |
| Щелчок средней кнопкой мыши по вкладке | Закрывает его. |
| Кнопка закрытия (крестик) вкладки | Закрывает его. |
| ****+** в конце такта | **Новая карта** в новой вкладке. |
| Щелкните правой кнопкой мыши вкладку | **Закрыть**, **Закрыть другие карты** (если открыто несколько карт), **Копировать путь** и **Показать в папке** (для сохраненной карты). |

Длинные имена сокращаются; панель прокручивается вбок, когда вкладки не помещаются.

<a id="commands"></a>
## Команды

| Команда | Ключ по умолчанию | Описание |
| --- | --- | --- |
| **Файл > Новая карта** | `Ctrl+N` | Открывает новую пустую карту в новой вкладке. |
| **Файл > Открыть карту...** | `Ctrl+O` | Открывает карту в новой вкладке (см. ниже). |
| **Файл > Закрыть** | `Ctrl+F4` | Закрывает показанную карту после запроса на сохранение ее изменений (*Сохранить изменения на карте перед ее закрытием?*). Закрытие последней карты оставляет новую пустую. |
| **Файл > Закрыть другие карты** | | Закрывает все остальные карты, по очереди запрашивая каждую измененную. |
| **Окно > Следующая карта** | `Ctrl+Tab` | Показывает следующую вкладку. |
| **Окно > Предыдущая карта** | `Ctrl+Shift+Tab` | Показывает предыдущую вкладку. |
| **Окно > Открыть карты** | | Перечисляет открытые карты (показанная отмечена флажком); щелкните один, чтобы показать его. |

При выходе из Hammer Pro по очереди запрашивается информация о каждой измененной карте.

<a id="opening-maps"></a>
## Открытие карт

С помощью **Открывать карты в новых вкладках** (**Настройки > Общие**, раздел **Карты**, клавиша `workflow.open_in_new_tab`, включено по умолчанию):

- открытая карта получает собственную вкладку;
- вместо пустой вкладки заменяется новая нетронутая карта «без названия»;
- карта, которая уже открыта, отображается вместо того, чтобы загружаться дважды.

Выключено, открытая карта заменяет текущую после запроса на сохранение ее изменений, например Hammer.

Все, что принадлежит карте, следует за ее вкладкой: камеры, выбор, история отмены, файл точек, поворот поворота и данные карты в ее дополнительном файле (параметры выпуска, игнорируемые проблемы...). Автосохранение сохраняет каждую измененную открытую карту, а не только показанную (см. [Автосохранение и восстановление после сбоев](autosave-crash.md)).

<a id="layouts"></a>
## Макеты

Макет : это расположение представлений и панелей: вид в каждом квадранте, разделенные позиции, развернутый вид и отображаемые панели закрепления (текстуры, свойства объекта, визуальные группы, планировщик, модели, консоль).

| Команда | Описание |
| --- | --- |
| **Окно > Макет > Сохранить макет...** | Запрашивает имя (*Название макета:*, предложено `Layout N`) и сохраняет текущее расположение. Одноименная раскладка заменена (вы предупреждены). Максимум 32 макета. |
| **Окно > Макет > Сбросить макет** | Возврат к расположению по умолчанию: трехмерный вид, вид сверху, спереди и сбоку, разделение по центру, без развернутого вида, отображается каждая панель закрепления. |
| **Окно > Макет > Сохраненные макеты** | Щелкните макет, чтобы применить его. **Delete** перечисляет макеты для удаления. *Нет сохраненного макета*, когда список пуст. |

Макеты хранятся в файле settings.toml (`[workflow.layouts]`), поэтому они одинаковы для каждой карты.

<a id="mcp"></a>
## MCP

`list_tabs`, `switch_tab`, `close_tab`, `new_map`, `open_map` и `list_recent_maps` работают с открытыми картами из приложений AI; `set_view_layout` меняет вид секторов. См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="tips"></a>
## Советы

- Оставьте префаб или карту экземпляра открытой на второй вкладке и копируйте объекты между вкладками с `Ctrl+C` и `Ctrl+V`.
- Сохраните макет «освещения» с большим трехмерным изображением и макет «мазка» с четырьмя видами и переключитесь из меню **Окно**.
- **Копировать путь** в меню вкладок : это самый быстрый способ вставить путь на карте в сообщение или скрипт.

<a id="faq"></a>
## Частые вопросы

**Могу ли я открыть одну и ту же карту дважды?** Нет. При открытии уже открытой карты отображается только ее вкладка.

**Сохраняет ли каждая карта свою историю отмены?** Да. `Ctrl+Z` отменяет изменения только показанной карты.

**Как вернуться к одной карте за раз, как в Hammer?** Отключите параметр **Открывать карты в новых вкладках** в **Настройки > Общие**.
