# Кордоны

Кордон : это именованный прямоугольник, ограничивающий часть карты, над которой вы работаете. Пока кордоны используются, все, что находится за пределами каждого активного кордона, затемнено в представлениях, не может быть выбрано и может быть исключено из компиляции, поэтому вы можете протестировать одну комнату за считанные секунды вместо компиляции всей карты.

<a id="opening-it"></a>
## Как открыть

- **Инструменты > Активный инструмент > Инструмент «Кордон»** (или его кнопка на палитре инструментов) рисует и редактирует рамки в 2D-видах. У него нет сочетания клавиш по умолчанию: задайте его в **Настройки > Клавиатура** (см. [Сочетания клавиш](keyboard-shortcuts.md)).
- **Вид > Использовать кордоны** включает или выключает оцепление для всей карты. Кнопка кордона на панели инструментов делает то же самое. Если нет ни одного активного кордона, карта сохраняется с выключенными кордонами, чтобы Hammer и Hammer++ по-прежнему показывали всю карту.
- В разделе **Кордоны** на вкладке **Визгруппы** (правая док-станция) перечислены все кордоны карты.
- Пока кордоны используются, в строке состояния отображается красный значок **Кордон**. Его всплывающая подсказка показывает количество ящиков; щелчок останавливает использование кордонов.

Кордоны сохраняются в VMF, как это делает Hammer: карта с одним кордоном записывается со старым блоком `cordon` из Hammer (если файл уже не использовал более новый блок), карта с несколькими кордонами с новым блоком `cordons`. Кордоны с несколькими блоками, написанные другими редакторами, сохраняют все свои блоки при сохранении (инструмент редактирует первый блок каждого кордона, остальные прорисовываются слабо).

<a id="the-cordon-tool"></a>
## Инструмент «Кордон»

Инструмент редактирует по одному кордону, **цель**. Выберите его в списке **Кордон:** на панели параметров, щелкнув его строку в списке кордонов, с помощью **Редактировать блок с помощью инструмента кордона** в этом списке или щелкнув внутри его поля в 2D-виде (наименьшее поле выигрывает там, где поля перекрываются).

| Жест (2D-изображения) | Описание |
| --- | --- |
| Перетащите в пустое место | Перерисовывает рамку целевого кордона. Его глубина по оси, которую вы не видите, сохраняется. |
| Перетащите маркер | Изменяет размер поля. |
| Перетащите внутрь коробки | Перемещает ящик. |
| Нажмите внутри другого кордона | Делает это целью. |
| `Escape` | Отменяет текущее перетаскивание и выходит из режима **Новый кордон**. |

Каждое изменение применяется, когда вы отпускаете кнопку мыши, как один шаг отмены. Перетаскивание, не рисующее области, сохраняет поле в том виде, в котором оно было. В 3D-виде поля отображаются, но не редактируются.

Глубина нового прямоугольника (ось, которую вы не видите на виде, где вы его рисуете) берется из целевого кордона, в противном случае из выделения, в противном случае из карты с одним шагом сетки поля, в противном случае из поля по умолчанию Hammer (от -1024 до 1024).

<a id="options-bar"></a>
### Панель параметров

| Параметр | Описание |
| --- | --- |
| **Кордон:** | Кордон инструмент редактирует. Показывает **Новый кордон**, когда следующим полем будет новый кордон, **(нет)**, когда на карте нет кордона. |
| кнопка ****+** | **Новый кордон**: следующий нарисованный вами прямоугольник становится новым кордоном. |
| **Активен** | Включает этот кордон в оцепленную зону (подсказка: «Включить этот кордон в оцепленную зону»). |
| Размер | Размер целевого поля. |
| кнопка **х** | Удаляет этот кордон. |
| **Используйте кордоны** | То же, что и **Вид > Использовать кордоны**. |

<a id="right-click-menu"></a>
### Меню, вызываемое правой кнопкой мыши

| Вход | Описание |
| --- | --- |
| **Новый кордон вокруг выделения** | Новый кордон, соответствующий выбранным объектам. Плоское выделение получает один шаг толщины сетки. Нужен выбор. |
| **Delete этот кордон** | Удаляет целевой кордон. |
| **Используйте кордоны** / **Прекратите использовать кордоны** | Включает или выключает кордонирование. |

Подсказка в строке состояния напоминает вам о жестах и добавляет надпись «(Кордоны не используются.)», когда оцепление отключено.

<a id="the-cordon-list"></a>
## Список кордонов

В разделе **Кордоны** на вкладке [Визгруппы](visgroups.md) показаны:

| Элемент | Описание |
| --- | --- |
| **+** | Новый кордон вокруг выделения или куб в центре 2D-видов, когда ничего не выбрано. Имя начинается в режиме переименования. |
| **Использовать** | Используйте кордоны (аналогично **Вид > Использовать кордоны**). |
| Граф | Количество кордонов. |
| Флажок строки | Активный: включает кордон в оцепленную зону. |
| Щелкните строку | Делает его кордоном, который редактирует инструмент кордона. В подсказке указаны углы и размер. |
| Дважды щелкните строку | Переименовывает его. |
| Кнопка рамки | **Обрамляйте виды на этом кордоне**. |
| Кнопка коробки | **Отредактируйте блок с помощью инструмента «Кордон»**. |
| кнопка **х** | **Delete кордон**. |
| Щелкните правой кнопкой мыши строку | **Отредактируйте поле с помощью инструмента «Кордон»**, **Настройте виды на этот кордон**, **Переименовать**, **Delete кордон**. |

На кордоне без тома отображается сообщение «У этого кордона нет тома: он будет удален при следующем редактировании».

<a id="what-in-use-does"></a>
## Что означает «в использовании»

Кордоны используются, когда включена опция **Использовать кордоны** и хотя бы в одном активном кордоне есть пригодный для использования ящик. Тогда:

- рамки активных кордонов на каждом ракурсе нарисованы красным цветом;
- 2D-виды затенены за пределами каждого активного кордона (настройка ниже);
- объекты, лежащие полностью за пределами каждого активного поля, затемнены и их нельзя выбрать. Объект, касающийся коробки, считается находящимся внутри;
- название каждого активного кордона отображается в его углу, если их несколько.

Включение, выключение кордона, добавление, переименование, изменение размера или удаление кордона являются действиями отмены.

<a id="compiling-only-the-cordon"></a>
## Составление только кордона

В [Окне компиляции и запуска] (../compiler/compile-window.md) параметр **Компилировать только охраняемую область** сохраняет только то, что касается активных полей. Каждая коробка запечатывается шестью брашами из **материала печати кордона**, а карта компилируется как `<map>_cordon`, поэтому полная карта никогда не перезаписывается. Если ни один из игроков не находится внутри кордона, один игрок добавляется на пол первой коробки. Такая же опция есть на странице настроек **Компилировать** (**Компилировать только активный кордон**).

<a id="options"></a>
## Параметры

**Инструменты > Параметры... > Кордоны и визуальные группы** (`[visibility]` в `settings.toml`):

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Материал кордона** (`cordon_material`) | Материал брашов, герметизирующих оцепленный участок при составлении только кордонов. **Использовать текущий материал** : заполняет текущий материал. Пустое значение использует значение по умолчанию. | `tools/toolsskybox` |
| **Тень за кордонами в 2D** (`shade_outside_2d`) | Затемняет 2D-виды за пределами каждого активного кордона, пока используются кордоны. | Вкл. |
| **Непрозрачность оттенка** (`shade_opacity`) | Непрозрачность этого оттенка от 0 до 1. | 0.45 |
| **Названия кордонов в 2D** (`show_cordon_names`) | Показывает название каждого активного кордона в его углу, если их несколько. | Вкл. |

<a id="tips"></a>
## Советы

- Оставьте по одному кордону на каждую область, которую вы часто тестируете (комната, трасса для транспортных средств), и переключайте их с помощью флажка **Активен** вместо перерисовки полей.
- Предварительный просмотр освещения имеет собственный локальный режим: **Запекание вокруг камеры** запечатывает область вокруг 3D-камеры как кордон (см. [Предварительный просмотр освещения](lighting-preview.md)).
- Инструменты MCP: `list_cordons`, `add_cordon`, `edit_cordon`, `set_cordons_enabled`, `get_visibility` (см. [Справочник по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Я нарисовал оцепление, но ничего не затемнено.** Оцепление отключено. Установите флажок **Использовать кордоны** (панель параметров, список кордонов или меню «Вид») и убедитесь, что кордон **Активен**.

**Почему я не могу выбрать объект?** Он находится за пределами каждого активного кордона. Прекратите использовать кордоны или увеличьте коробку.

**Компиляция кордона перезаписывает мою карту?** Нет. Компиляция кордона называется `<map>_cordon`.

**Может ли кордон иметь несколько блоков?** Hammer Pro сохраняет лишние блоки карт, созданных где-то еще, и использует их в представлениях и компиляциях, но создает по одному блоку на каждый кордон. Вместо этого сделайте несколько кордонов.
