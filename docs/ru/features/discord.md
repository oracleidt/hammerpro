# Богатое присутствие Discord

Как и Hammer++, Hammer Pro может показывать то, что вы отображаете в своем профиле Discord: карту, активный инструмент, игру и время, проведенное на карте.

<a id="opening-it"></a>
## Как открыть

**Настройки > Discord** (**Инструменты > Параметры...**, `Ctrl+,`), раздел **Discord Rich Presence**. Настройки сохраняются как `[discord]` в файле settings.toml.

<a id="options"></a>
## Параметры

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Показать активность в Discord** | Включает присутствие. При его отключении активность сразу очищается. Ключ `enabled`. | на |
| **Показать название карты** | Показывает *Редактирование gm_city.vmf*; выкл., *Редактирование карты*. Ключ `show_map`. | на |
| **Показать прошедшее время** | Показывает время, проведенное на карте. Ключ `show_elapsed`. | на |
| **Показать активный инструмент** | Показывает инструмент, который вы используете. Выкл.: вместо этого отображается целевая игра (и *Компиляция...* во время компиляции). Ключ `show_tool`. | на |
| **Discord приложение ID** | Необязательно: ID вашего собственного приложения Discord для замены приложения Hammer Pro (раздел **Discord приложения**). Пусто: используется собственное приложение Hammer Pro. Ключ `application_id`. | пусто (приложение Hammer Pro) |
| **Ссылка на кнопку «Получить Hammer Pro»** | Дополнительная веб-страница (`https://...`), отображаемая в виде кнопки **Получить Hammer Pro** под действием; пусто: нет кнопки. Ключ `project_url`. | пустой |

<a id="what-discord-shows"></a>
## Что показывает Discord

| Линия | Содержание |
| --- | --- |
| Подробности | *Редактирование файла map.vmf*, *Редактирование карты* (название карты скрыто) или *Карта не открыта*. |
| Государство | Активный инструмент, или *Компиляция...* во время компиляции, или название игры. |
| Время | Время с момента открытия карты (если включен параметр **Показать прошедшее время**). |
| Большое изображение | Логотип Hammer Pro (ключ изображения `hammerpro`) с «Hammer Pro» и версией. |
| Маленькое изображение | Иконка игровой карты с ее названием. |

<a id="the-application"></a>
## Приложение

Hammer Pro поставляется с собственным приложением Discord под названием «Hammer Pro» с логотипом под ключом изображения `hammerpro`: здесь нечего настраивать. Поле приложения **Discord ID** пусто и отображает *Hammer Pro (встроенное)*.

Чтобы показать действие под другим именем или с другими изображениями, создайте собственное приложение на Портале разработчиков Discord, загрузите изображения в раздел **Rich Presence > Art Assets** (клавиша `hammerpro` для большого изображения; значки игр с ключами `gmod`, `hl2`, `hls`, `hl2dm`, `tf2`, `css`, `dods`, `portal`, `portal2`, `l4d`, `l4d2`, `csgo`, другие игры используют собственный идентификатор игры), и вставьте его **Приложение ID** (страница «Общая информация») в поле. ID : это число, состоящее из 17-20 цифр; все остальное отклоняется с сообщением. Очистите поле, чтобы вернуться к приложению Hammer Pro.

<a id="status"></a>
## Статус

Строка **Статус:** под опциями сообщает, что делает присутствие, и обновляется в течение секунды:

| Статус | Значение |
| --- | --- |
| *Подключено: ваша активность отображается в Discord* | Hammer Pro обращается к приложению Discord, и действие отправляется. |
| *Подключаюсь к Discord...* | Первое подключение или только что изменена опция. |
| *Discord не запускается (повторная попытка в фоновом режиме)* | На этом компьютере не ответило настольное приложение Discord. Hammer Pro повторяет попытку через 5 секунд, затем реже (максимум каждые 20 секунд): запустите Discord, и активность появится сама собой. |
| *Discord отказ в соединении (причина)* | Discord ответил, но отклонил заявку, например *Неверный клиент ID (4000)* с неправильным пользовательским кодом ID. |
| *Присутствие отключено* | **Показывать активность в Discord** отключено. |
| *Недопустимое приложение ID: присутствие отключено* | Поле содержит что-то, что не является приложением ID. |
| *Нет приложения ID: присутствие отключено* | Нет ID для использования (только в сборках без встроенного приложения). |
| *Выкл. при автоматических запусках* | `--script`, тесты: присутствие так и не запускается. |

<a id="requirements"></a>
## Требования

Настольное приложение Discord должно быть запущено на том же компьютере с включенной функцией **Поделиться обнаруженными действиями** в настройках Discord **Конфиденциальность действий**. Hammer Pro обращается к нему напрямую через локальное соединение Discord, в фоновом потоке: когда Discord не запущен, он спокойно повторяет попытку, и редактор никогда его не ждет. Автоматические прогоны (`--script`, тесты) никогда не доходят до вашего Discord.

<a id="tips"></a>
## Советы

- Отключите **Показывать название карты**, когда работаете над секретным проектом; тогда присутствие просто говорит *Редактирование карты*.
- Поделитесь ссылкой на страницу Мастерской вашей карты или в свое сообщество с помощью кнопки ссылки.

<a id="faq"></a>
## Частые вопросы

**В Discord ничего не отображается.** Посмотрите на строку **Статус:** в разделе **Настройки > Discord**, убедитесь, что настольное приложение Discord запущено и включен ли обмен действиями. См. [Присутствие Discord не отображается] (../troubleshooting/discord-presence.md).

**Замедляет ли это присутствие работу редактора?** Нет, он работает в отдельном потоке, и обновления ограничиваются.

**Работает ли это с веб-приложением Discord?** Нет, для присутствия требуется настольное приложение на том же компьютере.

**Нужно ли мне создавать приложение Discord?** Нет, у Hammer Pro есть свое собственное. Пользовательский ID предназначен только для отображения другого имени или других изображений.

<a id="mcp"></a>
## MCP

Помощники AI считывают состояние с помощью `get_discord_status` (статус, его текст, используемое приложение ID, отправленные сведения и строки состояния) и изменяют параметры с помощью `set_setting` на клавишах `discord.*`. См. [справку по инструменту MCP](../MCP.md).
