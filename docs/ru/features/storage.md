# Хранилище (использование диска)

Hammer Pro сохраняет настройки, кэши, автосохранения и временные файлы на вашем диске. Страница **Хранилище** показывает, сколько места они используют, что использует больше всего, а также позволяет удалить то, что вам не нужно. Только собственные папки Hammer Pro отображаются и очищаются: ваши карты, папки с играми и файлы рядом с вашими картами никогда не являются его частью.

<a id="opening-it"></a>
## Как открыть

**Настройки > Хранилище** (**Инструменты > Параметры...**, `Ctrl+,`). Страница сканирует папки в фоновом потоке при открытии: редактор никогда не ждет, а индикатор выполнения показывает местоположения и файлы, подсчитанные на данный момент.

<a id="the-list"></a>
## Список

Вверху отображается общая сумма, затем по одной строке для каждого типа данных, **сначала самая большая**. В каждой строке есть:

| Часть | Что это показывает |
| --- | --- |
| Флажок | Выбирает строку для **Delete выбранного**. |
| Имя и описание | Что это за данные и что произойдет, если они будут удалены. Цветной тег отмечает **Данные для восстановления** и **Ваши данные**. |
| Путь | Папка (наведите курсор на все папки строки). |
| Размер и файлы | Размер на диске и количество файлов, а также количество используемых и пропущенных элементов. |
| Бар | Доля от общего числа, в процентах. |
| **Открыть папку** | Открывает папку в файловом менеджере. |
| **Delete** | Удаляет строку после подтверждения. |

<a id="what-is-listed"></a>
## Что указано

| Строка | Содержание | Риск |
| --- | --- | --- |
| Миниатюры | Эскизы материалов, моделей и сборных конструкций | безопасно, нарисовано снова |
| Кэш пакетов, компиляция содержимого, компиляция вывода, компиляция временных файлов, компиляция истории, выпуск сборок | Файлы компилятора и релиз-упаковщика | безопасно, пересобирается при следующей компиляции |
| Декомпилированные карты и извлеченные ресурсы | Карты декомпилированы для лаборатории, модели извлечены из игр | в безопасности, снова извлечен |
| Результаты BSP Sniffer | VMF, BSP, содержимое и отчет каждого запуска [BSP Sniffer](bsp-sniffer.md) (папка по умолчанию) | ваши данные |
| Журналы | Логи предыдущего запуска (записываемый лог сохраняется) | безопасный |
| Индекс содержания | Сохраненный индекс игрового контента | безопасен, восстанавливается при следующем сканировании содержимого |
| Обновление загрузок | Загруженные пакеты обновлений во временную папку системы | безопасный |
| Временные файлы | `hammerpro_*` элементы во временной папке системы | безопасный |
| Другие кэшированные данные | Что-нибудь еще в папке кэша | безопасный |
| Автосохранение и резервное копирование | Восстановительные копии редактируемых карт | данные восстановления |
| Отчеты о сбоях | Отчеты и экстренные сохранения | данные восстановления |
| По состоянию на карте | Сохраненный вид и макет каждой карты. | ваши данные |
| Настройки | settings.toml (параметры, привязки клавиш, последние карты) | ваши данные |
| Префабы, пресеты Sprinkle | Что вы создали в папках по умолчанию | ваши данные |

Порядок строк соответствует размерам, а не этой таблице. Используемые файлы (записываемый журнал, маркеры запущенных сессий, временные файлы этой сессии) учитываются, но пропускаются при удалении. Папки, которые другие функции добавляют в кэш Hammer Pro, включаются в список по мере их появления.

<a id="deleting"></a>
## Удаление

- **Delete** в строке или отметьте строки и нажмите **Delete выбрано (N, размер)**.
- В окне подтверждения точно указано, что будет удалено (имя, размер, папки) и освобождено место. Строки с **Ваши данные** или **Данные для восстановления** содержат четкое предупреждение, поскольку эти данные невозможно восстановить.
- Удаление выполняется в фоновом потоке с индикатором выполнения. По его завершении в сводке отображается освобожденное пространство и для каждого элемента, который не удалось удалить (используется, нет разрешения), путь и причина. Список обновляется сам.
- Строки, связанные с компиляцией, нельзя удалить во время компиляции.
- Каждый путь проверяется перед удалением: он должен разрешиться внутри папки своей строки. Во всем остальном отказывается. Ссылки удалены, никогда не переходили.
- Сами папки остаются, удаляется только их содержимое.

<a id="tips"></a>
## Советы

- Удаление **Миниатюр** и **Компиляция вывода** всегда безопасно и часто освобождает большую часть ресурсов.
- Сохраняйте **автосохранение и резервные копии** до тех пор, пока ваши карты не будут сохранены и скомпилированы.
- Удаление settings.toml здесь удаляет сохраненный файл, который записывается снова при изменении параметра или выходе.

<a id="faq"></a>
## Частые вопросы

**Удаляет ли это мои карты?** Нет. Очищаются только собственные папки Hammer Pro. Папки `.hammerpro_build` рядом с вашими картами не являются его частью.

**Почему после удаления размер не равен нулю?** Используемые файлы пропускаются и перечисляются в сводке. Закройте программу, используя их, и нажмите **Обновить**.

**Где находятся папки?** В каталогах `%APPDATA%\HammerPro` (настройки, префабы, отчеты о сбоях) и `%LOCALAPPDATA%\HammerPro` (кэши, автосохранение, журналы) в Windows и во временной системной папке.

<a id="mcp"></a>
## MCP

AI помощники используют `get_storage_usage` (общее количество и отсортированный список с идентификаторами, размерами, рисками и путями) и `delete_storage` (идентификаторы и `confirm` true для действительного удаления; `allow_user_data` также верно для настроек, префабов, пресетов и состояния карты). Без `confirm` ничего не удаляется и инструмент сообщает, что будет. См. [справку по инструменту MCP](../MCP.md).
