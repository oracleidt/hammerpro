# Инструмент сущности

Инструмент создания объектов размещает точечные объекты: на поверхностях в 3D-виде (опирающихся на полы, стены, потолки и модели пропов) или на сетке в 2D-видах. Он также размещает префабы, выбранные на вкладке «Префабы».

Модель, зафиксированная в определении объекта или предоставленная как модель по умолчанию FGD, имеет приоритет над браузером моделей. Его кожа также сохранилась; скин браузера применяется только к общим свойствам, использующим выбранную модель браузера.

<a id="opening-it"></a>
## Как открыть

- **Инструменты > Активный инструмент > Инструмент «Объект»**, палитра инструментов или `Shift+E`.
- Если класс еще не выбран, инструмент использует настройку **Объект точки по умолчанию** (`info_player_start`).

<a id="placing-an-entity"></a>
## Размещение объекта

- **3D-просмотр**: щелкните поверхность. Коробка сущности опирается на него снаружи: на полу стоит, на потолке свисает, на стене касается стены. В реквизите объект опирается на реальную сетку модели (а не на ее коробку); там, где в модели нет треугольника, он проваливается на поверхность позади. Если под курсором нет поверхности, объект перемещается на плоскость земли (высота 0).
- **2D-виды**: щелкните, чтобы поместить объект в точку сетки под курсором. Его глубина (вдоль оси вида) : это начало координат последнего объекта, помещенного в 3D, в противном случае : центр выделения, в противном случае : 0.
- Перед щелчком мыши за курсором следует призрачное поле с именем класса.

Модификаторы:

| Клавиша | Эффект |
|---|---|
| `Shift` + клик | Сохраните текущий выбор (в противном случае новый объект станет выбором). |
| `Alt` + клик | Привязка к сетке отсутствует (смещение покоя затем округляется до 0,01 единицы). |

Позиции привязываются к сетке представления; на браши, несущей собственную сетку, объект приземляется на эту сетку (см. [Сетки](grids.md)). Смещение покоя округляется до целых единиц (или до сетки, если оно меньше одной единицы), поэтому начало координат остается чистым.

Каждое размещение представляет собой один шаг отмены. Новый объект получает значения ключей FGD по умолчанию и флаги появления своего класса.

<a id="size-of-the-ghost-box"></a>
### Размер призрачного ящика

Поле, используемое для размещения объекта на поверхности, находится в следующем порядке: коллизионная оболочка модели (для пропа и для классов с фиксированной моделью и без размера, например `info_player_start`, который использует корпус игрока 32 x 32 x 72), иначе границы модели, иначе размер, указанный в FGD, или куб из 16 единиц.

<a id="options"></a>
## Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Класс** | Средство выбора классов с возможностью поиска (см. ниже). Его подсказка показывает FGD-описание класса. Без загруженных определений объектов оно становится обычным текстовым полем (**Имя класса**). | Настройка **Объект точки по умолчанию** |
| **Модель** | Только для общих классов пропа (`prop_*` или вспомогательного пропа студии, без фиксированной модели или непустой модели по умолчанию FGD): модель, выбранная в браузере моделей, или **Модель не выбрана**. | |
| **Скин N** | Скин, выбранный в браузере модели, записанный в новые пропы (отображается, если он не является скином по умолчанию). | |
| **Модели...** | Открывает вкладку «Модели» в браузере моделей для выбора модели. | |
| **Выровнять по поверхности** | Только для классов пропа: поверните пропы так, чтобы их верхняя ось соответствовала нормали поверхности (установлено ключевое значение `angles`). | выкл. |

Объект, размещенный без выбранной модели, создается без модели, и на консоль выводится предупреждение.

<a id="the-class-picker"></a>
## Выбор класса

Нажмите кнопку класса, чтобы открыть список:

- Введите **Искать классы...**: каждое слово должно присутствовать в имени класса; имена, начинающиеся с первого слова, идут первыми.
- `Up` и `Down` перемещаются по списку, `Enter` выбирает выделенный класс, `Escape` закрывает список.
- **Недавние**: последние размещенные вами классы (показано до 6) отображаются первыми, когда поиск пуст.
- **Используйте «имя»**: имя класса, которого нет в FGD (например, объекты из сценария Garry's Mod), все равно можно использовать.
- В каждой строке отображается цвет редактора класса и его описание в виде всплывающей подсказки. В нижней строке подсчитываются совпадающие классы.

<a id="placing-prefabs"></a>
## Размещение префабов

Дважды щелкните префаб на вкладке **Префабы**: инструмент управления объектами переключится на размещение префаба. Затем на панели параметров отображается **Префаб:** с его именем, кнопка **Назад к объектам** и флажок **Группировать**.

| Жест | Результат |
|---|---|
| Нажмите в 3D-виде | Вставьте префаб в исходном размере, опираясь на поверхность под курсором. |
| Щелкните в 2D-виде | Вставьте его по центру точки сетки (на глубине, которую использует инструмент создания объектов). |
| Перетащите рамку в 2D-виде | Вставьте его в масштабе нарисованного прямоугольника. |
| `Escape` | Отбросьте рисуемый прямоугольник, иначе вернитесь к размещению объектов. |

Смещения привязываются к сетке, поэтому префабы, построенные на сетке, остаются на ней. Каждая вставка заменяет токен `&i` префаба следующим номером карты. **Group** (настройка `[placement] group_prefabs`, включена по умолчанию) группирует объекты каждого вставленного префаба. См. [Префабы](prefabs.md) для библиотеки.

<a id="tips"></a>
## Советы

- Сначала выберите модель в [Браузере моделей] (model-browser.md), затем щелкните инструментом объекта: каждый щелчок создает новый проп с этой моделью и скином.
- Используйте `Shift` + щелчок, чтобы разместить ряд источников света, не теряя выделения, над которым вы работаете.
- Чтобы отредактировать значения ключей после размещения, откройте [Свойства объекта](entity-properties.md) (`Alt+Enter`).
- Инструменты MCP `create_entity` и `set_current_entity_class` делают то же самое с помощью помощника AI (см. [Справочник инструментов MCP](../MCP.md)).
- `set_tool_options` с инструментом `entity` задает, что поставит следующий щелчок: `class`, `model` (путь `.mdl`, пусто для отсутствия), `skin` (от 0 до 255) и `align` (пропы следуют наклону поверхности).

<a id="faq"></a>
## Частые вопросы

**Почему мой объект парит над полом?** Инструмент удерживает коробку объекта на поверхности; для модели используется коллизионная оболочка, которая может быть больше видимой сетки. Используйте `Alt` + щелкните или переместите его позже.

**Моего пользовательского объекта Lua нет в списке.** Введите его имя в поле поиска и выберите **Использовать «имя»**.

**Почему у объекта нет модели?** В браузере моделей модель не выбрана. Нажмите **Модели...**, выберите одну и разместите снова.
