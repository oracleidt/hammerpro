# Буфер обмена

Вырезайте, копируйте и вставляйте объекты карты, вставляйте множество копий одновременно с помощью специальной вставки, дублируйте выделенные фрагменты и копируйте ключевые значения из одного объекта в другие.

<a id="the-commands"></a>
## Команды

Все они находятся в меню **Редактировать** и в контекстном меню представлений:

| Команда | Сочетание клавиш | Описание |
|---|---|---|
| **Вырезать** | `Ctrl+X` | Копирует выбранные объекты в буфер обмена и удаляет их. |
| **Копировать** | `Ctrl+C` | Копирует выбранные объекты в буфер обмена. |
| **Вставить** | `Ctrl+V` | Вставляет содержимое буфера обмена; вставленные объекты становятся выделенными |
| **Специальная вставка...** | `Ctrl+Shift+V` | Открывает специальный диалог «Вставка» (несколько копий, смещение, поворот). |
| **Delete** | `Delete` | Удаляет выбранные объекты |
| **Дубликат** | `Ctrl+D` | Копирует выделение на один шаг сетки по X и Y без использования буфера обмена; копии выбраны |
| **Дубликат массива...** | `Ctrl+Shift+D` | Открывает диалог Массив: копии выделения по одной или нескольким осям с зазором между ними. |
| **Копировать ключевые значения** | нет | Копирует ключевые значения выбранного объекта. |
| **Вставьте ключевые значения** | нет | Вставляет их в выбранные объекты. |

<a id="where-paste-puts-the-objects"></a>
## Куда Paste помещает объекты

- `Ctrl+V` при наведении указателя на 2D-изображение: содержимое центрируется вокруг курсора и сохраняет свою глубину.
- `Ctrl+V` при наведении указателя на трехмерное изображение: содержимое находится на поверхности под курсором.
- Смещение следует за сеткой, поэтому объекты в сетке остаются на ней.
- В любом другом месте (меню, указатель за пределами представлений): объекты перемещаются на один шаг сетки по X и Y, если включен параметр **Смещение вставленных объектов** (по умолчанию), в противном случае они вставляются на исходное место.

<a id="what-the-clipboard-holds"></a>
## Что хранится в буфере обмена

Буфер обмена : это системный буфер обмена в виде текста VMF: блоки верхнего уровня `solid`, `entity` и `hidden`. Итак:

- Вы можете копировать между двумя окнами Hammer Pro, а также между Hammer Pro и Hammer или Hammer++ в обоих направлениях.
- Можно вставить любой фрагмент VMF, даже целый VMF. Визгруппы всего VMF объединены по имени.
- Ведущий блок `hammerpro_clipboard` (игнорируемый другими редакторами) содержит группы, поэтому вставка сохраняет группировку даже в другом экземпляре Hammer Pro.
- Вставленные объекты получают новые идентификаторы.

<a id="paste-special"></a>
## Специальная вставка

**Правка > Специальная вставка...** (`Ctrl+Shift+V`) вставляет буфер обмена несколько раз, при этом каждая копия перемещается и поворачивается относительно предыдущей (например, специальная вставка в Hammer):

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Копии** | Количество копий (от 1 до 10000; выше 1000 диалоговое окно предупреждает, что карта становится намного тяжелее) | 1 |
| **Смещение на копию** | Смещение X, Y, Z добавлено для каждой копии. Кнопка `<` рядом с осью принимает размер содержимого буфера обмена на этой оси (копирует рядом) | 64, 0, 0 |
| **Ротация каждой копии** | Поворот в градусах вокруг X, Y и Z добавлен для каждой копии вокруг центра скопированных объектов. | 0, 0, 0 |
| **Префикс имени** | Необязательный префикс, добавляемый к имени каждого именованного вставленного объекта. | пустой |
| **Начните с исходной позиции** | Первая копия размещается точно над скопированными объектами. | Выкл. |
| **Сгруппируйте каждую копию** | Каждая копия становится группой | Выкл. |
| **Сделайте имена объектов уникальными** | Вставленные объекты, имя которых уже существует, переименовываются (`name_2`, `name_3`...) | Выкл. |
| **Поворот вокруг оси** | Вращение происходит вокруг подвижной оси, а не вокруг центра скопированных объектов. Доступно только тогда, когда отображается ось (**Подвижная ось**) | Вкл. |

- В диалоговом окне отображается **Смещение последней копии**, чтобы вы могли проверить общую сумму.
- Пока диалоговое окно открыто, каждое изменение (копирование, смещение, поворот, начало в исходном положении, поворот вокруг оси вращения) немедленно отображает результат в виде зеленого каркасного призрака всех копий в 3D- и 2D-видах, а в диалоговом окне указывается, сколько объектов и копий отображается в предварительном просмотре. Ничего не будет вставлено, пока вы не нажмете **Вставить** или не нажмете `Enter`; **Отмена**, `Escape` или закрытие окна удаляет призрак. Предварительный просмотр следует за буфером обмена, если он изменяется при открытом диалоге, а при очень большом количестве копий показывает первые (в диалоге указано, сколько).
- Переименованные объекты продолжают работать вместе: ключи вставленных объектов, которые называют другой вставленный объект (цели, фильтры), следуют за новыми именами.
- `Enter` вставляется, `Escape` закрывается. Значения остаются в течение сеанса.
- Вся вставка представляет собой один шаг отмены.
- Инструмент MCP `paste_special` вставляет текст или буфер обмена (`text` или `from_clipboard`) с `copies`, `offset`, `rotation`, `pivot`, `start_at_original`, `group`, `unique_names` и `name_prefix`. С `preview: true` он ничего не вставляет и показывает в представлениях один и тот же зеленый призрак, отвечающий объектам, копиям, отображаемым копиям, количеству строк и границам призрака; `clear_preview: true` удаляет его, очищает и настоящая паста.

<a id="array-duplicate"></a>
## Дубликат массива

**Правка > Дубликат массива...** (`Ctrl+Shift+D`) дублирует выбранные браши и объекты вдоль одной или нескольких осей одновременно за один шаг отмены:

| Параметр | Описание | По умолчанию |
|---|---|---|
| **X, Y, Z** (флажки) | Оси для дублирования. Проверьте один для строки, два для сетки, три для блока | Х |
| **Копии** | Копии по каждой проверенной оси (от 1 до 1024; всего не более 4096 копий) | 3 |
| **Пробел** | Space между ограничивающими рамками двух соседей на этой оси (а не расстояние между центрами). Отрицательные значения перекрывают копии. | 0 |
| **Шаг** | Только для чтения: расстояние между двумя копиями на этой оси после выравнивания по сетке. | |

- Шаг каждой оси : это размер выделения на этой оси плюс зазор, округленный до активной сетки, и копии помещаются в сетку. Это следует за **активной сеткой**, включая повернутые и пользовательские сетки: X, Y и Z тогда являются осями этой сетки. Если параметр **Привязать к сетке** отключен, зазор используется точно.
- Копии по нескольким осям заполняют всю сетку (2 копии по X и 1 по Y создают 5 новых копий).
- Он работает с брашами, точечными объектами, брашами и группами. Новые копии выбираются. `Enter` применяется, `Escape` закрывается.
- Имена объектов нумеруются автоматически, см. ниже. Инструмент MCP `array_duplicate` делает то же самое с `axes`, `count` или `counts`, `gap` или `gaps` и `snap`.

<a id="names-of-duplicated-entities"></a>
## Имена повторяющихся объектов

Когда копия, вставка, дубликат, клон или массив содержат именованные объекты, имена которых уже существуют, копии получают новые имена, поэтому они никогда не конфликтуют:

- Имя, оканчивающееся цифрами, увеличивается: набор, состоящий из `porte1` (a `func_door`) и `btn1` (a `func_button`), становится `porte2` и `btn2`, следующая копия `porte3` и `btn3`. Один и тот же шаг номера используется для всего набора, и во всей карте всегда свободно следующее число (ведущие нули сохраняются: `door01` дает `door02`).
- Имя без цифр получает номер только тогда, когда это необходимо, чтобы избежать дублирования (`lamp` дает `lamp2`).
- Имена, которые еще не существуют (вырезав, затем вставив, вставив на другую карту), остаются такими, какие они есть.
- Все в скопированном наборе, указывающее на переименованную сущность, следует: цели выходов, `parentname` и ключи типа target (`target`, фильтры...) перезаписываются на новые имена. Ссылки на объекты вне набора остаются в покое.

<a id="duplicate-and-clone"></a>
## Дублировать и клонировать

**Дублировать** (`Ctrl+D`) копирует выделение на один шаг сетки по X и Y. С помощью [Инструмента выделения] (selection-tool.md) вы также можете клонировать, удерживая `Shift` во время перетаскивания (перемещение, масштабирование, поворот, наклон, гизмо, растягивание) или с помощью `Shift+arrow keys`. Все эти копии остаются в визгруппах своих оригиналов, если включен параметр **Сохранять визгруппы при клонировании** (страница **Выбор**, по умолчанию включено). Они не касаются буфера обмена.

<a id="copy-and-paste-keyvalues"></a>
## Скопируйте и вставьте ключевые значения

Выберите один объект и используйте **Правка > Копировать значения ключей**, затем выберите другие объекты и используйте **Правка > Вставить значения ключей**: каждый ключ вставляется, кроме `id`, `classname`, `origin` и `targetname`, за один шаг отмены. Копирование значений ключей также помещает ключи в системный буфер обмена в виде строк `"key" "value"`, которые можно прочитать в текстовом редакторе. Эти же две команды есть и в меню панели сущностей. Включите параметр **Вставить значения ключей, также вставляется имя (целевое имя)** (страница **Сущности и браузеры**, отключена по умолчанию), чтобы также вставить имя. См. [Свойства объекта](entity-properties.md).

<a id="settings"></a>
## Настройки

| Параметр | Страница | Описание | По умолчанию |
|---|---|---|---|
| **Смещенные вставленные объекты** | **Редактирование** | Вставка перемещает объекты на один шаг сетки, чтобы они не перекрывались (когда вставка не следует за курсором). | Вкл. |
| **Сохранять визгруппы при клонировании** | **Выбор** | Клоны остаются в визгруппах своих оригиналов. | Вкл. |
| **Вставка значений ключей также вставляет имя (целевое имя)** | **Объекты и браузеры** | Вставка ключевых значений также копирует `targetname` | Выкл. |

<a id="tips"></a>
## Советы

- Чтобы выложить ряд одинаковых частей с точным зазором, используйте **Дубликат массива** и проверьте одну ось.
- Чтобы выложить ряд одинаковых кусочков, скопируйте один, откройте «Специальная вставка», нажмите `<` на оси ряда и задайте количество копий.
- Винтовая лестница: один шаг, **Вращение на копию** 15 по оси Z и **Смещение на копию** 8 по оси Z, с поворотом на оси лестницы.
- **Файл > Экспортировать выделение как VMF...** сохраняет выделение в файл, а не в буфер обмена (см. [Совместимость VMF](../getting-started/vmf-compatibility.md)).

<a id="faq"></a>
## Частые вопросы

**Могу ли я вставить в Hammer?** Да. Буфер обмена содержит простые блоки VMF, которые читают Hammer и Hammer++. Блок групп там просто игнорируется.

**Вставка сообщает, что буфер обмена не содержит объектов карты.** Буфер обмена содержит что-то еще (текст, изображение). Сначала скопируйте объекты.

**Мои вставленные объекты потеряли свои ссылки.** Вставленные объекты автоматически переименовываются, если их имена существуют, и за ними следуют ссылки внутри вставленного набора. Используйте **префикс имени** в специальной вставке для собственного имени.
