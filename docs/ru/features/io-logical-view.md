# I/O и логическое представление

Выходы и входы соединяют объекты вместе: «когда это сработает, отправьте этот вход этим объектам». Hammer Pro редактирует их на вкладках **Выходы** и **Входы** панели объектов (редактор Hammer I/O), рисует их в виде линий в представлениях и показывает всю логику карты в виде схемы в логическом представлении.

<a id="opening-it"></a>
## Как открыть

| Что | Как |
|---|---|
| Вкладки «Выходы» и «Входы» | **Правка > Свойства** (`Alt+Enter`), затем вкладки **Выходы (N)** и **Входы (N)** на вкладке **Объект**. |
| Линии соединения на видах | **Вид > Параметры отображения > Показать соединения** переключает режим; **Настройки > Помощники > Input/output соединений** устанавливает его. |
| Окно логического просмотра | **Просмотр > Логический вид** (открывает и закрывает). |
| 2D-логическое представление в квадранте | **Вид > Логическое 2D-вид** устанавливает представление под курсором мыши (в противном случае используется последнее) или выберите **Логическое 2D** в меню типа представления заголовка представления. |
| Галерея объектов | **Карта > Вставить галерею объектов**. |

Ни у одного из них нет сочетания клавиш по умолчанию; вы можете привязать их в **Настройки > Клавиатура** (см. [Сочетания клавиш](keyboard-shortcuts.md)).

<a id="outputs-tab"></a>
## Вкладка «Выходы»

На вкладке перечислены выходные данные выбранных объектов. Если выбрано несколько объектов, отображаются только общие выходные данные (изменения применяются к соответствующим выходным данным каждого объекта), а в примечании указывается количество **Скрытых выходных данных (не общих для каждого выбранного объекта)**. У мира здесь нет выходов.

<a id="toolbar"></a>
### Панель инструментов

| Кнопка | Клавиша | Описание |
|---|---|---|
| **+ Добавить** | `Insert` | Добавляет выходные данные к каждому выбранному объекту и выбирает его. Новый вывод : `OnTrigger`, если он есть у класса, в противном случае : первый вывод класса, иначе `OnUser1`; он сгорает всегда. |
| **Копировать** | `Ctrl+C` | Копирует выбранные выходные данные (также в системный буфер обмена в виде строк `"Output" "value"`). |
| **Вставить** | `Ctrl+V` | Вставляет скопированные выходные данные в каждый выбранный объект. |
| **Delete** | `Delete` | Удаляет выбранные выходы. |
| (вырезать) | `Ctrl+X` | Копии затем удаляют выбранные выходные данные. |
| (выбрать все) | `Ctrl+A` | Выбирает каждую выходную строку. |
| **Отметить** | | Выбирает объекты, на которые нацелены выбранные выходные данные (имена, подстановочные знаки `*`, имена классов) и центрирует представления по ним. |

Клавиши : это сочетания клавиш приложений для копирования, вырезания, вставки, Delete и «Выбрать все». Они действуют на выходные данные, пока указатель мыши находится над вкладкой и ни одно текстовое поле не находится в фокусе; в остальных местах они действуют на карте как обычно.

Справа **Неверно: N** подсчитывает выходы с проблемой.

<a id="the-table"></a>
### Стол

Столбцы: столбец состояния (**!** для проблемы, иначе количество повторных срабатываний выхода ограничено), **Выход**, **Цель**, **Вход**, **Параметр**, **Задержка**. Проблема показана красным в своей ячейке:

- **Этот вывод не существует для этого класса**;
- **Ни один объект не имеет такого целевого имени**;
- **Цель не принимает эти входные данные**.

Наведите курсор на строку, чтобы узнать полное соединение, его параметр, задержку, повторные срабатывания и проблемы. Щелчок выбирает строку, `Ctrl+click` переключает одну, `Shift+click` выбирает диапазон.

<a id="editing-the-selected-outputs"></a>
### Редактирование выбранных выходов

Под таблицей редактор изменяет все выбранные выходные данные одновременно (**(несколько значений)**, если они различаются). **Выберите вывод для его редактирования (Ctrl и Shift выберите несколько).**

| Поле | Описание |
|---|---|
| **Мой выход по имени** | Выбор выходов класса (каждый выход, когда класс неизвестен). |
| **Названия целевых объектов** | Текст с завершением названий карты и специальных целей (`!self`, `!activator`, `!caller`, `!player`, `!pvsplayer`, `!speechtarget`, `!picker`). Красный, если ни у одной сущности нет имени. `Tab` завершает, выбирает стрелки, `Enter` принимает. |
| **Через этот вход** | Выбор входных данных классов, к которым разрешается цель (каждый входной сигнал, который разрешается ни к чему не известным). |
| **С переопределением параметра** | Произвольный текст, **<none>**, если он пуст. Двойные кавычки отклоняются; если введено `RunScriptCode`, **Использовать обратные кавычки** заменяет их обратными кавычками. |
| **После задержки в секундах** | От 0 до 3600 секунд. Перетащите или введите. |
| **Выстрелите несколько раз** | **Всегда** (-1) или число (Hammer++ срабатывает повторно). Перетащите или введите число; 0 пропускается, так как он никогда не сработает. |

<a id="inputs-tab"></a>
## Вкладка «Входы»

В нем перечислены выходные данные других объектов (и мира), нацеленных на выбранные объекты: **Выходные данные, нацеленные на этот объект: N**, со столбцами **Source**, **Выход**, **Вход**, **Параметр**, **Задержка**. Сущность без имени не может стать целью: так указано на вкладке.

Дважды щелкните строку или выберите ее и нажмите **Перейти к источнику**, чтобы выбрать исходный объект и центрировать представления по нему.

<a id="esc-delimiter"></a>
## разделитель ESC

Внутри файла карты поля вывода разделяются запятыми (старый Hammer) или символом ESC (более новые сборки Hammer и Hammer++). При использовании ESC параметр может содержать запятые. Garry's Mod читает оба.

**Настройки > Объекты и браузеры > Новые выходные данные используют разделитель ESC** (`[entities] io_esc_delimiter`, включено по умолчанию) : выбирает разделитель выходных данных, добавленных на вкладке **Выходные данные**. Существующие результаты сохраняют свои. Выходные данные, добавленные из логического представления, используют запятые.

<a id="connection-lines-in-the-views"></a>
## Линии соединения на видах

Каждый результат можно нарисовать в виде линии от объекта к каждой цели со стрелкой на цели в 2D- и 3D-видах.

| Режим | Ярлык настроек | Что нарисовано |
|---|---|---|
| Выкл. | **Скрыто** | Ничего. |
| Выбрано (по умолчанию) | **Выбранные объекты** | Результаты выбранных объектов и результаты, которые на них нацелены. |
| Все | **Каждая сущность** | Каждый вывод карты. |

**Вид > Параметры отображения > Показать соединения** циклически переключается «Выкл.», «Выбрано», «Все», и появляется уведомление о новом режиме. Режим сохраняется как `[helpers] connections`.

Цвета (легенда находится в разделе **Настройки > Помощники**):

- зеленый: **Действительно**;
- красный: **Отсутствует цель**, отображается в виде креста у источника;
- желтый: **Выход неизвестен для FGD**.

Специальные цели (`!activator`, `!player`...) разрешаются во время выполнения, поэтому они не получают строки.

<a id="logical-view"></a>
## Логическое представление

Логическое представление показывает объекты карты и их результаты в виде схемы. Оно существует в виде плавающего окна (**Вид > Логическое представление** с названием **Логическое представление**) и в виде типа представления из четырех представлений (**Логическое 2D**, например Hammer). Каждый квадрант, показывающий его, имеет собственное панорамирование, масштабирование, поиск и фильтр. Выбор : это выбор карты, поэтому он следует за другими видами в обоих направлениях.

<a id="what-is-shown"></a>
### Что показано

- Узлы: каждый объект карты по умолчанию, например Hammer: точечные объекты (`light`, `light_spot`, `light_environment`, `info_` объекты, логика...) и объекты браши, названные или нет. Узел показывает значок редактора своего класса (помощник FGD `iconsprite()` или `sprite()`, значок 2D- и 3D-представлений), имя (**(безымянное)**, если его нет) и класс с цветом акцента в зависимости от семейства классов (логика и фильтры, триггеры, `func_`, освещение и окружающая среда, пропы и NPCs, объекты информации и пути, другие). Объекты, скрытые визгруппой, отображаются блеклыми.
- Края: по одному на каждый выход, окрашенные в цвет линий соединения (зеленый : допустимый, красный : отсутствующая цель с крестиком и именем, желтый выход или вход неизвестны для FGD). Вывод в собственный объект зацикливается над узлом.
- Наведите курсор на край `Output > target.Input (parameter) after N s (once)` и, если проблема, укажите причину.
- При уменьшении масштаба текст и порты остаются за кадром, а края становятся прямыми, поэтому большие карты остаются плавными.

<a id="toolbar-1"></a>
### Панель инструментов

| Контроль | Описание |
|---|---|
| **Найти объект...** | Показывает только узлы, имя или класс которых содержит текст, и выделяет их во время ввода. `Enter` обрамляет результаты. |
| Фильтр | **Все объекты** (по умолчанию), **Именованные и подключенные** (объекты с именем или соединением) или **Только подключенные** (объекты с исходящим или входящим соединением). Каждое представление имеет свой собственный фильтр. |
| **Кадрировать все** | Показывает каждый объект (`Home` при наведении курсора мыши на вид). |
| **Выбор кадра** | Рамки результатов поиска, в противном случае : выбранных объектов. |
| **Упорядочить** | Автоматически размещает каждый объект и сохраняет позиции на карте (один шаг отмены, «Упорядочить логическое представление»). |

В строке состояния указано **Объекты: N, выходные данные: N**, количество результатов поиска, **Выходные данные с проблемой: N** и цветовая легенда.

<a id="mouse"></a>
### Мышь

| Действие | Результат |
|---|---|
| Щелкните узел | Выбирает его (`Ctrl` переключает, `Shift` добавляет). |
| Щелкните край | Выбирает исходную сущность. |
| Нажмите пустое место | Очищает выбор. |
| Перетащите на пустое место | Выбор поля (добавляет `Ctrl` или `Shift`). |
| Перетащите узел | Перемещает выбранные узлы; один шаг отмены («Перемещение в логическом представлении») при выпуске. |
| Перетащите из выходного порта узла на другой узел. | Открывает форму **Новый вывод**. |
| Дважды щелкните узел | Выбирает его и открывает его свойства. |
| Среднее или правое сопротивление | Сковороды. |
| Колесо | Масштабирует курсор. |
| `Escape` | Отменяет текущее перетаскивание. |

Скрытые объекты никогда не выбираются из логического представления.

Меню, вызываемое правой кнопкой мыши: **Свойства**, **Центрировать вид** и **Использовать автоматическое положение** (для выбранных узлов, положение которых сохранено).

<a id="positions"></a>
### Позиции

Позиции хранятся в ключе `logicalpos` каждого объекта, например Hammer, поэтому они сохраняются в VMF. Узлы без сохраненной позиции размещаются с помощью автоматического многоуровневого макета (источники слева, каждый выводит на один столбец правее), пересчитываемого только при изменении соединений. Перемещение узла сохраняет его положение; **Использовать автоматическое положение** удаляет его.

<a id="new-output-form"></a>
### Новая форма вывода

При перетаскивании из выходного порта на другой узел открывается **Новый выход**:

| Поле | Содержание |
|---|---|
| **Выход** | Выходные данные исходного класса, напечатанные или выбранные. Первое предложение : это результат самого класса, а не общих баз (`OnUser1`...); `OnTrigger`, когда класс неизвестен. |
| **Цель** | Целевое имя. Если у цели нет имени, в поле предлагается `class_id`: **У цели нет имени: она получает это**. |
| **Ввод** | Входные данные целевого класса, напечатанные или выбранные. |
| **Параметр** | Свободный текст. |
| **Задержка** | От 0 до 3600 секунд. |
| **Только один раз** | Срабатывает один раз, а не всегда. |

**Добавить** (включено, если заданы выходные данные, входные данные и имя цели) добавляет выходные данные, при необходимости сначала называя цель, за один шаг отмены. **Отмена** или `Escape` закрывает форму.

<a id="entity-gallery"></a>
## Галерея объектов

**Карта > Вставить галерею объектов** помещает по одному объекту каждого класса точек FGD в сетку в центре вида сверху, каждый из которых имеет ключевые значения по умолчанию для своего класса, за один шаг отмены. Интервал соответствует наибольшему размеру объекта (от 128 до 512 единиц). Используйте его, чтобы быстро проверить значки, модели и помощники, а затем отменить действия. Без FGD отображается сообщение **Определения объектов не загружены: галерее нужен FGD**.

<a id="tips"></a>
## Советы

- Заголовок вкладки «Выходы» становится выделенным, когда с выходом возникает проблема: обратите внимание на красные ячейки.
- Используйте **Упорядочить** один раз на импортированной карте, затем переместите нужные узлы: остальные будут следовать автоматическому расположению.
- Через MCP: `list_connections`, `add_connection`, `edit_connection`, `remove_connections`, `get_io_graph`, `list_targetnames`, `rename_targetname`, `check_entity`, `get_logical_graph` (узлы, значки и края логического представления с его фильтром) и `get_views` (квадрант вида `logical`). См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="faq"></a>
## Частые вопросы

**Почему на вкладке «Выходы» отображается меньше выходных данных, чем я ожидал?** Выбрано несколько объектов, и перечислены только те выходные данные, которые являются общими для всех. Выберите один объект, чтобы увидеть все его результаты.

**Почему мои выходные данные красные, хотя целевая существует?** Проверьте, какая ячейка красная: выходные данные могут не существовать для исходного класса, или входные данные могут не существовать для целевого класса в вашем FGD.

**Меняет ли расположение логического вида мою карту в игре?** Нет. `logicalpos` : это клавиша редактора, как в Hammer.

**Мои линии подключения исчезли.** **Показать соединения** переключается между тремя режимами: запускайте его снова, пока в уведомлении не будет указан нужный режим.

**Должен ли я оставить разделитель ESC включенным?** Да, для Garry's Mod: он читает оба, а ESC позволяет параметрам содержать запятые. Выключайте его только для инструментов, которые не могут читать ESC.
