# Операции с брашем

Команды, которые изменяют браши в целом: вырезание, создание пустот, слияние, привязка брашов к объекту и обратно к миру, преобразование в `func_detail`, запрет рисования на скрытых гранях, браши-подсказки и блокировки текстур, которые определяют, как текстуры следуют за преобразованиями.

Все они находятся в меню **Инструменты** (кроме **Создать браш-подсказку**, только в [палитре команд](command-palette.md)) и работают с текущим выделением. Каждый из них представляет собой один шаг отмены.

<a id="command-summary"></a>
## Сводка команд

| Команда | Сочетание клавиш по умолчанию | Потребности |
|---|---|---|
| **Вырезать** | `Ctrl+Shift+C` | одна или несколько брашов |
| **Сделать пустоту** | `Ctrl+H` | одна или несколько брашов |
| **Объединить браши** | `Ctrl+Shift+M` | минимум две браши |
| **Объединить с выпуклым телом** | нет | минимум две браши |
| **Пересекающиеся браши** | `Ctrl+Shift+K` | минимум две браши |
| **Союз брашов** | нет | минимум две браши |
| **Привязка к объекту** | `Ctrl+T` | выбор |
| **Свяжите каждого с отдельным объектом** | `Ctrl+Shift+T` | выделение с мировыми брашами |
| **Перейти в мир** | `Ctrl+Shift+W` | браши сущностей браши |
| **Сделать func_detail** | `Ctrl+Alt+D` | выделение с брашами мира |
| **Не рисовать на скрытых гранях...** | нет | ничего (сканирует всю карту) |
| **Создайте браш-подсказку** | нет (палитра команд) | грани, выбранные с помощью инструмента текстуры |
| **Блокировка текстур** | `Shift+L` | |
| **Блокировка масштаба текстур** | `Shift+K` | |

Если команде требуются браши, а ни одна из них не выбрана, отображается уведомление **Сначала выберите одну или несколько брашов** (или **Выберите хотя бы две браши**). Сочетания клавиш можно изменить в **Настройки > Клавиатура** (см. [Сочетания клавиш](keyboard-shortcuts.md)).

<a id="carve"></a>
## Вырезать

**Инструменты > Вырезать** (`Ctrl+Shift+C`) вычитает выбранные браши из мировых брашов, которые они пересекают, как в Hammer's Carve.

- Выбранные (резьбовые) браши не изменяются. Сохраните их или удалите позже.
- Обрезаются только видимые браши мира: браши сущностей и скрытые браши остаются в покое.
- Обрезанные браши разделены на несколько выпуклых частей с новыми идентификаторами граней. Далее следуют наложения и списки граней `env_cubemap`: разрезанное на части грань заменяется всеми ими, вырезанное полностью грань удаляется из списка.
- Браши режутся параллельно на всех ядрах процессора, поэтому вырезание сразу через сотни брашей остается быстрым.

Carve делает множество маленьких брашов. Для простых отверстий [инструмент выдавливания/вырезания] (extrude-tool.md) (контур, выделенный на одной грани, вырезается только этой брашем, с как можно меньшим количеством частей), [инструмент обрезки] (clip-tool.md) или несколько блочных брашов часто дают более чистую геометрию.

<a id="make-hollow"></a>
- Дисплейсменты на вырезанных брашах сохраняются на каждой части, как и у инструмента обрезки (см. [Инструмент обрезки](clip-tool.md)); **Пересечение** тоже их сохраняет.
## Сделать полым

**Инструменты > Сделать пустоту** (`Ctrl+H`) превращает каждую выбранную браш в стены. Для небольшого окна требуется указать **толщину стены**:

| Поле | Описание | По умолчанию |
|---|---|---|
| **Толщина стенки** | Толщина стен в единицах от -4096 до 4096. Отрицательное значение расширяется наружу: стены строятся за пределами браши, поэтому исходный объем становится внутренней комнатой. | 32 |
| **OK** / `Enter` | Пустота выделения. | |
| **Отмена** / `Esc` | Закрывается без изменений. | |

Поле толщины находится в фокусе клавиатуры при открытии окна, поэтому вы можете ввести значение и нажать `Enter`. Стенки каждой мировой браши группируются (например, Hammer) и выделяются. Если браш слишком мала для толщины, ничего не изменится и появится ошибка. Списки граней наложения и кубической карты перемещаются на внешние грани стен.

<a id="merge-brushes"></a>
## Объединить браши

**Инструменты > Операции с брашами > Объединить браши** (`Ctrl+Shift+M`) объединяет выбранные браши в одну только тогда, когда их объединение уже выпукло («Объединить браши» в Hammer++). Каждое грань сохраняет текстуру грани, из которого оно родилось.

- Если объединение не выпуклое, ничего не изменится и появится предупреждение: **Объединить в выпуклое тело**. Проверка точна до 0,02 единицы: ступенька или выемка, даже глубиной в одну единицу, никогда не заполняется.
- Все браши должны быть мировыми брашами или принадлежать одному и тому же объекту, в противном случае появится предупреждение **Все браши должны быть мировыми брашами или принадлежать одному объекту**.

<a id="merge-into-convex-solid"></a>
## Слияние с выпуклым телом

**Инструменты > Объединить в выпуклое тело** заключает выбранные браши в их выпуклую оболочку, даже если это добавляет объема. Результат заменяет первую браш (тот же идентификатор, данные владельца и редактора), а остальные удаляются.

<a id="intersect-brushes"></a>
## Пересекающиеся браши

**Инструменты > Операции с брашами > Пересекающиеся браши** (`Ctrl+Shift+K`) сохраняет только объем, общий для всех выбранных брашов. В результате получается одна выпуклая браш, которая заменяет первую выбранную браш (тот же идентификатор, данные владельца и редактора); остальные удалены.

- Выжившие грани сохраняют свою текстуру. Новые вырезанные грани принимают текстуру грани, которое их вырезало, например Carve.
- Если браши не перекрываются (прикосновения недостаточно), ничего не меняется и отображается предупреждение **Браши не перекрываются: нет общего объема, который можно было бы сохранить**.
- Все браши должны быть мировыми брашами или принадлежать одному и тому же объекту, в противном случае появится предупреждение **Все браши должны быть мировыми брашами или принадлежать одному объекту**.

<a id="union-of-brushes"></a>
## Союз брашов

**Инструменты > Операции с брашами > Объединение брашов** объединяет выбранные браши в наименьшее количество выпуклых брашов, которые точно покрывают их объединение, без добавления объема (в отличие от **Объединить в выпуклое тело**).

1. Перекрывающиеся браши обрезаются так, чтобы они больше не перекрывались, а части, скрытые внутри другой браши, удаляются.
2. Соприкасающиеся соседи снова объединяются в одну браш, если их объединение выпукло (точно, как для **Объединить браши**: ступенька в одну единицу сохраняется).

Таким образом, два перекрывающихся блока в линии становятся одним блоком, а форма L остается двумя брашами, которые соприкасаются, не перекрываясь. Каждая браш сохраняет свой идентификатор, пока в ней еще есть кусок; браши целиком внутри других удаляются. Новые фрагменты сохраняют данные владельца и редактора браши, из которой они взяты, и выбираются тогда, когда они были. Если ни к чему не может быть присоединено, отображается предупреждение **Нечего присоединять**. Применяется то же правило владельца, что и для **Объединить браши**. Один шаг отмены. Разрезание идет на всех ядрах процессора, а пары, которые никогда не дадут выпуклую браш, сразу пропускаются, поэтому объединение нескольких сотен брашей занимает долю секунды.

<a id="tie-to-entity"></a>
## Привязать к сущности

**Инструменты > Привязать к объекту** (`Ctrl+T`) ведет себя как Hammer:

- Если среди выделенных только один объект браши плюс другие браши, эти браши добавляются к этому объекту, который сохраняет свой класс и ключи.
- Если выбрать один объект браши, откроются его свойства.
- В противном случае выделение привязано к новому объекту браши класса **Объект браши по умолчанию** (настройка `default_brush_entity`, по умолчанию `func_detail` в **Настройки > Редактирование > Новые объекты**) со значениями ключей по умолчанию для этого класса из FGD.
- Когда класс FGD имеет ключ `origin` (`func_tracktrain`, `func_tanktrain`, `func_rotating`, `func_door_rotating`...), новый объект помещает его в центр своих брашов, как Hammer. Игра перемещает и поворачивает объект вокруг этой точки: поезд помещает его в узлы `path_track` (поднятые ключом `height`). **Инструменты > Центрировать начало** позже перемещает его обратно в центр.

Браши, взятые из других объектов-брашов, перемещаются в объект, а объекты-браши, оставшиеся без брашов, удаляются. Объект выбирается и открывается панель **Свойства объекта** (см. [Свойства объекта](entity-properties.md)).

<a id="tie-each-to-its-own-entity"></a>
## Привяжите каждого к своей сущности

**Инструменты > Привязать каждый к своему собственному объекту** (`Ctrl+Shift+T`, Hammer++) помещает каждую выбранную мировую браш в отдельный новый объект класса объектов браши по умолчанию. Браши, которые уже принадлежат объекту, остаются в покое. Новые объекты будут выбраны, и откроется панель объектов.

<a id="move-to-world"></a>
## Переместиться в мир

**Инструменты > Переместить в мир** (`Ctrl+Shift+W`) перемещает браши выбранных объектов браши обратно в мир. Объекты браши, оставшиеся без брашов, удаляются. Перемещенные браши выбраны.

<a id="convert-to-func_detail"></a>
## Сделать func_detail

**Инструменты > Операции с брашами > Сделать func_detail** (`Ctrl+Alt+D`, также кнопка **В func_detail** на панели инструментов и контекстное меню видов) превращает выбранные браши мира в `func_detail` за один шаг отмены, каким бы ни был класс объекта браши по умолчанию: один объект на выделение (или на группу соприкасающихся брашей), группы, visgroup и текстуры сохраняются, браши, уже входящие в `func_detail`, остаются как есть. Сначала проверка утечек убеждается, что ни один браш не герметизирует карту, и спрашивает перед преобразованием таких брашей. Если выделение уже является `func_detail`, отображается уведомление **Выбор уже func_detail**. **Инструменты > Операции с брашами > Выбрать кандидатов в func_detail...** находит браши, которые стоит преобразовать. Всё описано на странице [func_detail](func-detail.md).

<a id="nodraw-on-hidden-faces"></a>
## Не рисовать на скрытых гранях

**Инструменты > Операции с брашами > Не рисовать на скрытых гранях...** ищет по всей карте грани браши, полностью покрытые другими брашами, которые никогда не видны.

1. Поиск выполняется в фоновом режиме (**Поиск скрытых граней...** в консоли).
2. Найденные грани выбираются, и [инструмент нанесения текстуры] (texture-tool.md) становится активным, и вы можете проверить их на видах.
3. В окне написано, сколько граней было найдено. **Применить nodraw** дает им `tools/toolsnodraw`, **Отмена** закрывает его.

Правила, используемые при поиске:

- Кандидатами являются грани видимого мира и браши `func_detail`, которые не являются дисплейсментами и еще не имеют текстуры инструмента.
- Покрывающие браши : это браши видимого мира без дисплейсментов и без прозрачных материалов. Текстуры инструментов, отличные от nodraw, black и skybox, считаются прозрачными, как и названия материалов, содержащие стекло, воду, окно, забор, решетку, звено цепи, полупрозрачный или альфа.
- `func_detail` никогда ничего не скрывает, поэтому грани между двумя брашами `func_detail` остаются в покое.

Если задействованная браш изменилась между поиском и **Применить отсутствие рисования**, ничего не применяется и отображается **Карта изменилась с момента поиска: запустите ее снова**.

<a id="make-hint-brush"></a>
## Сделать браш-подсказку

**Создать браш-подсказку** (только палитра команд) превращает браши в браши-подсказки: выберите грани, которые должны стать гранями-подсказками, с помощью [инструмента нанесения текстуры] (texture-tool.md), затем запустите команду. Эти грани получают `TOOLS/TOOLSHINT`, а все остальные грани их брашов : `TOOLS/TOOLSSKIP`. Если грани не выбраны, отображается уведомление **Сначала выберите грани, которые станут подсказками, с помощью инструмента текстуры**. Консоль сообщает, сколько брашов-подсказок было сделано.

<a id="texture-lock-and-texture-scale-lock"></a>
## Блокировка текстур и блокировка масштаба текстур.

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Блокировка текстур** (`Shift+L`, `texture_lock`) | Текстуры следуют за брашами, когда они перемещаются, вращаются, масштабируются или переворачиваются. Выключено, текстуры остаются фиксированными в мире (и выравниваются по миру, когда повернутое грань больше не может их использовать). | на |
| **Блокировка масштаба текстуры** (`Shift+K`, `texture_scale_lock`) | Масштабирование браши также масштабирует ее текстуру. Используется только с включенной блокировкой текстур. Без него текстура сохраняет свой масштаб и остается прикрепленной к центру браши. | выкл. |

Оба находятся в меню **Инструменты** в разделе **Настройки > Редактирование > Поведение**, а в диалоговом окне «Преобразование» отображается блокировка текстуры с помощью кнопки **Переключение** (см. [Преобразование и выравнивание](transform-align.md)). Они сохраняются в таблице `[edit]` в `settings.toml`.

<a id="mcp"></a>
## MCP

Для помощников AI: `carve`, `hollow`, `merge_brushes` (`convex_hull` верно для слияния в выпуклое тело), `intersect_brushes`, `union_brushes`, `tie_to_entity`, `move_to_world`, `make_func_detail`, `select_detail_candidates`, `make_hint_brushes`, `find_hidden_faces`, `apply_nodraw` и `run_action` для других команд. См. [ссылку на инструмент MCP](../MCP.md).

<a id="tips"></a>
## Советы

- Используйте отрицательную толщину в **Сделать полым**, чтобы превратить блок, нарисованный по размеру комнаты, в эту комнату со стенами наружу.
- Запустите **Nodraw on скрытых граней...** перед окончательной компиляцией: скрытые грани тратят на рендеринг и пространство карты освещения впустую.
- `Ctrl+T` с существующим объектом браши и выбранными новыми брашами добавляет их к этому объекту: удобно расширить дверь или `func_detail`.
- Установите **Объект браши по умолчанию** для класса, который вы используете чаще всего (например, `func_brush`), чтобы `Ctrl+T` и `Ctrl+Shift+T` создавали его напрямую.

<a id="faq"></a>
## Частые вопросы

**Carve ничего не делал на моем func_detail.** Carve только обрезал браши мира. Сначала используйте **Переместить в мир**, вырежьте, а затем снова свяжите детали.

**При объединении брашов указывается, что форма не выпуклая.** Объединенные браши должны образовывать выпуклую браш. Используйте **Объединить в выпуклое тело**, если можно добавить объем, или сохраните их как отдельные браши.

**Объединение брашов оставляет несколько брашов.** Результат состоит только из выпуклых брашов, поэтому для невыпуклого объединения (L, T) требуется как минимум две. Они больше не перекрываются и не имеют общих внутренних граней.

**Сделать углубление не удалось.** Браш слишком тонкая для толщины стены. Уменьшите толщину или увеличьте браш.

**Почему в инструменте текстурирования выбраны неотрисованные грани?** Чтобы вы могли проверить их перед применением. Ничего не изменится, пока вы не нажмете **Применить nodraw**.
