# Преобразовать и выровнять

Команды, которые перемещают, вращают, масштабируют, зеркально отражают, выравнивают или отбрасывают выбранные объекты по точным правилам вместо перетаскивания маркеров: диалоговое окно «Преобразование», «Выравнивание», «Переворот», «Привязка к сетке», «Перемещение к floor/ceiling», «Центр координат», «Произвольное вращение по оси Z», «Подвижный шарнир», «Физическое размещение» и массивы (Специальная вставка).

Каждая команда ниже работает с текущим выбором и представляет собой один шаг отмены. Большинство из них находятся в меню **Инструменты** (выравнивание, отражение, перемещение на пол, начала координат и случайный поворот собраны в подменю **Инструменты > Расположение**). Чтобы перетащить объекты с помощью мыши, см. [Инструмент выбора] (selection-tool.md).

<a id="transform-dialog"></a>
## Диалоговое окно преобразования

**Инструменты > Трансформировать...** (`Ctrl+M`) открывает окно **Трансформировать**: переместите, поверните или масштабируйте выделение по введенным значениям. Окно сохраняет свои значения на протяжении всего сеанса, поэтому вы можете применять одно и то же преобразование несколько раз.

| Поле | Описание | По умолчанию |
|---|---|---|
| **Переместить** / **Повернуть** / **Масштабировать** / **Случайное Z** | Кнопки режимов вверху. **Случайное вращение по оси Z** описано в разделе [Случайное вращение по оси Z](#random-z-rotation). | **Переместить** |
| **Смещение** (Переместить) | Расстояние X, Y, Z в единицах, добавленных к выделению. | 0 0 0 |
| **Углы (градусы)** (Поворот) | Вращение вокруг X, Y и Z: сначала применяется Z, затем Y, затем X (в том же порядке, что и специальная вставка). | 0 0 0 |
| **Факторы** (Масштаб) | Масштабный коэффициент по X, Y и Z (шаг перетаскивания 0,01). Коэффициент 0 отклоняется (**Масштабные коэффициенты не могут быть равны нулю**). Негативные факторы зеркальны. | 1 1 1 |
| **Поворот** (только поворот и масштабирование) | **Центр выделения**: центр границ выделения. **Мировое начало**: точка 0 0 0. **Подвижный стержень**: крест стержня (см. ниже); кнопка неактивна, а точка поворота скрыта, а ее всплывающая подсказка указывает положение точки поворота. | **Центр выбора** |
| **Блокировка текстур** | Показывает, включена ли блокировка текстур; **Toggle** переключает его (так же, как `Shift+L`). | следует настройке |
| **Сброс** | Возвращает значения текущего режима к значениям по умолчанию (0 или 1). | |
| **Применить** | Применяет преобразование (также `Enter`). Выделено серым цветом, ничего не выбрано. | |
| **Закрыть** | Закрывает окно (также `Esc`). | |

Строка под полями подсчитывает выбранные объекты. Ошибки (ничего не выбрано, недопустимые значения, неудачное преобразование) отображаются в окне красным цветом.

При открытии окна и при смене режима курсор встаёт в первое поле (X), его текст выделен, так что можно сразу печатать. `Tab` и `Shift+Tab` переходят между полями и кнопками окна по кругу и никогда не доходят до сочетаний клавиш видов (например, `Tab`, который переключает 2D-вид).

Поворот смешанного выделения поворачивает всё вокруг одной опорной точки в одну сторону, как в Hammer: браши, пропы, точечные сущности и источники света. Для `light_spot`, `light_environment` и `light_directional` свет светит туда, куда его повернули: ключ **Pitch** получает новый наклон (положительный вверх, как его читает VRAD), а углы записываются как в Hammer, поэтому модель прожектора смотрит вдоль луча. Ручки поворота, гизмо, специальная вставка и инструменты MCP `rotate_objects` и `transform_objects` поворачивают объекты так же.

<a id="snap-to-grid"></a>
## Привязка к сетке

- **Привязать выделение к сетке** (`Ctrl+B`): перемещает выделение целиком так, чтобы минимальный угол его границ находился в ближайшей точке текущей сетки. В инструментах «Выделение», «Вершина» и «Скос» `Ctrl+B`, когда курсор находится на краю браши в 3D-виде, вместо этого скашивает этот край (см. [Инструмент «Скос»](bevel-tool.md)).
- **Привязать каждый объект к сетке** (`Ctrl+Shift+B`): делает то же самое для каждого выбранного объекта отдельно.

Размер сетки : это текущий размер сетки (см. [Сетки](grids.md)).

<a id="move-to-floor-and-ceiling"></a>
## Переходим к полу и потолку

Выпадение в стиле Hammer++:

- **Переместить на пол** (`Alt+N`) перемещает каждый объект прямо вниз, пока его настоящая форма не коснется настоящей поверхности под ним: самая нижняя точка сетки модели пропа (с учетом углов и масштаба) ложится точно на браши, дисплейсменты и сетки других пропов, без зазора и без пересечения. Это тот же механизм, что и у инструмента MCP `drop_to_surface`.
- **Переместить к потолку** (`Alt+U`) перемещает его прямо вверх.
- Варианты **выровнены по поверхности** (`Ctrl+Alt+N`, `Ctrl+Alt+U`) также поворачивают точечные объекты так, что их верхняя ось повторяет нормаль поверхности, на которую они приземляются, максимально сохраняя направление.

Подробности:

- Каждая группа (самая внешняя группа) или разгруппированный объект перемещается самостоятельно.
- Погруженный в пол объект поднимается на него, а не проваливается. Невидимые служебные браши (clip, trigger, hint...) поверхностями не считаются.
- Браши и пропы (объекты с моделью `.mdl`) являются поверхностями. Сами перемещенные объекты игнорируются.
- Объект, у которого нет ничего ниже (или выше), остается на месте. Когда ничего не движется, появляется сообщение: **Нет поверхности ниже выделенного** (или выше).
- Другие команды по реальным формам (поставить на другой объект, прижать к стене, поставить рядом, опустить висящие пропы, подогнать ножки к земле) находятся в **Инструменты > Размещение и пропы**: см. [Размещение по реальным формам](real-shape-placement.md).

<a id="physics-placement"></a>
## Размещение по физике

**Инструменты > Размещение физики (падение и стабилизация)** сбрасывает выбранные объекты один за другим, начиная с самых низких, поэтому каждый из них опирается на землю или на уже размещенные объекты, а не проходит сквозь них, как объекты, падающие под действием силы тяжести. Группа падает целиком. Проп наклоняется к поверхности, на которую он приземляется. Касания считаются по настоящим сеткам пропов и настоящим формам брашей и дисплейсментов. Когда все уже лежит на поверхности, отображается уведомление **Нечего удалять: выделенный фрагмент уже лежит на поверхности.**.

<a id="flip"></a>
## Перевернуть

«Отразить» отражает выделение по плоскости, которая проходит через подвижную опорную точку, когда она отображается, а в противном случае : через центр выделения.

- **Повернуть X**, **Повернуть Y**, **Повернуть Z** отразить зеркально вдоль этой мировой оси.
- **Перевернуть по горизонтали** (`Ctrl+L`) и **Перевернуть по вертикали** зависят от вида под указателем мыши (в противном случае используется последний вид). В 2D-виде они отражаются вдоль горизонтальной или вертикальной оси этого вида. В 3D-виде горизонтально зеркально отражается вдоль мировой оси (X или Y), ближайшей к правому направлению камеры, и вертикально вдоль Z.

Браши сохраняют внешние грани, и их перемещения отражаются вместе с ними. Применяется блокировка текстур.

<a id="align"></a>
## Выровнять

Выравнивание стиля Hammer: выбранные объекты выравниваются по **последнему выбранному объекту**, который не перемещается. Необходимо как минимум два объекта (**Выберите не менее двух объектов**).

| Команда | Выстраиваются в ряд |
|---|---|
| **Выравнивание по левому краю** | минимум границ на горизонтальной оси вида |
| **Выравнивание по правому краю** | максимум по горизонтальной оси |
| **Выровнять по верху** | максимум по вертикальной оси |
| **Выровнять по низу** | минимум по вертикальной оси |
| **Выровнять центры по горизонтали** | центры на горизонтальной оси |
| **Выровнять центры по вертикали** | центры на вертикальной оси |

Оси : это оси 2D-вида под указателем (или последнего использованного). В 3D-виде используются оси вида сверху. Остальные объекты движутся вместе как один блок.

<a id="center-origins"></a>
## Истоки центра

**Инструменты > Центрировать начало** устанавливает ключ `origin` выбранных объектов браши (`func_door_rotating`, `func_rotating`...) в центр их брашов. Используйте браш только для объектов, у которых есть изменение ключа `origin`; достаточно выбрать одну из их брашов. Если ничего не изменилось, отображается уведомление **Ни один выбранный объект браши не имеет начала координат в центре**.

<a id="random-z-rotation"></a>
## Случайное вращение по оси Z

**Инструменты > Расположение > Случайное вращение по оси Z** поворачивает каждый выбранный точечный объект, имеющий клавишу `angles` (`prop_static`, `prop_dynamic`, `prop_physics`, источники света, любой точечный объект с углами) вокруг Z на свою случайную величину, вокруг своего собственного начала. Это один шаг отмены (**Случайное вращение**). Браши, объекты-браши и объекты без ключа `angles` пропускаются; в уведомлении указано, сколько поворотов и сколько пропущено, например **Случайное вращение по оси Z: 12 поворотов, 3 пропущено (браши, объекты браши или ключ без углов)**.

Параметры находятся в режиме **Случайное Z** окна «Преобразование» (**Инструменты > Параметры произвольного вращения по Z...**), сохраняются в настройках:

| Поле | Описание | По умолчанию |
|---|---|---|
| **Диапазон отклонения** | Поворот, добавляемый к рысканию каждого объекта, выбирается между этими двумя значениями в градусах. | от 0 до 360 |
| **Мгновенный шаг** | **Свободно**, **15°**, **45°**, **90°** или любой шаг до 180: поворот кратен шагу (при значениях от 0 до 360 и 90 каждый объект обращен в одно из четырех направлений). | Бесплатно |
| **Дрожание по тангажу и крену** | Также наклоняет наклон и крен на случайную величину до указанного количества градусов (от 0 до 45). | выкл., 3° |
| **Сброс** | Возвращает эти параметры к значениям по умолчанию. | |
| **Применить** | Поворачивает выделение (также `Enter`); в окне написано, сколько обратилось. | |

Возможные варианты: клавиши `random_yaw_min`, `random_yaw_max`, `random_yaw_snap`, `random_tilt` и `random_tilt_deg` таблицы `[selection]` (см. [Справочник по настройкам](../reference/settings.md)).

<a id="movable-pivot"></a>
## Подвижный шарнир

**Инструменты > Подвижная точка** отображает перекрестие оси в центре выделения (в начале одноточечного объекта) или скрывает его, когда оно отображается.

- С помощью [Инструмента выбора] (selection-tool.md) перетащите крестик в 2D-виде, чтобы переместить его (он привязывается к сетке, когда привязка к сетке включена). В 3D-виде штуковина находится на шарнире: возьмите ее ближе к центру штуковины.
- Вокруг него вращаются вращения и масштабы ручек, гизмо и модальные преобразования. Переверните через него зеркала. В диалоговом окне «Преобразование» он используется с **Поворот > Подвижная точка**, а специальная вставка : с **Поворот вокруг оси**.
- Поворот перемещается вместе с объектами, когда вы их перемещаете. Он удаляется при изменении выбранного набора (например, Hammer++).

<a id="arrays-paste-special"></a>
## Массивы (специальная вставка)

**Правка > Специальная вставка...** (`Ctrl+Shift+V`) вставляет несколько копий буфера обмена, каждая из которых перемещается и поворачивается немного больше, чем предыдущая: лестницы, колонны, круг объектов. Поля: **Копии** (до 10 000, с предупреждением выше 1000), **Смещение на копию** (по умолчанию 64 0 0, с кнопками **<**, которые перемещают размер буфера обмена по оси), **Вращение на копию**, **Поворот вокруг оси**, **Начать с исходной позиции**, **Группировать каждую копию**, **Сделать имена объектов уникальными** и **Имя. префикс**. Полное описание находится на странице [Вырезать, копировать и вставить](clipboard.md).

<a id="texture-lock-and-texture-scale-lock"></a>
## Блокировка текстур и блокировка масштаба текстур.

- **Блокировка текстур** (`Shift+L`, настройка `texture_lock`, по умолчанию включено): текстуры следуют за брашами, когда они перемещаются, вращаются, масштабируются или переворачиваются. Выключено, текстуры остаются фиксированными в мире.
- **Блокировка масштаба текстуры** (`Shift+K`, настройка `texture_scale_lock`, по умолчанию отключено): масштабирование браши также масштабирует ее текстуру. Используется только с включенной блокировкой текстур; без него текстура сохраняет свой масштаб.

Оба также находятся в **Настройки > Редактирование > Поведение** и сохраняются в таблице `[edit]` `settings.toml`.

<a id="mcp"></a>
## MCP

Те же операции существуют для помощников AI: `transform_objects`, `move_objects`, `rotate_objects`, `resize_objects`, `snap_objects_to_grid`, `drop_to_surface`, `flip_objects`, `align_objects`, `center_entity_origins`, `random_rotate_objects` (произвольное вращение по оси Z с его диапазоном, привязкой, наклоном и начальным значением), `array_duplicate` и `run_action` (например, `physics_placement` или `toggle_pivot`). См. [справку по инструменту MCP](../MCP.md).

<a id="tips"></a>
## Советы

- Чтобы повернуть дверь вокруг петли, отобразите **Подвижную ось**, перетащите ее на петлю, затем поверните ее за ручки или установите для параметра **Трансформировать...** значение **Подвижная ось**.
- Выравнивание использует последний выбранный объект в качестве ссылки: Ctrl+щелкните последнюю ссылку.
- **Переместить на пол** для группы пропа перемещает всю группу как одну, поэтому стол с объектами остается собранным.
- **Привязка каждого объекта к сетке** позволяет исправить множество объектов вне сетки одновременно, не перемещая их все на одинаковую величину.
- После размещения ряда одинаковых камней, ящиков или деревьев **Случайное вращение по оси Z** делает их менее скопированными; установите **Шаг привязки** на 90° для ящиков, которые должны оставаться перпендикулярными стенам.

<a id="faq"></a>
## Частые вопросы

**Почему «Подвижная опорная точка» выделена серым цветом в диалоговом окне «Преобразование»?** Поворотная точка скрыта. Сначала используйте **Инструменты > Подвижная точка**.

**Моя опорная точка исчезла.** Она удаляется при изменении выделения. Покажите его еще раз после выбора.

**Выравнивание ничего не делает.** Выберите как минимум два объекта и убедитесь, что ссылка (последний выбранный объект) еще не совмещена с другими объектами на этой оси.

**Перемещение на пол не привело к перемещению ни одной пропы.** Под ним ничего не было. Поверхностями считаются только браши и проп (объекты с моделью `.mdl`); другие точечные объекты этого не делают.
