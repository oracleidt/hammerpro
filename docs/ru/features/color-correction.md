# Цветокоррекция

Hammer Pro создает таблицы поиска цветов, которые Garry's Mod использует для объектов `color_correction`, и просматривает эти объекты в 3D-изображениях так, как их применяет игра.

Два инструмента:

- **редактор цветокоррекции**, который создает и редактирует таблицу с живыми изображениями «до» и «после» и может отображать ее в 3D-изображениях;
- предварительный просмотр **color_correction**, который применяет таблицы, названные объектами `color_correction` и `color_correction_volume` карты, в зависимости от расстояния до камеры.

<a id="the-file-format-and-where-it-goes"></a>
## Формат файла и его расположение

Таблица цветокоррекции представляет собой файл `.raw` размером ровно 98304 байт: куб 32 x 32 x 32 байтов RGB (32 x 32 x 32 x 3), красный цвет меняется быстрее всего, затем зеленый, затем синий. Таблица идентичности оставляет каждый цвет неизменным.

Сущность `color_correction` называет свою таблицу с помощью ключа **Имя файла поиска** (`filename`). Движок считывает этот путь через свою файловую систему относительно папки игры или дополнения, поэтому значение ключа должно быть путем к файлу в том виде, в котором он поставляется. Редактор предлагает три папки:

| Папка | Примечания |
|---|---|
| `scripts/colorcorrection` (по умолчанию) | `scripts/colorcorrection/cc_name.raw`. |
| `materials/colorcorrection` | Тот же механизм, другая папка. |
| `materials/correction` | Соглашение Source SDK (`materials/correction/cc_name.raw`). |

Какую бы папку вы ни выбрали, редактор показывает точную цифру `Lookup Filename`, которую нужно ввести, с помощью кнопки **Копировать**. Если вы публикуете дополнение в Мастерской, убедитесь, что выбранная вами папка разрешена белым списком дополнений упаковщика дополнений Garry's Mod.

<a id="opening-the-editor"></a>
## Открытие редактора

- **Инструменты > Редактор цветокоррекции...** (действие `color_correction_editor`) открывает окно и снова закрывает его.
- MCP: `open_media_editor` с `editor`, установленным на `color` (и `path` для загрузки `.raw`).

<a id="the-editor"></a>
## Редактор

Левый столбец содержит элементы управления, правый : предварительный просмотр и сохранение.

| Раздел | Параметры |
|---|---|
| **Предустановки** | Нейтральный, Черно-белый, Сепия, Теплый, Холодный, Высокий контраст, Блеклый, Ночной, Яркий, Кинематографичный, Ужасы, Инвертировать. Предустановка заменяет текущие настройки. |
| **Базовый** | Экспозиция (EV, при линейном освещении), Яркость, Контраст, Гамма, Насыщенность, Яркость (больше усиливает тусклые цвета), Оттенок (градусы), Инвертировать. |
| **Цветовой баланс** | Температура (от прохладного до теплого), Зеленый/пурпурный, Тени и Светлые участки (поднимите или опустите только темную или только яркую часть). |
| **Оттенок и раскрашивание** | Tint умножает цвета на цвет; Colorize заменяет оттенок на цвет, сохраняя при этом яркость (сепия, дуотон). У каждого есть сумма. |
| **Уровни** | Входной черный и белый, средние тона (гамма), выходной черный и белый, для главного RGB и для красного, зеленого и синего каналов. |
| **Кривые** | Плавная кривая для каждого канала (основной RGB, красный, зеленый, синий). Щелкните, чтобы добавить точку, перетащите точку, чтобы переместить ее, щелкните точку правой кнопкой мыши, чтобы удалить ее. |

Щелкните правой кнопкой мыши ползунок, чтобы сбросить его. Порядок операций следующий: экспозиция, температура и баланс оттенков, яркость, контрастность, тени и светлые участки, уровни, кривые, гамма, оттенок, насыщенность и яркость, оттенок, раскрашивание, инвертирование.

<a id="preview"></a>
### Предварительный просмотр

**До** и **После** показывают встроенный тестовый шаблон (небо, полосу оттенков, серую шкалу, оттенки кожи, образцы цвета) или любое изображение, загруженное вами с помощью **Использовать изображение...**. Линия под изображениями показывает, насколько далеко таблица перемещает цвета.

**Предварительный просмотр в 3D-видах** включается при открытии редактора и сразу отражает изменения настроек. Чтобы учитывать расстояние и границы объёма, перед открытием выберите один объект `color_correction` или `color_correction_volume`. Его максимальный вес и состояние включения также сохраняются. Остальные объекты используют собственные таблицы. Без выбранной коррекции черновик применяется глобально с полным весом. Закрытие окна или отключение просмотра восстанавливает просмотр карты.

<a id="importing-a-raw"></a>
### Импорт .raw

**Импортировать .raw...** выбирает файл; поле рядом с ним загружает игровой путь (`scripts/colorcorrection/cc_name.raw`). Импортированная таблица становится базовой, и все исправления применяются поверх нее, поэтому вы можете уточнить существующую таблицу. **Удалить** возвращает к базе данных.

<a id="saving"></a>
### Сохранение

Выберите **Папку игры или аддона** (корень, кнопкой **Обзор...**), **Подпапку** внутри неё и **Имя**, затем **Сохранить .raw**. По умолчанию корневой папкой является папка над папкой `maps` сохраненной карты, в противном случае : папка с игрой. Существующий файл заменяется только в том случае, если вы установите флажок **Заменить существующий файл**.

<a id="previewing-the-color_correction-entities-in-the-3d-views"></a>
## Предварительный просмотр объектов color_correction в 3D-видах

Самый быстрый способ : режим рендеринга **3D-цветокоррекция** (**Вид > Режим 3D-рендеринга**, `Alt+9`, список режимов панели инструментов, MCP `set_render_mode` с `color_corrected`): текстурированный вид с примененными справочными таблицами объектов карты, без включения настройки ниже. Это текстурированный режим плюс предварительный просмотр, поэтому он подчиняется тем же правилам.

**Просмотр > Параметры отображения > Предварительный просмотр color_correction объектов** (действие `toggle_color_correction_preview`, настройка `lab.color_correction_preview`, по умолчанию отключено) применяет таблицы поиска объектов карты к 3D-представлениям с камеры редактора или, в [виде игрока] (player-view.md), с камеры игрока. Далее идет игра:

| Ключевое значение | Эффект |
|---|---|
| `filename` | Стол. Сущность без читаемой таблицы ничего не делает (инструмент MCP сообщает `no_file` или `file_not_found`). |
| `minfalloff`, `maxfalloff` | Полный вес до `minfalloff` единиц, постепенное затухание до 0 при `maxfalloff`. Когда либо равно -1, либо оба равны, вес не зависит от расстояния. |
| `maxweight` | На него умножается вес. |
| `fadeInDuration`, `fadeOutDuration` | Секунды, необходимые для исчезновения, когда объект становится активным, и исчезновения, когда он останавливается. |
| `exclusive` | Хотя эксклюзивный объект имеет некоторый вес, неэксклюзивные игнорируются. |
| `StartDisabled` | Объект при запуске отключен (входы `Enable` и `Disable` существуют только в запущенной игре). |

Несколько объектов смешиваются: их веса суммируются (уменьшаются вместе, когда общее число превышает 1), а остальное представляет собой неизмененное изображение. Объекты `color_correction_volume` (`filename`, `maxweight`, `fadeDuration`, `StartDisabled`) применяются, когда камера находится внутри их брашов.

Поиск выполняется самим 3D-проходом: окончательное изображение преобразуется в отображаемые цвета, ищется в таблице с помощью трилинейной фильтрации и преобразуется обратно. Коррекция применяется в каждом режиме затенения и отделена от цветовой коррекции настроек освещения Hammer++ для всей карты, которая по-прежнему следует за запеченным отображением освещения.

<a id="mcp"></a>
## MCP

| Инструмент | Использование |
|---|---|
| `color_correction_presets` | Предустановки, параметры уклона с их диапазонами, формат файла и соглашение о пути. |
| `color_correction_generate` | Создает таблицу из `preset` или `grade` (и необязательной таблицы `base`) и сохраняет ее как `root/folder/name.raw`; возвращает точное значение ключа `filename`. `dry_run` сообщает без записи. |
| `color_correction_inspect` | Проверяет `.raw` (размер, идентичность, средний цвет, насколько далеко перемещаются цвета). |
| `color_correction_preview` | «Предварительный просмотр в 3D-видах» редактора: пресет, оценка или `.raw` до `off`. |
| `color_correction_zones` | Каждый объект color_correction со своим файлом, расстоянием, спадом, весом и статусом. |
| `open_media_editor` | Открывает окно. |

Переключатель также доступен через `set_setting` (`lab.color_correction_preview`) и `run_action` (`toggle_color_correction_preview`).
