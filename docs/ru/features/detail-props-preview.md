# Детальный просмотр пропа

Материалы с ключом `%detailtype` (текстуры травы Garry's Mod и подобные) при компиляции карты получают объекты детализации: спрайты травы, небольшие модели. В этом предварительном просмотре одни и те же объекты в 3D-виде разбрасываются во время редактирования, поэтому вы видите траву на каждой текстуре без компиляции.

<a id="turning-it-on"></a>
## Включение

- Кнопка **Детальный просмотр пропа (трава)** на панели инструментов (значок листа), рядом с кнопками тумана.
- **Настройки > Рендеринг > Предварительный просмотр деталей пропа (трава)**, настройка `render.detail_preview` (выключено по умолчанию).
- Действие `toggle_detail_preview` или инструмент MCP `detail_preview` с `enabled` true или false. `detail_preview` без аргументов только отчеты.

<a id="what-is-drawn"></a>
## Что нарисовано

- Каждое дисплейсмент и каждая грань браши (мировые браши и `func_detail`), материал которых имеет `%detailtype`, когда `detail.vbsp` карты определяет группу с таким именем. Этот файл является свойством `detailvbsp` объекта worldspawn (свойства карты), иначе `detail.vbsp`, иначе `scripts/detail.vbsp` игрового контента.
- Размещение соответствует VBSP: плотность группы на площадь поверхности, вершина альфа, нарисованная при дисплейсменте, выбирающая группы по их весам `alpha`, `minAngle` и `maxAngle` относительно наклона поверхности, `upright`, `amount`. На одну и ту же поверхность всегда попадают одни и те же объекты.
- Записи спрайтов представляют собой рекламные щиты, вырезанные из листа спрайтов мира `detailmaterial` (по умолчанию `detail/detailsprites`) с их прямоугольниками `spritesize` и `spriterandomscale`; `sprite_shape` крест и три рисуются как двух- и трехпересекающиеся четверные; `sway` заставляет верхнюю часть спрайта покачиваться во времени (это соответствует опции **Анимировать материалы**); `detailOrientation` уважается. Записи моделей отображаются как модели.
- Закрашиваются только поверхности вокруг 3D-камеры, ближайшие к началу, на расстоянии обзора игры (1200 единиц, исчезающих за последние 400, или `fademindist` и `fademaxdist` `env_detail_controller`), максимум 60000 спрайтов и 1500 моделей. Объекты генерируются на нескольких поверхностях в кадре, поэтому камера остается гладкой и прорисовывается экземплярами.
- Представление игрока рисует подробные пропы скомпилированной карты и скрывает этот предварительный просмотр.

<a id="reading-the-state"></a>
## Чтение состояния

Инструмент MCP `detail_preview` возвращает прочитанный файл и количество его типов, материал спрайта, количество поверхностей, использующих `%detailtype`, сколько из них находится в диапазоне, количество спрайтов и моделей, сокращаются ли ограничения, а также для каждого материала тип детали, который он называет (`known` является ложным, если в файле нет такой группы).

См. также [Режимы рендеринга и параметры отображения](render-modes-display.md), [Разброс по материалу](scatter-by-material.md).
