# Инструмент для посыпки

Инструмент «Разбрызгивание» рисует объекты (пропы, растения, камни, источники света…) на поверхностях карты с помощью круглой кисти, как инструмент «Разбрызгивание» в Hammer++ и CS:GO Hammer. То, что он размещает, берется из файлов определений разбрызгивания в том же формате, что и Hammer++, поэтому существующие определения работают так, как они есть.

<a id="opening-it"></a>
## Как открыть

- **Инструменты > Активный инструмент > Инструмент «Опрыскивание»** или его кнопка на палитре инструментов. У него нет сочетания клавиш по умолчанию (вы можете назначить его в **Настройки > Клавиатура**, см. [Сочетания клавиш](keyboard-shortcuts.md)).
- Выберите тип посыпки в списке **Тип:** на панели параметров. Без типа на рисунке отображается **Сначала выберите тип посыпки**. Без какого-либо определения строка состояния сообщает вам, в какую папку поместить файлы `.txt`.

<a id="painting"></a>
## Живопись

Браш представляет собой круг, нарисованный под курсором (зеленый, красный при стирании).

- В 3D-виде он следует за поверхностью под курсором; его плоскостью является одна из главных осей нормали к поверхности (полу, стене или потолку).
- В 2D-виде он лежит в плоскости обзора, и объекты приземляются на первую поверхность, видимую наблюдателем.

Плоскость разбивается на ячейки сетки (сетка типа или сетка редактора с параметром **Использовать сетку**). Каждая ячейка получает не более одного объекта, размещенного на поверхности под ячейкой.

| Жест | Описание |
| --- | --- |
| Нажмите или перетащите | Примените текущий режим к ячейкам под брашем. Каждая ячейка обрабатывается один раз за ход. Весь штрих : это один шаг отмены. |
| `Ctrl`+перетащить | Сотрите все объекты типа под брашем, независимо от режима и плотности. |
| `Alt`+колесо мыши | Измените радиус щетки (около 15 % на ступеньку). |
| `Escape` во время инсульта | Отбросьте весь ход. |

Объекты попадают только на мировые браши и на браши `func_detail`, `func_brush`, `func_wall` и `func_lod`, у которых есть хотя бы одна грань без материала `tools/` (триггеры, клипы и другие объемы пропускаются). Скрытые сущности никогда не трогаются.

Сущность «принадлежит» типу, когда ее класс является одним из классов типа, а когда тип устанавливает модели, его модель также является одной из них. Вычитание, Замена, Перезапись и стирание `Ctrl` действуют только на эти объекты.

<a id="modes"></a>
## Режимы

| Режим | Описание |
| --- | --- |
| **Добавить** | Заполните пустые ячейки: каждая пустая ячейка получает объект с плотностью как шанс. |
| **Вычесть** | Удалите объекты данного типа, плотность каждого из которых равна шансу. |
| **Заменить** | Выберите новую запись для ячеек, содержащих сущность данного типа. |
| **Перезаписать** | Опустошите ячейки, затем снова заполните их по плотности. |

<a id="options"></a>
## Параметры

Параметры сохраняются в `settings.toml` в `[placement.sprinkle]`.

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Тип:** | Тип посыпки для рисования. В подсказке каждого типа указывается файл, из которого он взят. | нет |
| Кнопка «Обновить» | Прочтите определения еще раз. | |
| Кнопка редактирования | Открытый исходный код: файл определения типа в текстовом редакторе (отключен, если файл находится внутри архива). | |
| Кнопка папки | Откройте папку с посыпками Hammer Pro. | |
| Режим | **Добавить**, **Вычесть**, **Заменить** или **Перезаписать** (см. выше). | **Добавить** |
| **Плотность:** | Вероятность в процентах, что ячейка получит сущность (или потеряет ее при вычитании), от 0 до 100 %. | 50 % |
| **Радиус:** | Радиус кисти в единицах от 8 до 4096 (`Alt`+колесо). | 128 |
| **Использовать сетку** | Используйте сетку редактора вместо сетки определения (в подсказке отображается сетка типа). | Выкл. |
| **Случайное отклонение** | Превратите каждую сущность в случайное отклонение от курса. | Вкл. |
| **Смещение:** | Случайное перемещение внутри ячейки, в процентах от половины ячейки, от 0 до 100 %. | 50 % |
| **Смещение по оси Z:** | Расстояние от поверхности от -4096 до 4096 единиц. | 0 |
| **Выровнять по нормальному** | Наклоняйте объекты так, чтобы они следовали за поверхностью, на которой они лежат. Смещение Z тогда проходит вдоль нормали к поверхности. | Выкл. |

Если сетка слишком мала для радиуса (более 40 000 ячеек под брашем), ничего не помещается и отображается **Сетка слишком мала для этого радиуса: ничего не было разбрызгано**: поднимите сетку или уменьшите радиус.

<a id="definition-files"></a>
## Файлы определений

Файл определений : это файл `.txt`, содержащий один или несколько типов:

```text
"Jungle foliage"
{
    base { "classname" "prop_static" grid "64 64" }
    10 { "model" "models/props/plant01.mdl" }
    30 { "model" "models/props/plant02.mdl" "skin" "1" }
}
```

- Имя блока (`"Jungle foliage"`) : это имя, отображаемое в списке **Тип:** (типы сортируются по имени).
- `base` содержит ключевые значения, которые получает каждый объект, и `grid` типа (`"64 64"` для X и Y в плоскости браши или `"64"` для обоих). Ключевые значения, записанные непосредственно в блоке типа, также считаются базовыми. Без сетки используется шрифт 64 x 64.
- Каждый пронумерованный блок представляет собой запись, выбранную с этим весом (здесь `plant02` встречается в три раза чаще, чем `plant01`). Его значения ключей переопределяют базовые.
- `grid`, `origin` и `id` никогда не записываются в объекты.
- Тип без полезной записи (без положительного веса или без `classname`) пропускается. Найденные проблемы засчитываются в **{0} проблемы в определениях (см. консоль)** и детализируются в консоли.

<a id="where-definitions-are-read"></a>
### Где читаются определения

| Место | Примечания |
| --- | --- |
| `scripts/hammer/sprinkle/` игрового контента | Прочитайте смонтированный игровой контент (базовая игра, дополнения, смонтированные папки). |
| `bin/hammerplusplus/scripts/sprinkle/` и `bin/win64/hammerplusplus/scripts/sprinkle/` установки Garry's Mod | Папки Hammer++ доступны только для чтения. |
| `bin/scripts/hammer/sprinkle/` и `bin/win64/scripts/hammer/sprinkle/` установки Garry's Mod | Папки Hammer только для чтения. |
| `%APPDATA%\HammerPro\sprinkle` | Папка Hammer Pro (кнопка папки на панели параметров). |
| Дополнительные папки | Добавлено в **Настройки > Префабы > Посыпать** с помощью **Добавить папку...**, сохранено как `extra_dirs`. |

Читаются только файлы `.txt`, без подпапок, до 1 MB на файл и 512 файлов на место. Файлы читаются в рабочем потоке и сохраняются в кеше во время модификации, поэтому при обновлении анализируются только измененные файлы. Определения считываются повторно кнопкой Обновить, при изменении списка папок и при повторном монтировании игрового контента.

<a id="tips"></a>
## Советы

- Используйте **Перезаписать** с низкой плотностью, чтобы проредить и перетасовать область за один проход.
- Для травы на склоне включите **Выравнивание по нормали** и задайте небольшое отрицательное **Смещение по оси Z:**, чтобы основание не плавало.
- Помощники AI могут распределять объекты по MCP с помощью инструмента `sprinkle` (взвешенные элементы, количество, интервал, случайное отклонение, выравнивание, максимальный наклон), а также читать или изменять параметры инструмента с помощью `get_tool_options` / `set_tool_options` (инструмент `sprinkle`). См. [справку по инструменту MCP](../MCP.md).

<a id="faq"></a>
## Частые вопросы

**Список типов пуст.** Определение не найдено. Поместите файл `.txt` в `%APPDATA%\HammerPro\sprinkle` (кнопка папки) или добавьте свою папку в **Настройки > Префабы > Посыпать**, затем нажмите Обновить.

**На моей пропе или триггере ничего не отображается.** Объекты приземляются только на поверхности браши (мировые браши и `func_detail`, `func_brush`, `func_wall`, `func_lod`); модели и браши инструментов пропускаются.

**Ctrl стерты объекты, которые я разместил вручную.** При стирании удаляются все видимые объекты, принадлежащие этому типу (тому же классу и, если тип устанавливает модели, той же модели). Скройте те, которые хотите сохранить.

**Я отредактировал определение, но ничего не изменилось.** Нажмите кнопку «Обновить» на панели параметров.
