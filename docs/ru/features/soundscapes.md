# Звуковые ландшафты

Редактор звукового ландшафта записывает файл звукового ландшафта вашей карты: окружающие звуки, которые воспроизводят `env_soundscape` объекты (ветер, птицы, машины, случайные отдаленные шумы). Он редактирует `soundscapes_<map>.txt` как список звуковых ландшафтов, каждый со своими правилами, выбирает волны из звуковых файлов игрового контента и позволяет вам их слушать.

<a id="opening-it"></a>
## Как открыть

**Карта > Звуковые ландшафты...** открывает окно **Звуковые ландшафты карты** (без сочетания клавиш по умолчанию). Он остается открытым, пока вы работаете; закройте его кнопкой закрытия.

Карту необходимо сначала сохранить: редактор работает с файлом `soundscapes_<map>.txt` рядом с файлом карты. Для несохраненной карты в окне отображается сообщение **Сначала сохраните карту: рядом с ней указан файл звукового ландшафта.**

В верхней части окна отображается путь к файлу **(не сохранен)**, если у вас есть несохраненные изменения, и напоминание: **Игра загружает scripts/soundscapes_<map>.txt: запакуйте этот файл вместе с картой. Используйте сущности env_soundscape, чтобы разыграть их.**

<a id="buttons"></a>
## Кнопки

| Кнопка | Описание |
|---|---|
| **Сохранить** | Записывает файл. Включается, когда что-то изменилось. Файл записывается безопасно (временный файл, затем переименовывается поверх старого) и только при нажатии **Сохранить**. |
| **Перезагрузить** | Снова читает файл с диска, удаляя несохраненные изменения. |

Если файл не может быть прочитан (например, его размер превышает 4 MB), в окне отображается **Файл не может быть прочитан (сохранение отключено)**, поэтому сохранение не может его уничтожить.

<a id="the-soundscape-list"></a>
## Список звуковых ландшафтов

Слева:

- **Новое имя звукового ландшафта** и **+** (**Добавить звуковой ландшафт**) добавляют звуковой ландшафт с `dsp`, установленным на `1`. Имя не может быть пустым, содержать пробелы, кавычки или фигурные скобки или уже существовать в файле.
- Нажмите звуковой ландшафт, чтобы отредактировать его.
- Звуковой ландшафт, имя которого уже используется в звуковом ландшафте смонтированного игрового контента, помечается как **имя, используемое игрой**. Имена Soundscape являются глобальными в движке, поэтому переименуйте их.

<a id="editing-a-soundscape"></a>
## Редактирование звукового ландшафта

Справа для выбранного звукового ландшафта:

- **Delete** удаляет звуковой ландшафт.
- **Эффект DSP** устанавливает ключ `dsp`.
- **+ playloop**, **+ playrandom** и **+ playsoundscape** добавляют правило.
- Каждое правило имеет **×** (**Удалить это правило**).

Каждое поле представляет собой обычный текст. Очистка поля удаляет его ключ; двойные кавычки не принимаются.

<a id="rules"></a>
### Правила

| Правило | Поля | Добавлено с |
|---|---|---|
| `playlooping` (зацикленный звук) | **Громкость**, **Шаг**, **Волна**, **Положение**, **Уровень звука** | `volume 1`, `pitch 100`, пустая волна |
| `playrandom` (случайные звуки в случайное время) | **Громкость**, **Шаг**, **Время (мин,макс)**, волны блока `rndwave`, **Уровень звука** | `volume 1`, `pitch 100`, `time 10,20`, одна пустая волна |
| `playsoundscape` (воспроизводится другой звуковой ландшафт) | **Громкость**, **Soundscape** (название другого звукового ландшафта) | `volume 1`, пустое имя |

В каждой строке **Волна** есть текстовое поле, элемент выбора **♪** со списком звуковых файлов игрового контента, кнопка **▶** для воспроизведения волны и **×** (**Удалить эту волну**). **+ волна** добавляет волну к правилу `playrandom`. Громкость предварительного просмотра - это **Настройки > Объекты и браузеры > Громкость предварительного просмотра звука**.

Ключи, оставленные пустыми (правило, добавленное еще без волны), не записываются в файл, поэтому движок на них не жалуется. Ключи и блоки, неизвестные редактору, сохраняются такими, какие они есть.

<a id="tips"></a>
## Советы

- Назовите свои звуковые ландшафты префиксом карты (например, `gm_mymap.forest`), чтобы избежать предупреждения **имя, используемое в игре**.
- Движок читает `scripts/soundscapes_<map>.txt`: поместите или запакуйте туда файл, чтобы игра могла его использовать. См. разделы [Создать и сохранить как контент](build-content-release.md) и [Сопоставить ресурсы](map-assets.md).
- Выберите волну с помощью кнопки **♪**, а не вводите ее: в списке содержатся только файлы, существующие в смонтированном содержимом.
- Через MCP `run_action` с `edit_soundscapes` открывает окно. См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="faq"></a>
## Частые вопросы

**Почему в окне пустое сообщение?** Карта никогда не сохранялась, поэтому нет папки, в которую можно было бы записать файл звукового ландшафта. Сохраните карту, затем снова откройте редактор.

**Почему параметр «Сохранить» неактивен?** С момента последнего сохранения или перезагрузки ничего не изменилось, или файл невозможно прочитать (в этом случае сохранение отключается для его защиты).

**Мой звуковой ландшафт не воспроизводится в игре.** Убедитесь, что объект `env_soundscape` использует свое имя, что файл находится в `scripts/` как `soundscapes_<map>.txt` (упакован вместе с картой) и что имя не помечено как используемое игрой.

**Могу ли я редактировать звуковые эффекты самой игры?** Нет. Редактор редактирует только файл вашей карты. Звуковые ландшафты игры читаются, чтобы предупредить о конфликтах имен.

## Назначение собственного звукового ландшафта

Для `env_soundscape` и `env_soundscape_triggerable` введите имя записи скрипта непосредственно в поле **Soundscape**, например `sunless_cavesound_entree`, затем нажмите Enter. Кнопка рядом предлагает варианты FGD и имена из подключённых скриптов. Собственные имена сохраняются в VMF и поддерживают отмену и повтор изменений.
