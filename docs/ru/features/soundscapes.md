# Звуковые ландшафты

Звуковые ландшафты (soundscapes) это фоновые звуки карты Source: ветер, птицы, механизмы, случайные далёкие шумы. Сущность `env_soundscape` называет ландшафт игры или файла карты `scripts/soundscapes_<карта>.txt`, а движок проигрывает ландшафт ближайшей сущности, в радиусе которой находится игрок и которую он видит.

В Hammer Pro для них есть три инструмента. Ни один не работает, пока вы его не включите:

| Инструмент | Где | Что делает |
|---|---|---|
| **Редактор звуковых ландшафтов** | **Карта > Звуковые ландшафты...** (действие `edit_soundscapes`) | Показывает ландшафты игры и карты, проигрывает их, редактирует и сохраняет файл ландшафтов карты, назначает ландшафт выделенному `env_soundscape`. |
| **Вид ландшафтов** | **Вид > Предпросмотр окружения > Показывать ландшафты** (действие `toggle_soundscape_view`, по умолчанию выключено) | Рисует сущности ландшафтов, их радиус, цели позиций и имена, радиусы `ambient_generic` и окрашивает пол ландшафтом, который игрок там услышит. |
| **Звук в виде игрока** | **Вид > Предпросмотр окружения > Слышать ландшафты в виде игрока** (действие `toggle_soundscape_hearing`, по умолчанию выключено) или `K` в виде игрока | Проигрывает активный ландшафт и звуки `ambient_generic`, пока вы ходите в виде игрока, с затуханием и сменой ландшафтов как в движке. |

**Вид > Предпросмотр окружения > Параметры ландшафтов** содержит ползунок громкости, **Без звука**, **Активные зоны** и **Звуки ambient_generic**.

## Редактор звуковых ландшафтов

**Карта > Звуковые ландшафты...** открывает окно **Редактор звуковых ландшафтов**; тот же пункт закрывает его.

### Файл

Вверху окна показан файл, в который сохраняются ландшафты карты: `scripts/soundscapes_<карта>.txt` в папке над папкой `maps` карты (папка вашего аддона или проекта) или в папке игры, если карта лежит не в папке `maps`. Именно этот файл движок загружает для карты, поэтому он работает в игре как есть, а [Создать и сохранить как контент](build-content-release.md) упаковывает его вместе с картой.

- **Папка...** выбирает другую папку игры или аддона; **Папка по умолчанию** возвращает обратно.
- **(не сохранено)** показывается, когда есть изменения. Они хранятся, пока работает Hammer Pro (и при закрытии окна, и при смене карты), предпросмотр, звук в виде игрока и инструменты MCP уже используют их, но файл меняется только по кнопке **Сохранить**.
- **Сохранить** записывает файл безопасно (временный файл переименовывается поверх старого). Файл из списка `scripts/soundscapes_manifest.txt` игры никогда не записывается: редактор пишет только файл карты.
- **Перезагрузить** перечитывает файл и отбрасывает несохранённые изменения.
- Сначала карту нужно сохранить (файл называется по ней).
- Старые версии Hammer Pro писали `soundscapes_<карта>.txt` рядом с файлом карты, где игра его не читает. Такой файл читается, пока файла в `scripts` ещё нет, окно сообщает об этом, а **Сохранить** записывает его в `scripts/` (старый файл не трогается).

### Список

Слева ландшафты файла карты, затем **Ландшафты игры**: из каждого файла `scripts/soundscapes_manifest.txt` в подключённом контенте. **Все**, **Карта** и **Игра** фильтруют список, а поле поиска оставляет имена, содержащие все слова.

- **Имя нового ландшафта** и **+** добавляют ландшафт в файл карты (с `dsp` 1). Имена не могут содержать пробелы, кавычки или фигурные скобки.
- Ландшафт карты с именем ландшафта игры показывается цветом предупреждения: имена ландшафтов в движке глобальные, переименуйте его.
- Ландшафты игры только для чтения. **Скопировать в файл карты** копирует ландшафт под новым именем (`<карта>.<имя>`), чтобы его можно было менять.

### Ландшафт

Справа:

| Элемент | Что делает |
|---|---|
| **Предпросмотр** / **Стоп** | Проигрывает ландшафт с вложенными ландшафтами и случайными звуками в случайное время, без расстояния, до нажатия **Стоп**. |
| **Назначить выделению (n)** | Задаёт ключ `soundscape` выделенных сущностей `env_soundscape` и `env_soundscape_triggerable` (один шаг отмены **Назначение ландшафта**). |
| **Используется** | Сущности ландшафтов карты, указывающие этот ландшафт; щелчок выделяет сущность. |
| Строка сводки | Сколько зацикленных и случайных звуков он играет с вложенными ландшафтами, его DSP, несуществующие вложенные имена, циклы вложения. |
| **Эффект DSP** | Эффект помещения `dsp`, который движок включает при запуске ландшафта (0 нет, 1 обычная комната, 2...28 стандартные помещения Source; показано имя пресета). Его задаёт только ландшафт, указанный сущностью, вложенные нет, а без ключа остаётся прежний эффект. **×** удаляет ключ. |
| **DSP игрока** | `dsp_player`: второй эффект поверх эффекта помещения (те же номера), сохраняется, пока другой ландшафт его не изменит. |
| **Громкость эффекта** | `dsp_volume`: громкость эффекта помещения (по умолчанию 1). |
| **+ playlooping**, **+ playrandom**, **+ playsoundscape** | Добавляют правило. У каждого правила есть **×** для удаления. |

Правила:

| Правило | Поля |
|---|---|
| `playlooping`: зацикленный звук | **Громкость**, **Высота тона**, **Звук**, **Уровень звука**, **Позиция** |
| `playrandom`: случайные звуки в случайное время | **Интервал (секунды)**, **Громкость**, **Высота тона**, его звуки, **Уровень звука**, **Позиция** (также **случайно вокруг игрока**) |
| `playsoundscape`: проигрывает другой ландшафт | **Ландшафт** (ввести или выбрать, **Открыть** показывает его), **Громкость** (умножает громкости вложенного ландшафта), **Смещение позиций** (`position`, прибавляется к его номерам позиций), **Замена позиции**, **Позиция фоновых звуков** |

- **Громкость**, **Высота тона** и **Интервал** принимают одно число или, с отмеченным **диапазон**, диапазон: движок каждый раз выбирает в нём случайное значение.
- **(по умолчанию)** после поля значит, что ключа нет в файле и действует значение движка, как в игре: `playlooping` без громкости ничего не играет, `playrandom` без громкости ничего не играет, без высоты тона игнорируется движком, а без интервала повторяется каждый кадр. Редактор предупреждает о каждом случае; новые правила добавляются с рабочими значениями.
- **Звук**: введите путь внутри `sound/` или выберите **♪** звуковой файл подключённого контента (в списке есть поиск), **▶** проигрывает его, **×** удаляет. Отмечаются звуки, которых нет в контенте, и звуки `playlooping` без меток цикла (игра проиграет их один раз; предпросмотр повторяет).
- **Уровень звука** задаёт, насколько далеко слышен позиционный звук (`SNDLVL_NORM` = 75 дБ). Фоновые звуки его не учитывают.
- **Позиция**: **нет (фон)** играет звук везде одинаково. **position0**...**position7** играют его из сущности, указанной ключом `position0`...`position7` у `env_soundscape`, с затуханием по расстоянию. Вид рисует эти цели.

Неизвестные редактору ключи и блоки сохраняются как есть. Пустые ключи (правило, добавленное ещё без звука) не записываются.

### Параметры звука

Вторая строка окна содержит **Показывать в видах**, **Активные зоны**, **Слышать в виде игрока**, **Звуки ambient_generic**, **Громкость** и **Без звука** (те же настройки, что в меню). Пока вид игрока проигрывает ландшафты, окно показывает текущий ландшафт и почему он выбран.

## Вид ландшафтов

Когда **Показывать ландшафты** включено, каждый вид рисует:

- каждую `env_soundscape`, `env_soundscape_proxy` и `env_soundscape_triggerable` с окружностью её `radius` (три окружности в 3D) цветом имени её ландшафта, подпись с именем ландшафта и радиусом (**везде** для радиуса -1), **(выключен)** для Start Disabled, главную сущность прокси и **(через trigger_soundscape)** для активируемых;
- линии от сущности к целям `position0`...`position7` с подписями **position0**...**position7**;
- каждый `ambient_generic` голубой окружностью его `radius` с подписью звукового файла (**(начинает без звука)**, если это так);
- каждый `trigger_soundscape` рамкой цвета ландшафта той `env_soundscape_triggerable`, которую он называет, линией к ней и подписью (или предупреждением, если `env_soundscape_triggerable` с таким именем нет);
- с **Активными зонами** (по умолчанию) плитки на полу цветом ландшафта, который игрок услышит, стоя там, на высоте 3D-камеры (или игрока в виде игрока), по правилам движка ниже. Внутри `trigger_soundscape`, если другого ландшафта в радиусе и в прямой видимости нет, плитка получает ландшафт его активируемой сущности. Серые плитки вне всех радиусов: игрок продолжает слышать предыдущий ландшафт. После изменений плитки заполняются за несколько кадров;
- в 3D-видах подпись в углу **Ландшафт здесь** с ландшафтом, слышимым у камеры.

Как движок выбирает ландшафт (код `env_soundscape` и системы ландшафтов из Source SDK 2013, воспроизведён точно):

- Каждый кадр сервера сначала проверяется текущий ландшафт, затем остальные сущности (`env_soundscape`, `env_soundscape_proxy` и `env_soundscape_triggerable`). Выключенный текущий ландшафт сбрасывается; выключенные пропускаются.
- Сущность в радиусе, когда её `radius` строго больше расстояния до уха игрока или когда радиус ровно `-1`. Любой другой отрицательный радиус, радиус 0 и отсутствующий радиус (0) никого не достигают.
- В радиусе она должна ещё видеть ухо: трассировка от начала координат сущности до уха игрока (глаза: 64 единицы над ногами стоя, 28 сидя) с маской `MASK_SOLID_BRUSHONLY | MASK_WATER`. Её блокируют твёрдые браши мира, брашевые сущности, стёкла, решётки, вода и коллизия твёрдых `prop_static`; клипы, триггеры, `func_illusionary`, другие пропы и игроки не блокируют. Сущность, чьё начало координат внутри твёрдого браша или ровно на его поверхности, начинает в твёрдом и никого не видит.
- Прошедший проверки кандидат становится текущим, если текущий их не прошёл или если он ближе. Если не прошёл никто, текущий ландшафт остаётся.
- `env_soundscape_proxy` играет ландшафт и цели позиций сущности, указанной в `MainSoundscapeName`.
- `trigger_soundscape`, в который входит игрок, сразу делает текущей `env_soundscape_triggerable`, указанную его ключом `soundscape` (побеждает последний); выход возвращает к другому триггеру, в котором игрок ещё стоит, или к отсутствию ландшафта. Правила радиуса работают каждый кадр, так что ландшафт в радиусе и в видимости снова перехватывает. Когда у сервера нет ландшафта, клиент продолжает играть последний.
- Движок проверяет только ландшафты, чья видимость (PVS) достигает кластера игрока; свободная трассировка внутри радиуса всегда это обеспечивает, поэтому результат тот же.

## Звук в виде игрока

Включите **Слышать ландшафты в виде игрока**, войдите в вид игрока (F6) и ходите. Hammer Pro выполняет клиентскую систему ландшафтов движка:

- При смене ландшафта каждый зацикленный звук идёт к новой громкости со скоростью трети полной громкости в секунду (`soundscape_fadetime`, 3 секунды); зацикленный звук с тем же файлом и высотой тона в новом ландшафте продолжает звучать с новой громкостью. Фоновые циклы начинают с тишины, позиционные с 0,05.
- Звуки `playrandom` начинаются через половину случайного интервала, затем ждут случайный `time` между проигрываниями, со случайной громкостью, высотой и уровнем звука; `position random` играет их в 36 единицах вокруг глаз, как движок.
- Позиционные звуки затухают с расстоянием по уровню звука и панорамируются влево и вправо; фоновые звучат везде со своей громкостью.
- Применяются эффект помещения (`dsp`), `dsp_player` и `dsp_volume` ландшафта: реверберация, эхо и фильтр, близкие к каждому стандартному пресету Source (комнаты, металл, туннели, залы, яркие помещения, под водой, бетон, улица, пещеры, странное), с переходом за 3 секунды. Значения больше 28 играют как обычная комната.
- Объёмы `trigger_soundscape` активируют свою `env_soundscape_triggerable`, когда вы через них проходите.
- С **Звуки ambient_generic** сущности `ambient_generic` играют как при старте карты: зацикленные постоянно, кроме Start Silent, остальные один раз; `radius` становится уровнем звука как в движке, `health` громкостью, `pitch`, Play Everywhere, Source Entity Name. Их входы `PlaySound`, `StopSound`, `ToggleSound`, `Volume`, `Pitch`, `FadeIn` и `FadeOut`, а также входы `Enable`, `Disable` и `ToggleEnabled` сущностей ландшафтов, посылаемые симуляцией входов и выходов вида игрока, учитываются.

`K` включает и выключает звук прямо в виде игрока; счётчики показывают текущий ландшафт, звуки и громкость. Ключи `Soundmixer` меняют только баланс с игровыми звуками (оружие, голоса), которые редактор не играет. Звук идёт через устройство по умолчанию в Windows; аудиовыход освобождается через десять секунд после последнего звука.

## Советы

- Начинайте имена ландшафтов карты с имени карты (`gm_mymap.forest`), чтобы ни один ландшафт игры не назывался так же.
- Давайте правилам `playlooping` зацикленные звуки (редактор звуков умеет добавлять метки цикла: [Редактор звуков](sound-editor.md)).
- Включите вид и посмотрите на плитки пола: комнате, в которой слышен уличный ландшафт, обычно нужна своя `env_soundscape` внутри, ближе уличной.

## FAQ

**Мой ландшафт не играет в игре.** Проверьте, что `env_soundscape` использует его имя (вид его подписывает), что игрок в её радиусе и видит её (плитки это покажут), и что файл называется `scripts/soundscapes_<карта>.txt` и лежит в папке игры или аддона либо упакован с картой.

**Почему в коридоре продолжает играть старый ландшафт?** Вне всех радиусов движок оставляет текущий ландшафт. Добавьте `env_soundscape`, покрывающую коридор.

**Можно ли редактировать ландшафты игры?** Нет, они только для чтения. Скопируйте ландшафт в файл карты и меняйте копию.

**env_soundscape никогда не играет, хотя игрок рядом.** Вероятно, её начало координат внутри браша или ровно на полу: трассировка движка тогда начинается в твёрдом и не проходит. Поднимите её на несколько единиц над полом; `soundscape_at` сообщает `start_solid` для каждого кандидата.

**В виде игрока ничего не слышно.** Звук по умолчанию выключен: включите его (или нажмите `K` в виде игрока), проверьте **Без звука** и громкость, а также что звуки существуют (редактор отмечает отсутствующие).

## Назначение собственного звукового ландшафта

Для `env_soundscape` и `env_soundscape_triggerable` введите имя записи скрипта непосредственно в поле **Soundscape**, например `sunless_cavesound_entree`, затем нажмите Enter. Кнопка рядом предлагает варианты FGD и имена из подключённых скриптов. Собственные имена сохраняются в VMF и поддерживают отмену и повтор изменений. **Назначить выделению** в редакторе ландшафтов делает то же для всех выделенных сущностей ландшафтов.
