# Звуковой браузер

Браузер звуков перечисляет звуки смонтированного игрового контента, либо звуки игры, определенные звуковыми сценариями (`Streetwar.d3_c17_13_horn`), либо звуковые файлы (`ambient/alarms/klaxon1.wav`), с проигрывателем предварительного просмотра, громкостью, автозапуском и записью звукового сценария для каждого звука игры. Звуковые клавиши на панели объектов имеют собственный быстрый выбор звука и могут отправить вас в браузер для выбора звука.

<a id="opening-it"></a>
## Как открыть

- **Вид > Панели > Браузер звуков** добавляет вкладку **Звуки** на правую док-станцию (или удаляет ее). Сохранено как `show_sound_browser` в `[browser]` (по умолчанию выключено).
- Кнопка обзора звуковой клавиши на панели объектов также открывает ее (см. «Выбор звука для клавиши» ниже).
- Нет сочетания клавиш по умолчанию. При использовании предустановленной раскладки клавиатуры Hammer++ (**Настройки > Клавиатура**) сочетание клавиш : `Shift+F12`.
- Кнопка `🗗` (**Открыть в окне**) перемещает браузер в собственное плавающее окно; `⊟` (**Назад в док**) возвращает его в док.

<a id="the-list"></a>
## Список

| Контроль | Описание |
|---|---|
| **Звуки игры** / **Файлы** | Что показывает список: звуки игры, звуковые сценарии или звуковые файлы. |
| `⟳` **Перезагрузить звуковые сценарии** | Снова читает звуковые сценарии (после того, как вы их отредактировали). |
| **Поиск звуков (исключая !word)** | Сохраняет звуки, содержащие каждое слово (любой падеж). В режиме звуков игры слово может соответствовать имени или воспроизводимому файлу. Слово, начинающееся с `!`, исключается. |
| Source фишек **Все**, **Игра**, **Дополнения**, **Мастерская** | Сохраняйте звуки одного вида источника (фишка появляется только тогда, когда контент имеет такой вид). |
| **Только контент Garry's Mod** | Только то, что есть у каждого игрока Garry's Mod. Доступно совместно с браузерами моделей и частиц (`gmod_only` в `[browser]`). |
| **Звуки: Н** | Количество звуков в списке («Чтение звуковых сценариев...» во время их загрузки). |

В каждой строке есть кнопка воспроизведения, имя и в режиме звуков игры первый воспроизводимый волновой файл, а затем значок, указывающий, откуда взялся файл (**GMod**, **game: ...**, **addon**, **Workshop ...**, **custom** или **not Found**, если ни один смонтированный файл не соответствует). Воспроизведение звука выделено жирным шрифтом. Наведите курсор на строку, чтобы увидеть полное название источника.

Звуки игры берутся из `scripts/game_sounds_manifest.txt` (его записи `precache_file`, `preload_file` и `autocache_file`), считываются в фоновом режиме один раз для каждого животного и сортируются по имени. Когда два звуковых сценария определяют одно и то же имя, побеждает первый.

<a id="mouse-and-keyboard"></a>
## Мышь и клавиатура

- Щелкните звук, чтобы выбрать его; при включенном параметре **Воспроизвести при выборе** он воспроизводится.
- Кнопка воспроизведения строки воспроизводит этот звук.
- Двойной щелчок: в режиме выбора записывает звук в клавишу; иначе играет.
- Пока указатель находится над списком: `Up` / `Down` переместите выделение (и воспроизведите его с помощью **Play on select**), `Enter` делает то же, что и двойной щелчок.

<a id="footer"></a>
## Нижний колонтитул

| Контроль | Описание | По умолчанию |
|---|---|---|
| Выбранный звук | Его название (или «Выбор звука»). | |
| **▶ Воспроизведение** / **■ Стоп** | Воспроизводит или останавливает выбранный звук. | |
| Ползунок громкости (от 0 до 100 %) | **Громкость предварительного просмотра** каждого предварительного просмотра звука, в том числе на панели объектов. `sound_volume` в `[browser]` (от 0 до 1). | 80 % |
| **Играть по выбору** | Выбор звука воспроизводит его. `sound_autoplay` в `[browser]`. | Вкл. |
| **Звуковой сценарий...** | Для звука игры: открывает небольшое окно с записью звукового сценария (сначала имя файла). Наведите курсор на кнопку файла звукового сценария. | |
| **Скопировать имя** | Копирует выбранное имя в буфер обмена. | |
| **Заменить все варианты использования (N)** | В режиме выбора, когда ключ уже имеет другой звук: каждый объект, ключ которого содержит старый звук, получает выбранный (один шаг отмены), и режим выбора завершается. | |

Предварительный просмотр воспроизводит файлы WAV (PCM и ADPCM), MP3 и OGG смонтированного контента только в Windows; в другом месте в нижнем колонтитуле написано, что предварительный просмотр невозможен. Звук игры воспроизводит свой первый волновой файл.

<a id="picking-a-sound-for-a-key"></a>
## Выбор звука для клавиши

Звуковая клавиша панели сущности (например, `message` из `ambient_generic`) имеет три кнопки (см. [Свойства сущности](entity-properties.md)):

- `♪` открывает быстрый выбор: список звуков игры с возможностью поиска (с файлом, который они воспроизводят), за которым следуют звуковые файлы. У каждого предмета есть кнопка воспроизведения. Вы также можете ввести значение, которого нет в списке.
- `▶` / `■` воспроизводит или останавливает звук, удерживаемый клавишей (неактивен, если его невозможно воспроизвести).
- Кнопка обзора («Выбрать в браузере звука (дважды щелкните звук)») открывает браузер звука в режиме выбора.

В режиме выбора браузер отображает баннер «Выберите *ключ*: дважды щелкните элемент или выберите его и нажмите «Использовать». Выбирается звук, который уже есть в клавише (браузер переключается на **Файлы**, если значением является файл `.wav`, `.mp3` или `.ogg`). Дважды щелкните звук, нажмите `Enter` или нажмите **Использовать**, чтобы записать его (один шаг отмены); панель возвращается на вкладку **Объект**. **Отмена** выходит из режима выбора.

<a id="tips"></a>
## Советы

- Отключите параметр **Воспроизведение при выборе**, чтобы спокойно просматривать длинный список с помощью клавиш со стрелками, а затем нажмите кнопку воспроизведения нужной строки.
- [Редактор звукового ландшафта] (soundscapes.md) использует тот же быстрый выбор звука.
- Через MCP `search_sounds` ищет звуки контента (см. [Справочник по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Почему список остается пустым?** Не загружается игровой контент («Не загружается игровой контент: укажите в настройках папку с игрой»), либо поиск, исходные фишки или **Только контент Garry's Mod** скрывают все.

**Я отредактировал звуковой сценарий, в браузере отображается старая запись.** Нажмите `⟳`, чтобы снова прочитать звуковой сценарий.

**Почему я ничего не слышу?** В Windows воспроизводятся только файлы WAV, MP3 и OGG смонтированного контента. Проверьте ползунок громкости и убедитесь, что на значке не написано **не найден**.
