# Запуск игры

Hammer Pro быстро тестирует вашу карту в игре: он загружает скомпилированную карту в уже запущенный Garry's Mod вместо того, чтобы запускать игру заново, может загружать игру во время компиляции карты, может поместить вас к камере редактора и может вернуть проп, который вы разместили в игре, обратно на карту. На карте запускаются и другие игры Source, без дополнений Garry's Mod.

<a id="commands"></a>
## Команды

| Команда | Ключ по умолчанию | Описание |
| --- | --- | --- |
| **Файл > Компиляция > Скомпилировать и запустить...** | `Ctrl+F9` | Открывает окно компиляции, где **Запустить игру** запускает карту после компиляции. |
| **Файл > Компиляция > Скомпилировать** | `F9` | Компилируется с текущими настройками (и запускает игру, когда включен параметр **Запустить игру**). |
| **Файл > Компиляция > Запустить карту в игре** | | Загружает скомпилированную карту открытого документа в запущенной игре или запускает игру на ней. |
| **Файл > Компиляция > Перезагрузить карту в игре** | | То же самое для уже запущенной игры. |
| **Файл > Импорт > Импортировать проп из игры** | | Переносит на карту проп, размещенный в игре (нужен мост). |

Если установлено сочетание клавиш Hammer или Hammer++, `F9` открывает окно компиляции и `Ctrl+F9` сразу компилируется (см. [Сочетания клавиш](keyboard-shortcuts.md)).

Карту необходимо сохранить и скомпилировать: скомпилированная карта получает имя VMF (*Сначала сохраните и скомпилируйте карту*). Для Garry's Mod `<map>.bsp` должен находиться в папке карт игры (*сначала скомпилируйте карту*).

<a id="how-the-map-gets-into-the-game"></a>
## Как карта попадает в игру

- **Повторное использование запущенной игры** (по умолчанию включено): при запуске Garry's Mod карта загружается в него без второго процесса и без окна «Source Engine Not Running» во время загрузки игры. В противном случае игра начнется на карте.
- Если игра запускается, карта ожидает игрового окна и загружается, как только она будет готова (*Garry's Mod запускается: карта загружается, как только она будет готова*).
- В строке состояния отображается состояние игры: **Игра готова**, **Игра запускается** или ничего, если она не запущена.

<a id="launch-options-of-the-compile-window"></a>
## Параметры запуска окна компиляции

В настройках компиляции строка **Игра** содержит параметры запуска. Они применяются, когда отмечен флажок **Запустить игру** и игра не открывается **Через Steam**.

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Запустите игру** | Запускает карту после компиляции. | на |
| **Через Steam** | Открывает карту по ссылке `steam://` вместо запуска исполняемого файла игры. | выкл. |
| **Аргументы игры** | Дополнительные аргументы в пользу игры. `-game`, `-hijack` (повторное использование запущенной игры) и `+map` добавляются, если вы их не установили. `{map}` заменяется названием карты. | `-console -dev` (плюс `-novid`, добавленный один раз) |
| **Запуск игры:** **после компиляции** | Запускает игру после компиляции карты (как Hammer). | выбрано |
| **Запустите игру:** **когда начнется компиляция** | Запускает игру сразу после начала компиляции: она загружается во время работы компилятора, затем загружает карту. Только Garry's Mod. | |
| **Повторно используйте запущенную игру** | Загружает карту в уже запущенной игре вместо того, чтобы запускать ее заново. | на |
| Состояние игры | **Игра готова**, **Игра запускается** или **Игра не запущена**. | |

<a id="fast-start"></a>
### Быстрый старт

Кнопка **Быстрый старт** открывает параметры, ускоряющие запуск игры для тестирования. Каждый параметр добавляет или удаляет свой флаг в **Аргументах игры**, поэтому выполняется то, что вы читаете в этом поле.

| Параметр | Флаг | Описание |
| --- | --- | --- |
| **Пропустить вступительное видео** | `-novid` | Экономит несколько секунд при каждом запуске. Добавлен один раз в аргументы игры при первом запуске. |
| **Оконный** | `-windowed` | Запускает игру в окне. |
| **Без границ** | `-noborder` | Окно без границ. |
| **Размер окна** | `-w`, `-h` | Ширина и высота окна игры (1600 х 900 при включении; 320 на 7680 на 240 на 4320). |
| **Откройте консоль** | `-console` | Показывает консоль разработчика при запуске. |
| **Сообщения разработчиков** | `-dev` | Показывает сообщения разработчика; также пропускает фоновую карту меню. |
| **Частная локальная игра** | `+sv_lan 1 +maxplayers 1` | Локальный сервер только для вас: не требуется настройка сети, запуск быстрее. |
| **Пропустить неиспользуемый Мастер-класс и дополнения** | `-noworkshop`, `-noaddons` | Когда на карте ничего из них не используется, игра не монтирует загрузки Мастерской и аддоны: запуск быстрее, но аддонные инструменты и оружие в игре недоступны. Настройка `launch.skip_unused_content`, по умолчанию выключена. |
| **Сообщите о времени загрузки карты** | | Сообщает, сколько времени ушло игре на загрузку карты и куда ушло время (файлы и контент, сущности и скрипты). Нужен мост. Настройка `launch.load_report`, по умолчанию выключена. Последний результат показан ниже: *Последняя загрузка: карта в Н с*. |

<a id="the-hammer-pro-bridge"></a>
## Мост Hammer Pro

Мост : это небольшой аддон в `garrysmod/addons/hammerpro_bridge`, который позволяет Hammer Pro разместить вас у камеры редактора и импортировать проп, который вы расставляете в игре. Он никогда не запаковывается в ваши карты и действует только в локальных играх (серверах прослушивания).

Установите его из **Настройки > Игра**, раздел **Тестирование в игре**:

| Контроль | Описание |
| --- | --- |
| **Hammer Pro мост: установлено/не установлено/нет папки с игрой** | Состояние аддона. |
| **Установить** / **Обновить** / **Удалить** | Устанавливает, обновляет или удаляет аддон. Перезапустите игру после этого. |
| **Появляется возле камеры редактора** | Когда карта загружается в игру, помещает игрока туда, где находится 3D-камера редактора (noclip). Нужен мост. Настройка `launch.spawn_at_camera`, по умолчанию выключена. |

Редактор и игра обмениваются небольшими файлами в `garrysmod/data/hammerpro/` (`cmd.json`, `ack.json`, `props.json`); все прочитанное обратно ограничено по размеру и проверено.

<a id="import-props-from-the-game"></a>
### Импортируйте проп из игры.

Создайте и расположите проп в игре (с установленным мостом и работающей картой), затем запустите **Файл > Импорт > Импортировать проп из игры**. Пропы появляются на карте за один шаг отмены: `prop_physics` остается `prop_physics`, `prop_dynamic` и `prop_physics_multiplayer` становится `prop_static`, со своей моделью, скином, положением и углами. Без моста вы получаете *Сначала установите мост Hammer Pro (Настройки > Игра), затем перезапустите игру*; без ответа, *Игра не ответила: карта работает с установленным мостом?*

<a id="other-games"></a>
## Другие игры

Для игры, отличной от Garry's Mod, **Запустить карту в игре** запускает исполняемый файл с `-game <folder>`, аргументами вашей игры и `+map`, как только скомпилированная карта окажется в папке карт (скомпилируйте ее с помощью **Копировать в игру**). Повторное использование запущенной игры, настройка времени, мост и импорт пропа : это функции Garry's Mod.

<a id="mcp"></a>
## MCP

`launch_game` (с `reload: true` для перезагрузки в запущенной игре) запускает или перезагружает карту из приложений AI. См. [Справочник по инструменту MCP] (../../MCP.md).

<a id="tips"></a>
## Советы

- Держите игру открытой между тестами: **Повторное использование запущенной игры** загружает новую карту через несколько секунд.
- Выберите **при запуске компиляции** при длительной компиляции: игра загружается во время освещения.
- **Появление возле камеры редактора** переносит вас туда, куда вы смотрели в редакторе, в noclip.

<a id="faq"></a>
## Частые вопросы

**Игра запускает вторую копию вместо загрузки карты.** Убедитесь, что опция **Повторное использование запущенной игры** включена и игра была запущена из установки, настроенной в **Настройки > Игра**.

**Возрождение возле камеры редактора выделено серым цветом.** Сначала установите мост и перезапустите игру.

**Входит ли мост в мой выпущенный аддон?** Нет, он никогда не входит в карту или релиз.
