# Инструмент «Текстура»

Инструментом применения текстур является режим Hammer «Редактирование граней»: вы выбираете грани в 3D-виде, затем панель **Редактирование граней** меняет их материал, масштаб, сдвиг, вращение, масштаб карты освещения, выравнивание, выравнивание, группы сглаживания и дисплейсменты, все выбранные грани одновременно. Он также содержит [UV-редактор] (uv-editor.md).

<a id="opening-it"></a>
## Как открыть

| Как | Сочетание клавиш |
|---|---|
| **Инструменты > Приложение «Текстура»** или его кнопка на панели инструментов. | `Shift+A` |

При переключении на инструмент с выделенными объектами их грани становятся выделенными гранями; когда вы выходите из него, выбор грани очищается и выбранные вами объекты возвращаются. В правой панели отображается панель **Редактирование грани**, когда инструмент активен, и вкладка **Текстуры** после нее.

<a id="selecting-faces"></a>
## Выбор граней

Выбор работает в 3D-виде. Грани под мышкой обрисовываются; выбранные грани выделяются красным цветом в 3D-виде и контуром в 2D-виде.

| Мышь в 3D виде | Результат |
|---|---|
| Нажмите | Выделяет грань (заменяет выделение). |
| `Ctrl+click` | Добавляет или удаляет грань. |
| `Shift+click` | Выбирает каждую грань твердого тела. `Ctrl+Shift+click` добавляет их. |
| Удерживайте левую кнопку и проведите пальцем | Выбирает грани под курсором мыши одно за другим (`Ctrl` или `Shift`: добавлено к выделению). |
| Щелкните в пустоте | Очищает выбор грани. |
| `Alt+click` | Пипетка: материал грани становится текущим материалом. |
| Щелкните правой кнопкой мыши | Применяет текущий материал к грани. |
| `Alt+right click` | Обтекание: копирует материал первой выбранной грани на грань, по которой щелкнули, и продолжает его текстуру по общему краю. Сначала выберите исходную грань. |
| `Escape` | Очищает выбор грани. |

Строка состояния напоминает эти клавиши. **Редактирование > Предыдущий выбор грани** (`Alt+Z`) и **Редактирование > Следующий выбор грани** (`Alt+Y`), а также кнопки **◀ Предыдущий выбор** и **Следующий выбор ▶** в верхней части панели позволяют перемещаться вперед и назад по ранее выбранным граням.

<a id="the-face-edit-panel"></a>
## Панель редактирования грани

В первой строке показано количество выбранных граней (и сколько дисплейсментов). Если грань не выбрано, на панели отображается только сообщение **Грань не выбрано**.

<a id="material"></a>
### Материал

В поле материала отображается материал выбранных граней. Когда они используют несколько материалов, отображается **(несколько значений)** с указанием до четырех миниатюр и количества материалов (наведите курсор на список).

| Контроль | Описание |
|---|---|
| **Просмотр...** | Открывает браузер текстур: следующий выбранный там материал применяется к выбранным граням, затем панель возвращается обратно. |
| **Редактировать материал** | Открывает [редактор материалов] (material-editor.md) для материала выбранных граней (для всех из них, если грани используют несколько). |
| **Применить ток** | Применяет текущий материал браузера текстур к выбранным граням. |
| Кнопка изображения (**Сделать это текущим материалом**) | Делает материал граней текущим (только если они имеют один общий материал). |
| Поместите материал на коробку | Применяет перетаскиваемый материал к выбранным граням. |

<a id="values"></a>
### Ценности

| Поле | Описание |
|---|---|
| **Масштаб** X/U и Y/V | Масштаб текстуры по каждой оси (от 0 отказывается). |
| **Shift** X/U и Y/V | Сдвиг текстур в текселях. |
| **Вращение** | Поворот текстуры в градусах. **-90** и **+90** поворачивают текстуру каждого грани на четверть оборота. |
| **Масштаб карты освещения** | Люксовый размер граней (от 1 до 1024, чем меньше, тем тоньше). |

В поле, которое различается по граням, отображается **(несколько значений)**; ввод или перетаскивание устанавливает это значение на каждом грани. Непрерывное перетаскивание : это один шаг отмены. Число десятичных знаков и шаги перетаскивания задаются в разделе **Настройки > Объекты и браузеры > Приложение «Текстура» (Редактирование грани)**:

| Настройка | Введите `[entities]` | По умолчанию |
|---|---|---|
| **Показаны десятичные дроби** (от 0 до 6) | `texture_decimals` | 4 |
| **Shift шаг перетаскивания** (текселей на точку, от 0,01 до 64) | `texture_shift_step` | 1 |
| **Шаг перетаскивания шкалы** (на точку, от 0,0005 до 1) | `texture_scale_step` | 0.005 |

<a id="uv-editor"></a>
### UV редактор

Раздел редактора **UV** рисует грань поверх его текстуры и позволяет перемещать, масштабировать и вращать его с помощью мыши, редактировать вершины и края, а также перемещать другие слои материала. **Открыть как отдельное окно** помещает его в отдельное окно. См. [редактор UV](uv-editor.md).

<a id="justify-and-align"></a>
### Обосновать и согласовать

| Контроль | Описание |
|---|---|
| **Выравнивание**: **Слева**, **Справа**, **Сверху**, **Снизу** | Помещает этот край текстуры на тот же край грани. |
| **Центр** | Помещает центр текстуры в центр грани. |
| **Подходит** | Масштабирует текстуру так, чтобы она покрывала грань ровно один раз. |
| **Относиться как к одному** | Выровняйте и подогнать все выбранные грани как одну поверхность, а не каждую грань отдельно. По умолчанию выключено. |
| **Выравнивание**: **Мир** | Проецирует текстуру с ближайшей мировой оси (выравнивание Hammer's World). |
| **Грань** | Накладывает текстуру на плоскость грани (выравнивание Hammer's Face). |
| **Просмотреть** | Выравнивает текстуры по 3D-камере. |
| **Повторите** U, V и **Подойдите** | Масштабирует текстуру так, чтобы она повторяла количество раз U и время V на грани (от 0,01 до 256, по умолчанию 1 и 1). Также используется **Treat as one**. |

<a id="smoothing-groups"></a>
### Группы сглаживания

Кнопки с **1** по **24** переключают группы сглаживания выбранных граней (используются освещением для сглаживания граней одной и той же группы). Номер в цвете предупреждения установлен только для некоторых граней: щелкните его, чтобы установить его для всех.

<a id="displacement"></a>
### Дисплейсмент

| Контроль | Описание |
|---|---|
| **Создание, сила:** **2**, **3**, **4** | Превращает выбранные грани в дисплейсменты этой степени (грани должны иметь 4 стороны). |
| **Уничтожить** | Превращает выбранные дисплейсменты обратно в простые грани. |

См. [Инструмент «Дисплейсмент»](displacement-tool.md) для создания скульптуры.

<a id="selection"></a>
### Выбор

| Контроль | Описание |
|---|---|
| **Отметить** | Выделяет каждую грань карты, используя те же материалы, что и при выделении. |
| **Скрыть маску** | Скрывает красную подсветку выбранных граней (чтобы оценить текстуру). |
| **Нет выбора** | Очищает выбор грани. |

<a id="related-commands"></a>
## Связанные команды

| Команда | Меню | Сочетание клавиш |
|---|---|---|
| **Применить текущую текстуру** | **Инструменты** | `Shift+T` (работает с любым инструментом: выбранными гранями или каждой гранью выбранных объектов) |
| **Блокировка текстур** | **Инструменты**, панель инструментов | `Shift+L` |
| **Блокировка масштаба текстур** | **Инструменты**, панель инструментов | `Shift+K` |
| **Найти и заменить текстуры...** | **Инструменты** | `Ctrl+Shift+R` (нет клавиши с пресетами Hammer и Hammer++) |

Блокировки текстур описаны в разделе [Операции с брашами](brush-operations.md).

<a id="tips"></a>
## Советы

- Выделите всю комнату с `Shift+click` на каждой стене, затем **Justify > Fit** с **Treat as one**, чтобы растянуть одну текстуру на всю комнату.
- `Alt+click` грань, которое вам нравится, затем щелкните правой кнопкой мыши другое грань, чтобы раскрасить его материал.
- Чтобы продолжить текстуру вокруг угла, выберите текстурированную грань, затем `Alt+right click` следующую.
- **Отметка** на выделенном фрагменте показывает все остальные грани, в которых используются те же материалы, готовые к одному изменению.

<a id="faq"></a>
## Частые вопросы

**Нажатия на 2D-видах ничего не делают.** Грани выбираются только в 3D-виде; 2D-виды показывают контуры выбранных граней.

**Почему Scale отказывается от 0?** Нулевой масштаб сделал бы текстуру бесконечной; поле игнорирует его.

**Красная подсветка скрывает мою текстуру.** Включите **Скрыть маску**.

**Как мне вернуться к предыдущему выбору грани?** `Alt+Z` (**Предыдущий выбор грани**) и `Alt+Y`, чтобы вернуться.
