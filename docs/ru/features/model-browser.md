# Браузер модели

В браузере моделей перечислены все модели (`.mdl`) смонтированного игрового контента, сгруппированные по папкам, с предварительным просмотром в реальном времени в 3D, информацией о модели, ее группами тел и последовательностями, инспектором, который находит недостающие файлы и материалы («Crowbar lite»), а также инструментами для извлечения, декомпиляции и компиляции моделей. Здесь же вы выбираете модель пропа.

<a id="opening-it"></a>
## Как открыть

- **Вид > Панели > Браузер моделей** показывает или скрывает вкладку **Модели** на правой панели закрепления. По умолчанию вкладка скрыта (`show_model_browser = false` в таблице `[ui]` `settings.toml`).
- Кнопка обзора рядом с ключом модели на панели объектов сама открывает вкладку (см. «Выбор модели для ключа» ниже).
- Нет сочетания клавиш по умолчанию. При использовании предустановленной раскладки клавиатуры Hammer++ (**Настройки > Клавиатура**) сочетание клавиш : `Shift+F10`.

Пока игровой контент монтируется, на вкладке отображается счетчик. Без папки с игрой он так говорит и предлагает кнопку **Параметры...**, которая открывает окно настроек (см. [Настройка игры](../getting-started/game-setup.md)).

<a id="finding-a-model"></a>
## Поиск модели

| Контроль | Описание |
|---|---|
| **Поиск моделей** | Сохраняет модели, путь которых содержит каждое введенное вами слово (в любом случае). Слово, начинающееся с `!`, исключает модели, которые его содержат: `vent office !dynamic`. |
| Source фишек **Все**, **Игра**, **Дополнения**, **Мастерская** | Сохраняйте только модели из такого источника. Чип появляется только тогда, когда смонтированный контент имеет такой источник. |
| **Только контент Garry's Mod** | В списке указано только то, что есть у каждого игрока Garry's Mod (без установленных игр, дополнений или предметов Мастерской). Опубликовано в браузерах звуков и частиц и сохранено (`gmod_only` в `[browser]`, по умолчанию отключено). |
| Раскрывающийся список папок | **Все папки** или одна папка верхнего уровня под `models/` (например, `props_c17`). |
| **Модели: N** | Количество моделей в списке. |
| Кнопка сетки/списка (`⊞` / `☰`) | Переключение между сеткой миниатюр и списком. Сохранено (`model_grid_view` в `[browser]`, по умолчанию: сетка). |
| **+** | **Файл > Импорт > Импортировать модель (FBX, OBJ, glTF)...**, см. [Импорт модели](model-import.md). |
| **++** | **Файл > Импорт > Импорт моделей (пакетный)...**: множество файлов или папок одновременно, см. [Пакетный импорт](model-import.md#batch-import). |
| **Недавние (N)** | Последние использованные вами модели (показано до 8, запомнено 16 для сеанса) над списком. Нажмите, чтобы выбрать, дважды щелкните, чтобы использовать. |

В списке модели сгруппированы по заголовкам папок с указанием их количества; щелкните заголовок, чтобы свернуть или развернуть его. В каждой строке отображается имя файла, а если у контента несколько источников, значок, сообщающий, откуда взята модель: **GMod**, **game: cstrike**, **папка garrysmod**, **addon**, **Workshop 123456**, **custom** (папка пользовательского контента). Наведите курсор на строку, чтобы увидеть полный путь.

В сетке каждая плитка представляет собой рендер модели (или, если ее невозможно нарисовать, миниатюру ее первого материала или `?`). Размер плитки определяется ползунком **Размер плитки** в [браузере частиц](particles.md) (от 48 до 256 точек, по умолчанию 96, `tile_size` в `[browser]`). Наведите курсор на плитку пути и источника.

Клавиатура, когда указатель находится над списком или сеткой: `Up` / `Down` перемещает выделение, `Enter` выполняет то же самое, что и двойной щелчок.

<a id="using-a-model"></a>
## Использование модели

- **Перетащите** модель из списка или сетки в вид, чтобы разместить там проп: в рамке показано, где он находится (на поверхности под указателем в 3D). Проп : это `prop_static`, если модель является статической, иначе : `prop_dynamic`. Скин, выбранный в превью, идет вместе с ним, а модель становится моделью нового пропа.
- **Двойной щелчок** (или `Enter`) использует модель для новых пропов или записывает ее в выбранный вами ключ.
- Кнопки под названием модели:

| Кнопка | Описание |
|---|---|
| **+ Используйте для нового пропа** | [Инструмент создания объектов] (entity-tool.md) становится активным и помещает эту модель как `prop_static` для статической модели пропа, иначе `prop_physics`, со скином, показанным в предварительном просмотре. |
| **Применить к выбранному реквизиту (N)** | Устанавливает эту модель (и скин предварительного просмотра, если он не скин 0) для выбранных объектов, которые принимают модель (классы `prop_*` и классы, FGD которых дает им модель студии). Один шаг отмены. |
| **Подать заявку в объект размещения** | Только при выборе ключа: записывает модель в этот ключ. |
| **Копировать** | Копирует путь модели в буфер обмена. |

<a id="choosing-a-model-for-a-key"></a>
## Выбор модели ключа

Кнопка обзора ключа модели на панели объектов (см. [Свойства объекта](entity-properties.md)) открывает вкладку «Модели» с баннером: «Выберите модель для *класса (ключа)*, затем дважды щелкните ее или нажмите «Применить». Выбрана модель, которая уже есть в ключе. Дважды щелкните модель, нажмите `Enter` или нажмите **Применить**, чтобы записать ее (со скином предварительного просмотра, когда клавиша `model` и скин не равен 0); панель возвращается на вкладку **Объект**. **Отмена** выходит из этого режима. Написание : это один шаг отмены.

<a id="preview"></a>
## Предварительный просмотр

Предварительный просмотр показывает выбранную модель в 3D:

- Перетащите на орбиту, колесо мыши для масштабирования, дважды щелкните, чтобы сбросить вид.
- Раскрывающийся список **Skin N**: отображаемый скин (активно, если у модели их несколько). Он сбрасывается на скин 0 при выборе другой модели.
- `▦` переключает каркас, `↺` сбрасывает вид.
- Вновь выбранная модель воспроизводит свою первую последовательность, как в игре.

В разделе **Display** над моделью нарисованы помощники (параметры Half-Life Model Viewer):

| Параметр | Шоу |
|---|---|
| **Каркас** | Сетка в виде линий. |
| **Ограничительная рамка** | Рамка вокруг видимой сетки. |
| **Подвижная коробка** | Оболочка перемещения заголовка модели (`$bbox`), поле Hammer используется для размещения таких объектов, как `info_player_start`. |
| **Хитбоксы** | Хитбоксы набора по умолчанию, в позе привязки. |
| **Последовательность последовательности** | Ограничивающая рамка воспроизводимой последовательности (иначе первая). |
| **Кости** | Скелет в связанной позе, суставы оранжевого цвета. |
| **Вложения** | Точки крепления (`$attachment`). |
| **Обычные** | Вершинные нормали. |
| **Исходные оси** | X красным, Y зеленым, Z синим в начале координат модели. |
| **Иллюм. позиция** | Точка, из которой движок освещает модель (`$illumposition`). |
| **Земля** | Сетка на высоте начала координат модели. |
| **Физическая модель** | Модель столкновения файла `.phy`. |
| **Поле обзора** | От 10 до 120 градусов, по умолчанию 40. |

Эти помощники и камера предназначены для сеанса; они не сохраняются.

<a id="information-tabs"></a>
## Информационные вкладки

**Информация**: размер, минимальный и максимальный размер поля, размер коллизионного корпуса (если он есть в модели), треугольники и вершины (с общими суммами для каждой группы тела, если они различаются), сетки (вызовы отрисовки), материалы, кости, хитбоксы, LODs, скины, части тела, последовательности, статическая проп (да или нет), свойства поверхности, масса (если известна) и MDL версия. **Материалы (N)** разворачивает список материалов.

Когда выбранный проп использует другую модель, **Заменить все использования (N)** присваивает модель браузера каждому объекту карты, который использует модель пропа (один шаг отмены).

**Группы тел (N)**: по одному раскрывающемуся списку для каждой группы тел, в которой есть выбор. Он начинается со значения `body` первого выбранного пропа с использованием этой модели. **Значение ключа тела** показывает результирующее число, а **Применить к выбранным реквизитам (N)** записывает его в свой ключ `body`.

**Последовательности (N)**: последовательности с количеством кадров. Нажмите один, чтобы воспроизвести его в режиме предварительного просмотра; `▶` / `⏸` воспроизводится или приостанавливается, `↺` перезапускается. Дважды щелкните последовательность или нажмите **Установить как анимацию по умолчанию для выбранных пропов (N)**, чтобы записать ее в ключ `DefaultAnim`.

<a id="inspector-crowbar-lite"></a>
## Инспектор («Ломик облегченный»)

Вкладка **Инспектор** считывает заголовок модели (без геометрии) и проверяет файлы вокруг него:

- Строка состояния: **Найдены все файлы и материалы** или **Отсутствующие файлы и материалы: N**.
- Подсчитывается: кости, вложения, последовательности, части тела, гибкие контроллеры, уровни детализации (считываются из VVD) и **имена вложений (N)**.
- Сопутствующие файлы (`.vvd`, `.vtx`, `.phy`, если они существуют); недостающий отмечен красным. Модель без коллизий специально не имеет `.phy`, что не является ошибкой.
- **Включенные модели (N)** (`$includemodel`), недостающие отмечены красным.
- Один раздел для каждого скина с его материалами: отсутствующий VMT выделен красным («Материал (VMT) не найден»), VMT, базовая текстура которого отсутствует, выделен оранжевым («Текстура не найдена: ...»). Развернуты скины с проблемами.

Инструменты под него:

| Кнопка | Описание |
|---|---|
| **Предпросмотр формы** | Открывает окно [предпросмотра формы](real-shape-placement.md#предпросмотр-формы) для этой модели: её реальная форма сверху, спереди, сбоку и в 3D, с размерами, началом координат, самой нижней точкой и мешем столкновений. |
| **Извлечь файлы...** | Копирует модель и ее файлы VVD, VTX, PHY и ANI из содержимого игры (VPK, GMA или папок) в выбранную вами папку, сохраняя их папки (`models/props/x.mdl`). |
| **Декомпилировать с помощью Crowbar** | Извлекает модель во временную папку (`hammerpro_models` во временной папке системы) и открывает ее в Crowbar. Crowbar.exe запрашивается в первый раз и запоминается (`crowbar_exe` в `[entities]`); щелкните кнопку правой кнопкой мыши и выберите **Выбрать другой Crowbar.exe...**, чтобы изменить его. |
| **Составьте QC...** | Запускает studiomdl игры (`bin/win64/studiomdl.exe`, иначе `bin/studiomdl.exe` в папке Garry's Mod) для выбранного вами файла QC с именем `-game <game folder> -nop4 -verbose`. Его вывод поступает на консоль; кнопка **Отмена** останавливает его. Неактивен, если studiomdl не найден. |

<a id="collision-models-in-the-views"></a>
## Модели столкновений в представлениях

Два переключателя **Вид > Параметры отображения** показывают столкновения пропов:

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Модели столкновений** | Рисует коллизионную оболочку объектов поверх них в 3D-виде и в предварительном просмотре браузера модели. Также в **Настройки > Рендеринг**. `collision_models` в `[render]`. | Выкл. |
| **Показать столкновения моделей** | В 3D-изображениях каждая модель отображается только как модель столкновения (то, с чем сталкивается игрок); оранжевая рамка отмечает модель, у которой нет модели коллизий. Также кнопка на панели инструментов. `collision_only` в `[render]`. | Выкл. |

<a id="settings"></a>
## Настройки

| Клавиша | Описание | По умолчанию |
|---|---|---|
| `[ui] show_model_browser` | Вкладка «Модели» находится в доке. | `false` |
| `[browser] model_grid_view` | Сетка вместо списка. | `true` |
| `[browser] tile_size` | Размер плитки сетки (от 48 до 256). | `96` |
| `[browser] gmod_only` | Только контент Garry's Mod (модели, звуки, частицы). | `false` |
| `[entities] crowbar_exe` | Лом, выбранный у инспектора. | нет |
| `[render] collision_models` | Модели столкновений над реквизитом. | `false` |
| `[render] collision_only` | Модели столкновений вместо моделей. | `false` |

<a id="tips"></a>
## Советы

- Выберите скин в предварительном просмотре перед перетаскиванием: он будет получен размещенным реквизитом.
- Вкладка **Инспектор** : это самый быстрый способ узнать, почему модель показывает в игре фиолетовые и черные текстуры.
- Через MCP помощник AI может использовать `search_models`, `get_model_info` и `list_used_models` (см. [справку по инструменту MCP](../MCP.md)).

<a id="faq"></a>
## Частые вопросы

**Почему отсутствует вкладка «Модели»?** По умолчанию она скрыта: включите **Вид > Панели > Браузер моделей**.

**В сетке отображается текстура вместо модели. Почему?** Модель не удалось отобразить (пока); плитка возвращается к своему первому материалу или к `?`, если его нет.

**Почему пункт «Компилировать QC...» выделен серым цветом?** studiomdl не найден в папке `bin` настроенной установки Garry's Mod.

**Перетаскивание дает `prop_dynamic`, дважды щелкните `prop_physics`: почему?** При перетаскивании используется `prop_dynamic` для моделей, которые не являются статическими пропами, а для параметра **Использовать для новых пропов** используется `prop_physics`. Измените класс на панели объектов, если вам нужен другой.
