# Ландшафт: карты высот и процедурная генерация

Три команды создают или экспортируют целые ландшафты, состоящие из дисплейсментов. Они находятся в меню **Инструменты** и в палитре команд (`Ctrl+P`):

| Команда | Идентификатор действия | Описание |
| --- | --- | --- |
| **Импортировать карту высот...** | `import_heightmap` | Создает ландшафт из изображения карты высот. |
| **Создать ландшафт...** | `generate_terrain` | Создает ландшафт из фрактального шума с эрозией и автоматическим текстурированием. |
| **Экспортировать карту высот...** | `export_heightmap` | Записывает выбранные дисплейсменты в 16-битную карту высот (и карту пятен). |

Они создают сетку из квадратных плиток. Каждая плитка представляет собой кисть со дисплейсментом на верхней грани. Плитки сшиты: вершины на общем крае одинаковые, поэтому трещин нет. Все, что создает одна команда, : это **один шаг отмены**, после чего выбираются новые плитки, готовые к использованию [инструмента дисплейсмента](displacement-tool.md) (лепка, рисование альфа, эрозия).

Существуют те же функции, что и у инструментов MCP `import_heightmap`, `export_heightmap` и `generate_terrain` (см. [Инструменты MCP](#mcp-tools)).

<a id="concepts"></a>
## Концепции

- **Плитка.** Одно дисплейсмент мощности 2, 3 или 4 (4 x 4, 8 x 8 или 16 x 16 ячеек) на браши размером **Глубина браши** единиц. Размер местности разбивается на целое число равных плиток, ближайших к **Размеру плитки**. **Расстояние между вершинами** : это размер плитки, разделенный на количество ячеек. В окне отображается количество плиток и расстояние в реальном времени («8 x 8 плиток (64 дисплейсменты), расстояние между вершинами 64 единицы»).
- **Высота.** Значение поля высоты меняется от черного (0) к белому (1) и становится высотой между **Самая низкая высота** и **Самая высокая высота**. **Вертикальный масштаб** : это разница между этими двумя вариантами. **Происхождение Z** : это мировая высота, на которой находится высота 0.
- **Ориентация.** X увеличивается справа от изображения, а Y (север) увеличивается к верхнему краю изображения. **Перевернуть X** и **Перевернуть Y** отразить его.
- **Ограничения.** Максимум 4096 плиток, размером от 16 до 32768 единиц на сторону и вся местность в пределах карты (плюс-минус 16384 единицы). В окне отображается красная причина, когда настройка выходит за пределы допустимого диапазона, а кнопки остаются неактивными.

<a id="import-heightmap"></a>
## Импортировать карту высот

Откройте **Файл > Импорт > Импортировать карту высот...**. Окно имеет эти разделы.

<a id="file"></a>
### Файл

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Карта высот** | Изображение: PNG (8 или 16 бит серого; цветные изображения считываются как яркость), TIFF, EXR или HDR (с плавающей запятой, масштабируется от 0 до 1, если значения выходят за пределы этого диапазона), BMP, TGA, JPEG или файл **RAW** (`.raw`, `.r16`, `.bin`, `.data`). **Обзор...** открывает диалоговое окно файла. Относительный путь указан относительно папки карты. | пустой |
| **Ширина RAW**, **Высота RAW** | Пиксели файла RAW (16 бит без знака). Оба 0 означают квадратное изображение, исходя из размера файла. | 0, 0 |
| **RAW с прямым порядком байтов** | В 16-битных значениях сначала сохраняется самый старший байт. | Выкл. |

16-битные изображения сохраняют свою полную точность: 16-битный PNG дает 65536 шагов высоты по вертикали. Сторона изображения ограничена 16384 пикселями. В окне отображается размер изображения и, если файл не читается, причина.

<a id="size-and-height"></a>
### Размер и высота

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Размер X**, **Размер Y** | Размер местности в единицах (от 16 до 32768) | 4096, 4096 |
| **Происхождение X**, **Y**, **Z** | Положение местности | 0, 0, 0 |
| **В центре происхождения** | Вкл.: начало координат : центр местности. Выкл.: это угол с наименьшими X и Y. | Вкл. |
| **Самая низкая высота** | Высота черного цвета | 0 |
| **Самая высокая высота** | Высота белого | 512 |
| **Сила плитки** | 2, 3 или 4 | 3 |
| **Размер плитки** | Желаемый размер плитки в единицах (от 16 до 16384) | 512 |
| **Кайма-юбка** | Понижает внешнее кольцо вершин на это количество единиц, так что открытый край ландшафта исчезает из поля зрения. 0 выключен | 0 |
| **Глубина браши** | Глубина браши под каждой плиткой (от 1 до 4096) | 16 |
| **Материал** | Материал смещенных граней. Используйте материал смешивания, чтобы увидеть текстуры раздела текстурирования. | `DEV/DEV_BLENDMEASURE` |
| **Масштаб карты освещения** | Единицы дисплейсменты на люкс | 16 |

Верхняя грань браши под каждой плиткой находится на самой низкой высоте, а на остальных гранях используется `TOOLS/TOOLSNODRAW`.

<a id="image"></a>
### Изображение

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Инвертировать** | Белый становится низким, а черный становится высоким | Выкл. |
| **Перевернуть X**, **Перевернуть Y** | Отразить изображение | Выкл. |
| **Бикубическая выборка** | Плавно производит выборку изображения между пикселями (Catmull-Rom, никогда не выходя за пределы соседних пикселей). Выкл.: билинейная выборка. Когда изображение имеет ровно один пиксель на вершину, оба значения дают значения пикселей. | Вкл. |
| **Проходы сглаживания** | Размывает высоты (фильтр 3 x 3 за проход, от 0 до 64) перед построением ландшафта. | 0 |

<a id="texturing"></a>
### Текстурирование

Текстурирование записывает **4-сторонние строки перехода** (`multiblend`) и альфу дисплейсментов, поэтому материал смешивания показывает текстуру 1 на ровной земле, текстуру 2 на камне, текстуру 3 на снегу и текстуру 4 на песке. Затем вы можете закрасить его в режиме **Paint Alpha**.

| Режим | Описание |
| --- | --- |
| **Нет** | Без текстурирования (по умолчанию) |
| **Наклон и высота** | Автоматическое текстурирование: **камень** (канал 2) на крутых склонах, **трава** (канал 1) на ровной поверхности, **снег** (канал 3) выше высоты и **песок** (канал 4) ниже высоты. Снег и песок не прилипают к камням. |
| **Карта сплат** | Второе изображение создает смесь |

Пороговые значения **Наклона и высоты**:

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Камень со склона** | Наклон в градусах, при котором появляется скала (от 0 до 89). | 35 |
| **Рок-смесь** | Ширина перехода в градусах | 10 |
| **Снег над головой** | Доля диапазона высот (от 0 до 1), выше которой появляется снег | 0.8 |
| **Снежная смесь** | Ширина перехода, как доля диапазона | 0.1 |
| **Песок внизу** | Доля диапазона высот, ниже которого появляется песок. 0 выключает песок | 0 |
| **Песочная смесь** | Ширина перехода | 0.05 |

**Карта Splat** принимает либо одно изображение **Splat Map** (RGB или RGBA: красный, зеленый, синий и альфа : каналы с 1 по 4; изображение RGB не имеет канала 4), либо, если это поле пусто, четыре изображения в оттенках серого **Канал 1** : **Канал 4** (пустое поле означает, что канал равен 0). Веса нормализованы для каждой вершины. Изображения знаков зеркально отражаются с помощью **Flip X** и **Flip Y**, как и карта высот, и могут иметь любой размер.

<a id="preview-and-import"></a>
### Предварительный просмотр и импорт

На рисунке **Макет плитки** показана карта высот (после инвертирования, переворота и сглаживания) на контуре местности с границами плитки, выделенными желтым цветом, и `N` для северного края. Нажмите **Импортировать**, чтобы построить ландшафт. Кнопка **Импорт** остается неактивной до тех пор, пока не будет передан файл и все настройки не станут действительными. Ошибки (нечитаемый файл, неправильный размер RAW) отображаются в виде уведомлений и ничего не меняют.

<a id="generate-terrain"></a>
## Создать местность

Откройте **Инструменты > Создать ландшафт...**. Рельеф создается из фрактального шума, затем при необходимости подвергается эрозии и текстурированию. Пока окно открыто, в 3D-виде отображается **предварительный просмотр** (максимум 65 x 65 вершин): затененная поверхность с крупной сеткой и желтым контуром контура. Предварительный просмотр следует за каждым изменением. Отключите его с помощью **Предварительного просмотра в режиме 3D**. Он убирается при закрытии окна. Эрозия в предварительном просмотре выполняется максимум за 200 проходов и с более грубым разрешением, поэтому она лишь аппроксимирует конечный результат.

<a id="presets"></a>
### Пресеты

| Предустановка | Смотри |
| --- | --- |
| **Холмы** | Мягкие симплексные холмы с небольшой перекосом |
| **Горы** | Ребристый шум Перлина с 6 октавами и приподнятой кривой высоты. |
| **Каньон** | Инвертированный гребневый шум, разбитый на 4 террасы: горы и ущелья. |
| **Острова** | Симплексный шум с уровнем моря и маской круглого острова |
| **Дюны** | Риджевый шум, растянутый по оси Y с сильным искажением |
| **Плато** | Шум Перлина с уровнем моря и двумя резкими террасами |

Пресет загружает только настройки шума (сохраняются начальное число, размер и диапазон высоты). **Случайное семя** выбирает новое семя; одно и то же семя и настройки всегда дают один и тот же ландшафт (сид находится в уведомлении и в результате MCP).

<a id="noise"></a>
### Шум

| Параметр | Описание | По умолчанию (холмы) |
| --- | --- | --- |
| Основа: **Перлин** или **Симплекс**. | Функция шума | Симплекс |
| Форма: **Обычная**, **Ребристая**, **Волна** | Ребристый образует острые гребни, волнистый образует округлые выступы. | Обычный |
| **Особенности** | Количество крупнейших объектов на самой длинной стороне ландшафта (от 0,1 до 64). Ландшафт выглядит одинаково в любом размере | 3 |
| **Октавы** | Слои детализации (от 1 до 10) | 4 |
| **Настойчивость** | Вес каждого более тонкого слоя (от 0,05 до 1) | 0.45 |
| **Искажение домена** | Преобразует шум с другим шумом (от 0 до 2). 0 выключен | 0.1 |
| **Растянуть** | Удлиняет объекты по Y (выше 1) или X (ниже 1). | 1 |
| **Контраст** | Распределяет шум по диапазону высот (от 0,1 до 4). | 1.4 |
| **Кривая высоты** | Показатель степени по высоте: выше 1 сглаживает низины и обостряет вершины (от 0,2 до 5). | 1.2 |
| **Инвертируйте шум** | Вершины становятся долинами | Выкл. |
| **Уровень моря** | Доля диапазона высот (от 0 до 0,95), обрезанная внизу | 0 |
| **Террасы** | Количество плоских шагов, 0 выключено | 0 |
| **Террасная резкость** | 0 : мягкие шаги, 1 : обрывы между ступенями. | 0.5 |
| **Маска острова** | Уменьшает высоту до нуля по направлению к краям | Выкл. |
| Остров: **Круглый** или **Квадратный**, **Ширина спада**, **Сила спада** | Форма маски, доля радиуса, используемого затуханием, и как долго центр остается высоким. | Раунд, 0,5, 1 |

<a id="result"></a>
### Результат

- **Новые дисплейсменты** создают плитки с настройками размера, начала координат, диапазона высот, мощности плитки и размера плитки, глубины браши, материала, юбки и масштаба карты освещения, которые такие же, как в окне импорта.
- **Заменить выбранное N** сохраняет выбранные дисплейсменты и заменяет их высоты сгенерированным ландшафтом (настройки размера, начала координат и плитки не используются). Ландшафт покрывает площадь выделения с наименьшим расстоянием между вершинами выбранных дисплейсментов (максимум 1025 вершин на сторону), поэтому плитки с несколькими дисплейсментами остаются сшитыми. Самая нижняя точка диапазона высот лежит на плоскости грани. Дисплейсменты сбрасываются, ряды перехода перезаписываются при включении текстурирования, а затем поверхность сшивается за один шаг отмены.

<a id="erosion"></a>
### Эрозия

**Термическая эрозия** (материал скатывается по склонам, более крутым, чем **Угол осыпи**) и **Гидравлическая эрозия** (дождь копает там, где вода течет быстро, и выбрасывает осадок там, где она замедляется) используют те же алгоритмы и те же параметры, что и [инструмент дисплейсмента](displacement-tool.md): эрозия: проходы, угол осыпи, сила, дождь, испарение, мощность, отложение. Они выполняются на основе сгенерированного поля высот до построения тайлов, сначала термического. Гидравлический дождь использует семена.

<a id="texturing-1"></a>
### Текстурирование

**Текстура по наклону и высоте** (по умолчанию включена) использует те же пороговые значения, что и при импорте. Отключите его, чтобы сохранить строки смешивания замененных дисплейсментов.

<a id="apply"></a>
### Применить

**Применить** строит ландшафт (или заменяет высоты) и отображает уведомление с начальным значением. **Закрыть** удаляет предварительный просмотр.

<a id="export-heightmap"></a>
## Экспортировать карту высот

Выберите дисплейсменты (или тела, у которых они есть) и откройте **Файл > Экспорт > Экспортировать карту высот...**.

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| **Файл карты высот** | Выходной файл; расширение выбирает формат: `.png` (16 бит серого), `.tif` или `.tiff` (16 бит), `.raw` (16 бит с прямым порядком байтов) | пустой |
| **Файл карты Splat** | Дополнительный PNG с четырехсторонними весами смешивания (альфа, когда дисплейсмент не имеет строк смешивания): красный, зеленый, синий и альфа : каналы с 1 по 4. | пустой |
| **Самая низкая высота**, **Самая высокая высота** | **Фиксированное** дает высоту, записанную как черным, так и белым цветом. Выкл: самая низкая и самая высокая точка | Выкл. |

Изображение покрывает зону выбранных дисплейсментов с вершиной на северном (+Y) краю и по одному пикселю на вершину самого мелкого дисплейсменты. Импортированный ландшафт экспортируется обратно ровно с одним пикселем на вершину. Перекрывающиеся поверхности сохраняют самую высокую точку, а пиксели без дисплейсменты заполняются относительно своих соседей. В уведомлении указывается размер изображения и высота, записанные в черно-белом виде: используйте их как **Самую низкую высоту** и **Самую высокую высоту** при повторном импорте файла с тем же размером, чтобы получить тот же рельеф (инструмент MCP также возвращает размер и угол).

<a id="mcp-tools"></a>
## Инструменты MCP

Полные параметры находятся в [Справочнике инструментов MCP] (../MCP.md); параметры окна имеют одинаковые имена. Короче говоря:

- `import_heightmap`: `path`, параметры RAW, `size_x`, `size_y`, `origin`, `centered`, `min_height`, `max_height` (или `height_scale`), `tile_power`, `tile_size`, `invert`, `flip_x`, `flip_y`, `smoothing`, `sampling`, `skirt`, `thickness`, `material`, `lightmap_scale`, `texturing` (`none`, `auto`, `splat`) с пороговыми значениями `splat` и `splat_channels`. `preview` true сообщает только о макете плитки.
- `export_heightmap`: дисплейсменты (`faces`, `ids`, `solid_ids` или выбор), `path`, `splat_path`, `min_height`, `max_height`, `overwrite`. Он возвращает высоты и площадь для повторного импорта.
- `generate_terrain`: `preset`, `seed`, параметры шума, размера, эрозии и текстурирования, `replace_selected` и `preview` (`show` или `hide`) для предварительного просмотра в 3D. Он возвращает семя.

Каждый вызов представляет собой один шаг отмены, помеченный «MCP: импорт карты высот» или «MCP: создание ландшафта».

<a id="tips"></a>
## Советы

- Для местности размером с карту тайл мощности 3 из 512 единиц дает вершину каждые 64 единицы. Чтобы получить более подробную информацию, уменьшите **Размер плитки** или увеличьте **Мощность плитки**.
- Source необходимо, чтобы ландшафт был изолирован от пустоты, как и любая другая геометрия: постройте стены вокруг него или используйте **Border юбка** с кольцом браши Skybox.
- После импорта используйте [инструмент дисплейсмента] (displacement-tool.md), чтобы лепить, **Раскрашивать альфа**, сшивать с другим ландшафтом или изменять мощность с помощью **Сохранить форму**.
- Экспортированные карты высот открываются в любом редакторе изображений и в инструментах ландшафта, таких как World Machine или Gaea (16-битный PNG).
