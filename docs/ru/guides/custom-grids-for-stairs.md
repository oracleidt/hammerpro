# Нестандартные сетки для лестниц

У Hammer одна сетка, одинаковый шаг по каждой оси. Лестницы к нему подходят редко: обычная ступень имеет высоту 8 и глубину 12, причем лестница часто поворачивается вместе со своим зданием. Пользовательские сетки Hammer Pro имеют свой собственный шаг по оси, начало координат, ориентацию и дополнительные ограничения, поэтому каждый шаг точно привязывается. В этом руководстве строится лестница из одного.

<a id="step-1-create-the-grid"></a>
## Шаг 1: создайте сетку

1. Откройте **Карта > Сетки > Диспетчер сеток...**. Откроется окно **Сетки**.
2. В разделе **Пользовательские сетки** нажмите **Новая сетка**. Все начинается с размера глобальной сетки.
3. Заполните поля:

| Поле | Для лестницы | Примечания |
|---|---|---|
| **Имя** | `Stairs` | Уникальный на карте. |
| **Шаг X Y Z** | `12`, `64`, `8` | Любой размер, разрешены десятичные дроби. Равные шаги изменяются вместе: удерживайте `Shift`, пока вы меняете один, чтобы установить его отдельно. |
| **Происхождение** | нижний угол первой ступени | Там находится узел сетки. |
| **Качание по тангажу** | `0 0 0` (или рыскание перевернутого здания) | Ориентация сетки, например углы объекта. |
| **Основная строка каждые** | e.g. `4` | 0: настройка видов. |
| **Ограничения** | ящик на лестничной клетке | Необязательно: сетка применяется только внутри этого поля, глобальная сетка : снаружи. **Подогнать к выделенному** устанавливает границы выделения. |
| **Цвет** | любой | Дополнительный цвет линий. |

Сетка **сохраняется вместе с картой** (блок `hammerpro_grids` в VMF). **Сохранить как предустановку** копирует ее в настройки, чтобы она была доступна на каждой карте; **Копировать на карту** выполняет обратное действие.

<a id="step-2-make-it-the-active-grid"></a>
## Шаг 2: сделайте его активной сеткой

Нажмите **Использовать** в диспетчере сеток или выберите **Карта > Сетки > Пользовательская сетка**. Строка **Активная сетка:** в верхней части окна переключается между вариантами **Глобальная сетка**, **Одна сетка на представление**, **Пользовательская сетка** и **Сетка выбора**. Кнопка сетки на панели инструментов открывает те же варианты.

Когда пользовательская сетка активна, 2D-виды рисуют ее линии, а **Нарисовать пользовательскую сетку в 3D-виде** также рисует ее в 3D-виде. `[` и `]` вместе масштабируют каждый шаг пользовательской сетки.

<a id="step-3-draw-the-steps"></a>
## Шаг 3: нарисуйте ступеньки

1. Возьмите инструмент «Блок» (`Shift+B`).
2. На виде сбоку или спереди (тот, который показывает глубину и высоту лестницы) нарисуйте первую ступеньку: ее углы привязываются к 12 единицам по X и 8 единицам по Z.
3. Нажмите `Enter`, чтобы создать его.
4. Клонируйте его: с помощью инструмента выделения перетащите его, удерживая `Shift` (перетаскивание клона), на один шаг вперед и на один шаг вверх; копия привязывается к сетке. **Правка > Специальная вставка...** (`Ctrl+Shift+V`) также вставляет несколько копий со смещением.
5. Повторите или используйте массив (см. [Преобразование и выравнивание](../features/transform-align.md)).

Для повернутой лестницы установите **Yaw** сетки в соответствии с углом здания: привязка, перемещение и линии сетки следуют ее осям. **Уклон** соответствует уклону, например, для размещения перил вдоль лестницы.

<a id="step-4-keep-the-grid-with-the-stairs"></a>
## Шаг 4: сохраните сетку с лестницей

Выберите готовую лестницу и нажмите **Прикрепить к выделению** (или **Карта > Сетки > Прикрепить сетку к выделению**). Если параметр **Объекты используют свою сетку** включен (по умолчанию), редактирование этих объектов или рисование на них привязывается к их сетке, независимо от того, какая сетка активна. **Сетка выделения** делает сетку выбранных объектов активной сеткой. **Карта > Сетки > Отсоединить сетку выделения** удаляет ссылку. Менеджер сетки показывает, к скольким объектам или группам прикреплена каждая сетка карты.

<a id="shortcuts-to-a-grid"></a>
## Сочетания клавиш к сетке

- **Карта > Сетки > Сетка из выделения**: сетка, подогнанная к выделению (для точечного объекта: ее начало координат и углы; для брашов: оси первого тела с узлом в углу его границ) с шагом глобальной сетки. Выберите существующую ступень лестницы, запустите ее, затем установите **Шаг X Y Z** в диспетчере.
- **Карта > Сетки > Сетка от грани**: сетка на выбранной грани (инструмент текстуры): ее плоскостью является грань, X вдоль ее самого длинного края. Удобно для пандуса или наклонного потолка.

Оба создают новую пользовательскую сетку и делают ее активной.

<a id="faq"></a>
## Частые вопросы

**Мои блоки не вращаются вместе с сеткой.** Нарисованные прямоугольники остаются на одной линии с мировыми осями: при повёрнутой сетке каждая мировая ось принимает шаг ближайшей к ней оси сетки. Постройте лестницу в соответствии с миром, а затем поверните готовую лестницу.

**Остальная часть карты странно фиксируется.** Установите **Ограничения** для сетки, чтобы она применялась только к лестничной клетке, или вернитесь к **Глобальной сетке**.
